# CRON Write Task

## What This Does
Runs `CRDT` documentation workflow for this workspace.

**Trigger:** Every 30 minutes in Asia/Seoul timezone (`*/30 * * * *`)
**Delivery mode:**
 - delivery.mode = none (internal, no webhook)
- channel/discord/to set but not supported → will be ignored

## Files Handled
Reads `CRON_CRD_WRITE.md` and executes the steps defined inside it.

Output:
 1. One CRDT doc processed in this run.
2. Short summary reply with completion details (runId, time).
