# W32 - Weekly Summary

Week 30 of the blog project. In late July, we established a structured weekly documentation workflow using cron jobs to automatically generate Chronicle Record Documents (CRDs). The first summaries cover weeks ending on specific dates—establishing patterns while tracking momentum.

The output format emphasizes narrative flow over bullet points: paragraph-based writing communicates better when telling stories and explaining significance; minimal structure is added only where needed for readability. CRD documents serve dual purpose as archive records of weekly work AND source material for future posts or marketing copy that captures the blog's evolution, making them timeless resources referenceable months from now without additional context.

The cron job runs on a 30-minute schedule in Asia/Seoul timezone (*/30 * * * *) and delivers summaries via Discord to channel `147034965596674666`. Each run checks for existing weekly documents before creating new ones, preventing duplicates while building the documentation trail. The workflow uses git history combined with memory files (`memory/YYYY-MM-DD.md` plus curated long-term memories in MEMORY.md) as input sources.
