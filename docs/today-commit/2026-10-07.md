## 요약 (AI 작성)

maru는 편집기 프로젝트 검색의 기반을 올렸습니다. VS Code 방식(디스크는 ripgrep, 열린 문서는 편집 모델 우선) 구성과 ripgrep 15.2.0을 앱 번들의 `Contents/Helpers/rg`로 싣는 작업을 [#4196](https://github.com/ohah/maru/pull/4196)으로 병합했습니다. 이어서 백그라운드 worker가 `rg` 출력을 점진적으로 해석하고 열린 문서의 불변 사본을 먼저 검색하는 백엔드를 [#4208](https://github.com/ohah/maru/pull/4208)로 병합했습니다. PR 본문 기준으로 검색 도크 연결은 아직이며, AppSession·IME 연결 [#4218](https://github.com/ohah/maru/pull/4218)은 이날 열려 다음 날 병합됐습니다. 언어 서버 쪽에서는 서버를 프로세스 그룹째, 메인 스레드를 막지 않고 내리도록 했습니다([#4213](https://github.com/ohah/maru/pull/4213)). 서버만 SIGKILL해 rust-analyzer가 띄운 `cargo check`·build-script가 고아로 남던 문제와, initialize에 답이 없으면 「시작 중」에 영원히 머물던 문제 등을 함께 고쳤습니다. 워크스페이스 신뢰 계획 문서([#4217](https://github.com/ohah/maru/pull/4217))를 두고, 신뢰 확인을 사용자 권한·격리 없음 같은 대가를 밝히는 신뢰 시트로 바꿨습니다(WT1, [#4221](https://github.com/ohah/maru/pull/4221)).

테스트 러너의 HOME 격리 후속도 이어졌습니다. HOME이 `/`일 때 경로 비교가 루트를 빈 문자열로 읽어 러너가 자기 자신을 끝없이 다시 실행하던 문제를 [#4209](https://github.com/ohah/maru/pull/4209)에서 막았고, 임시 홈·XDG 처리와 환경 변수 복원도 손봤습니다([#4207](https://github.com/ohah/maru/pull/4207)·[#4214](https://github.com/ohah/maru/pull/4214)·[#4215](https://github.com/ohah/maru/pull/4215)·[#4216](https://github.com/ohah/maru/pull/4216)). 설정 파일을 읽지 못하는 상태(권한, 1 MiB 초과 등)에서 메뉴 Reload를 누르면 그 창만 설정이 통째로 기본값이 되던 문제는 지금 설정을 지키도록 고쳤습니다([#4194](https://github.com/ohah/maru/pull/4194)). 설정 로그의 중복 억제와 토큰 가리기도 다듬었습니다([#4200](https://github.com/ohah/maru/pull/4200)·[#4211](https://github.com/ohah/maru/pull/4211)). 문구 보간이 버퍼를 넘으면 표시 없이 잘리고 한국어 글자 중간에서 끊기던 문제는 「…」로 잘림을 보이게 했고, 진단 호버에 기대 토큰 대신 `빠짐: {s}`가 그대로 뜨던 문제도 고쳤습니다([#4193](https://github.com/ohah/maru/pull/4193)). 그 밖에 이름 자르기·이름 바꾸기 상자의 UTF-8 경계와 패널 위치([#4199](https://github.com/ohah/maru/pull/4199)·[#4210](https://github.com/ohah/maru/pull/4210)), Lab 오버레이와 팝업 경계 여백([#4204](https://github.com/ohah/maru/pull/4204)), 실제 IME 전환·후보창 상태에서 공유 뷰를 닫는 검증([#4203](https://github.com/ohah/maru/pull/4203)·[#4223](https://github.com/ohah/maru/pull/4223))이 들어갔습니다. 10월 6일에 열린 확인 모달 좁은 창 대응 [#4190](https://github.com/ohah/maru/pull/4190)과 공유 뷰 닫기·백업 보존 검증 [#4185](https://github.com/ohah/maru/pull/4185)도 이날 병합됐습니다. 잠자기 뒤 재접속 [#4222](https://github.com/ohah/maru/pull/4222)와 정체 관측 [#4219](https://github.com/ohah/maru/pull/4219)는 이날 열려 다음 날 병합됐습니다.
