# 2026-09-20

## 요약 (AI 작성)

`@ohah/pdf` v0.1.0 이 npm 에 첫 출시된 날입니다 — Zig → wasm(321KB) PDF 엔진, 읽기·그리기·글자층·검색·양식 채우기·주석·서명 확인·암호·병합·XFA, 바닐라·React·Vue·Svelte. 이 판에는 라디오 묶음 배타와 겉모습 없는 주석 렌더가 들어갔습니다.

maru 편집기는 자동완성 ①-d 로 옆 문서 패널(목록이 열려 있으면 ⌃Space 로 토글, 강조 항목의 detail+documentation 을 목록 상자 옆에)을 붙이고, LSP 2단 ⑧ 로 semantic tokens 를 보이는 범위만 우리 11색으로 매핑해 tree-sitter 위에 겹쳤으며, property 는 ANSI 7(white)·attribute 는 ANSI 5(magenta) 로 enumMember·member 를 가릅니다. 에이전트 훅은 PostToolUse(Bash) 의 bashEditDiff.changedFiles 로 셸 편집을 귀속합니다(AT3b-2). session-host 는 client_slot 레지스트리 스캔이 tick 마다 192KiB 를 memcpy 해 세션 수에 비례하던 앱 CPU 를 잡고, 같은 UI 프레임 안 host 소켓 «비었나» 질문을 한 번만 해 poll 시스템콜을 15배 줄였으며(CPU 이득은 ≈0.25%p), resize 발행이 화면 청크에 배치 끝 표식을 달아 PartialFrame 의 생산자를 없앴습니다. E3c 의 「4,096 registry scan 가설 기각」은 계수기 사각이 만든 오판이라 정정했습니다. 마커 프리뷰는 그 pane 에 뜨고 리페인트에 죽지 않고 그림 뒤가 비치지 않습니다.

zntc 는 dev 서버 CSS 결함을 몰아서 고쳤습니다 — watch 이벤트가 CSS 등 asset 산출물을 보고하고(#4660), css-update href 를 주입된 `<link>` 와 맞춰 전체 리로드를 없애고(#4672), dev 산출 디렉토리를 CSS 탐색에서 제외해 dev 후 build 실패를 고치고(#4674), dev 의 PostCSS 변환 유실과 macOS 원자적 저장 후 watch 정지(#4679·#4682), dev 가 import 한 plain CSS 를 페이지에 연결하는 것(#4675). hwpjs 는 EMF 의 world transform·clip·fill·rendering origin·interpolation·compositing 과 EMF+ rectangle·lines·draw string·images·driver strings·container 를 파싱합니다(39커밋).
