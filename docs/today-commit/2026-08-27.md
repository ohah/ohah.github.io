# 2026-08-27

## 요약 (AI 작성)

편집기가 편집기다워진 날입니다. 괄호가 저절로 닫히고 고른 것을 감싸며(§3.7), ⌘/ 가 줄을 주석 처리하는데 그러려면 없던 언어 판정을 세워야 했고(§3.7a), 조합 중인 한글이 편집기에 보이고(N3 §11), ⌘Z 로 되돌립니다 — 기능은 서 있었고 키가 없었습니다. session-host 는 릴리스 어댑터를 시작했습니다: typed release evidence 검증, publication order, adapter contract 동결, adapter 파일 보안, GitHub context 결속, release 응답 검증, Git tag chain 해석. `--stream` 이 첫 화면만 흘리고 멈추던 것도 고쳤습니다. scm 은 커밋·턴 파일 줄이 몇 줄 바뀌었는지 말하고, Windows 는 파일 카드 ✕ 가 눌리며 열 배치를 중립으로 모았습니다.
