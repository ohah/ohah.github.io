## 요약 (AI 작성)

react-native-mcp는 `take_screenshot`의 회전 함수를 `visual_compare`에서도 써서, 가로 모드 캡처를 먼저 바로 세운 뒤 요소를 잘라 비교하도록 고쳤습니다([#102](https://github.com/ohah/react-native-mcp/pull/102)). Bridge 환경에서 `nativeTag`로 `UIManager.measure`를 직접 부르는 `measureByNativeTag`를 추가하고 런타임 쿼리·직렬화와 Babel 플러그인을 보완했으며([#104](https://github.com/ohah/react-native-mcp/pull/104)), 서버 패키지 버전은 0.1.0-rc.7([#103](https://github.com/ohah/react-native-mcp/pull/103))과 rc.8로 올렸습니다.

react-wasm-table 저장소가 이날 시작됐습니다. 데이터 저장·필터링·정렬·가상 스크롤을 맡는 Rust 크레이트와 WASM 바인딩, 표 컴포넌트를 담은 React 패키지, 도구 설정과 CI로 초기 구성을 잡았습니다. 초기 스펙 문서와 패키지 이름을 `@ohah/react-wasm-table`로 바꾸는 [#1](https://github.com/ohah/react-wasm-table/pull/1)도 이날 열렸습니다.

hwpjs는 HTML 뷰어와 그 이미지·스타일·`HtmlOptions`·쪽 나눔·렌더 모듈 단위 테스트 PR 여섯 개를 열었습니다([#25](https://github.com/ohah/hwpjs/pull/25), [#26](https://github.com/ohah/hwpjs/pull/26), [#27](https://github.com/ohah/hwpjs/pull/27), [#28](https://github.com/ohah/hwpjs/pull/28), [#29](https://github.com/ohah/hwpjs/pull/29), [#30](https://github.com/ohah/hwpjs/pull/30)). ohah.github.io에는 2월 24일 요약과 CRD 문서 작성 크론의 완료 표시가 올라갔습니다.
