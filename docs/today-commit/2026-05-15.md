## 요약 (AI 작성)

zntc는 새벽에 전날 이어 온 파서 정합성 수정과 TSC 감사 오라클 보강을 계속했습니다. for 문 머리의 `using`·`await using` 선언([#3202](https://github.com/ohah/zntc/pull/3202)), if·while·for 본문 첫머리의 `/`를 정규식으로 다시 읽기([#3206](https://github.com/ohah/zntc/pull/3206)), 타입 있는 화살표 함수 재해석 실패의 롤백([#3207](https://github.com/ohah/zntc/pull/3207)), 문맥 키워드 레이블과 제네릭 메서드 이름 처리, stage3 accessor 데코레이터의 computed key([#3203](https://github.com/ohah/zntc/pull/3203))를 고쳤고, 추측 파싱의 저장·복원을 `SpeculationCheckpoint`로 묶었습니다([#3217](https://github.com/ohah/zntc/pull/3217)). RN 에셋은 등록된 릴리스 에셋만 복사하도록 고친 뒤([#3216](https://github.com/ohah/zntc/pull/3216)) 복사를 비동기 병렬로 바꾸고 `AssetRegistry` 메타데이터를 번들러 API로 노출하는 정리가 이어졌습니다([#3222](https://github.com/ohah/zntc/pull/3222)). Flow는 라벨 있는 튜플 요소와 Hermes 규격을 따르는 튜플·조건부 타입·declare export·match 패턴 처리를 더했습니다([#3282](https://github.com/ohah/zntc/pull/3282), [#3292](https://github.com/ohah/zntc/pull/3292), [#3298](https://github.com/ohah/zntc/pull/3298)).

낮부터는 minify 결과 크기를 줄이는 작업이 하루의 대부분을 차지했습니다. mangle을 tree-shake 뒤로 미뤄 죽은 바인딩이 짧은 이름을 차지하던 문제를 고치고([#3229](https://github.com/ohah/zntc/pull/3229)), Phase B 예약 이름을 모듈 단위로 좁히고 전역 예약 집합을 모듈 사이에 공유했습니다([#3247](https://github.com/ohah/zntc/pull/3247), [#3280](https://github.com/ohah/zntc/pull/3280)). CJS 래퍼는 객체 리터럴 간접 참조 제거, 콜백 매개변수 단축, 쓰지 않는 `module` 매개변수와 `createRequire` shim 생략, 래퍼 안 `"use strict"` 제거 등을 하나씩 적용해 rxjs 번들을 PR마다 수 퍼센트씩 줄였습니다([#3250](https://github.com/ohah/zntc/pull/3250)–[#3264](https://github.com/ohah/zntc/pull/3264)). 한 번만 쓰는 순수 복합식 인라인([#3232](https://github.com/ohah/zntc/pull/3232))과 쓰지 않는 함수식 이름 제거([#3266](https://github.com/ohah/zntc/pull/3266))에 이어, 모듈 수준 죽은 최상위 선언을 감사하고 사용자 순수 모듈에서 지우는 N-step 작업으로 mobx를 3.2KB 줄였습니다([#3268](https://github.com/ohah/zntc/pull/3268), [#3272](https://github.com/ohah/zntc/pull/3272), [#3274](https://github.com/ohah/zntc/pull/3274)). mobx 형식의 CJS main shim을 자동 감지해 mobx 번들을 21% 줄인 resolver 변경([#3290](https://github.com/ohah/zntc/pull/3290))과 `typeof` 비교 단축, `void 0` 괄호 제거, return·throw 뒤 공백 제거 같은 세부 최적화도 병합됐습니다. 화살표 IIFE 축약은 커밋으로 main에 들어갔고 같은 이름의 PR [#3231](https://github.com/ohah/zntc/pull/3231)은 닫혔습니다.

그 밖에 Zig CLI의 `--browserslist`와 opera를 Chromium으로 대응시키는 처리([#3242](https://github.com/ohah/zntc/pull/3242), [#3244](https://github.com/ohah/zntc/pull/3244)), esbuild·swc처럼 네이티브 API를 처음 호출할 때 자동 초기화하는 기능([#3245](https://github.com/ohah/zntc/pull/3245)), React 19 vite와 react-compiler 예제([#3249](https://github.com/ohah/zntc/pull/3249)), Astro 문서 사이트의 SSR 막힘을 echarts 지연 로딩으로 푼 수정([#3239](https://github.com/ohah/zntc/pull/3239))이 들어왔습니다. 블로그 저장소 ohah.github.io의 커밋 8개는 크론 점검 기록과 일일 요약 갱신입니다.

공개 커밋 108개, 해당일 생성 또는 병합된 PR 93개를 정리했습니다. PR 생성 93개·병합 92개는 같은 PR이 양쪽에 포함될 수 있습니다.
