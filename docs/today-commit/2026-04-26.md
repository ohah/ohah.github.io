## 요약 (AI 작성)

zntc는 ES5 다운레벨링에 쓰는 런타임 헬퍼를 가상 모듈로 바꿨습니다. `__generator` 같은 헬퍼를 모듈마다 인라인하지 않고 가상 모듈에서 import하도록 로더 인프라를 깔고([#1970](https://github.com/ohah/zntc/pull/1970)), 미등록 헬퍼 매핑과 graph 파싱 단계의 transformer pre-pass, 코드 분할 모드의 헬퍼 import 분배, 소스맵 ID 정리를 묶어 병합했으며([#1971](https://github.com/ohah/zntc/pull/1971)), 단일 번들 모드에서도 활성화했습니다([#1977](https://github.com/ohah/zntc/pull/1977)). 흩어져 있던 transformer 옵션 사본 14개는 `transform_options_base` 하나로 모았습니다([#1974](https://github.com/ohah/zntc/pull/1974), [#1975](https://github.com/ohah/zntc/pull/1975), [#1979](https://github.com/ohah/zntc/pull/1979)). ESM 출력의 external import를 require로 바꾸지 않고 보존하고([#1983](https://github.com/ohah/zntc/pull/1983)), axios 번들링을 위해 try 블록 안 해석 실패 require를 optional로 처리하며 ESM external default import의 별칭을 냈습니다([#2026](https://github.com/ohah/zntc/pull/2026), [#2028](https://github.com/ohah/zntc/pull/2028)).

나머지는 다운레벨 의미 보존 수정이 대부분이었습니다. optional 메서드 호출의 this와 단락 평가, 논리·거듭제곱 대입의 멤버 참조, optional eval의 간접 호출([#1985](https://github.com/ohah/zntc/pull/1985)~[#1989](https://github.com/ohah/zntc/pull/1989)), optional·static·논리 대입·괄호로 감싼 super와 파생 생성자 안 super 프로퍼티 receiver([#1991](https://github.com/ohah/zntc/pull/1991), [#1992](https://github.com/ohah/zntc/pull/1992), [#1994](https://github.com/ohah/zntc/pull/1994), [#2001](https://github.com/ohah/zntc/pull/2001), [#2029](https://github.com/ohah/zntc/pull/2029), [#2032](https://github.com/ohah/zntc/pull/2032), [#2035](https://github.com/ohah/zntc/pull/2035)), 파생 생성자의 런타임 검사와 return 평가 순서, 여러 단계 super 체인의 `new.target` 보존([#2004](https://github.com/ohah/zntc/pull/2004), [#2009](https://github.com/ohah/zntc/pull/2009), [#2021](https://github.com/ohah/zntc/pull/2021), [#2025](https://github.com/ohah/zntc/pull/2025)), 클래스 메서드를 descriptor로 정의하기, 기본값 초기화의 TDZ, 배열 구조 분해의 iterable 읽기([#2005](https://github.com/ohah/zntc/pull/2005), [#2007](https://github.com/ohah/zntc/pull/2007), [#2008](https://github.com/ohah/zntc/pull/2008)), tagged template의 잘못된 escape([#2014](https://github.com/ohah/zntc/pull/2014)), Annex B sloppy 함수 호이스팅의 lexical 충돌([#2015](https://github.com/ohah/zntc/pull/2015))이 있었습니다. 번들러 쪽은 namespace 값 객체를 importer끼리 공유하고([#1990](https://github.com/ohah/zntc/pull/1990)), 죽은 조건부 require를 건너뛰며([#2006](https://github.com/ohah/zntc/pull/2006)), 래퍼 합성 심볼과 CJS require 래퍼 이름도 mangling하고([#2003](https://github.com/ohah/zntc/pull/2003), [#2020](https://github.com/ohah/zntc/pull/2020)), 플러그인 transform 결과를 캐시 키에 넣고 순수 클래스 식을 tree shaking합니다([#2041](https://github.com/ohah/zntc/pull/2041), [#2043](https://github.com/ohah/zntc/pull/2043)).

suji는 main에 직접 커밋 56개를 올렸습니다. Linux/Windows CI 빌드 회귀와 Rust SDK 테스트의 use-after-free를 고친 뒤, Electron 호환을 목표로 시스템 트레이, 알림, 애플리케이션 메뉴 커스터마이즈, 파일 시스템 API, 전역 단축키, 창 resize·focus·move 이벤트를 차례로 추가했습니다. 보안 쪽으로는 프런트엔드 경로 화이트리스트 기반 fs sandbox, 앱별 CEF cache 격리, IPC 유효성 검사와 CSP 기본 헤더, macOS App Sandbox entitlements 자동화, iframe sandbox와 origin allowlist를 넣었고, CEF locale 정리와 바이너리 strip으로 앱 크기를 약 38MB 줄였습니다. 마지막으로 WebContentsView에 해당하는 view 데이터 모델과 IPC, macOS NSView 합성, JS API와 E2E를 갖춘 Phase 17-A를 마무리했습니다.

bungae는 기본 번들러를 zts로 바꾸고 zts 서버 헬퍼를 정리했으며 서브모듈을 올렸습니다([#73](https://github.com/ohah/bungae/pull/73)). cheolsu-proxy에서는 자동 TLS passthrough를 보강하는 [#339](https://github.com/ohah/cheolsu-proxy/pull/339)가 열렸습니다. ohah.github.io에는 2026년 4월 월간 타임라인과 4월 25·26일 오늘의 커밋 요약, ZTS 개발기 11편 맞춤법 수정이 올라왔습니다.
