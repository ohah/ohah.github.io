## 요약 (AI 작성)

maru는 스크롤백을 올리면 지금 보이는 출력을 만든 명령줄을 종료 상태와 함께 맨 위에 고정하는 sticky command([#1043](https://github.com/ohah/maru/pull/1043))와 워크스페이스 사이드바의 세로 스무스 스크롤·스크롤바([#1042](https://github.com/ohah/maru/pull/1042))로 시작했습니다. 에이전트 완료 알림은 제목에 Claude·Codex 종류와 끝난 Term을, 본문에 답변을 더 길게 보여 주도록 바꾸고 리뷰 후속을 반영했습니다([#1044](https://github.com/ohah/maru/pull/1044), [#1046](https://github.com/ohah/maru/pull/1046)).

중심 작업은 수식키를 누르고 있으면 단축키를 알려 주는 힌트였습니다. 설계 문서([#1047](https://github.com/ohah/maru/pull/1047))에 이어 활성 pane 우상단의 HUD 컴포넌트([#1049](https://github.com/ohah/maru/pull/1049)), 카탈로그에서 카테고리와 키캡을 만드는 빌더([#1050](https://github.com/ohah/maru/pull/1050)), 스키마 주도 `keyhint.*` 설정([#1051](https://github.com/ohah/maru/pull/1051)), 홀드 트리거([#1052](https://github.com/ohah/maru/pull/1052)), 키캡 배경과 light·dark 대비 보정([#1053](https://github.com/ohah/maru/pull/1053), [#1054](https://github.com/ohah/maru/pull/1054))이 들어왔습니다. 이후 사용자 요청에 따라 한 상자 목록 대신 각 chrome 요소 우상단에 배지를 띄우는 방식으로 바꾸고 탭 바 +와 활성 탭 배지를 더했습니다([#1056](https://github.com/ohah/maru/pull/1056), [#1057](https://github.com/ohah/maru/pull/1057)). 배지가 가끔 뜨지 않던 문제는 판정을 순수 Zig 상태 기계로 옮겨 해결했고([#1063](https://github.com/ohah/maru/pull/1063)), 멀티 윈도우에서 배지가 남는 문제 등 리뷰 8건과 Cmd를 떼도 배지가 남던 문제를 고쳤습니다([#1065](https://github.com/ohah/maru/pull/1065), [#1069](https://github.com/ohah/maru/pull/1069)). 기능 브랜치를 대상으로 연 [#1048](https://github.com/ohah/maru/pull/1048)은 병합되지 않고 닫혔습니다.

헤더와 사이드바 아이콘 렌더링도 손봤습니다. ◧·⚙ 아이콘을 목표 크기로 직접 래스터해 확대 번짐을 없앤 뒤([#1055](https://github.com/ohah/maru/pull/1055), [#1058](https://github.com/ohah/maru/pull/1058)), 빌드 때 SVG를 coverage 마스터로 바꿔 합성 glyph로 그리는 인프라([#1060](https://github.com/ohah/maru/pull/1060))를 만들고 헤더 아이콘 전체를 PUA SVG 합성으로 통일하며 🔔·🔍 이모지를 단색화했습니다([#1062](https://github.com/ohah/maru/pull/1062)). 사이드바의 claude·codex 심볼도 합성 아이콘으로 바꿨고([#1064](https://github.com/ohah/maru/pull/1064)), 작은 크기에서 뭉개지던 브랜치 아이콘은 GitHub octocat 마크로 교체했으며([#1067](https://github.com/ohah/maru/pull/1067)), 알림 종의 가로 늘어남과 호버 배경 정렬([#1066](https://github.com/ohah/maru/pull/1066), [#1070](https://github.com/ohah/maru/pull/1070))을 바로잡았습니다. 파일 경로와 추가 스킴 링크를 Cmd+클릭으로 여는 [#1071](https://github.com/ohah/maru/pull/1071)은 이날 PR이 열렸습니다. 블로그 저장소에는 hwpjs 월간 오픈소스 문서 갱신 커밋이 올라갔습니다.
