# 2026-09-12

## 요약 (AI 작성)

hwpjs 가 차트에 들어간 날입니다(44커밋) — 차트 cell slot 과 raw 값 보존, 명시적으로 선택된 차트 type 선언과 참조 추적, dual string 디코드, footnote 조립, series v2 prefix, 순차적 axis 경계와 nullable post-surface axis 제목, text block 보조 객체 해석, OLE ordinal 참조 검증. Contents 관찰과 포맷 규칙을 구분해 적었습니다.

maru 원격 활동은 RAV7a(안 자랐으면 안 훑는다)·RAV7b 를 완성하고 RAV4b·RAV8a 의 기존 결함 둘을 잡았습니다. session-host 는 알림 후보 축을 세웠습니다 — app receipts 결속, callback 경로, continuity identity 노출과 증명, candidate identity, scenario receipt, R2c 가 하나의 절대 마감시간을 쓰는 것, 제품 브리지, 앱이 정확 알림 정리를 증명하는 것. 첫 화면이 8MiB 를 넘는 세션이 영영 못 붙던 것, 한도로 막힌 업그레이드가 무엇이 컸는지 안 남기던 것, 연결이 어느 줄에서 닫혔는지 안 남기던 것을 고쳤고, recipe 다이제스트를 프레임당 한 번만 계산합니다. 터미널은 안 움직인 이미지까지 generation 이 올라가 재업로드 폭풍이 나던 것과 U=1 애니메이션·delta placeholder 를 고쳤습니다. 편집기는 가로 상한을 설정으로 내고 걸렸을 때 알리며, CI 밖이던 macOS 판정자 아홉(하나는 빨간 채로)을 안으로 들였습니다.
