## 요약 (AI 작성)

이날 zts 저장소의 이름이 zntc로 바뀌었습니다([#2687](https://github.com/ohah/zntc/pull/2687)). 이름 변경 뒤 예제 빌드 전에 workspace 링크를 새로 고치도록 고쳤습니다([#2690](https://github.com/ohah/zntc/pull/2690)). 그 전까지는 RN 번들 크기를 줄이는 작업이 이어졌습니다. RN에서 legal comment 기본값을 Metro처럼 none으로 두고([#2677](https://github.com/ohah/zntc/pull/2677)), import scanner가 조건식의 죽은 분기와 transformer가 인라인한 boolean 조건의 죽은 분기에 있는 `require`를 걷어내며([#2678](https://github.com/ohah/zntc/pull/2678), [#2680](https://github.com/ohah/zntc/pull/2680)), 함수·화살표 함수·메서드 본문 안의 `require`를 lazy로 표시하게 했습니다([#2682](https://github.com/ohah/zntc/pull/2682)). RN core의 lazy getter를 문장 단위로 도달성 판정하는 tree-shaker 개선([#2685](https://github.com/ohah/zntc/pull/2685))은 PR 제목 기준 212 KB를 줄였는데, 바깥 변수 참조 회귀가 나와 되돌리는 PR [#2686](https://github.com/ohah/zntc/pull/2686)을 열었다가 닫고, getter 본문이 `require`만 하는 경우에만 사실을 등록하는 핫픽스([#2688](https://github.com/ohah/zntc/pull/2688))로 수습했습니다.

오후에는 안정성 수정이 이어졌습니다. 경로에 NUL 바이트가 있으면 `hashFileStreaming`이 panic하던 문제([#2693](https://github.com/ohah/zntc/pull/2693))와 store 왕복 뒤 dangling BufNode로 panic하던 문제를 `parse_arena`를 heap 포인터로 바꿔 근본 수정했고([#2696](https://github.com/ohah/zntc/pull/2696)), 같은 증상을 우회하려던 PR들([#2691](https://github.com/ohah/zntc/pull/2691), [#2695](https://github.com/ohah/zntc/pull/2695))은 닫았습니다. dev_mode 증분 재빌드에서 전체 번들 출력을 건너뛰어 PR 제목 기준 HMR 시간을 113ms에서 89ms로 줄였고([#2697](https://github.com/ohah/zntc/pull/2697)), preserveModules를 ESM이 아닌 형식과 쓰면 전용 진단 코드로 오류를 내게 했습니다([#2699](https://github.com/ohah/zntc/pull/2699)). React Native CLI 오버레이 초기화 기능([#2698](https://github.com/ohah/zntc/pull/2698))과 NAPI 패키지 smoke 테스트 CI 매트릭스([#2692](https://github.com/ohah/zntc/pull/2692))도 추가했습니다. 기본 Babel 변환 패스를 피하는 RN 수정 [#2700](https://github.com/ohah/zntc/pull/2700)은 이날 열려 5월 8일에 병합됐습니다.

블로그 저장소 ohah.github.io의 커밋 15개는 크론의 `CRON_CRD_WRITE.md` 점검 기록 13개와 `_meta.json`·요약 갱신 2개입니다.
