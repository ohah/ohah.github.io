## 요약 (AI 작성)

maru는 영속 터미널 세션 호스트를 P1부터 P3까지 한꺼번에 쌓았고, 이날 maru PR은 모두 main에 병합됐습니다. 먼저 Maru 소유 runtime ID와 별도 세션 호스트의 소유권·종료·다중 workspace attach 계약을 정의한 문서([#1471](https://github.com/ohah/maru/pull/1471))를 병합하고, provider 세션 연속성 잔여를 걷어냈습니다([#1474](https://github.com/ohah/maru/pull/1474)). P2에서는 PTY와 셸의 수명·입출력을 GUI 레이아웃에서 떼어 내는 `TermRuntimeBackend` 계약과 in-process 어댑터를 만들고([#1476](https://github.com/ohah/maru/pull/1476)), GUI를 그 handle 계약으로 배선했습니다([#1480](https://github.com/ohah/maru/pull/1480)).

P3는 순서대로 진행됐습니다. wire codec과 frame parser([#1483](https://github.com/ohah/maru/pull/1483)), 화면 snapshot·delta 레코드 codec([#1484](https://github.com/ohah/maru/pull/1484)), runtime당 controller 1명과 observer N명을 관리하는 `TerminalRuntimeRegistry`([#1485](https://github.com/ohah/maru/pull/1485)), 연결 dispatch 상태 기계([#1486](https://github.com/ohah/maru/pull/1486)), 실제 unix 소켓 어댑터·소켓 발견 정책·`maru-sessiond` 진입점·분리 실행 launcher와 `__session-host` CLI([#1487](https://github.com/ohah/maru/pull/1487)부터 [#1491](https://github.com/ohah/maru/pull/1491)), host client의 hello·RPC 왕복([#1492](https://github.com/ohah/maru/pull/1492)), `runtime.spawn/terminate`와 `RuntimeOps` seam([#1493](https://github.com/ohah/maru/pull/1493)), 실제 runtime manager와 daemon 배선([#1496](https://github.com/ohah/maru/pull/1496)), attach·input·resize dispatch([#1497](https://github.com/ohah/maru/pull/1497))가 들어갔습니다. 응답 크기 상한 등 리뷰에서 나온 정확성·보안 결함도 [#1495](https://github.com/ohah/maru/pull/1495)로 고쳤습니다.

그 위에 화면 스트리밍을 얹었습니다. 화면 snapshot 투영([#1499](https://github.com/ohah/maru/pull/1499)), attach 시 snapshot 전송([#1501](https://github.com/ohah/maru/pull/1501)), delta 계산과 client push([#1502](https://github.com/ohah/maru/pull/1502), [#1503](https://github.com/ohah/maru/pull/1503)), client 쪽 화면 조립기([#1504](https://github.com/ohah/maru/pull/1504))와 `RenderSnapshot` 셀 변환([#1505](https://github.com/ohah/maru/pull/1505)), `Surface.renderSnapshot()` 렌더 seam([#1506](https://github.com/ohah/maru/pull/1506)), Surface의 원격 화면 소스([#1507](https://github.com/ohah/maru/pull/1507))와 client 쪽 원격 runtime([#1508](https://github.com/ohah/maru/pull/1508))이 이어졌고, 원격 화면 stream 소비 결함 7건을 고쳤습니다([#1509](https://github.com/ohah/maru/pull/1509)). 마지막으로 frame loop pump의 원격 모드([#1510](https://github.com/ohah/maru/pull/1510)), host-backed `RemoteTermBackend`([#1511](https://github.com/ohah/maru/pull/1511)), 원격 Term 입력·resize 라우팅([#1512](https://github.com/ohah/maru/pull/1512))을 붙였습니다.

파일 패널에서는 Mermaid 라이브 프리뷰를 연결하고 cold·warm helper deadline 계약을 맞췄으며([#1473](https://github.com/ohah/maru/pull/1473)), smoke 타임아웃 조정([#1478](https://github.com/ohah/maru/pull/1478)), 메인 액터 tick의 lock 대기 계측([#1479](https://github.com/ohah/maru/pull/1479)), 두 512 상한 문서 정리([#1481](https://github.com/ohah/maru/pull/1481)), 응답 없는 render mailbox 회수([#1482](https://github.com/ohah/maru/pull/1482))가 뒤따랐습니다. CI는 required 게이트에 macOS·Web 제품 검사를 넣고([#1475](https://github.com/ohah/maru/pull/1475)) perf artifact 검사를 substring grep에서 정확한 JSON 검증으로 바꿨습니다([#1477](https://github.com/ohah/maru/pull/1477)). 웹 패널 포커스 시 ⌘C·⌘V·⌘A를 WebKit에 넘기고([#1489](https://github.com/ohah/maru/pull/1489)), 모드 전환 때 iframe이 editor를 덮던 CSS 누락([#1494](https://github.com/ohah/maru/pull/1494)), 소스 모드 세로 스크롤바와 위젯 잔존([#1498](https://github.com/ohah/maru/pull/1498)), 소스 모드 gutter 재도색과 우클릭 메뉴([#1500](https://github.com/ohah/maru/pull/1500))도 고쳤습니다.

zntc는 증분 빌드와 CJS 출력 정확성 PR 3개를 병합했습니다. `--preserve-modules --format=cjs`에서 재할당되는 export가 순환 중 undefined로 굳던 문제를 exports 객체를 저장소로 쓰는 방식으로 고쳤고([#4592](https://github.com/ohah/zntc/pull/4592)), const를 구워 넣은 소비자를 provider가 바뀔 때만 캐시에서 빼는 B-precise 전략을 넣었으며([#4593](https://github.com/ohah/zntc/pull/4593)), 증분 fingerprint가 interop 모드와 공유 namespace 변수명 변화를 놓치던 두 구멍을 메웠습니다([#4594](https://github.com/ohah/zntc/pull/4594)). 세 건 모두 리뷰 지적 반영 커밋이 뒤따랐습니다.

공개 커밋 53개, 해당일 생성 또는 병합된 PR 44개를 정리했습니다. PR 생성 42개·병합 44개는 같은 PR이 양쪽에 포함될 수 있습니다.
