maru는 config 파일이 바뀌면 자동으로 다시 읽는 `behavior.auto-reload`를 [#4137](https://github.com/ohah/maru/pull/4137)로 병합했습니다(기본 켜짐). 이어서 Reload Config가 활성 창만이 아니라 모든 창에 적용되도록 했고([#4155](https://github.com/ohah/maru/pull/4155)), 변경마다 보고 로그를 한 번만 남기도록 했습니다([#4151](https://github.com/ohah/maru/pull/4151)). 전체 초기화도 모든 창에 같은 방식으로 적용되게 바로잡았습니다([#4158](https://github.com/ohah/maru/pull/4158)). 편집기에는 활성 문서의 도크 아웃라인 [#4134](https://github.com/ohah/maru/pull/4134)이 새벽에 병합됐습니다. 정규식 검색은 줄 단위에서 문서 전체로 넓어져 여러 줄 검색과 캡처 치환이 가능해졌습니다([#4153](https://github.com/ohah/maru/pull/4153)). 평문 찾기에서는 반복 UTF-8 해독 비용을 줄였습니다([#4145](https://github.com/ohah/maru/pull/4145)). 프로젝트 검색 엔진 후보 실측 [#4140](https://github.com/ohah/maru/pull/4140)은 병합됐고, 현재 문서 검색과 ripgrep 재비교 [#4167](https://github.com/ohah/maru/pull/4167)는 이날 열려 다음 날 병합됐습니다.

같은 폴더에서 Codex를 두 pane으로 띄우면 사이드바의 상태와 제목이 뒤바뀌던 문제를 고쳤습니다([#4139](https://github.com/ohah/maru/pull/4139)). Codex 0.157 이상의 공유 데몬이 먼저 뜬 pane의 환경을 물려받아 생긴 문제라, 훅을 pane 이름이 아니라 세션 ID로 귀속하도록 바꿨습니다. 테스트가 띄운 제품 실행 파일이 개발자의 실제 HOME에 쓰고 정리까지 하던 문제는 공용 테스트 러너에서 HOME을 격리해 막았습니다([#4141](https://github.com/ohah/maru/pull/4141)). 그 밖에 재접속 작업의 종료 사유 기록([#4138](https://github.com/ohah/maru/pull/4138)), ReleaseFast에서만 나던 세션 호스트 테스트 fixture 결함([#4143](https://github.com/ohah/maru/pull/4143)), 청크 kitty 전송의 OOM 경로([#4150](https://github.com/ohah/maru/pull/4150)), alt 화면에서 창을 줄일 때의 kitty 이미지 처리([#4157](https://github.com/ohah/maru/pull/4157)), 새 활동이 붙어도 보던 항목을 유지하는 에이전트 활동 목록([#4156](https://github.com/ohah/maru/pull/4156))을 수정했습니다.
