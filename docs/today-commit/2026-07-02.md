## 요약 (AI 작성)

maru의 이날 PR 15개는 모두 main에 병합됐고, 중심은 앱 시작 안정성이었습니다. 설정의 `shell.command`에 실행할 수 없는 경로를 넣으면 셸이 즉시 죽고 첫 창이면 앱까지 종료되던 문제를 기본 셸 폴백으로 막았고([#1144](https://github.com/ohah/maru/pull/1144)), 근본 원인인 생명주기 계층을 고쳐 출력 없이 비정상 종료한 창은 앱을 끝내지 않고 유지하게 했습니다([#1146](https://github.com/ohah/maru/pull/1146)). 리뷰를 거쳐 exit code 게이트·grace window·죽은 입력 가드·좀비 reap으로 판정을 다듬었고([#1147](https://github.com/ohah/maru/pull/1147)), 유지된 창에 Enter 재시도·지속 안내·`workspace.hold-on-startup-failure` 설정을 얹었습니다([#1151](https://github.com/ohah/maru/pull/1151)). 이 재시도가 이름 변경·검색 중 Enter를 가로채던 회귀는 바로 수정됐습니다([#1152](https://github.com/ohah/maru/pull/1152)).

같은 사건의 트리거를 없애려고 설정 화면에 시작 디렉터리(`workspace.root`) 필드를 노출했고([#1148](https://github.com/ohah/maru/pull/1148)), PTY login 래퍼가 셸 경로와 인자를 작은따옴표로 감싸 공백이 든 경로가 쪼개지지 않게 했습니다([#1149](https://github.com/ohah/maru/pull/1149)). 렌더링에서는 BSU→ESU가 한 tick 안에 지나가 완성 프레임을 놓치고 최대 1초까지 표시가 막히던 문제를 ESU 누적 카운트로 고쳤고([#1143](https://github.com/ohah/maru/pull/1143)), 사이드바 에이전트 스피너를 DECSET 2026 동기화 hold와 분리해 따로 표시하게 했으며([#1145](https://github.com/ohah/maru/pull/1145)), sync 게이트 관측 로거를 `.sync` 카테고리로 승격했습니다([#1153](https://github.com/ohah/maru/pull/1153)).

워크스페이스 직렬화는 진화 계획을 문서로 남긴 뒤([#1140](https://github.com/ohah/maru/pull/1140)) 스칼라 필드를 순서와 무관하게 이름으로 읽는 key-addressed 리더로 바꿔, 필드가 추가돼도 옛 파일이 깨지지 않게 했습니다([#1141](https://github.com/ohah/maru/pull/1141)). 사이드바 카드는 좌측 accent 막대색을 우클릭 메뉴에서 배경색과 별도로 지정할 수 있게 됐고([#1139](https://github.com/ohah/maru/pull/1139)), 배경 tint가 카드 밖으로 번지던 문제 등 리뷰 지적이 반영됐습니다([#1142](https://github.com/ohah/maru/pull/1142)). 데스크톱 알림 제목에는 발신 위치(탭 › 팬)가 붙게 됐습니다([#1150](https://github.com/ohah/maru/pull/1150)).

공개 커밋 15개, 해당일 생성 또는 병합된 PR 15개를 정리했습니다. PR 생성 15개·병합 15개는 같은 PR이 양쪽에 포함될 수 있습니다.
