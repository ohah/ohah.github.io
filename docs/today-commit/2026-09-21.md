# 2026-09-21

## 요약 (AI 작성)

`@ohah/pdf` v0.2.0 이 나갔습니다 — PDF → Markdown/JSON, LLM 에 먹이는 꼴로. `pdf.markdown({ pages? })` 와 `pdf.blocks({ pages? })` 가 제목 계층·문단(하이픈 잇기)·목록·코드·표·머리말/꼬리말을 뽑고, 태그 PDF 는 구조 나무를 따라가며 괘선 없는 표도 찾습니다. 글자 뽑기를 pdf.js 수준으로 올리고(조각 폭·틈 판정·합자·내장 인코딩), 한국어 실전 문서로 다듬어 docling 과 맞댔으며, 무작위 27편(arXiv 22·한국 보고서 5)에서 드러난 아홉을 고치고, 큰 암호 문서 여는 데 56초 걸리던 것을 90ms 로 줄이고 누운 글(arXiv 스탬프)을 거릅니다. zntc 도 v0.1.10 을 냈습니다 — dev 가 사라진 CSS import 의 `<link>` 를 지우고(#4671), 아직 없는 경로도 감시 목록에 남기고(#4683), 중첩된 dev 산출 디렉토리를 CSS 탐색·복사에서 제외하며(#4678), CSS 파이프라인 사전 패스의 비용 측정과 D2a 선행 조건 재판정을 RFC 에 적었습니다.

maru 편집기는 파일 없이 여는 편집기(U1)와 이름 없는 문서 저장(U2), 저장 실패 사유와 「연 뒤 바뀌었나」 질문(C0), 저장 충돌을 «고르게» 하는 것과 네이티브 다시 읽기(C1a)를 얻었고, LSP 2단은 foldingRange 접힘 3층(⑨), didSave 통지(⑩ — rustc 진단이 저장에만 다시 돌아 고친 오류가 남아 있었다), 참조 피커 ⇧F12(⑪), 구현·타입 정의·선언으로 이동(⑫, open)까지 갔습니다. 비교 뷰에도 구문 색이 납니다. 에이전트 훅은 원격 Term 의 턴 스냅샷·✎ 귀속을 저쪽 기계에서 세우고(AT3c), ✎ 의 근거를 로컬·원격으로 통일하고(AT3d), 훅 커맨드 하나로 로컬/원격 설치기의 핑퐁을 없애고(RA8), 원격 tmux pane 별 훅 슬롯 테이블·라우팅·사이드바 행·«+N pane 밀림» 고지까지 RA7 조각 다섯을 쌓았습니다. 실기 e2e(새 Maru.app → maru ssh → loopback sshd → claude 한 턴) 도구와 결과를 문서로 남겼습니다.

`build.zig` 는 21,352줄에서 8,835줄로 줄었습니다 — 등록을 «바뀌는 이유» 별로 `build/` 로 가르고, 빌드 등록을 문자열이 아니라 AST 뷰 build_graph 로 세며, tests/boundary/ 판정자 스무 개를 표로 모았습니다. #3833 과 #3839 가 각자 초록으로 머지돼 main 이 컴파일되지 않던 것을 고쳤고, 잃은 게 없는데 저장을 막아 껐다 켤 때마다 배치가 사라지던 두 교착도 닫았습니다. hwpjs 는 EMF 레코드 wire 지원을 분류하고 polyline·Path 기하·closure·fill path/ellipse 를 조립하며, hwp5 가 EMF+ world transform 을 replay 합니다.
