## 요약 (AI 작성)

zntc는 오전에 Zig를 0.14.0에서 0.15.2로 올리고 CI 버전도 맞췄습니다([#206](https://github.com/ohah/zntc/pull/206)). 이때 전날 기능 브랜치에 쌓아 둔 `@panic("OOM")`의 오류 전파 전환과 Arena 통합·OOM 스트레스 테스트 커밋이 main에 함께 들어왔고, 함수 선언의 타입 매개변수 파싱 수정([#207](https://github.com/ohah/zntc/pull/207)), Test262 러너와 테스트 헬퍼까지 Arena를 적용한 [#208](https://github.com/ohah/zntc/pull/208)이 이어졌습니다. 이후 번들러 설계 결정(D064부터 D081까지)을 문서로 정리하고 모듈 번들러 구현을 시작했습니다.

번들러는 기본 타입과 import 스캐너([#209](https://github.com/ohah/zntc/pull/209), [#210](https://github.com/ohah/zntc/pull/210)), 상대·절대 경로와 `node_modules`·`package.json`을 다루는 resolver와 캐시·external 패턴([#211](https://github.com/ohah/zntc/pull/211)부터 [#213](https://github.com/ohah/zntc/pull/213)까지), 양방향 간선을 가진 모듈 그래프와 순환 감지([#216](https://github.com/ohah/zntc/pull/216)), 단일 파일 emitter와 공개 API([#217](https://github.com/ohah/zntc/pull/217), [#218](https://github.com/ohah/zntc/pull/218)), CLI `--bundle` 모드([#219](https://github.com/ohah/zntc/pull/219))로 첫 단계를 마쳤습니다. 오후에는 import·export 바인딩 스캐너와 모듈 간 심볼을 잇는 linker([#224](https://github.com/ohah/zntc/pull/224)), 이름 충돌 감지와 리네이밍([#226](https://github.com/ohah/zntc/pull/226)), 예약어 검사, 코드 생성까지 이어지는 `symbol_ids` 전달을 넣고 linker를 번들 파이프라인에 연결해([#231](https://github.com/ohah/zntc/pull/231)) scope hoisting을 완료로 표시했습니다. 밤에는 통합 테스트 120개를 추가하면서 버그 7개를 고친 [#235](https://github.com/ohah/zntc/pull/235)(inline type import 지원, 비 minify 출력 간격 등 포함), 잘못된 입력에서 OOM이 나지 않도록 23개 파싱 루프에 진행 가드를 단 [#236](https://github.com/ohah/zntc/pull/236), 테스트 28개 추가와 `.mts`·`.cts` 해석 수정([#237](https://github.com/ohah/zntc/pull/237))을 병합했고, Flow 지원 전략 분석을 문서에 남겼습니다.

cheolsu-proxy는 MCP 도구의 비즈니스 로직을 새 `cheolsu_ops` 크레이트로 세 단계에 걸쳐 옮기고([#305](https://github.com/ohah/cheolsu-proxy/pull/305)부터 [#308](https://github.com/ohah/cheolsu-proxy/pull/308)까지), 이를 공유하는 CLI 크레이트를 추가했습니다([#309](https://github.com/ohah/cheolsu-proxy/pull/309)). CLI 바이너리는 `cheolsu`, TUI는 `cheolsu-tui`로 이름을 정리했고([#310](https://github.com/ohah/cheolsu-proxy/pull/310)), Claude 스킬 커맨드와 설치·제거 명령, 한영 CLI 문서, `--version`·`--output json`·셸 completion([#311](https://github.com/ohah/cheolsu-proxy/pull/311)부터 [#313](https://github.com/ohah/cheolsu-proxy/pull/313)까지), 빠진 settings 서브커맨드([#314](https://github.com/ohah/cheolsu-proxy/pull/314), [#315](https://github.com/ohah/cheolsu-proxy/pull/315))가 들어왔습니다. 저녁에는 TLS 핑거프린팅을 우회하려고 upstream 인증서의 키 타입과 클라이언트의 ClientHello를 그대로 따라 하는 미러링과 키 타입별 leaf 키 캐시([#316](https://github.com/ohah/cheolsu-proxy/pull/316)), 앱 시작 시 기본 패스스루 도메인 비활성화가 데몬에 반영되지 않던 문제 수정([#317](https://github.com/ohah/cheolsu-proxy/pull/317))을 병합했습니다.

react-native-mcp는 Snapshot과 Refs 패턴의 `rn-mcp` CLI([#125](https://github.com/ohah/react-native-mcp/pull/125))를 병합했습니다. 블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋과 3월 21일 오늘의 커밋 요약 작성이 올라왔습니다.
