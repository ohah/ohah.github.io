# 2026-09-10

## 요약 (AI 작성)

zntc v0.1.7 이 나간 날입니다. maru 활동 뷰는 옛 형식의 JSON 껍데기를 벗겨 라벨의 74.4% 가 명령이 되고(§2.2), chunk 껍데기를 벗겨 갇힌 출력 191.5MB 를 되찾았으며(§2.4), 「구조는 벗기고 글자는 안 알아본다」를 계약으로 뒀습니다(§2.3). 편집기는 줄별 폭 캐시(L2)로 접힘 토글이 문서를 다시 안 훑고(30.3ms→1.29ms), caret 이 가장자리에 붙기 전에 굴립니다(세로 5·가로 0).

모바일은 누름이 표를 지나게 하고(서버 목록 M12a·원격 세션 목록 M12b — 뜻은 «그 세션의 id»), 남은 화면을 옮기고 옛 자리를 없애 M12 를 닫았습니다(M12c). 서버 목록 줄이 머리를 덮던 것과 추천 단어가 통째로 들어가던 것도 고쳤습니다. 터미널은 kitty 를 켠 앱에서 키를 누르고 있어도 한 번만 먹던 것(repeat 은 press 다), DECRQM 이 ?1048 을 «모른다» 고 답하던 것(목록을 소스에서 뽑는다), 애니메이션이 메모리 예산을 우회하고 LRU 를 뒤집던 것을 고쳤습니다. session-host 는 target_invalid 의 진짜 이유를 남기고(자식이 자기 파일에 적는다), 새 빌드를 깔 때마다 host 가 하나씩 늘던 것을 잡았습니다 — 늦게 추가한 tag 가 필수였습니다.
