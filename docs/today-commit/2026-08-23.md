# 2026-08-23

## 요약 (AI 작성)

`@maru/*` 를 쓸 만하게 만든 날입니다. 진짜 PTY 로 TUI 를 검증하며 IME 결함을 고치고, 화면·스크롤 제어와 상태 이벤트, 검색과 OSC 사건(정책은 소비자가 정한다), 직렬화·키 가로채기·선택 조회까지 API 표면을 마무리했습니다. 렌더 비용을 재 보니 WebGL 렌더러(F7.5)는 필요 없어 계획에서 지웠습니다.

Windows 는 드래그 선택과 caret(W8.3⒞3), 폰트 id 다리와 자유 위치 셀로 measured 텍스트, 소스 컨트롤이 눌리고(접기와 고르기) 스테이지·언스테이지가 진짜 git 을 움직이며, 창이 터미널과 도크로 갈렸습니다. 굵기 0 이 run 을 조용히 지우던 것은 이음매 굵기를 타입으로 막았습니다. 편집기는 ⌘F 가 문서를 검색하고(있던 기능이 아니라 조용히 틀린 것이었다, §5.1) 탭 폭을 설정에서 받습니다 — 완성된 세터에 호출자가 없었습니다.

에이전트 턴은 write-tree 를 재보고 턴 캡처를 git 에서 떼어냈으며, 링의 주인을 저장소에서 세션으로 옮겼습니다(AT0). 모바일은 친 글자가 두 번 나가고 소켓으로 나가려 최대 2초 기다리던 것, 엔터·탭이 원격에 안 가던 것, tmux prefix 다음 키·시스템 바 겹침을 고쳤습니다. session-host 는 raw TTY 진입 전 출력 프리미티브와 진입 장벽을 고정하고 hostile pump 증거를 닫았으며, 편집기 N2 버퍼 게이트를 걷고 "뒤집힐 조건" 으로 바꿨습니다.
