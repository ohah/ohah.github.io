## 요약 (AI 작성)

react-wasm-table은 이날 PR 여섯 개를 모두 main에 병합했습니다. 하위 행 펼치기 데모와 TanStack 데모 라우트 정리([#42](https://github.com/ohah/react-wasm-table/pull/42)), 캔버스 Sparkline 셀 렌더러와 데모([#43](https://github.com/ohah/react-wasm-table/pull/43)), `Table`과 `Thead`·`Td` 같은 구조 컴포넌트가 `TableCellContent`를 자식으로 받게 한 변경([#44](https://github.com/ohah/react-wasm-table/pull/44))이 먼저 들어왔습니다. 문서 사이트는 영어·한국어 문서 분리, 로고·파비콘, twoslash·mermaid·file-tree 플러그인, CI에서 문서 전에 WASM을 빌드하는 단계를 갖췄고([#45](https://github.com/ohah/react-wasm-table/pull/45)), Benchmark 페이지의 버튼과 드롭다운을 Tailwind CSS v4와 shadcn 컴포넌트로 바꿨습니다([#46](https://github.com/ohah/react-wasm-table/pull/46)). 마지막으로 TanStack 호환 Pagination·Grouped·Faceted 행 모델과 `useGridTable` 상태, 테스트, 데모를 추가하고, 페이지 이동이 데이터를 다시 넣지 않고 WASM 엔진의 `view_indices`만 잘라 쓰도록 했습니다([#47](https://github.com/ohah/react-wasm-table/pull/47)).

hwpjs는 COLORREF JSON을 `{r,g,b}` 형태로 되돌리고 테스트 컴파일을 고쳤으며([#78](https://github.com/ohah/hwpjs/pull/78)), Node 패키지 버전을 0.1.0-rc.6으로 올렸습니다([#79](https://github.com/ohah/hwpjs/pull/79)). CLI가 버전을 하드코딩하지 않고 `package.json`에서 읽게 했고([#80](https://github.com/ohah/hwpjs/pull/80)), 표 기본 테두리와 셀 테두리의 우선순위, 이미지 크기, `background-size`를 손봤습니다([#81](https://github.com/ohah/hwpjs/pull/81)). LaTeX 테스트 픽스처([#82](https://github.com/ohah/hwpjs/pull/82)), iOS 전용 빌드를 위한 `to_pdf` 시그니처 정렬([#83](https://github.com/ohah/hwpjs/pull/83)), 스냅숏 HTML을 11300 포트로 띄우는 스크립트([#85](https://github.com/ohah/hwpjs/pull/85)), collect 경계 사례 자리 테스트와 소수점 반올림 유틸([#86](https://github.com/ohah/hwpjs/pull/86))도 병합됐습니다. 가로 방향 용지에서 너비와 높이를 바꿔 쓰는 처리와 CONTRIBUTING의 Colima·Apple Silicon 빌드 설명 보강도 커밋됐습니다. 표 셀과 도형의 다단 렌더링([#89](https://github.com/ohah/hwpjs/pull/89))과 markdown 뷰어 테스트 PR [#84](https://github.com/ohah/hwpjs/pull/84)·[#87](https://github.com/ohah/hwpjs/pull/87)·[#90](https://github.com/ohah/hwpjs/pull/90)은 이날 열려 다음 날 병합됐고, [#88](https://github.com/ohah/hwpjs/pull/88)은 병합 없이 닫혔습니다.

cheolsu-proxy는 Pages 배포를 되살리고 문서·의존성·Tauri 설정을 갱신했으며 에이전트 명령을 `.cursor`에서 `.claude`로 옮겼습니다([#57](https://github.com/ohah/cheolsu-proxy/pull/57)). 이어 v1 크레이트(`proxyapi`, `proxyapi_models`)와 v1 Tauri 명령, 쓰지 않는 `hyper-tls` 의존성을 지우고 `proxy.rs`를 `system_proxy.rs`로 바꾸는 정리([#58](https://github.com/ohah/cheolsu-proxy/pull/58))가 병합됐고, oxfmt·oxlint 개발 의존성 추가와 포맷 적용이 뒤따랐습니다.

공개 커밋 59개, 해당일 생성 또는 병합된 PR 21개를 정리했습니다. PR 생성 21개·병합 16개는 같은 PR이 양쪽에 포함될 수 있습니다.
