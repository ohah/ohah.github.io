> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 lazy dev 모듈 HMR 작업을 진행했습니다. dev+split lazy 빌드가 모듈을 개별 factory로 감싸 전역 per-module `__zntc_modules` 레지스트리에 등록하도록 바꿔 청크를 넘나드는 hot-replace를 가능하게 했고([#4088](https://github.com/ohah/zntc/pull/4088)), `zntc dev` 웹 dev 서버에서 컴포넌트를 편집하면 리로드 없이 state를 보존하는 React Fast Refresh를 연결했습니다([#4089](https://github.com/ohah/zntc/pull/4089)). Zig DevServer의 `/@react-refresh` preamble이 `__ReactRefresh` 글로벌을 세팅하지 않던 문제([#4091](https://github.com/ohah/zntc/pull/4091))와 automatic JSX dev 다중 모듈 빌드에서 겹치는 jsx-runtime helper 선언 때문에 `_jsx$1 is not defined`가 나던 문제([#4092](https://github.com/ohah/zntc/pull/4092))도 고쳤습니다.

이어 dev_split의 청크 간 결함을 잇달아 수정했습니다. 동적 청크가 entry 모듈 export를 노출하지 않아 lazy 라우트가 렌더되지 않던 회귀([#4090](https://github.com/ohah/zntc/pull/4090)), re-export forwarding([#4093](https://github.com/ohah/zntc/pull/4093)), 청크 간 공유 CJS의 `import`·`require()`([#4094](https://github.com/ohah/zntc/pull/4094))와 re-export-from-CJS·`export *`·side-effect([#4095](https://github.com/ohah/zntc/pull/4095))를 글로벌 레지스트리로 해석하게 했습니다. 예약어 `default`를 구조 분해하며 생기던 SyntaxError([#4096](https://github.com/ohah/zntc/pull/4096), [#4099](https://github.com/ohah/zntc/pull/4099)), const export를 초기화 전에 snapshot하던 문제([#4098](https://github.com/ohah/zntc/pull/4098)), star 재노출 누락([#4100](https://github.com/ohah/zntc/pull/4100))도 바로잡았습니다. 청크 간 같은 이름 export 충돌(이슈 #4101)은 방어 테스트 스위트([#4103](https://github.com/ohah/zntc/pull/4103))를 먼저 깔고, 비활성 전역 네이밍 인프라([#4104](https://github.com/ohah/zntc/pull/4104))를 거쳐 dev_split에서 이를 활성화했습니다([#4105](https://github.com/ohah/zntc/pull/4105)). production splitting의 같은 한계는 todo 테스트로 고정해 두었습니다([#4106](https://github.com/ohah/zntc/pull/4106)).

파서 쪽에서는 `zig build test`에서 빠져 있던 parser 유닛 테스트를 포함시키고([#4112](https://github.com/ohah/zntc/pull/4112)), 바인딩 타깃 없이 `= default`만 오는 구조 분해 패턴에서 나던 세그폴트([#4113](https://github.com/ohah/zntc/pull/4113)), import attribute 중복 키 검사의 use-after-scope로 정상 키를 거부하던 문제([#4114](https://github.com/ohah/zntc/pull/4114)), automatic 런타임에서 spread 하나뿐인 children이 잘못된 JS를 만들던 문제([#4115](https://github.com/ohah/zntc/pull/4115))를 고쳤습니다. 블로그 저장소에는 오늘의 커밋 누락 날짜 보강과 요약 작성, 맞춤법 교정 커밋이 올라갔습니다.

공개 커밋 23개, 해당일 생성 또는 병합된 PR 22개를 정리했습니다. PR 생성 22개·병합 22개는 같은 PR이 양쪽에 포함될 수 있습니다.
