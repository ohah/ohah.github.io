## 요약 (AI 작성)

maru는 브라우저 주소창을 일반 텍스트 필드처럼 편집할 수 있게 만들었고, 관련 PR은 모두 main에 병합됐습니다. caret·선택·마우스 편집 설계 문서(슬라이스 0, [#1394](https://github.com/ohah/maru/pull/1394))를 시작으로, `TextField` 순수 모델·레이아웃·hit-test(슬라이스 1, [#1407](https://github.com/ohah/maru/pull/1407)), `fieldLayout` 단일 소스 렌더(슬라이스 2, [#1408](https://github.com/ohah/maru/pull/1408)), 마우스·키보드 편집과 `OverlayInput`에서 `TextField`로의 모델 교체(슬라이스 3, [#1409](https://github.com/ohah/maru/pull/1409)), ⌘C·⌘V·⌘X 클립보드 브리지(슬라이스 4, [#1410](https://github.com/ohah/maru/pull/1410))를 쌓았습니다. ⌘X는 별도 ABI 대신 OSC 52 쓰기 경로를 재활용했고, 그 과정에서 `terminal/grapheme.zig`를 최상위 중립 유틸로 옮겼습니다.

caret 모양은 손 테스트에 따라 세로 막대, 반투명 블록, 터미널 커서 재활용을 거쳐 설계 원안인 정적 반전 블록 셀로 돌아왔습니다. 한글이 NFD 자모로 분해돼 보이던 문제는 NFC 조합으로 고쳤고([#1411](https://github.com/ohah/maru/pull/1411)), 실제 IME 진입점을 거치는 한글 조합 회귀 테스트를 붙였습니다([#1415](https://github.com/ohah/maru/pull/1415)). 리뷰에서 나온 ⌘←/→가 편집을 취소하고 URL을 날리던 문제와 붙여 넣을 때 C0 제어 문자를 다 걸러 내지 못하던 문제를 고쳤고([#1412](https://github.com/ohah/maru/pull/1412)), 편집 중 ⌘A가 터미널을 전체 선택하던 문제와 ⌘⌫가 포커스를 웹 패널로 튕기던 문제도 수정했습니다([#1413](https://github.com/ohah/maru/pull/1413), [#1414](https://github.com/ohah/maru/pull/1414)).

zntc는 번들러 수정 3건을 병합했습니다. 증분 emit 캐시가 provider 쪽 상태 변화를 놓치던 문제를 provider emit fingerprint의 Merkle deep-fold로 고쳤고([#4546](https://github.com/ohah/zntc/pull/4546)), `--splitting`에서 raw `require()`가 다른 청크의 CJS 썽크를 import 없이 참조해 ReferenceError가 나던 문제([#4547](https://github.com/ohah/zntc/pull/4547)), manualChunks로 옮겨진 wrapped entry가 호출되지 않던 문제([#4550](https://github.com/ohah/zntc/pull/4550))를 수정했습니다. manualChunks가 user entry를 아예 옮기지 않도록 바꿔 이 계열 버그의 뿌리를 없애는 PR [#4554](https://github.com/ohah/zntc/pull/4554)는 이날 열렸습니다.

공개 커밋 20개, 해당일 생성 또는 병합된 PR 14개를 정리했습니다. PR 생성 13개·병합 13개는 같은 PR이 양쪽에 포함될 수 있습니다.
