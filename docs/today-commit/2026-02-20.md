## 요약 (AI 작성)

react-native-mcp는 콘솔·네트워크·네트워크 모킹·상태 변경 등 다섯 개의 버퍼 비우기 도구를 하나의 `clear` 도구로 합치고, 렌더 계열 도구가 React 컴포넌트 기준이라는 점 등 도구 설명을 명확히 해 도구 수를 38개로 정리한 [#64](https://github.com/ohah/react-native-mcp/pull/64)를 병합했습니다. 렌더 하이라이트는 react-scan과 bippy 기준에 맞춰 host fiber 판별을 통일하고 라벨 표시를 고쳤습니다([#67](https://github.com/ohah/react-native-mcp/pull/67)). E2E 전체 35단계의 iOS·Android 불안정 구간에 대기를 넣고, `REACT_NATIVE_MCP_TAP_TIMEOUT_MS`로 CI에서만 탭 타임아웃을 늘릴 수 있게 했습니다([#66](https://github.com/ohah/react-native-mcp/pull/66)).

E2E 결과를 `runs.json` 기반 HTML로 보여 주는 대시보드 리포터와 `test report show` CLI, 스텝 상세 펼침을 추가했고([#71](https://github.com/ohah/react-native-mcp/pull/71)), VS Code 확장에는 접근성 감사 CodeLens, E2E 대시보드 패널, 네트워크 모킹, 컴포넌트 트리에서 testID로 소스 위치를 찾아가는 기능을 넣었습니다. fetch와 XHR이 같은 요청을 두 번 기록하던 문제도 이때 고쳤습니다([#72](https://github.com/ohah/react-native-mcp/pull/72)). 상태 변경에 소스 위치를 붙여 이동하는 기능은 넣었다가 확장 쪽 연동만 다시 뺐습니다. 문서 사이트는 개요 페이지를 분리해 사이드바를 정리하고([#68](https://github.com/ohah/react-native-mcp/pull/68)), 인덱스 페이지가 없어 깨지던 링크와 빌드 실패를 고쳤습니다([#69](https://github.com/ohah/react-native-mcp/pull/69), [#70](https://github.com/ohah/react-native-mcp/pull/70)). CI E2E 기기를 지정하고 Android 해상도·방향을 고정하는 [#73](https://github.com/ohah/react-native-mcp/pull/73)은 이날 열렸습니다.

ohah.github.io에는 2월 20일 요약과 오늘의 커밋 메타 갱신이 올라갔습니다.

공개 커밋 29개, 해당일 생성 또는 병합된 PR 9개를 정리했습니다. PR 생성 8개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
