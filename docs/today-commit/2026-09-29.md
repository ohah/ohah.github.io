## 요약 (AI 작성)

maru는 9/28 실측에서 런타임 16개를 든 host가 `delta_seq_mismatch`로 GUI 연결 전체를 닫은 사건을 추적했습니다. [#3997](https://github.com/ohah/maru/pull/3997)이 어긋난 seq·gen 값을 로그에 싣고, 창 크기가 A→B→A로 제자리에 돌아오면 격자는 같아도 세대가 2 늘어 연결이 끊기던 원인을 [#4001](https://github.com/ohah/maru/pull/4001)이 스냅샷 전송으로 막았습니다. 다른 이유로 frontier가 어긋나도 해당 스트림만 무효화하고 resync로 복구하도록 [#4008](https://github.com/ohah/maru/pull/4008)이 바꿨고, runtime 8개 이상인 host가 poison 뒤 재접속하지 못하던 문제는 host당 resident charge 하나로 고쳤습니다([#4011](https://github.com/ohah/maru/pull/4011)). 업그레이드 handoff 실패·host 자연 종료·spawn 재시도에서 로그가 없거나 틀리던 세 자리를 보완한 [#4014](https://github.com/ohah/maru/pull/4014)는 이날 밤 열려 자정 직후 병합됐습니다.

편집기 쪽은 아침에 한글 IME 별칭을 포함한 명령 팔레트 퍼지 검색 [#3995](https://github.com/ohah/maru/pull/3995)가 병합됐습니다. 가장 잘 맞는 퍼지 정렬로 점수를 매기고, IME 조합이 남아 있을 때 Enter를 무시하며, 모달 IME 입력이 지속 검색보다 우선하게 하는 수정도 함께 들어갔습니다. 이어서 IME 조합 중인 글자를 모든 커서에 함께 보여 주고([#4000](https://github.com/ohah/maru/pull/4000)), 인레이 힌트가 있는 줄을 랩할 때 공백 표시가 debug 빌드에서 단언으로 죽거나 기호를 빠뜨리던 문제를 고쳤습니다([#4006](https://github.com/ohah/maru/pull/4006)). 사이드바·pane 라벨 등의 인라인 이름 변경은 caret 편집기로 옮겨 화살표 키로 커서를 움직일 수 있게 됐습니다([#4003](https://github.com/ohah/maru/pull/4003)). 그리기 op 목록이 잘린 경우를 보고하고 op 저장 방식 후보(B2)를 측정·평가하는 작업([#4002](https://github.com/ohah/maru/pull/4002), [#4004](https://github.com/ohah/maru/pull/4004))도 병합됐고, 인접한 검색 강조 op를 병합하는 [#4010](https://github.com/ohah/maru/pull/4010)은 이날 열려 다음 날 병합됐습니다. 편집기 검색·IME 구현 현황 문서([#3998](https://github.com/ohah/maru/pull/3998), [#3999](https://github.com/ohah/maru/pull/3999))도 갱신했습니다.

오래 켜 둔 앱에서 한글이 엉뚱한 글리프로 그려지던 문제는 버려진 글리프 배치를 아틀라스가 업로드된 것으로 기억한 탓이었고, [#4009](https://github.com/ohah/maru/pull/4009)에서 고쳤습니다. 터미널 PCRE2 찾기 병합 뒤 하루 가까이 빨갛던 main의 session host 잡은 찾기 요청 골든을 고친 [#4012](https://github.com/ohah/maru/pull/4012)로 복구했습니다. Chromium 웹 패널은 제어 채널 버전 불일치 안내·`maru-chromium` 설치물·라이선스·entitlements를 다룬 W7a1 [#4005](https://github.com/ohah/maru/pull/4005)와 후속 [#4013](https://github.com/ohah/maru/pull/4013)이 기능 브랜치 `docs/web-panel-osr-backend`에 병합됐고, main 통합 PR [#3867](https://github.com/ohah/maru/pull/3867)은 집계 시점에도 열려 있습니다.

spinon은 새벽에 Taffy 레이아웃 R10 적합성 실험 [#9](https://github.com/ohah/spinon/pull/9)를 병합하고, wgpu 모바일 GPU 경로 위험 검증 [#10](https://github.com/ohah/spinon/pull/10), 플랫폼 생명주기와 GPU 복구 검증 [#11](https://github.com/ohah/spinon/pull/11), 공통 호스트 계약 초안 [#12](https://github.com/ohah/spinon/pull/12), R03 명세 링크 수정 [#13](https://github.com/ohah/spinon/pull/13)을 병합했습니다. R06 스레드·소유권 위험 표 [#14](https://github.com/ohah/spinon/pull/14)는 이날 열려 다음 날 병합됐습니다. hwpjs는 검증된 zlib 래핑 스트림을 받아들이게 하고, 잘못된 문서 속성 길이를 식별하며, HWP5 읽기 전용 문서 투영을 추가했습니다.
