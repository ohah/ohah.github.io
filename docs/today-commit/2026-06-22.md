## 요약 (AI 작성)

maru는 하루 131개 커밋으로 세팅 화면과 설정 항목을 크게 채웠습니다. 전날 열린 세팅 폼 검색 [#836](https://github.com/ohah/maru/pull/836)과 리셋 위임 [#835](https://github.com/ohah/maru/pull/835)를 병합한 뒤 env 변수 삭제와 단축키 해제, 섹션을 넘나드는 검색과 단축키 충돌 경고, SV 그리드와 hue 띠로 임의 색을 고르는 HSV picker([#841](https://github.com/ohah/maru/pull/841))를 넣었고, picker는 Shift 미세 조정, 셀 사이 포인터 선택, hex 입력, 화면 색 추출까지 이어졌습니다. Reset to Defaults는 두 리셋을 하나로 합치고 확인 모달을 붙인 뒤 config 파일 삭제 대신 기본 상태를 atomic write로 덮어쓰도록 바꿨습니다. 테마 프리셋은 맨 위에 두고 활성 시 색을 잠그며 16색 팔레트까지 영속하게 했고, 섹션 키보드 이동, 모달 크기 고정, 선택 행 위젯 가림 수정이 이어졌습니다. 글로벌 핫키 설정 섹션과 변경 즉시 OS 재등록([#914](https://github.com/ohah/maru/pull/914), [#917](https://github.com/ohah/maru/pull/917)), 기존 chord를 자동으로 해제하는 키바인드 재바인딩도 들어왔습니다.

설정 항목으로는 창 투명도 `window.opacity`([#843](https://github.com/ohah/maru/pull/843)), 커서 깜빡임 주기와 포커스 잃을 때의 커서 모양, 휠 스크롤 배수, URL 클릭 수식키, 타이핑 중 마우스 숨김, 폴백 폰트 `font.fallback`([#856](https://github.com/ohah/maru/pull/856)), 비활성 pane 디밍, `input.option-as-meta`([#866](https://github.com/ohah/maru/pull/866)), 우클릭 동작, OSC 52 읽기 정책, 단어 구분자, 시각 벨과 Dock 배지([#882](https://github.com/ohah/maru/pull/882)), bold·italic 폰트 패밀리와 italic 렌더([#884](https://github.com/ohah/maru/pull/884)), 시스템 라이트·다크 자동 전환([#887](https://github.com/ohah/maru/pull/887)), 배경 이미지와 파일 선택창([#889](https://github.com/ohah/maru/pull/889)), 배경 블러([#892](https://github.com/ohah/maru/pull/892))가 추가됐습니다. pane을 사이드바로 끌어 워크스페이스를 나누거나 합치는 grip 핸들([#871](https://github.com/ohah/maru/pull/871))과 `move_pane_to_workspace` 키 동작도 생겼습니다. 알림은 클릭하면 보낸 터미널로 이동하고([#885](https://github.com/ohah/maru/pull/885)), 사이드바 종 아이콘의 인앱 알림 센터([#895](https://github.com/ohah/maru/pull/895))에 읽음·지우기, 배너와의 읽음 동기화, 스크롤, 말풍선 팝오버([#937](https://github.com/ohah/maru/pull/937))를 더했으며, 이를 위해 모달 오버레이의 픽셀 클리핑 인프라([#923](https://github.com/ohah/maru/pull/923))를 넣었습니다.

안정성 쪽에서는 스크롤백을 화면마다 별도 `Scrollback` 구조체로 나눠 alt screen에 스크롤바가 남던 문제를 해결하고([#850](https://github.com/ohah/maru/pull/850)), `scrollback.lines`를 줄이면 즉시 잘라 내며 좌표를 보정했고, glyph baseline을 정수 픽셀에 맞춰 글자가 흔들리지 않게 했습니다. macOS 번들에 CLI를 넣어 Install CLI 실패를 고쳤고, 버그 점검에서 나온 기능 결함과 문서 불일치를 일괄 수정했으며, 테스트가 실제 config를 덮어쓰지 못하게 막았습니다. 마지막으로 `core.zig`를 나누는 계획을 문서로 정하고 OSC 응답, 스크롤백 ring, DCS·OSC 라우터, kitty graphics 파싱, 탭스톱·dirty 추적·charset을 `osc.zig`·`parser.zig`·`screen.zig`로 옮기는 분할 10단계([#930](https://github.com/ohah/maru/pull/930)부터 [#942](https://github.com/ohah/maru/pull/942)까지)를 진행했습니다.

zntc는 test262 lexer 중복을 없애고 벤치마크를 ubuntu에서만 돌리며 문서 PR은 건너뛰게 해 CI 잡 수를 줄였습니다([#4461](https://github.com/ohah/zntc/pull/4461)). 블로그 저장소에는 오늘의 커밋 요약 커밋들과 맞춤법 수정이 올라갔습니다.

공개 커밋 138개, 해당일 생성 또는 병합된 PR 109개를 정리했습니다. PR 생성 107개·병합 109개는 같은 PR이 양쪽에 포함될 수 있습니다.
