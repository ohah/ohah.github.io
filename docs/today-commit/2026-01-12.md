## 요약 (AI 작성)

chrome-remote-devtools는 React Native 쪽 PR 세 개를 병합했습니다. [#67](https://github.com/ohah/chrome-remote-devtools/pull/67)은 Android·iOS 네이티브 수준에 `Runtime.getProperties` 처리기를 넣어, 콘솔에 찍힌 객체를 전역 `__cdpObjects` Map에 저장해 두었다가 DevTools에서 펼쳐 볼 수 있게 했습니다. 객체 저장 로직을 공용 헬퍼로 뽑고, 빈 속성 응답 처리를 함수로 묶었으며, Android JNI에서 promise 수명을 `shared_ptr`로 늘리고 시간 제한을 상수로 정리했습니다.

[#68](https://github.com/ohah/chrome-remote-devtools/pull/68)은 Windows의 CMake 경로 길이 제한 문제를 다뤘습니다. `android.experimental.cmakeShortBuildDir`를 켜고, react-native-nitro-modules와 react-native-mmkv에 빌드 스테이징 디렉터리 설정을 적용하는 postinstall 패치 스크립트를 추가해 리뷰에 따라 예외 처리와 중복 적용 검사를 다듬었으며, CMake 빌드 산출물을 `.gitignore`에 넣었습니다.

[#69](https://github.com/ohah/chrome-remote-devtools/pull/69)는 inspector 패키지에서 Zustand 래퍼와 쓰지 않는 Redux 미들웨어 코드, zustand 의존성을 지우고, Redux DevTools Extension 폴리필이 Zustand 액션을 정규화하도록 바꿨습니다. 기본 익명 액션 유형 `@@ZUSTAND/SET`을 두고 스토어 이름에서 문자열 `instanceId`를 만들며, 액션 정규화의 연산자 우선순위 오류를 고쳤습니다. 폴리필과 Metro 설정 단위 테스트, React Native inspector 테스트용 GitHub Actions 워크플로를 추가하고 CI에서 실패하던 테스트를 바로잡았습니다.
