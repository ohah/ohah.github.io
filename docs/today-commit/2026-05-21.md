> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 이날 저장소 활동이 사실상 전부였습니다. 오전에는 module store 오류 경로에서 `freeCachedModule` 재사용, pnpm 경로 헬퍼 정리, RN 에셋 플러그인의 중복 Metro scale 폴백 제거 같은 정리 작업과 함께 `waitForServer`를 `@zntc/test-helpers` 워크스페이스로 합쳤습니다([#3612](https://github.com/ohah/zntc/pull/3612)). RN 쪽은 릴리스 빌드에서 minify 없이 dev 분기를 잘라 내고 worklet 오류 전역을 closure에서 빼 worklet 번들링을 안정화했고([#3615](https://github.com/ohah/zntc/pull/3615)), re-export 소스의 부수 효과 보존([#3620](https://github.com/ohah/zntc/pull/3620)), HMR에서 resolver 옵션과 부수 효과 import 순서 보존([#3624](https://github.com/ohah/zntc/pull/3624))을 병합했습니다. 렉서는 `@jsxImportSource` pragma의 scoped 패키지 경로를 유지하도록 고치고 번들 수준 회귀 가드를 붙였습니다([#3617](https://github.com/ohah/zntc/pull/3617), [#3619](https://github.com/ohah/zntc/pull/3619)).

번들러는 코드 분할 emit 경로에도 문장 단위 export DCE를 적용하고 used-names 누수를 막았으며([#3623](https://github.com/ohah/zntc/pull/3623), [#3627](https://github.com/ohah/zntc/pull/3627)), 앱 빌드에서 jsx 옵션이 `buildApp`에 전달되지 않아 "React is not defined"가 나던 문제를 고쳤습니다([#3626](https://github.com/ohah/zntc/pull/3626)). 같은 수정을 다른 브랜치로 올린 PR 두 개는 닫았습니다. 예제는 react-19-zntc, react-19-vite, rspack을 워크스페이스에 넣고, host가 zntc remote를 렌더하는 Module Federation 브라우저 데모와 예제 빌드 브라우저 스모크 CI를 추가했습니다([#3630](https://github.com/ohah/zntc/pull/3630), [#3631](https://github.com/ohah/zntc/pull/3631)). RN config 예제 문서도 더했습니다([#3621](https://github.com/ohah/zntc/pull/3621)).

오후에는 32비트와 macOS Intel CLI 릴리스 빌드 회귀를 고친 뒤([#3632](https://github.com/ohah/zntc/pull/3632)) npm 퍼블리시 인증 문제와 씨름했습니다. `.npmrc` 리터럴 토큰, `npm publish` 전환, setup-node의 registry-url 제거를 차례로 시도한 끝에 workspace 프로토콜 자동 변환을 위해 `bun publish`로 돌아가 버전을 0.1.1로 올리고([#3636](https://github.com/ohah/zntc/pull/3636)), 인증은 `NPM_CONFIG_TOKEN` 환경 변수로 해결했습니다([#3637](https://github.com/ohah/zntc/pull/3637)). 이후 `@zntc/core` 0.1.1의 optionalDependencies에 맞춰 lock 파일을 갱신하고, measure-first 결과로 성능 백로그를 정리했습니다([#3638](https://github.com/ohah/zntc/pull/3638)). 블로그 저장소 ohah.github.io의 커밋 10개는 크론의 문서 점검 표시와 요약 갱신 커밋입니다.

공개 커밋 45개, 해당일 생성 또는 병합된 PR 29개를 정리했습니다. PR 생성 29개·병합 27개는 같은 PR이 양쪽에 포함될 수 있습니다.
