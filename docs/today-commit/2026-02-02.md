## 요약 (AI 작성)

chrome-remote-devtools는 React Native 예제 앱을 Console·Network·Store·Storage 하단 탭으로 재구성하고, Android e2e Maestro 플로우를 워크플로에 넣었으며, Metro 설정에서 원본 소스를 포함한 소스맵을 캐시해 `Page.getResourceContent`로 Sources 탭에 보여 주도록 했습니다([#106](https://github.com/ohah/chrome-remote-devtools/pull/106)). 인스펙터의 클라이언트 목록은 5초 폴링 대신 서버의 SSE 엔드포인트 `/json/clients/events`로 연결·해제 시 갱신되게 바꾸고 디버그 로그를 정리했습니다([#107](https://github.com/ohah/chrome-remote-devtools/pull/107)). Redux·Metro polyfill의 디버그 로그 제거([#108](https://github.com/ohah/chrome-remote-devtools/pull/108))도 병합했고, MMKV 업데이트 바와 검증을 빼고 타입 열만 남기는 [#109](https://github.com/ohah/chrome-remote-devtools/pull/109)는 이날 열렸습니다.

electron-mcp-server는 이날 첫 커밋으로 시작했습니다. Bun 모노레포와 Cursor 규칙·커맨드로 초기 구성을 잡은 뒤([#1](https://github.com/ohah/electron-mcp-server/pull/1)), MCP 서버를 Electron을 띄우지 않는 Node stdio 서버로 만들고 Electron 앱은 `examples/electron-mcp-demo`로 분리했습니다([#2](https://github.com/ohah/electron-mcp-server/pull/2)). CI와 타입 수정, 스크린샷 저장 경로를 작업 디렉터리 아래로 제한하는 리뷰 반영도 이어졌습니다. 패키지 이름을 `@ohah/electron-mcp-server`로 바꾸고 데모에 Vite dev·preload·CSP를 넣는 [#4](https://github.com/ohah/electron-mcp-server/pull/4)는 이날 열렸습니다.

gif2mp4는 문서 데드 링크와 GitHub Pages 서브패스용 Rspress 배포 설정을 고치고([#3](https://github.com/ohah/gif2mp4/pull/3)), docs 워크플로 리뷰 피드백을 반영했습니다([#5](https://github.com/ohah/gif2mp4/pull/5)). 같은 내용을 다룬 #4와 #6, #7은 병합 없이 닫혔습니다. 샘플과 벤치마크에 쓰는 GIF를 `umjjal.gif`로 통일하고 쓰지 않던 루트 `src/main.rs`를 지웠으며([#8](https://github.com/ohah/gif2mp4/pull/8)), `@gif2mp4/core` npm 배포 설정을 담은 [#9](https://github.com/ohah/gif2mp4/pull/9)가 열렸습니다.

공개 커밋 23개, 해당일 생성 또는 병합된 PR 14개를 정리했습니다. PR 생성 14개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
