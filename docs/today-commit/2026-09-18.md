## 요약 (AI 작성)

maru 편집기의 LSP 2단이 이어진 날입니다. 전날 열린 [#3790](https://github.com/ohah/maru/pull/3790)으로 호버 박스의 진단 줄을 VS Code 마커 호버 모양(평문 메시지와 흐린 `출처(코드)`)으로 맞춘 뒤, F12와 ⌘클릭이 definition을 §5.2의 navigateTo로 잇고 ⌃-/⌃⇧-로 뒤로·앞으로 오가게 했습니다(②, [#3791](https://github.com/ohah/maru/pull/3791)). 시그니처 힌트는 트리거 글자·재트리거·caret 이동에 signatureHelp를 묻고 활성 파라미터를 accent로 보이며 ⇧⌘Space로 부를 수 있고(③, [#3793](https://github.com/ohah/maru/pull/3793)), 문서 포맷은 ⇧⌥F가 textDocument/formatting의 TextEdit[]을 되돌리기 하나·caret 보존 규칙으로 적용합니다(④, [#3794](https://github.com/ohah/maru/pull/3794)). 각 단계는 적대적 변이 검증으로 판정자를 보강했습니다. session-host는 세션 27개가 붙은 host의 업그레이드가 반복 실패한 사례에서, 예약 대조가 어긋난 축을 남기지 않아 원인을 두 번 틀리게 짚었던 진단 구멍을 메웠습니다([#3792](https://github.com/ohah/maru/pull/3792)).

zntc는 `@mui/material` import가 `createStyled is not a function`으로 죽던 #4659를 고친 [#4661](https://github.com/ohah/zntc/pull/4661)을 병합해 package.json `module` 필드 해석분에 Node CJS interop을 적용하지 않게 했고, 그 파생으로 re-export 체인의 CJS interop을 import 문의 주인 기준으로 판정하게 했습니다([#4662](https://github.com/ohah/zntc/pull/4662)). 8월 31일 이후 계속 빨갰던 NAPI CI는 CLI 테스트 하네스를 browserslist 데이터 노화에 안 흔들리게 고정해 복구했습니다([#4663](https://github.com/ohah/zntc/pull/4663)). CJS default import 직접 축약을 ESM importer에도 적용하는 [#4664](https://github.com/ohah/zntc/pull/4664)는 이날 PR이 열렸습니다.

공개 커밋 11개, 해당일 생성 또는 병합된 PR 9개를 정리했습니다. PR 생성 7개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
