# 2026-09-18

## 요약 (AI 작성)

LSP 2단이 이어진 날입니다. 정의로 이동·되돌아가기 — F12·⌘클릭이 definition 을 §5.2 의 navigateTo 로 잇고 ⌃-/⌃⇧- 로 뒤로·앞으로(②, §8.2c), 시그니처 힌트 — 트리거 글자·재트리거·caret 이동에 signatureHelp 를 묻고 활성 파라미터를 accent 로, ⇧⌘Space(③), 문서 포맷 — ⇧⌥F 가 textDocument/formatting 의 TextEdit[] 을 §3.6 규칙으로 적용(④, §8.2e). session-host 는 예약 대조가 어긋난 «축» 을 안 남겨 원인을 두 번 틀리게 짚었던 진단 구멍을 메웠습니다.
