## 요약 (AI 작성)

maru의 편집기 커서가 움직이기 시작한 날입니다. 이동 일습·랩 시각 행·스크롤 앵커를 넣고(§3.2·§4.1c·§4.1g, [#2718](https://github.com/ohah/maru/pull/2718)), 저장 안 한 편집을 dirty 표시와 닫기 보호로 알리며([#2725](https://github.com/ohah/maru/pull/2725)), 복사·붙여넣기·잘라내기가 멀티 커서를 알고([#2731](https://github.com/ohah/maru/pull/2731)) 삭제가 낱말·줄 단위를 알게 했습니다([#2739](https://github.com/ohah/maru/pull/2739)). 판정자를 뮤턴트로 전수 훑어 도구가 열한 번 거짓말한 것도 고쳤습니다([#2714](https://github.com/ohah/maru/pull/2714)). 전날 열린 접근성 서술자의 host 연결 [#2703](https://github.com/ohah/maru/pull/2703)(스냅숏·ABI v173·Swift 어댑터)과 「턴이 끝나는 그 순간」을 지키게 한 [#2707](https://github.com/ohah/maru/pull/2707)도 병합됐고, 넓힌 봉인 조건 때문에 셸 전용 턴이 사라지던 후속 문제도 고쳤습니다.

session-host는 알림 축을 세웠습니다. bounded notification journal([#2722](https://github.com/ohah/maru/pull/2722)), stable OSC 알림 admit([#2726](https://github.com/ohah/maru/pull/2726)), 알림 메타데이터 전달, macOS 알림 전달([#2733](https://github.com/ohah/maru/pull/2733)), GUI 히스토리 투영([#2734](https://github.com/ohah/maru/pull/2734)), cold notification 응답 라우팅까지 이어졌습니다. 회복 가능한 spawn 실패가 앱 abort로 승격되던 것, P5d 게이트가 정상 서명을 "runtime 없음"으로 읽던 것, 쓰기만 되던 incident 진단을 고쳤고([#2727](https://github.com/ohah/maru/pull/2727)), poison이 어느 불변식에서 났는지 남기게 했습니다([#2730](https://github.com/ohah/maru/pull/2730)). GUI 앱의 진단을 `/dev/null` 대신 파일로 남기고([#2729](https://github.com/ohah/maru/pull/2729)), 화면 코덱을 OS 중립 자리로 옮겼으며(S11-3), session host 기본값의 출처와 override를 reset에서도 보존했습니다. G3 release 계약을 닫고([#2740](https://github.com/ohah/maru/pull/2740)), 버전 단일 출처를 macOS 산출물에 잇고([#2741](https://github.com/ohah/maru/pull/2741)) 검증된 draft를 덮어쓰지 않고 게시하는 CI를 넣었습니다([#2743](https://github.com/ohah/maru/pull/2743)). 성공한 upgrade를 실패로 읽던 자리를 닫는 [#2742](https://github.com/ohah/maru/pull/2742)와 서명을 고정 태그 워크플로로 제한하는 [#2745](https://github.com/ohah/maru/pull/2745)는 이날 열렸습니다.

Windows는 전날 열린 하단 상태표시줄 [#2705](https://github.com/ohah/maru/pull/2705)(W8.9)를 병합하고, 스크롤바를 띄웠으며(W8.10, [#2723](https://github.com/ohah/maru/pull/2723)), `maru install-cli`가 돌게 했습니다(W10, [#2720](https://github.com/ohah/maru/pull/2720)). 판정 각본이 제품에서도 돌고 있던 것을 고치면서 에이전트 카드·그룹([#2732](https://github.com/ohah/maru/pull/2732))과 정렬 토글([#2738](https://github.com/ohah/maru/pull/2738))이 눌리게 했습니다. 훑는 동안 창이 멈추던 것을 제출과 수령을 갈라 고치는 [#2746](https://github.com/ohah/maru/pull/2746)은 이날 열렸습니다. 파일 트리는 발행 비교가 두 좌표계를 견주고 있어 좌클릭이 영영 안 열리던 문제를 고쳤습니다([#2744](https://github.com/ohah/maru/pull/2744)). AT3b를 짜기 전에 FSEvents를 재 보고 가정 둘이 갈린 것을 문서로 남겼고([#2721](https://github.com/ohah/maru/pull/2721)), FSEvents가 설계상 손실이 있다는 점에서 tree 제거의 전제를 다시 보는 [#2724](https://github.com/ohah/maru/pull/2724)는 이날 열렸습니다.

공개 커밋 62개, 해당일 생성 또는 병합된 PR 38개를 정리했습니다. PR 생성 33개·병합 34개는 같은 PR이 양쪽에 포함될 수 있습니다.
