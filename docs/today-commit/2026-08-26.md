# 2026-08-26

## 요약 (AI 작성)

편집기 커서가 움직이기 시작한 날입니다 — 이동 일습·랩 시각 행·스크롤 앵커(§3.2·§4.1c·§4.1g). 판정자를 뮤턴트로 전수 훑어 도구가 열한 번 거짓말한 것을 고쳤습니다. session-host 는 알림 축을 세웠습니다: bounded notification journal, stable OSC 알림 admit, 알림 메타데이터 전달, GUI 히스토리 투영, 그리고 poison 이 어느 불변식에서 났는지 남기기(결론만 있고 이유가 없었다). G3 release 계약을 닫고, 성공한 upgrade 를 실패로 읽던 자리를 닫고 테스트 격리와 진단을 세웠습니다.

Windows 는 `maru install-cli` 가 돌고(W10), 판정 각본이 제품에서도 돌고 있던 것과 에이전트 카드·그룹·정렬 토글이 눌리는 것, 훑는 동안 창이 멈추던 것(제출과 수령을 가른다)을 고쳤습니다. 파일 트리는 좌클릭이 영영 안 열렸는데 발행 비교가 두 좌표계를 견주고 있었습니다. FSEvents 는 설계상 손실이 있어 tree 제거의 전제를 다시 봤습니다.
