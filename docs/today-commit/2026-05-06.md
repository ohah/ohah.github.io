## 요약 (AI 작성)

zntc는 전날 시작한 `@zts/react-native` dev server를 실제 앱에 붙여 보며 다듬었습니다. 전날 열린 oxfmt 0.48 업그레이드([#2628](https://github.com/ohah/zntc/pull/2628))와 `zts.config.ts`의 transformer·serializer·server 영역 매핑([#2630](https://github.com/ohah/zntc/pull/2630))이 병합됐고, `serializer.prelude`·`transformer.babel` 매핑([#2634](https://github.com/ohah/zntc/pull/2634)), RN CLI 플래그 매트릭스와 sourcemap 옵션 매핑([#2638](https://github.com/ohah/zntc/pull/2638), [#2645](https://github.com/ohah/zntc/pull/2645)), production asset 복사([#2639](https://github.com/ohah/zntc/pull/2639)), HMR 클라이언트 로그 색상([#2646](https://github.com/ohah/zntc/pull/2646))이 더해졌습니다. 사용자 보고를 바탕으로 babel 플러그인 이름 접두사 처리, JSC에서 안전한 URL 정규화, iOS 26.4 Hermes에 맞춘 preset 배너의 `globalThis` 할당 제거, Bun stdin Buffer를 받지 못하던 터미널 단축키, 기본으로 켜지 않던 dev server sourcemap, broadcast가 조용히 실패하던 문제, `withExpo`와 `EXPO_ROUTER_APP_ROOT` 절대 경로, DevTools sourcemap ignore 목록을 고쳤습니다([#2631](https://github.com/ohah/zntc/pull/2631), [#2633](https://github.com/ohah/zntc/pull/2633), [#2635](https://github.com/ohah/zntc/pull/2635), [#2642](https://github.com/ohah/zntc/pull/2642), [#2643](https://github.com/ohah/zntc/pull/2643), [#2656](https://github.com/ohah/zntc/pull/2656), [#2671](https://github.com/ohah/zntc/pull/2671)). Reanimated에서 드러난 회귀로 `__extends`가 열거되지 않는 static 메서드를 상속하지 않던 문제와 for-of 임시 변수 참조 span 문제도 수정했습니다([#2632](https://github.com/ohah/zntc/pull/2632), [#2641](https://github.com/ohah/zntc/pull/2641)).

번들러 sourcemap은 래퍼 닫는 괄호와 region·wrap·endregion 영역까지 원본에 매핑하고 본문 안쪽 빈 줄을 채워 모든 줄을 덮게 했습니다([#2649](https://github.com/ohah/zntc/pull/2649), [#2650](https://github.com/ohah/zntc/pull/2650), [#2653](https://github.com/ohah/zntc/pull/2653)). 이어 chunk별 sourcemap을 지연 생성해 디스크에 쓰고 `sourceMappingURL` 주석을 붙이는 작업이 세 단계로 들어갔고([#2655](https://github.com/ohah/zntc/pull/2655), [#2657](https://github.com/ohah/zntc/pull/2657), [#2658](https://github.com/ohah/zntc/pull/2658)), 주석 추가 분기 정리([#2662](https://github.com/ohah/zntc/pull/2662))와 hash 치환 뒤로 emit을 미뤄 `file` 필드를 정확히 맞추는 수정([#2664](https://github.com/ohah/zntc/pull/2664))이 뒤따랐습니다. `sideEffects: false` barrel의 lazy load([#2640](https://github.com/ohah/zntc/pull/2640)), watch json ready 이벤트 race 수정([#2636](https://github.com/ohah/zntc/pull/2636)), export getter에 minify_whitespace가 적용되지 않던 문제 수정([#2673](https://github.com/ohah/zntc/pull/2673))도 있었습니다.

저녁에는 RN 정책을 정리했습니다. Hermes의 ES2015와 async/await 호환 매트릭스를 보강한 뒤([#2674](https://github.com/ohah/zntc/pull/2674)) RN preset이 class·블록 스코프·generator·async 등만 내리고 arrow·구조 분해·optional chaining 같은 문법은 그대로 두는 Metro 수준 다운레벨링으로 바꿨고([#2675](https://github.com/ohah/zntc/pull/2675)), RN production 빌드에서 부수 효과가 없고 순환·TLA·`require.context`가 없는 모듈은 lazy wrap 대신 scope-hoist하도록 했습니다([#2676](https://github.com/ohah/zntc/pull/2676)). bungae가 archive되고 RN 기능이 `@zts/react-native`로 흡수됨에 따라 문서와 지침에 남은 bungae 참조도 지웠습니다([#2672](https://github.com/ohah/zntc/pull/2672)). 그 밖에 pnpm·bun 심볼릭 링크 farm의 scoped 패키지와 다단계 transitive 의존성 회귀 테스트([#2666](https://github.com/ohah/zntc/pull/2666)부터 [#2670](https://github.com/ohah/zntc/pull/2670)까지), CI 병렬화와 E2E app builder 그룹 병렬 실행([#2665](https://github.com/ohah/zntc/pull/2665), [#2667](https://github.com/ohah/zntc/pull/2667)), 문서 사이트의 벤치마크 차트·Mermaid 개선([#2652](https://github.com/ohah/zntc/pull/2652), [#2659](https://github.com/ohah/zntc/pull/2659), [#2663](https://github.com/ohah/zntc/pull/2663))이 병합됐습니다.
