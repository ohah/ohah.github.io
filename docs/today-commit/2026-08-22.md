# 2026-08-22

## 요약 (AI 작성)

터미널 코어를 wasm 으로 내고 `@maru/*` 라이브러리를 만든 날입니다(packages). 앱 안에만 있던 clean-room VT 코어를 브라우저에서 쓸 수 있는 꾸러미로 뗀 첫 판입니다. session-host 는 복구된 세션을 launch 때 투영하고 채택하며, 실제 AppKit 복구와 IME·클립보드 연속성을 검증하고, CR6e 복구 예산과 soak 를 게이트로 걸었습니다.

Windows 는 셰이핑 다리를 제품 경로에 붙여 크롬 글자가 실제로 나오고, 편집기 본문·배경·스크롤바·스크롤·클릭 히트테스트가 차례로 화면에 섰습니다(W8.3⒜·⒞1·⒞2). 쿼드는 파이프라인이 아니라 셰이더였고, 셰이퍼의 임의 상한이 긴 줄을 통째로 지우고 있었으며, 표면 스모크는 그리기 호스트를 공유하며 지문으로 등가를 증명합니다. 탐색기 행은 chrome/ui typed component 로 그리고 히트테스트·호버를 발행된 tree 로 옮겼습니다(FT1·FT2).

편집기는 gutter 접기 화살표를 누르면 접히게 하고 그 클릭을 적대적으로 두들겨 판정 공백 넷을 메웠으며, 성능 게이트가 시간이 아니라 횟수를 세게 해 부하에 흔들리지 않게 했습니다. 모바일은 새 연결이면 컨트롤 축을 처음부터 잡습니다.
