# 2026-08-22

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru의 에이전트 훅 모드가 기본값으로 켜진 날입니다. 전날 열린 [#2530](https://github.com/ohah/maru/pull/2530)이 병합돼 Notification으로 「입력 대기」를 판정하고 AH6 비용을 다시 쟀으며, 적대적 검증이 잡은 상태 기계 결함 셋을 고쳤습니다. 게이트를 켜도 실제로는 훅 모드에 들어갈 수 없던 문제를 고치고 그 진입 순서를 테스트로 재현한 뒤, codex 대화형까지 실측해 선결 조건 셋이 닫혔다며 기본값을 켰습니다. 사이드바는 라벨 규칙 변경이 깬 회귀 가드 둘을 새 계약으로 갱신했습니다.

Windows는 셰이핑 다리를 제품 경로에 붙여 크롬 글자가 실제로 나오게 하고([#2545](https://github.com/ohah/maru/pull/2545)), 셰이퍼의 임의 상한이 긴 줄을 통째로 지우던 것을 걷었습니다([#2548](https://github.com/ohah/maru/pull/2548)). 이어 편집기 본문이 화면에 뜨고(W8.3⒜, [#2551](https://github.com/ohah/maru/pull/2551)), 쿼드가 파이프라인이 아니라 셰이더 문제였음을 확인하며 배경과 스크롤바를 그렸고([#2555](https://github.com/ohah/maru/pull/2555)), 스크롤이 굴러가게 했습니다(W8.3⒞1, [#2558](https://github.com/ohah/maru/pull/2558)). 표면 스모크는 그리기 호스트를 공유하며 지문으로 등가를 증명하게 바꿨습니다([#2550](https://github.com/ohah/maru/pull/2550)). 클릭 히트테스트를 중립으로 빼는 W8.3⒞2 [#2561](https://github.com/ohah/maru/pull/2561)은 이날 PR이 열렸습니다.

탐색기는 행 렌더를 chrome/ui 컴포넌트로 옮기는 단계 계획을 열고([#2554](https://github.com/ohah/maru/pull/2554)) 행을 typed component로 그렸으며(FT1, [#2556](https://github.com/ohah/maru/pull/2556)), 행 아이콘을 사이드바·뷰 바와 같은 2칸으로 맞췄습니다([#2552](https://github.com/ohah/maru/pull/2552)). 히트테스트·호버를 발행된 tree로 옮기는 FT2 [#2562](https://github.com/ohah/maru/pull/2562)는 이날 열렸습니다. 편집기는 gutter 접기 화살표를 누르면 접히게 하고([#2543](https://github.com/ohah/maru/pull/2543)) 그 클릭을 적대적으로 두들겨 판정 공백 넷을 메웠으며([#2547](https://github.com/ohah/maru/pull/2547)), 성능 게이트가 시간이 아니라 횟수를 세게 했습니다([#2553](https://github.com/ohah/maru/pull/2553)). 전날 열린 비교 뷰 CRLF 복사 수정 [#2541](https://github.com/ohah/maru/pull/2541)도 병합됐습니다.

session-host는 복구된 세션을 launch 때 투영하고([#2542](https://github.com/ohah/maru/pull/2542)) 채택하며([#2544](https://github.com/ohah/maru/pull/2544)), 실제 AppKit 복구와 IME·클립보드 연속성을 검증하고([#2559](https://github.com/ohah/maru/pull/2559)), CR6e 복구 예산과 soak를 게이트로 걸었습니다([#2563](https://github.com/ohah/maru/pull/2563)). 모바일은 새 연결이면 컨트롤 축을 처음부터 잡게 고쳤습니다([#2546](https://github.com/ohah/maru/pull/2546)). 터미널 코어를 wasm으로 내고 `@maru/*` 라이브러리를 만드는 [#2560](https://github.com/ohah/maru/pull/2560)은 이날 열렸고 병합은 다음 날입니다.

공개 커밋 39개, 해당일 생성 또는 병합된 PR 24개를 정리했습니다. PR 생성 22개·병합 21개는 같은 PR이 양쪽에 포함될 수 있습니다.
