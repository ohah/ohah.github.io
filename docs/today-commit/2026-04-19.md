## 요약 (AI 작성)

zntc는 이날 번들 크기를 줄이는 작업과 시맨틱 분석 구조 정리에 집중했습니다. 연속된 같은 종류의 선언을 하나로 합치는 minify([#1600](https://github.com/ohah/zntc/pull/1600))로 시작해, namespace 접근을 정밀하게 분석해 `export * as M` 재수출의 tree shaking을 개선하고([#1606](https://github.com/ohah/zntc/pull/1606), [#1607](https://github.com/ohah/zntc/pull/1607)), 텍스트 매칭 대신 스코프를 인식하는 namespace tree shaking으로 Effect 번들을 PR 기준 40% 줄였으며([#1617](https://github.com/ohah/zntc/pull/1617)), 도달할 수 없는 문장 안의 namespace 멤버 접근은 사용으로 치지 않게 했습니다([#1627](https://github.com/ohah/zntc/pull/1627), [#1628](https://github.com/ohah/zntc/pull/1628)). minify 모드에서 `__commonJS`를 `$cj`로 줄이고([#1620](https://github.com/ohah/zntc/pull/1620)), `new Set()` 같은 표준 빌트인 생성자를 순수로 인식합니다([#1625](https://github.com/ohah/zntc/pull/1625)). 번들 전체 mangling을 미리 보는 `--mangle-preview`는 넣었다가 방향을 tree shaking 쪽으로 돌리며 되돌렸고([#1612](https://github.com/ohah/zntc/pull/1612), [#1614](https://github.com/ohah/zntc/pull/1614)), esbuild·rolldown과 minify 크기를 비교하는 스크립트와 svelte tree shaking 스모크 시나리오를 추가했습니다([#1611](https://github.com/ohah/zntc/pull/1611), [#1629](https://github.com/ohah/zntc/pull/1629)).

버그 수정으로는 건너뛴 문장이 빈 줄을 남기던 codegen 문제([#1605](https://github.com/ohah/zntc/pull/1605)), mangler가 원래 이름으로 남는 매개변수 이름을 다른 슬롯에 다시 배정하던 충돌([#1610](https://github.com/ohah/zntc/pull/1610)), 재할당되는 let의 초기값을 상수처럼 인라인하던 문제와 재할당 없는 let의 const 승격([#1615](https://github.com/ohah/zntc/pull/1615)), 모듈을 넘는 default import의 mangling 이름 불일치([#1624](https://github.com/ohah/zntc/pull/1624)), 단일 파일 `--minify-identifiers`에서 export가 사라지던 문제([#1635](https://github.com/ohah/zntc/pull/1635))가 있었습니다. 마지막으로 시맨틱 분석기에 참조별 배열을 다시 들이고, mangler의 liveness와 문장별 참조 캐시를 이 배열에서 만들도록 옮기는 4단계 작업을 마쳤습니다([#1636](https://github.com/ohah/zntc/pull/1636)~[#1639](https://github.com/ohah/zntc/pull/1639)).

ohah.github.io에는 맞춤법 크론의 커밋 14개가 있었고, 대부분 상태 파일 갱신이며 몇 건은 본문 오탈자·띄어쓰기를 고쳤습니다.

공개 커밋 48개, 해당일 생성 또는 병합된 PR 23개를 정리했습니다. PR 생성 23개·병합 22개는 같은 PR이 양쪽에 포함될 수 있습니다.
