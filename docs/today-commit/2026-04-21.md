## 요약 (AI 작성)

zntc는 bungae 실측에서 드러난 HMR 재빌드 문제를 먼저 고쳤습니다. 캐시된 모듈의 alias table 소유권을 넘기며 double-free와 use-after-free를 막고([#1682](https://github.com/ohah/zntc/pull/1682)), 재파싱되지 않은 React 내부 모듈이 HMR 업데이트에 끼던 문제, 재빌드 때 캐시된 참조 횟수와 canonical 이름이 오염되던 문제, 가상 모듈 경로의 mtime 조회를 바로잡은 뒤 회귀 테스트를 붙였습니다([#1683](https://github.com/ohah/zntc/pull/1683)). 디버그·안전 빌드용 `-Dnapi-optimize`와 카테고리별로 켜는 디버그 로그([#1685](https://github.com/ohah/zntc/pull/1685))도 추가했습니다.

transformer 재설계 epic은 바뀌지 않은 모듈의 emit 결과를 재사용하는 compiled output cache([#1674](https://github.com/ohah/zntc/pull/1674))를 NAPI watch와 첫 빌드에도 연결했고([#1686](https://github.com/ohah/zntc/pull/1686), [#1687](https://github.com/ohah/zntc/pull/1687)), 바뀌지 않은 노드는 복제하지 않고 그대로 돌려주게 했습니다([#1689](https://github.com/ohah/zntc/pull/1689)). AST 수명 디버그 인프라를 깔고 transformer가 파서 AST를 제자리에서 바꾸는 단계([#1690](https://github.com/ohah/zntc/pull/1690)~[#1695](https://github.com/ohah/zntc/pull/1695))를 병합했지만, 같은 AST로 두 번째 HMR 재빌드를 할 때 범위를 벗어나는 문제가 생겨 in-place 변경 부분은 되돌렸습니다([#1700](https://github.com/ohah/zntc/pull/1700)). HMR은 dev 모드에서 minify 패스를 건너뛰고 감지 debounce를 25ms로 줄였습니다([#1698](https://github.com/ohah/zntc/pull/1698), [#1701](https://github.com/ohah/zntc/pull/1701)).

후반에는 profile·benchmark 인프라를 설계 문서([#1702](https://github.com/ohah/zntc/pull/1702))대로 하루 만에 올렸습니다. 기반 모듈과 CLI·NAPI·환경 변수 진입점 통합(기존 `--timing` 제거), parse·semantic·graph·transform·codegen·metadata 단계 타이머, `--stop-after=<phase>` 조기 종료, 통계를 내는 `zts bench` 서브커맨드와 NAPI `benchmark()`, HMR 세부 단계 시간, 문서와 CLI·NAPI parity 테스트까지 이어졌습니다([#1703](https://github.com/ohah/zntc/pull/1703), [#1704](https://github.com/ohah/zntc/pull/1704), [#1706](https://github.com/ohah/zntc/pull/1706)~[#1713](https://github.com/ohah/zntc/pull/1713)). 이 밖에 한 번만 읽히는 상수 인라인([#1696](https://github.com/ohah/zntc/pull/1696)), oxc식 엄격한 순수 빌트인 생성자 목록([#1697](https://github.com/ohah/zntc/pull/1697)), ESM 래핑 모듈이 CJS에서 가져온 named import를 이름 충돌 대상에서 빼는 수정([#1699](https://github.com/ohah/zntc/pull/1699))이 들어갔습니다.

ohah.github.io에는 맞춤법 크론이 월간 오픈소스 문서 여러 편(craby, react-native-mcp, react-wasm-table 등)의 오탈자를 고치고 검사 완료를 표시한 커밋, 4월 20일 오늘의 커밋 요약이 올라왔습니다.
