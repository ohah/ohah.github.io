> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 PTY와 앱 런타임 흐름을 이어 붙였습니다. 종료 상태를 보존하고 HUP→TERM→KILL 순서로 닫는 정책([#43](https://github.com/ohah/maru/pull/43)), surface 런타임 라우팅([#45](https://github.com/ohah/maru/pull/45))과 그 리뷰 후속, PTY reader 큐([#48](https://github.com/ohah/maru/pull/48)), 런타임 이벤트 펌프([#50](https://github.com/ohah/maru/pull/50)), 제한된 큐로 대량 stdout을 흘리는 스트레스 테스트([#52](https://github.com/ohah/maru/pull/52))가 들어왔습니다. reader 정지 생명주기는 self-pipe wake와 kqueue `NOTE_EXIT`로 닫기 경로의 절충을 없앤 형태로 병합됐고([#53](https://github.com/ohah/maru/pull/53)), 펌프가 종료 데이터를 반환하도록 정리한 뒤([#55](https://github.com/ohah/maru/pull/55)) 헤드리스 PTY 데모를 붙였습니다([#56](https://github.com/ohah/maru/pull/56)). 밤부터는 렌더러 계약으로 DrawList([#57](https://github.com/ohah/maru/pull/57)), 가짜 glyph 레이아웃([#58](https://github.com/ohah/maru/pull/58)), glyph atlas 캐시([#59](https://github.com/ohah/maru/pull/59)), 커서 overlay dirty([#60](https://github.com/ohah/maru/pull/60))가 차례로 들어왔고, 앱 호스트 frame smoke([#61](https://github.com/ohah/maru/pull/61))와 macOS 창 smoke([#62](https://github.com/ohah/maru/pull/62))까지 병합됐습니다. macOS Metal smoke [#63](https://github.com/ohah/maru/pull/63)은 이날 PR이 열렸습니다.

suji는 EventBus `off()`가 진행 중인 emit을 기다리게 해 UAF를 정리한 뒤([#69](https://github.com/ohah/suji/pull/69)) CPython 3.13을 프로세스 안에 임베드하는 Python 백엔드를 추가했습니다([#70](https://github.com/ohah/suji/pull/70)). Python이 없는 머신에서도 돌도록 .app·CLI 번들과 PYTHONHOME 해석을 갖추고([#71](https://github.com/ohah/suji/pull/71)), 타입 stub 패키지 `suji-stubs`의 PyPI 발행 잡([#72](https://github.com/ohah/suji/pull/72))을 넣었으며, iOS 시뮬레이터([#73](https://github.com/ohah/suji/pull/73))와 Android 에뮬레이터([#74](https://github.com/ohah/suji/pull/74))에서도 e2e를 통과시켰습니다. 모바일 Python 백엔드는 호스트 하니스에 넣어 CI에서 돌게 했고([#76](https://github.com/ohah/suji/pull/76)), `app.icon`으로 macOS 앱 아이콘을 지정하는 기능도 들어왔습니다.

zntc는 dev HMR 위상 보존 경로의 링크 비용을 줄였습니다. 결정적인 plugin만 허용하도록 게이트를 완화해 RN preset이 보존 경로를 쓰게 하고([#4170](https://github.com/ohah/zntc/pull/4170)), reuse-hit에서 심볼 참조 수 계산과 변경 없는 모듈의 source 해시를 건너뛰었으며([#4171](https://github.com/ohah/zntc/pull/4171), [#4172](https://github.com/ohah/zntc/pull/4172)), `renameReuseGuard`를 변경 모듈로 한정했습니다([#4173](https://github.com/ohah/zntc/pull/4173), [#4181](https://github.com/ohah/zntc/pull/4181)). 링크 하위 단계 분해 bench와 계측([#4177](https://github.com/ohah/zntc/pull/4177)), Persistent Linker RFC 초안을 바탕으로 `injectPreservedRenames` 문자열 borrow([#4179](https://github.com/ohah/zntc/pull/4179))와 불필요한 쓰기 제거([#4182](https://github.com/ohah/zntc/pull/4182)), namespace 접근 분석의 부분 생략([#4184](https://github.com/ohah/zntc/pull/4184))이 이어졌습니다. 같은 namespace를 여러 모듈이 쓸 때 병렬 emit에서 나던 double-free([#4183](https://github.com/ohah/zntc/pull/4183)), main의 포맷 체크 실패([#4180](https://github.com/ohah/zntc/pull/4180)), new-css-import 테스트 flake([#4185](https://github.com/ohah/zntc/pull/4185))도 고쳤습니다.
