## 요약 (AI 작성)

maru는 설정을 크게 넓혔습니다. window padding을 chrome이 아닌 셀 그리드에만 적용하고 상하좌우를 따로 지정하게 했으며([#676](https://github.com/ohah/maru/pull/676), [#678](https://github.com/ohah/maru/pull/678)), `scrollback.lines`·`bell.audible`([#677](https://github.com/ohah/maru/pull/677)), ANSI 16색 override([#679](https://github.com/ohah/maru/pull/679)), 행간·자간([#680](https://github.com/ohah/maru/pull/680)), maru·ghostty 테마 프리셋([#687](https://github.com/ohah/maru/pull/687))과 gruvbox·solarized·dracula·catppuccin 등 6종 추가([#688](https://github.com/ohah/maru/pull/688)), 네이티브 메뉴의 Reload Config·Reset to Defaults([#683](https://github.com/ohah/maru/pull/683))를 넣었습니다. 렌더링에서는 OSC 133 gutter 표시를 셀 바깥으로 옮겨 첫 열 글자와 겹치지 않게 했고([#682](https://github.com/ohah/maru/pull/682), [#684](https://github.com/ohah/maru/pull/684)), `CAMetalLayer`를 sRGB 색 공간으로 지정했습니다([#689](https://github.com/ohah/maru/pull/689)). 사이드바는 고정 탭을 맨 위 영역에 모으고 드래그를 그룹 안으로 제한했습니다([#685](https://github.com/ohah/maru/pull/685)).

입력 쪽은 파일·URL·텍스트 드래그 앤 드롭([#690](https://github.com/ohah/maru/pull/690))을 넣은 뒤 TUI가 이미지를 인식하도록 Cmd+V와 같은 붙여넣기 경로로 정리했고([#696](https://github.com/ohah/maru/pull/696)), Cmd+] / [를 pane 순환으로 바꾸고 Term 순환은 Cmd+Opt 조합으로 옮겼으며([#691](https://github.com/ohah/maru/pull/691)), Cmd+K로 화면과 스크롤백을 비우는 `clear_screen`([#694](https://github.com/ohah/maru/pull/694))을 추가했습니다. 사이드바·탭 라벨이 복원된 정적 제목에 고정되던 문제([#698](https://github.com/ohah/maru/pull/698)), 알림 권한 선요청([#699](https://github.com/ohah/maru/pull/699)), Claude·Codex가 별도 설정 없이 데스크톱 알림을 보내도록 하는 `TERM_PROGRAM=ghostty` 주입([#701](https://github.com/ohah/maru/pull/701))도 들어왔습니다. 스레딩 쪽에서는 IME 조합 확정 때의 코어 락 재진입 데드락을 고치고([#700](https://github.com/ohah/maru/pull/700)), 재진입 안전망 `CoreOwner`와 락 없는 코어 변경 감지([#703](https://github.com/ohah/maru/pull/703), [#704](https://github.com/ohah/maru/pull/704)), 직접 lock 호출을 막는 경계 가드를 추가했으며, `termLabel` use-after-free도 수정했습니다([#702](https://github.com/ohah/maru/pull/702)).

밤에는 배포와 원격 환경을 다뤘습니다. XTVERSION 자기 식별 응답([#705](https://github.com/ohah/maru/pull/705)), 서명·공증·staple을 자동화한 macos-dmg 빌드 스텝과 최소 macOS 11.0([#697](https://github.com/ohah/maru/pull/697)), opt-in `xterm-maru` terminfo([#709](https://github.com/ohah/maru/pull/709))와 이를 원격에 전파하는 `maru ssh` 래퍼([#707](https://github.com/ohah/maru/pull/707))가 들어왔고, 리뷰 후속으로 ControlMaster 단일 연결과 이식성을 손본 뒤 terminfo 소스를 바이너리에 넣어 로컬 설치 없이 동작하게 했습니다([#711](https://github.com/ohah/maru/pull/711), [#712](https://github.com/ohah/maru/pull/712)). 기능 브랜치를 대상으로 한 terminfo PR [#706](https://github.com/ohah/maru/pull/706)은 병합되지 않고 닫혔습니다.

iris는 Uint8Array·분기·숫자·프로퍼티 루프의 벌크 빠른 경로와 JS 계산 루프 빠른 경로([#69](https://github.com/ohah/iris/pull/69)부터 [#74](https://github.com/ohah/iris/pull/74)까지)를 채택하고, JSON payload 생성과 object traversal, JSON snapshot 기반 round-trip과 tail loop, 문자열 복사 제거, compact snapshot과 layout detector 최적화([#75](https://github.com/ohah/iris/pull/75)부터 [#81](https://github.com/ohah/iris/pull/81)까지)를 병합했습니다. 블로그 저장소에는 크론이 만든 CRD 점검과 맞춤법 커밋이 올라갔습니다.

공개 커밋 61개, 해당일 생성 또는 병합된 PR 51개를 정리했습니다. PR 생성 51개·병합 50개는 같은 PR이 양쪽에 포함될 수 있습니다.
