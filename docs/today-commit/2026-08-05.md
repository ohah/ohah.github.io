# 2026-08-05

## 요약 (AI 작성)

CIM 이관을 divider·scrollbar·탭 드래그까지 넓혀 마무리한 날입니다. CIM2c·2d 로 divider 드래그를 실제 AppKit 경로로 끌어 coalescing 을 증명하고 웹 패널이 덮은 divider 도 잡히는지 확인했고, CIM3a~3d 로 scrollbar 를 capture 대상으로 발행한 뒤 drag capture 를 chrome 으로 옮겨 스크롤을 tick 으로 모으고, 네 개의 스크롤 입구가 같은 상태를 움직이는지·그 상태를 이어받는지까지 단언해 닫았습니다. CIM4a 로 탭 순서 preview 를 model 밖 transaction 으로 꺼내 터미널 탭 드래그를 model 을 건드리지 않고 끌도록 했고, 복원 트리거를 각각 고정하며 끄는 도중의 실제 프레임을 스모크에 남겼습니다. 진행 중인 제스처를 오버레이보다 먼저 라우팅하고 primary 버튼으로 한정하는 수정, 탭 hit-test 를 버튼 무관하게 고치고 preview 가 영속 스크롤로 새지 않게 한 수정도 함께 들어갔습니다.

렌더링에서는 클리핑 책임을 backend 로 넘겼습니다. chrome quad 클리핑을 GPU per-quad 로 옮기고(ABI v95) 컴포넌트가 지고 있던 책임을 걷어냈으며, 제품 Metal 셰이더 컴파일을 CI 가 검증하도록 했습니다. 셀 경로 텍스트도 published clip 을 소비하게 하고 모달 scissor 의 원점을 좌상단으로 정정했으며, 배지 geometry 를 ui 프리미티브로 추출하면서 모든 컴포넌트를 ui 프리미티브로 구현한다는 방향을 문서에 명시했습니다. 시각 회귀는 골든 이미지로 자동 검증하도록 바꿔 — 도크 시각 계약을 골든으로 고정하고, 골든을 Chrome Lab 캡처로 옮기고, 스모크가 배선된 곳에서 캡처 부재를 실패로 만들고, radius 도형의 잘린 변까지 고정했습니다. Lab 은 제품과 같은 measured text 경로로 이관하고 두 텍스트 패스를 한 atlas 세대에 배치했으며, Lab 과 제품의 text artifact 차이를 문서로 명시했습니다.

세션 도크는 플리커와 기하 문제를 뿌리부터 잡았습니다. 텍스트를 같은 tick 에서 셰이핑해 빈 프레임을 없애고, 클리핑을 emit 시점 판정에서 픽셀 단위로 옮겼으며, 목록이 viewport 에 맞춰 줄어들던 것이 스크롤 플리커·글자 넘침·빈 액션 버튼의 공통 원인이었음을 찾아 고쳤습니다. 드래그 가능한 스크롤바를 내고 스크롤 겹침을 없앴으며, 도크가 터미널 키(Enter, `/`)를 뺏지 않도록 했습니다. 텍스트 크기는 터미널 글자에 맞춰 한 단계 낮추고 카드 높이 하한이 그 typography 를 가리지 않게 조정했으며, 카드 텍스트 폭 예산에서 disclosure 슬롯을 예약했습니다. 적대적 검증에서 나온 도크 결함 다섯 개도 함께 정리했습니다. 그 밖에 릴리스 서명 주체(조직명·Team ID)를 저장소에서 빼고 관련 테스트·픽스처의 조직명을 synthetic 값으로 바꿨습니다.
