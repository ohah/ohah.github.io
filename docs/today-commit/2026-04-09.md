# 2026-04-09

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 HMR과 소스맵을 RN DevTools에서 제대로 보이게 하는 데 집중했습니다. dev 모드의 모듈 간 참조를 `__zts_modules` 레지스트리 조회로 바꾸고 업데이트 때 팩토리를 실제로 실행하게 했으며([#937](https://github.com/ohah/zntc/pull/937), [#938](https://github.com/ohah/zntc/pull/938)), react-refresh는 Bun symlink 경로 해석과 require 노출을 거쳐 `$RefreshReg$` 첫 호출 때 lazy하게 찾는 방식으로 정리했습니다([#941](https://github.com/ohah/zntc/pull/941)~[#943](https://github.com/ohah/zntc/pull/943)). 이어 HMR을 롤리팝 패턴으로 재설계해 eval 기반 실행, 모듈별 `$RefreshReg$` 저장·복원, 50ms debounce 갱신을 도입했고([#944](https://github.com/ohah/zntc/pull/944), [#947](https://github.com/ohah/zntc/pull/947)), WS 프로토콜에 update-start/update-done 메시지를 더했으며([#946](https://github.com/ohah/zntc/pull/946)), 두 번째 변경부터 full reload가 나던 그래프 변경 감지를 경로 집합 비교로 고쳤습니다([#952](https://github.com/ohah/zntc/pull/952)).

소스맵은 가상 모듈 ID의 null byte가 JSON을 깨던 문제([#948](https://github.com/ohah/zntc/pull/948)), `__esm` 래핑 모듈의 매핑 누락([#949](https://github.com/ohah/zntc/pull/949)), 파서 lookahead 복원 때 줄 오프셋이 남아 줄 번호가 밀리던 문제([#955](https://github.com/ohah/zntc/pull/955))를 고쳤습니다. sources 경로는 상대 경로로 바꾼 뒤 RN용 절대 경로 출력을 넣었다 되돌리는 과정을 거쳤고([#950](https://github.com/ohah/zntc/pull/950), [#958](https://github.com/ohah/zntc/pull/958), [#959](https://github.com/ohah/zntc/pull/959), [#960](https://github.com/ohah/zntc/pull/960)), 들여쓰기된 줄의 column 0 매핑([#957](https://github.com/ohah/zntc/pull/957))과 banner·폴리필·런타임 prologue 전체를 하나의 가상 소스로 매핑하고 `x_google_ignoreList`에 올리는 처리([#961](https://github.com/ohah/zntc/pull/961), [#962](https://github.com/ohah/zntc/pull/962))로 콘솔이 폴리필 줄을 가리키던 문제를 없앴습니다.

그 밖에 진단에 에러 코드 120개를 등록하고([#934](https://github.com/ohah/zntc/pull/934)) 문서 사이트에 에러 코드 125개 페이지와 Playground 재현 링크를 붙였습니다([#935](https://github.com/ohah/zntc/pull/935), [#936](https://github.com/ohah/zntc/pull/936)). 플러그인 transform 훅은 Rolldown처럼 codegen 뒤가 아니라 파싱 전 그래프 단계에서 돌게 옮기고 응답의 `code` 필드도 받도록 했습니다([#965](https://github.com/ohah/zntc/pull/965)~[#968](https://github.com/ohah/zntc/pull/968)). ROADMAP과 벤치마크 데이터도 새 실측값으로 갱신했습니다([#963](https://github.com/ohah/zntc/pull/963)).

bungae는 ZTS dev 서버를 Metro에 가깝게 다듬었습니다. multipart/mixed 응답과 진행률로 "Loading from Metro" 표시와 사라지지 않던 Downloading 100% 바를 정리했고([#44](https://github.com/ohah/bungae/pull/44), [#50](https://github.com/ohah/bungae/pull/50), [#51](https://github.com/ohah/bungae/pull/51)), Metro 호환 sourceMappingURL·sourceURL과 jscSafeUrl 인코딩, `/symbolicate` 라우트 우선 처리([#46](https://github.com/ohah/bungae/pull/46), [#53](https://github.com/ohah/bungae/pull/53)), node_modules 에셋 경로와 AssetRegistry 이중 specifier로 이미지가 안 보이던 문제([#47](https://github.com/ohah/bungae/pull/47)~[#49](https://github.com/ohah/bungae/pull/49))를 고쳤습니다. Metro 스타일 터미널 출력([#55](https://github.com/ohah/bungae/pull/55)), 빌드 시간 표시, 에러 오버레이와 앱 콘솔의 터미널 전달, `bundle` 명령 별칭, dev 서버 네트워크 통합 테스트([#52](https://github.com/ohah/bungae/pull/52))도 추가했습니다.

공개 커밋 75개, 해당일 생성 또는 병합된 PR 42개를 정리했습니다. PR 생성 41개·병합 42개는 같은 PR이 양쪽에 포함될 수 있습니다.
