cheolsu-proxy는 데몬 프로세스 출력을 로그 파일로 돌리고 SIGTERM 때 시스템 프록시 설정을 되돌리는 등 데몬 로깅을 정리했습니다([#64](https://github.com/ohah/cheolsu-proxy/pull/64)). 이어 mitmproxy의 방식을 따라 TLS 핸드셰이크에 실패한 도메인을 기록해 다음부터 바이패스하는 자동 학습, WebSocket 메시지 주입, OpenSSL 3에서 TLS 1.0·1.1을 위한 설정, 정상 종료 로그의 등급 조정을 병합했습니다([#65](https://github.com/ohah/cheolsu-proxy/pull/65)). 하드코딩된 터널 모드 코드와 데드 코드를 지웠고, Tower Layer 구조로 바꾸는 [#66](https://github.com/ohah/cheolsu-proxy/pull/66)을 열었습니다.

MCP 서버 두 곳은 응답을 짧은 텍스트로 바꾸는 작업을 했습니다. electron-mcp-server는 번들에서 Zod를 빼 `util3` 참조 오류를 없애고 콘솔 중첩 객체를 끝까지 풀어 보이게 했으며([#18](https://github.com/ohah/electron-mcp-server/pull/18)), agent-browser식 compact 출력과 `ref` 기반 요소·프로세스 주소 체계, bunup에서 tsdown으로의 전환을 병합한 뒤 publish 워크플로의 `dist/index.cjs` 경로를 고쳤습니다([#19](https://github.com/ohah/electron-mcp-server/pull/19), [#20](https://github.com/ohah/electron-mcp-server/pull/20)). react-native-mcp는 `take_snapshot`·`describe_ui`·`query_selector` 등의 응답을 들여쓰기 텍스트와 키=값 형식으로 바꾸고 버전을 v0.1.0-rc.10으로 올렸으며([#108](https://github.com/ohah/react-native-mcp/pull/108)), 한국어·영어 문서를 갱신했습니다([#109](https://github.com/ohah/react-native-mcp/pull/109)).

hwpjs는 PDF 코어 구현을 보류 상태로 넣고 CLI와 배포물에서 PDF 기능을 뺐으며 rspress 문서를 갱신했고([#114](https://github.com/ohah/hwpjs/pull/114)), 불필요한 문서 정리와 CI 워크플로 추가, clippy 경고 수정, 0.1.0-rc.7 기준 로드맵·README 정리를 병합했습니다([#115](https://github.com/ohah/hwpjs/pull/115)). ohah.github.io에는 크론의 맞춤법 점검 상태 기록과 이날 요약 추가 커밋 20개가 남았습니다.
