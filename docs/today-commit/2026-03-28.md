## 요약 (AI 작성)

zntc는 모듈 간 BFS로 트리 셰이킹을 다시 짜 svelte 번들을 22KB에서 3KB로, three를 790KB에서 21KB로 줄였습니다([#467](https://github.com/ohah/zntc/pull/467)). 이어 lodash-es에서 나던 SIGSEGV를 재귀 깊이 제한으로 막고, emitter의 span 매칭을 최상위 문장으로 한정했으며([#468](https://github.com/ohah/zntc/pull/468)), 순수 식별자를 extends하는 클래스와 static block·계산된 키 같은 클래스 본문의 부수 효과 분석([#470](https://github.com/ohah/zntc/pull/470), [#471](https://github.com/ohah/zntc/pull/471)), namespace barrel re-export와 ESM에서 CJS로 이어지는 re-export 체인의 default 해석, `export * as ns` DCE를 고쳤습니다. effect 패키지 대응으로 넣은 [#478](https://github.com/ohah/zntc/pull/478)은 svelte 회귀를 일으켜 [#480](https://github.com/ohah/zntc/pull/480)에서 되돌렸고, rolldown 방식의 심볼 기반 BFS 시드([#481](https://github.com/ohah/zntc/pull/481))로 다시 해결했습니다.

오후에는 스모크 테스트를 미리 설치한 의존성으로 돌려 1분 45초에서 30초로 줄이고([#483](https://github.com/ohah/zntc/pull/483)), CJS의 `module["exports"]`에서 나던 패닉을 고쳤습니다([#486](https://github.com/ohah/zntc/pull/486)). 밤에는 generator의 try·catch·finally 안 yield([#487](https://github.com/ohah/zntc/pull/487)), bun·pnpm의 중첩 `node_modules`를 위한 symlink 실제 경로 해석([#490](https://github.com/ohah/zntc/pull/490))을 넣고 스모크 비교 대상에 rspack을 추가했으며, for 루프 본문 세미콜론 누락([#492](https://github.com/ohah/zntc/pull/492))과 템플릿 리터럴 안 식별자 리네임([#495](https://github.com/ohah/zntc/pull/495))을 고친 뒤 oxc의 liveness BitSet 방식 mangler를 통합했습니다([#496](https://github.com/ohah/zntc/pull/496)). minify 옵션을 공백·식별자·구문으로 나누는 [#497](https://github.com/ohah/zntc/pull/497)은 이날 PR이 열렸습니다.

agent-devtools는 `--debug` 모드가 API 요청만 보이도록 하고, Windows 지원과 GitHub Actions CI, npm·GitHub Releases·Claude 플러그인 배포 구조를 갖췄습니다. 오후에는 trace·profiler·annotate와 proxy·확장 프로그램·설정·인증·도메인 제한 기능을 한꺼번에 넣은 뒤 도메인 우회와 인증 저장소 경로 순회를 막는 보안 수정을 했고, FFmpeg 파이프 방식 비디오 녹화와 자체 PNG 인코더·디코더로 만든 `diff-screenshot`, 템플릿 3개, README 전면 재작성, agent-browser와 같은 CLI 명령 체계 정리가 이어졌습니다. 밤에는 실행 중인 Chrome·Electron을 찾는 `--auto-connect`, curl 한 줄 설치, Electron 연결 수정을 넣고 버전을 0.1.1로 올렸으며, Playwright 호환 Enter 키 이벤트와 CLI 출력 형식도 고쳤습니다.

블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋만 올라왔습니다.
