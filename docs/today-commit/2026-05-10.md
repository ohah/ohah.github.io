## 요약 (AI 작성)

zntc는 npm 배포 구조를 크게 손봤습니다. NAPI 바이너리를 플랫폼별 하위 패키지로 나누는 뼈대를 만들고([#2935](https://github.com/ohah/zntc/pull/2935)), `release.yml`에 매트릭스 NAPI 빌드와 npm publish job을 더했으며([#2936](https://github.com/ohah/zntc/pull/2936)), 빌드 스크립트와 플랫폼 목록을 한 곳으로 모았습니다([#2937](https://github.com/ohah/zntc/pull/2937)). 플랫폼은 musl과 win32-arm64·ia32를 포함한 9개로 늘었고, 로더는 linux libc를 구분해 musl 하위 패키지를 고르게 됐습니다([#2942](https://github.com/ohah/zntc/pull/2942)). `@zntc/core`는 ESM·CJS 이중 exports를 갖추고 rspack-loader가 퍼블리시 대상에 등록됐으며([#2938](https://github.com/ohah/zntc/pull/2938)), `vite-plugin-zntc`는 `@zntc/vite-plugin`으로 이름을 바꿨습니다([#2940](https://github.com/ohah/zntc/pull/2940)). smoke test는 작업 공간 대신 tarball을 import하도록 고치고 win32-ia32 검증과 `--deep`·`--minify-all` 단계를 추가했습니다([#2943](https://github.com/ohah/zntc/pull/2943), [#2962](https://github.com/ohah/zntc/pull/2962), [#2980](https://github.com/ohah/zntc/pull/2980)). CI 쪽은 `--frozen-lockfile` 일괄 적용과 bun-cache composite action으로 캐시 키를 하나로 묶었습니다([#2933](https://github.com/ohah/zntc/pull/2933), [#2934](https://github.com/ohah/zntc/pull/2934)).

변환 기능으로는 Hermes용 named capture group 정규식 다운레벨([#2930](https://github.com/ohah/zntc/pull/2930))과 transpile 경로의 react-refresh 지원이 들어왔습니다. `TranspileOptions`에 `reactRefresh`를 노출하면서 화살표 함수를 대입한 컴포넌트도 등록되게 했고([#2939](https://github.com/ohah/zntc/pull/2939)), 훅 서명 `$RefreshSig$`는 `reactRefreshHookSignatures`로 선택해 켜도록 했습니다([#2941](https://github.com/ohah/zntc/pull/2941)).

오후부터는 번들러·minify 결함 수정이 이어졌습니다. default re-export 체인에서 `_default` 대입이 사라지던 문제([#2944](https://github.com/ohah/zntc/pull/2944)), wrapper-barrel 모듈 감지와 tree-shake 시드([#2946](https://github.com/ohah/zntc/pull/2946), [#2950](https://github.com/ohah/zntc/pull/2950)), linker의 namespace import 이름 충돌([#2954](https://github.com/ohah/zntc/pull/2954)), minify한 ESM external import에서 식별자와 키워드 사이 공백이 빠지던 문제([#2963](https://github.com/ohah/zntc/pull/2963))를 고쳤습니다. mangler는 모듈 간 이름이 중첩 바인딩을 가리던 문제와 import 바인딩·한 글자 최상위 바인딩을 예약 이름에 넣지 않던 문제를 고쳤습니다([#2966](https://github.com/ohah/zntc/pull/2966), [#2973](https://github.com/ohah/zntc/pull/2973), [#2974](https://github.com/ohah/zntc/pull/2974)). codegen은 템플릿 리터럴, 빈 else 분기, `{`로 시작하는 화살표 함수 본문, new 호출 괄호 제거, 구조 분해 단축 속성 rename 회귀를 바로잡았고, 함수 매개변수와 같은 이름의 var를 같은 바인딩으로 묶었습니다([#2978](https://github.com/ohah/zntc/pull/2978)). 소스맵은 static member property 매핑 누락을 고친 뒤 매핑을 명시적으로 발행하는 방식으로 통일하고, 누락을 잡는 정적 감사를 CI에 넣었습니다([#2984](https://github.com/ohah/zntc/pull/2984), [#2986](https://github.com/ohah/zntc/pull/2986)). bundler deep-dive·Flow 지원 가이드 문서도 추가됐고([#2985](https://github.com/ohah/zntc/pull/2985)), 가이드 보강·HMR API 문서·소스맵 `names` 발행 PR([#2987](https://github.com/ohah/zntc/pull/2987), [#2988](https://github.com/ohah/zntc/pull/2988), [#2989](https://github.com/ohah/zntc/pull/2989))은 이날 열렸습니다. 블로그 저장소 ohah.github.io에는 크론의 점검 표시 커밋 2개가 있습니다.

공개 커밋 58개, 해당일 생성 또는 병합된 PR 45개를 정리했습니다. PR 생성 45개·병합 42개는 같은 PR이 양쪽에 포함될 수 있습니다.
