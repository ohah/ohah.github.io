## 요약 (AI 작성)

zntc는 데코레이터·클래스 변환 이슈의 후속 수정으로 시작했습니다. private method 안의 `super.x`를 `__superGet`으로 낮추는 수정([#3722](https://github.com/ohah/zntc/pull/3722))이 리뷰에서 나온 사각지대 15건 처리와 함께 병합됐고, 병합 뒤 effect-ts와 static block에서 회귀가 나오자 일부를 되돌렸다가 원래 의도를 살린 정밀 수정을 두 차례 다시 넣었습니다([#3724](https://github.com/ohah/zntc/pull/3724), [#3725](https://github.com/ohah/zntc/pull/3725), [#3726](https://github.com/ohah/zntc/pull/3726)). `useDefineForClassFields=false`에서 private field 선언 보존([#3727](https://github.com/ohah/zntc/pull/3727)), 쓰이지 않는 `super_proto_alias`가 `var _a;`를 남기던 문제([#3739](https://github.com/ohah/zntc/pull/3739))도 고쳤습니다. NAPI 누수 덤프는 atexit 대신 `napi_add_env_cleanup_hook`을 쓰도록 바꾸고, 전날 만든 누수 게이트 워크플로는 비활성화했습니다([#3723](https://github.com/ohah/zntc/pull/3723)).

번들러에서는 namespace getter가 지워진 바인딩을 가리키는 문제를 여러 단계로 좁혀 갔습니다. `isLocalBindingAlive`의 rename 접미사 폴백과 모듈 포함 여부 확인, tree shaker 판정 동기화([#3729](https://github.com/ohah/zntc/pull/3729), [#3730](https://github.com/ohah/zntc/pull/3730), [#3731](https://github.com/ohah/zntc/pull/3731))를 거쳐 링커 namespace 분석기의 빈 결과 폴백([#3732](https://github.com/ohah/zntc/pull/3732))과 텍스트 기반 폴백, 3단 안전망([#3735](https://github.com/ohah/zntc/pull/3735))을 넣었고, 마지막에 binding scanner와 링커 분석기를 하나로 합쳤습니다([#3736](https://github.com/ohah/zntc/pull/3736)). 이어 namespace 접근 색인 공유와 `registerNamespaceRewrites` 경로 최적화로 링크 단계를 줄였고([#3740](https://github.com/ohah/zntc/pull/3740), [#3741](https://github.com/ohah/zntc/pull/3741), [#3742](https://github.com/ohah/zntc/pull/3742)), 파서의 문장·화살표 함수 판별에 첫 바이트 사전 필터를 넣었습니다([#3743](https://github.com/ohah/zntc/pull/3743), [#3744](https://github.com/ohah/zntc/pull/3744)). 경로 resolve 결과를 intern하는 변경([#3748](https://github.com/ohah/zntc/pull/3748))은 PR 제목 기준 측정에서 1320ms를 95ms로 줄였고, 이후 `PathRef` enum으로 수명 규칙을 컴파일러가 강제하게 하고 intern 풀을 16개 shard mutex로 나눴습니다([#3753](https://github.com/ohah/zntc/pull/3753), [#3754](https://github.com/ohah/zntc/pull/3754)). CSS는 외부 `@import` URL 보존([#3746](https://github.com/ohah/zntc/pull/3746))과 파일 맨 앞 `@charset`·bare `@layer` 선언 보존([#3752](https://github.com/ohah/zntc/pull/3752)), manualChunks 흡수 뒤 빈 entry chunk의 placeholder 치환 누락 수정([#3728](https://github.com/ohah/zntc/pull/3728))이 병합됐습니다.

suji는 오후부터 WebContentsView를 CEF Views 기반으로 옮겼습니다. 자식 창 프로브, 순서 변경 시 숨긴 자식 뷰 보존, 창 생명주기 이벤트 복원, 자식 뷰 제거 안정화를 거쳐 CEF Views를 WebContentsView의 기본 경로로 삼고 API를 배선했습니다. 이후 macOS·Linux·Windows에서 도는 WebContentsView E2E를 추가하고, CI용 CEF 프로세스 플래그와 런타임 에셋 패키징, 렌더러 IPC를 브라우저 메인 프레임으로 보내는 처리, 초기 내비게이션 재시도 등 수십 개 커밋으로 E2E를 안정화해 17-B 단계 완료를 문서에 적었습니다. 새벽에는 Windows·Linux safeStorage, 크로스 플랫폼 `powerMonitor` 유휴 시간과 이벤트, `powerSaveBlocker`, `crashReporter` 첫 구현, 앱 배지 카운트 API, 내장 Node 실행 CLI, Rust용 TypeScript 핸들러 헬퍼, `types` CLI E2E를 추가했습니다.

외부 저장소 warpdotdev/warp에는 한국어 IME 조합이 분할 커밋과 Backspace에서 유지되도록 하는 PR [#11624](https://github.com/warpdotdev/warp/pull/11624)를 열었으나 병합되지 않고 닫혔습니다. 블로그 저장소 ohah.github.io의 커밋 17개는 크론의 문서 점검 표시와 요약 갱신 커밋입니다.
