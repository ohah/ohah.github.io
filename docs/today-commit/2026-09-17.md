# 2026-09-17

## 요약 (AI 작성)

편집기가 언어 서버에 붙은 날입니다. LSP seam 1단 — transport·수명·신뢰 프롬프트·Full sync·publishDiagnostics 합치기·상태바 설치 안내(§8.2a) — 를 세우고, 2단 ①로 호버 박스를 열었습니다. 포인터가 멈추면 진단 문장과 언어 서버 hover 를 낱말 아래 상자로 보이고, 진단 줄은 VS Code 마커 호버 모양(평문 메시지 + 흐린 출처와 code)으로 맞췄습니다(§8.2b).

zntc v0.1.8 이 나갔습니다. zntc.config 의 alias 를 app 빌드까지 배선하고 배열형 alias 디렉토리를 해석하며, ESM-wrap 의 named-local `export default` 가 var/function 을 이중 선언하던 것, `export default` 전역 참조와 onResolve external 미반영(#4650 검증 파생), `--outfile`/`--outdir` 이 산출물 보류 게이트를 건너뛰던 것을 고쳤고, v0.1.7 post-publish bun.lock 과 stale TSC 스냅샷을 갱신했습니다. 릴리즈 직후 package.json "module" 필드 해석분에 Node CJS interop 을 적용하지 않도록 한 수정(#4661)이 이어졌습니다.
