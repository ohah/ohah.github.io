## 요약 (AI 작성)

maru 사이드바 그룹에는 그룹 고정과 별개인 그룹-로컬 pin(GL1부터 GL4)이 들어왔습니다. `local_pinned` 필드·직렬화와 `stablePartitionSubtree` 토대, `toggleLocalPin`과 멤버 우클릭·드래그 clamp, 📌 렌더, 공존·중첩 하드닝을 차례로 쌓았고, 새 워크스페이스가 그룹 멤버로 흡수되던 `createTab` 문제와 그룹 고정 해제 후 로컬 pin이 남던 문제도 고쳤습니다. 그룹 드래그는 Cmd를 누르면 중첩, 그냥 끌면 형제 위치 변경으로 나뉘고 고스트 피드백이 붙었습니다([#1196](https://github.com/ohah/maru/pull/1196)). 이어 §2.1 재설계([#1197](https://github.com/ohah/maru/pull/1197))로 `top_level` 저장값을 도입해 그룹을 만들 때 선택한 탭만 묶고, 고정 탭과 그룹의 순서를 드래그로 섞을 수 있게 했으며(SR1부터 SR5), 고정된 요소는 어디에도 흡수되지 않는 정책과 ungroup 시 고정 속성을 넘기지 않는 처리, 두 차례 코드 리뷰 지적을 반영했습니다.

라이트 배경에서 읽기 어려운 ANSI 팔레트 색을 색상은 유지한 채 어둡게 보정하는 `theme.min-contrast` 대비 하한(기본 WCAG 3.0)이 추가됐습니다([#1198](https://github.com/ohah/maru/pull/1198)). OSC 52 클립보드 쓰기는 고정 2KB 버퍼 때문에 한 문단 크기만 넘어도 통째로 버려지던 것을 동적 버퍼로 고쳤고([#1201](https://github.com/ohah/maru/pull/1201)), 최대 16MB 버퍼가 계속 남던 회수 갭([#1204](https://github.com/ohah/maru/pull/1204))과 상한 초과를 알림으로 보여 주는 처리([#1207](https://github.com/ohah/maru/pull/1207))가 뒤따랐습니다.

문서 쪽에서는 세션 컨트롤 플레인 설계 PR [#1103](https://github.com/ohah/maru/pull/1103)이 병합됐습니다. ndjson JSON-RPC 프로토콜과 capability fd 인가, 네이티브 뷰 예외와 Phase별 테스트 전략, WKWebView 합성·z-order·브리지 설계, CEF opt-in 플러그인 방향, `maru-app://` 스킴, 창 사이 surface 이동 전략이 여러 차례 적대적 검증을 거쳐 정리됐습니다. 이 설계는 곧바로 코드로 내려와 앱 전역 `SurfaceIdAllocator`(M0a, [#1199](https://github.com/ohah/maru/pull/1199)), `WindowMembershipSnapshot`(M0b, [#1200](https://github.com/ohah/maru/pull/1200)), 창과 surface 배치를 다루는 순수 모델 `WindowGraph`(M1, [#1202](https://github.com/ohah/maru/pull/1202)), 런타임 소유 골격 `LiveSurfaceRegistry`(M2a, 아직 미배선, [#1206](https://github.com/ohah/maru/pull/1206))가 병합됐습니다.

컨트롤 플레인 Track C는 JSON-RPC 2.0·ndjson 프레이밍 스키마(1a, [#1203](https://github.com/ohah/maru/pull/1203)), unix 소켓 bind·peer uid 확인·hello(1b, [#1208](https://github.com/ohah/maru/pull/1208)), Surface DTO와 read-only 디스패치(1c, [#1209](https://github.com/ohah/maru/pull/1209)), CLI `sessions list/get`(1d, [#1210](https://github.com/ohah/maru/pull/1210)), capability 인가 판정 코어(1e, [#1213](https://github.com/ohah/maru/pull/1213))까지 진행됐습니다. `WindowGraph` OOM 롤백과 프레이머 프레임 유실 수정([#1205](https://github.com/ohah/maru/pull/1205)), 검증 반영 하드닝([#1211](https://github.com/ohah/maru/pull/1211)), CLI 사용법 오류에 스택 트레이스 대신 안내를 내는 수정([#1212](https://github.com/ohah/maru/pull/1212)), 커버리지 보강 테스트 14건([#1214](https://github.com/ohah/maru/pull/1214))도 함께 병합됐습니다.
