## 요약 (AI 작성)

chrome-remote-devtools는 devtools-frontend 서브모듈의 MMKV 패널에서 행 삭제와 전체 삭제 툴바를 고치고, 사이드바 라벨을 인스턴스 ID만 보이게 하고 버전 바를 없앤 [#112](https://github.com/ohah/chrome-remote-devtools/pull/112)를 병합했습니다. `react-native-inspector`는 `setNumber`·`setBoolean`으로 저장한 MMKV 값이 문자열로 읽히지 않도록 숫자·불리언을 먼저 확인하게 고쳤습니다. React Native 클라이언트는 첫 연결 때 5초 간격으로 다섯 번까지 WebSocket을 재시도하고 실패하면 Connect 버튼을 보여 주게 했고([#113](https://github.com/ohah/chrome-remote-devtools/pull/113)), RN·Reactotron 탭 라벨에 deviceId를 표시하며 오프라인 탭은 스타일로만 구분하게 했습니다([#114](https://github.com/ohah/chrome-remote-devtools/pull/114)).

이어 서버에 Metro WebSocket 프록시와 `GET /metro-resource`를 두어 DevTools가 Metro를 거쳐 소스맵을 불러오게 하는 [#115](https://github.com/ohah/chrome-remote-devtools/pull/115)를 병합했습니다. 다른 출처의 DevTools iframe을 위한 CORS 헤더, loopback 주소만 허용하는 SSRF 대응 같은 리뷰 반영이 함께 들어갔고, 예제 앱은 Metro를 모노레포 구조에 맞게 설정하고 `@craby/devkit` 의존을 걷어 냈습니다.

`react-native-inspector` 패키지는 tsdown 빌드를 없애 TS 소스를 그대로 배포하는 형태로 바꾸고 README를 영문·한글판으로 나눴습니다. 직전 태그 이후 커밋을 유형별로 묶고 PR 링크를 붙이는 `release-notes.ts`와 릴리스 스크립트도 추가했습니다.

공개 커밋 21개, 해당일 생성 또는 병합된 PR 4개를 정리했습니다. PR 생성 4개·병합 4개는 같은 PR이 양쪽에 포함될 수 있습니다.
