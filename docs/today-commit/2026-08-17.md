# 2026-08-17

## 요약 (AI 작성)

국제화를 화면 전체로 넓힌 날입니다. config 설명문 86건(I3b), 컨텍스트 메뉴(I3a 슬라이스 6, 225/339), 세션 도크와 아카이브 상세·SCM 도크(I3c 65/76)를 키로 옮기고, 언어 드롭다운에 읽을 수 있는 이름을 띄웠습니다(I4b). 한국어 라벨에 알림 패널 폭이 박혀 있던 것을 고치고 시각 골든 캡처의 UI 언어를 고정해 골든이 환경에 흔들리지 않게 했으며, CI 가 확인하지 못하는 구간을 문서에 남겼습니다.

Windows 는 W7 을 향한 선행 정리로 중립 레이어가 컴파일되지 않던 두 자리를 고치고, 경로 레이아웃을 `%LOCALAPPDATA%\maru\` 로, 홈 폴백을 `%USERPROFILE%` 로 정했습니다(W8.5). Win32 창과 메시지 펌프(W7.1)는 아직 열린 PR 입니다. 링크 쪽은 공백이 든 경로를 문법이 아니라 존재로 가르고, 한글·日本·café 이름이 든 경로가 열리도록 CRT 코드페이지를 벗어났습니다.

모바일은 제스처의 뜻을 상태 하나가 들게 정리하고(G0\~G5) 터치의 목적지를 코어가 정하도록 옮겼으며(R0\~R3), 터미널에 상단 앱 바를 두어 돌아갈 길을 만들고 마우스 휠·트랙패드 스크롤과 좌우 안전 영역을 받았습니다. CI 는 캐시가 스스로를 무효화하며 열린 PR 을 전부 깨뜨리던 축을 없애고, Mermaid 게이트를 빼고 ReleaseFast session host 를 릴리스 전 수동 실행으로 옮겼습니다. cheolsu-proxy 는 tauri 계열 crate 와 npm 패키지를 최신으로 올리고 nightly cargo build-dir 레이아웃 변경으로 깨진 로컬 실행과 타입 체크 오류를 고쳤습니다.
