Windows 가 처음으로 실제 터미널 화면을 띄운 날이기도 합니다. Win32 창과 메시지 펌프(W7.1)를 머지한 뒤 D3D11 + DXGI 표시 경로(W7.2a — 판정식은 화면 픽셀이다), 셀 인스턴스 드로우(W7.2b), 중립 프레임 계약 충족(W7.2c-1)을 거쳐 실제 터미널 화면이 뜨고(W7.2c-2, W7.2 완료), DirectWrite 글리프 래스터라이저와 폰트 티어로 한글까지 나오고(W7.3), 키보드·IME 조합·클립보드 입력이 이어지고(W7.4a/b/c), 마우스로 고르고 굴리고 복사하며 IME 후보창과 ConPTY 번들까지 붙였습니다(W7.4d·W7.6). 앞서 W7 선행 정리와 경로 레이아웃 `%LOCALAPPDATA%\maru\`·`%USERPROFILE%` 폴백(W8.5)도 이날입니다.
