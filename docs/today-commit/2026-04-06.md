# 2026-04-06

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 구조 개편과 ES5 다운레벨링 마무리를 함께 진행했습니다. 파서와 트랜스포머가 따로 쓰던 old/new AST를 하나의 append-only AST로 합쳤고([#775](https://github.com/ohah/zntc/pull/775)), ES2015 매개변수 lowering을 별도 2차 패스로 옮겼으며([#777](https://github.com/ohah/zntc/pull/777)), 모든 태그의 데이터 레이아웃을 한 표에 등록하고 comptime으로 검증하는 노드 레이아웃 인프라를 들였습니다. 이 과정에서 object_property·export default·JSX fragment 등의 레이아웃 오분류([#791](https://github.com/ohah/zntc/pull/791), [#792](https://github.com/ohah/zntc/pull/792))와 클래스 접근자 변환의 dangling pointer 크래시([#793](https://github.com/ohah/zntc/pull/793))가 드러나 고쳐졌습니다.

ES5 변환에는 tagged template, `new.target`([#781](https://github.com/ohah/zntc/pull/781)), for 루프 let/const 클로저 캡처를 위한 `_loop` 함수 추출, 블록 단위 let/const 이름 격리와 그 구조 분해 지원([#797](https://github.com/ohah/zntc/pull/797), [#801](https://github.com/ohah/zntc/pull/801)), `using`/`await using`과 `--sourcemap-debug-ids`([#822](https://github.com/ohah/zntc/pull/822))가 추가됐습니다. let을 var로 바꿀 때 `= void 0` 초기화가 빠져 RN Fabric 레이아웃이 깨지던 문제([#818](https://github.com/ohah/zntc/pull/818)), 클래스 필드 화살표 함수의 `_this` 캡처([#819](https://github.com/ohah/zntc/pull/819)), 템플릿 보간식과 spread `new`의 괄호([#795](https://github.com/ohah/zntc/pull/795), [#796](https://github.com/ohah/zntc/pull/796)), `__rest`의 Symbol 프로퍼티 복사([#817](https://github.com/ohah/zntc/pull/817))도 고쳤습니다. kangax compat-table 러너를 CI에 붙여 ES5 다운레벨링 99%를 기록했고([#815](https://github.com/ohah/zntc/pull/815)), 트랜스파일러로는 통과할 수 없는 항목을 스킵해 ES5 타깃 237개를 모두 통과했으며, SWC와 실행 결과를 비교하는 테스트도 CI에 넣었습니다([#820](https://github.com/ohah/zntc/pull/820)).

번들러는 RN 실행 안정화를 이어 갔습니다. 런타임 헬퍼 `__copyProps`·`__toCommonJS`를 Rolldown과 같은 방식으로 바꿔 non-enumerable getter를 살리고([#805](https://github.com/ohah/zntc/pull/805)), RN 엔트리 모듈도 `__esm`으로 감싸 초기화 순서를 보장하며 IIFE 래핑을 없앴습니다([#806](https://github.com/ohah/zntc/pull/806), [#807](https://github.com/ohah/zntc/pull/807)). namespace 인라인 객체를 getter로 만들어 live binding을 보존하고([#810](https://github.com/ohah/zntc/pull/810)), ESM default re-export의 `__toESM` 누락([#813](https://github.com/ohah/zntc/pull/813)), 자기 자신을 require하는 경우와 `--shim-missing-exports`([#814](https://github.com/ohah/zntc/pull/814)), top-level await 모듈의 async 래핑([#780](https://github.com/ohah/zntc/pull/780)), 번들 소스맵의 sourcesContent와 preamble 오프셋([#804](https://github.com/ohah/zntc/pull/804))을 처리했습니다.

bungae는 prod 빌드에서 에셋 파일을 출력 디렉터리로 복사하고 플랫폼별 스케일을 거르며 WebP/BMP 치수도 읽게 했고, `global`을 덮어쓰지 않도록 `__BUNGAE_GLOBAL__`로 치환하고 폴리필용 폴백을 두었습니다. suji는 윈도우 기능의 설계 결정(메인 윈도우 개념 제거, 이벤트 콜백의 preventDefault 등)과 테스트 계획을 문서로 정리했습니다. ohah.github.io에는 ZTS 개발기 3-9·3-10과 3월 28일부터의 오늘의 커밋 페이지가 추가됐습니다.

공개 커밋 66개, 해당일 생성 또는 병합된 PR 38개를 정리했습니다. PR 생성 37개·병합 37개는 같은 PR이 양쪽에 포함될 수 있습니다.
