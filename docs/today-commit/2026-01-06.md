## 요약 (AI 작성)

chrome-remote-devtools는 React Native inspector의 Zustand 연동을 정리했습니다. React Native에는 `import.meta.env?.MODE`가 없어 devtools 미들웨어가 꺼지는 점을 고려해 `enabled: true`를 기본으로 두는 devtools 래퍼를 만들고, `/zustand`·`/zustand/middleware` 경로로 다시 내보내는 구조와 package.json exports를 추가했습니다. 사용자가 `enabled: false`를 명시하면 그대로 따르도록 고쳤고, 확장 상태와 `connect()` 호출을 추적하는 디버깅 도우미와 예제 화면의 상태 표시도 넣었습니다.

Redux DevTools Extension 폴리필은 외부 모듈을 쓰지 않는 순수 함수 정의만 남기고 package.json에서 내보내도록 했습니다. 릴리스 모드 Metro 번들링 오류를 일으키던 Node.js `path`·`fs` 사용을 `require.resolve()`로 바꿨고, 콘솔 로그를 지운 뒤 예제가 수동 `connect()` 대신 `ChromeRemoteDevToolsInspectorProvider`를 쓰도록 바꾼 [#60](https://github.com/ohah/chrome-remote-devtools/pull/60)을 병합했습니다. Provider는 `useRef`와 초기화 가드로 중복 설정을 막게 했습니다. 저녁에는 Redux DevTools Extension 전체 API 통합 PR [#61](https://github.com/ohah/chrome-remote-devtools/pull/61)을 열었습니다.

포크한 devtools-frontend에서는 Redux 확장 프런트엔드를 추가하는 [#7](https://github.com/ohah/devtools-frontend/pull/7)을 `develop` 브랜치에 병합하고, Redux 디버깅 작업 [#8](https://github.com/ohah/devtools-frontend/pull/8)을 main에 병합했습니다.

공개 커밋 16개, 해당일 생성 또는 병합된 PR 4개를 정리했습니다. PR 생성 4개·병합 3개는 같은 PR이 양쪽에 포함될 수 있습니다.
