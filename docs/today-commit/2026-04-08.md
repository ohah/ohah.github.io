> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 React Native HMR을 실제로 동작시키는 데 먼저 힘을 쏟았습니다. 모듈별 HMR 코드를 IIFE와 init 호출로 감싸고([#899](https://github.com/ohah/zntc/pull/899)), 캐시 블록 중복으로 생긴 use-after-free와 빈 변경 시 reload를 막았으며([#900](https://github.com/ohah/zntc/pull/900)), React Refresh 런타임을 호출 시점에 찾도록 바꾸고([#901](https://github.com/ohah/zntc/pull/901)) `--dev`에서 `__DEV__`를 true로 두었습니다([#902](https://github.com/ohah/zntc/pull/902)). HMR 평가는 `new Function`에 헬퍼를 인자로 넘기는 방식으로 바꿨고([#903](https://github.com/ohah/zntc/pull/903)), 초기 로드 때 모듈 ID가 비어 컴포넌트가 교체되지 않던 문제를 고쳤습니다([#905](https://github.com/ohah/zntc/pull/905)). react-refresh 초기화 순서는 폴리필 주입과 entry 전 early init을 시도했다가 RN 런타임과 충돌해 되돌리고([#907](https://github.com/ohah/zntc/pull/907)~[#911](https://github.com/ohah/zntc/pull/911)), 롤리팝 방식으로 InitializeCore를 prelude로 자동 주입하는 것으로 정리했습니다([#912](https://github.com/ohah/zntc/pull/912)). watch 재빌드 때 소스맵도 다시 쓰게 했습니다([#914](https://github.com/ohah/zntc/pull/914)).

성능 작업도 있었습니다. tree-shake·link·emit 최적화([#917](https://github.com/ohah/zntc/pull/917))와 resolve 캐시 계층([#918](https://github.com/ohah/zntc/pull/918))에 이어, import/binding 스캐너를 파서에 합쳐 AST 재순회를 없애고([#919](https://github.com/ohah/zntc/pull/919)), 문장별 심볼 정보를 시맨틱 분석 시점에 미리 만들어 PR 기준 tree-shake 81%, 전체 31% 개선을 기록했습니다([#920](https://github.com/ohah/zntc/pull/920)). ES5 변환은 for-of를 배열 인덱스 대신 `Symbol.iterator` 프로토콜로 다시 쓰고 static private field를 descriptor 객체로 바꿨으며([#931](https://github.com/ohah/zntc/pull/931)), private field 화살표 함수의 `_this` 누락([#932](https://github.com/ohah/zntc/pull/932))과 Flow `import typeof`·export type 때문에 CJS 모듈을 ESM으로 오판하던 문제([#930](https://github.com/ohah/zntc/pull/930))를 고쳤습니다. ANSI 색과 코드 프레임, 에러 코드, "Did you mean?" 제안을 갖춘 rustc 수준 진단 렌더러와 top-level await 타깃 검증([#933](https://github.com/ohah/zntc/pull/933))도 병합됐고, 에러 코드 120개를 등록하는 [#934](https://github.com/ohah/zntc/pull/934)는 이날 PR이 열렸습니다.

문서 쪽은 Playground 모바일 반응형과 번들러 비교 벤치마크([#915](https://github.com/ohah/zntc/pull/915)), 코드 블록·표 스타일([#916](https://github.com/ohah/zntc/pull/916)), 프로덕션 로드맵([#923](https://github.com/ohah/zntc/pull/923)), esbuild·Vite·webpack 마이그레이션 가이드와 플러그인 레시피([#925](https://github.com/ohah/zntc/pull/925))가 추가됐고, TOC 사이드바와 본문 폭 레이아웃을 여러 차례 손봤습니다.

bungae는 dev 서버의 watchFolders가 매번 full reload를 보내 HMR을 덮던 문제를 막았고([#43](https://github.com/ohah/bungae/pull/43)), ZTS HMR 클라이언트 파일을 빌드 산출물에 복사했습니다. InitializeCore 전달 방식은 `--polyfill`, `--inject`를 시도한 뒤 `--run-before-main`으로 되돌렸고, Chrome DevTools의 Components 탭을 위한 `enableStandaloneFuseboxShell`, 소스맵 CORS 헤더와 `/symbolicate` 엔드포인트를 붙였습니다.

공개 커밋 51개, 해당일 생성 또는 병합된 PR 37개를 정리했습니다. PR 생성 37개·병합 36개는 같은 PR이 양쪽에 포함될 수 있습니다.
