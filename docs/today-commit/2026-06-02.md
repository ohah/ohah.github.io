## 요약 (AI 작성)

zntc는 깊게 중첩된 입력에서 나던 스택 오버플로우를 정리했습니다. 깊은 좌결합 이항 체인을 트랜스포머·코드젠·시맨틱에서 반복 변환하고, flag-gated walker 4곳과 private-field mangler, 남은 재귀 AST walker 6개를 명시 스택 순회로 바꿨으며(이슈 #4123), 새 재귀 walker가 다시 들어오지 않도록 CI 감사를 추가했습니다. `keyof keyof …`처럼 접두 타입 연산자가 수만 번 겹친 입력도 반복 파싱으로 처리합니다. 번들러에서는 production 코드 분할 시 서로 다른 모듈의 같은 export 이름이 한 청크에서 뭉개지던 문제와 namespace re-export 충돌을 청크 간 전역 이름으로 풀었고(이슈 #4101), CJS default·named를 청크 경계 너머로 re-export할 때 interop 바인딩이 엉뚱한 청크에 놓이던 문제(이슈 #4120)도 고쳤습니다. 값 없는 `key` 속성이 dev·automatic 런타임 인자를 밀어내던 JSX 버그, NAPI `watch` `stop()`의 use-after-free도 수정했습니다.

성능과 벤치마크 작업도 많았습니다. Zig 0.16 이전 뒤 생긴 번들 시간 회귀를 fan-out 그래프 discovery를 batch-drain으로 묶어 줄였고, CLI `--watch-delay`와 NAPI `watchDelay` 옵션으로 하드코딩된 폴링 간격과 디바운스를 조절할 수 있게 했습니다. esbuild·rolldown과 비교하는 incremental rebuild·cold build 벤치를 추가해 측정 대상과 방식을 몇 차례 바로잡고 100·1000모듈 fixture를 넣었으며, GitHub Pages 벤치 페이지에 두 차트를 올렸습니다. 벤치마크 CI는 ubuntu 수치를 기준으로 삼고 esbuild·Bun 대비 비율로 회귀를 경고하는 게이트를 갖췄습니다. 실수로 추적된 빌드 캐시도 추적 해제했습니다. 밤에는 코드젠을 precedence 기반 괄호 재유도로 바꾸는 작업(이슈 #4042)의 1~4단계로 Level enum과 연산자 표, `emitExpr` 진입점, 의미 동등성 회귀 하네스, `emitNode`와의 통합이 들어왔습니다.

suji는 os-info·autostart 플러그인과 창 생명주기 SDK 정렬, store의 values·entries를 추가했고, `suji.config.ts`에 빌드 훅과 플랫폼별 빌드, `dev.env`를 넣었습니다.

공개 커밋 34개, 해당일 생성 또는 병합된 PR 0개를 정리했습니다. PR 생성 0개·병합 0개는 같은 PR이 양쪽에 포함될 수 있습니다.
