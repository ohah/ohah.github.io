## 요약 (AI 작성)

chrome-remote-devtools는 테스트와 CI를 Rust 서버 기준으로 옮기는 PR 다섯 개를 병합했습니다. Inspector에서 탭을 바꿀 때 DevTools UI가 제대로 그려지고 localStorage가 분리되는지 확인하는 E2E 테스트를 추가했고([#73](https://github.com/ohah/chrome-remote-devtools/pull/73)), 이 테스트가 실제로 돌고 결과 댓글이 항상 올라가도록 GitHub Actions 스크립트의 glob 중복 선언 오류와 중복 단계를 고쳤습니다. Playwright 설정과 E2E 테스트는 deprecated된 TypeScript 서버 대신 Rust 서버를 쓰게 했고([#74](https://github.com/ohah/chrome-remote-devtools/pull/74)), Rust 서버가 압축하지 않은 메시지를 원래 형식 그대로 넘기도록 고쳤으며, 통합 테스트와 격리 테스트는 8080 포트 충돌을 피하려고 다시 별도 단계로 나눴습니다.

React Native inspector는 `Runtime.getProperties` 도입 뒤 생긴 iOS 빌드 오류를 고쳤습니다([#76](https://github.com/ohah/chrome-remote-devtools/pull/76)). DevTools 프런트엔드는 환영 패널 UI를 다듬고 React Native 클라이언트에서는 일부 패널만 보이도록 조건부 표시를 넣었으며, Tauri 환경에서는 DevTools iframe이 보낸 외부 링크를 Tauri shell로 열게 했습니다([#77](https://github.com/ohah/chrome-remote-devtools/pull/77)). 이어 cargo-llvm-cov로 Rust 테스트 커버리지를 재서 PR 댓글로 올리는 워크플로를 병합했습니다([#78](https://github.com/ohah/chrome-remote-devtools/pull/78)).

Android용 Maestro 테스트 설정 [#75](https://github.com/ohah/chrome-remote-devtools/pull/75)와 Rust 서버 단위·통합 테스트 [#79](https://github.com/ohah/chrome-remote-devtools/pull/79)는 이날 PR이 열렸습니다.

공개 커밋 14개, 해당일 생성 또는 병합된 PR 7개를 정리했습니다. PR 생성 7개·병합 5개는 같은 PR이 양쪽에 포함될 수 있습니다.
