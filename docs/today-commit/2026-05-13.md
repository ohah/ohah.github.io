## 요약 (AI 작성)

zntc는 전날 열어 둔 RN 번들 디버깅 정리 PR [#3141](https://github.com/ohah/zntc/pull/3141)을 병합하며 커밋 40여 개를 한꺼번에 main에 반영했습니다. React Native 쪽은 Metro와 동작을 맞추는 수정이 중심이었습니다. Metro RN exports 조건과 main 필드 순서, node modules 경로 전달, prelude 전역 선택, guard 오류 의미를 Metro에 맞췄고, 혼합 CJS 모듈을 Metro처럼 감싸고 CJS default에 Babel interop을 쓰게 했습니다. ESM import는 default는 즉시 로드하고 함수 전용·값 import는 사용 지점으로 지연하며, 없는 named import에는 shim을 두도록 정리했습니다. transformer는 async 제어 흐름과 try 안의 return 다운레벨, 매개변수 프로퍼티 기본값, private auto-accessor 데코레이터, super 이전 화살표 함수의 this 캡처, private 헬퍼 이름 충돌을 고쳤고, 파서는 generic get/set 메서드와 TS 함수 타입 매개변수의 문맥 키워드 이름, Flow 반환 타입 문맥 복원, `match` 호출을 Flow match로 오인하던 문제를 바로잡았습니다. resolver는 `.` 지정자와 끝에 슬래시가 붙은 패키지 import를 처리하게 됐습니다.

이어 object_extensions 다운레벨의 단축 키 보존([#3144](https://github.com/ohah/zntc/pull/3144)), stage3 accessor 저장소 이름 격리([#3145](https://github.com/ohah/zntc/pull/3145)), tslib UMD와 헬퍼 이름이 겹치지 않게 하는 컴파일 타임 검사([#3146](https://github.com/ohah/zntc/pull/3146)), Metro 호환 `disableHierarchicalLookup` resolver 옵션([#3148](https://github.com/ohah/zntc/pull/3148))이 병합됐고, `buildRnBundleOverride` 옵션 객체화와 쓰지 않는 `Module.interop` 제거, finalize·linker 정책 주석 정정이 뒤따랐습니다. 밤에는 호출 단위 프로파일링용 `metadata`·`resolve`·`graph_io` 감사 카테고리([#3157](https://github.com/ohah/zntc/pull/3157))와 새 모듈 경로 등록 때 dir-fd 캐시를 미리 데우는 최적화([#3158](https://github.com/ohah/zntc/pull/3158))가 들어왔습니다. RN 런타임 회귀를 고치는 [#3156](https://github.com/ohah/zntc/pull/3156)은 이날 열렸습니다.

블로그 저장소 ohah.github.io의 커밋 12개는 크론의 맞춤법 점검 표시와 요약 갱신이 대부분이고, `development-2.mdx` 문장부호와 `development-5.mdx`의 표기 수정이 포함됐습니다.
