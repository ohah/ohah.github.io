# 2026-04-16

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 bungae 연동에서 나온 RN 문제를 주로 고쳤습니다. AssetRegistry 모듈의 require가 번들 내부 require로 바뀌지 않던 문제([#1420](https://github.com/ohah/zntc/pull/1420))와 에셋 코드의 JSON 이스케이프([#1421](https://github.com/ohah/zntc/pull/1421))를 고치고, 에셋 `httpServerLocation`을 projectRoot 기준 `/assets/` 상대 경로로 바꾸면서 해시를 MD5로 맞추고 단순 화살표 매개변수 파싱 회귀도 함께 정리했습니다([#1430](https://github.com/ohah/zntc/pull/1430)). 플러그인 onResolve가 `{ disabled: true }`를 돌려주면 빈 모듈로 처리해 Metro의 `empty` 해석에 대응하게 했고([#1424](https://github.com/ohah/zntc/pull/1424)), 래핑된 소스 모듈을 named re-export할 때 getter가 소스의 exports를 직접 참조하도록 고친 뒤 자기 자신으로 순환하는 re-export는 진단으로 거부합니다([#1426](https://github.com/ohah/zntc/pull/1426), [#1427](https://github.com/ohah/zntc/pull/1427)).

번들 모드는 에러 진단이 있으면 esbuild·rolldown처럼 종료 코드 1을 내게 됐고, 이로 드러난 통합 테스트 실패 8건에 stub fixture와 devDependency를 보탰으며([#1432](https://github.com/ohah/zntc/pull/1432)), browser 기본 main_fields와 깨진 symlink 처리로 CI를 복구했습니다([#1434](https://github.com/ohah/zntc/pull/1434)). 시맨틱 에러를 `TranspileResult`로 노출해 Playground와 NAPI에서도 보이게 하고([#1437](https://github.com/ohah/zntc/pull/1437)), 진단에 여러 위치 라벨과 재선언 시 이전 선언 위치 힌트를 더했습니다([#1438](https://github.com/ohah/zntc/pull/1438)). 에러 코드 문서 126개를 영문으로 옮겼고([#1429](https://github.com/ohah/zntc/pull/1429)), NAPI 바이너리를 자동 복사하는 postinstall과 package.json 필드명 상수화([#1433](https://github.com/ohah/zntc/pull/1433), [#1436](https://github.com/ohah/zntc/pull/1436))도 들어갔습니다.

bungae는 extraNodeModules·resolveRequest·blockList 같은 Metro resolver hook을 ZTS 옵션으로 연결했고([#58](https://github.com/ohah/bungae/pull/58)), 에셋 처리를 ZTS 코어에 맡기며 IPC dead code 약 800줄을 정리했습니다([#59](https://github.com/ohah/bungae/pull/59)). ZTS 서브모듈을 210커밋 앞으로 올리고([#60](https://github.com/ohah/bungae/pull/60)), resolveRequest 어댑터가 모든 모듈을 빈 export로 만들어 번들이 28KB가 되던 버그를 ZTS의 disabled 플래그로 고쳤으며([#61](https://github.com/ohah/bungae/pull/61)), AssetRegistry alias를 없앴습니다([#62](https://github.com/ohah/bungae/pull/62)). ohah.github.io에는 맞춤법 크론이 수정 없이 상태 파일만 갱신한 커밋 20개가 쌓였습니다.

공개 커밋 47개, 해당일 생성 또는 병합된 PR 19개를 정리했습니다. PR 생성 19개·병합 19개는 같은 PR이 양쪽에 포함될 수 있습니다.
