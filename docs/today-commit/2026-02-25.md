## 요약 (AI 작성)

react-wasm-table은 프로젝트 스펙 문서와 에이전트 안내를 추가하고 패키지 이름을 `@ohah/react-wasm-table`로 바꾼 [#1](https://github.com/ohah/react-wasm-table/pull/1)을 병합한 뒤, 기존 패키지를 adapter·renderer·WASM 로더를 갖춘 `grid` 패키지로 교체했습니다. Rust 쪽에 열 단위 저장소(`ColumnarStore`)와 레이아웃 버퍼, 정렬·필터 인덱스를 두고 JS 행 데이터를 WASM 저장소로 밀어 넣는 data ingestor를 붙였으며([#2](https://github.com/ohah/react-wasm-table/pull/2)), 초기 렌더·스크롤·정렬·셀 클릭을 시험하는 Playwright E2E와 CI를 추가했습니다([#3](https://github.com/ohah/react-wasm-table/pull/3)). CI에는 Rust와 TS 테스트 커버리지를 PR 댓글로 남기는 단계도 들어갔습니다.

데모는 사이드바와 라우터를 갖추고 FlexDirection·FlexGrow·FlexWrap·Gap·JustifyContent·AlignItems·Margin·Padding·Overflow·Position 레이아웃 페이지를 추가했습니다([#4](https://github.com/ohah/react-wasm-table/pull/4)). 이어 `1fr`·`minmax`·`repeat`을 쓰는 CSS grid 열 템플릿 지원([#5](https://github.com/ohah/react-wasm-table/pull/5)), 레이아웃 디버그 로그와 개발용 `engineRef`([#6](https://github.com/ohah/react-wasm-table/pull/6)), Taffy 레이아웃과 같은 CSS를 나란히 비교하는 데모([#7](https://github.com/ohah/react-wasm-table/pull/7))를 병합했습니다. 격자선 계산을 별도 모듈로 빼 테두리를 통일하고([#8](https://github.com/ohah/react-wasm-table/pull/8)), 레이아웃 버퍼 항목을 12칸에서 16칸으로 늘려 Taffy가 계산한 셀 테두리를 담게 했으며([#9](https://github.com/ohah/react-wasm-table/pull/9)), 캔버스 렌더러는 버퍼만 읽도록 바꿨습니다. flex-wrap에서 격자선 행 범위를 `rowHeight`로 계산하는 [#10](https://github.com/ohah/react-wasm-table/pull/10)은 이날 열렸습니다.

hwpjs는 테스트 컴파일 오류 수정([#24](https://github.com/ohah/hwpjs/pull/24))과 전날 열린 HTML 뷰어 단위 테스트 PR들([#25](https://github.com/ohah/hwpjs/pull/25)부터 [#30](https://github.com/ohah/hwpjs/pull/30)까지)을 병합하고, 텍스트·페이지·문단 모듈 테스트([#31](https://github.com/ohah/hwpjs/pull/31), [#32](https://github.com/ohah/hwpjs/pull/32), [#34](https://github.com/ohah/hwpjs/pull/34))를 추가로 병합했습니다. 이후 표 렌더링 상수, 공통 모듈, MIME 유형, `FileHeader` 버전 문자열, 도형·셀·위치·SVG·요약 정보·미리 보기 등 모듈별 테스트 PR이 #35부터 #66까지 이어서 열렸고, 그중 #33과 #40에서 #45까지는 병합 없이 닫혔습니다. ohah.github.io에는 2월 25일 요약이 올라갔습니다.
