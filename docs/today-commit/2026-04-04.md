> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 React Native 번들을 Hermes에서 실제로 돌리며 나온 런타임 오류를 계속 고쳤습니다. `__esm` 래퍼 안 클래스 선언 호이스팅([#694](https://github.com/ohah/zntc/pull/694)), Flow covariant·contravariant 클래스 프로퍼티 스트리핑([#695](https://github.com/ohah/zntc/pull/695)), IIFE 안 `Object.defineProperty`가 바깥 변수를 가리키던 문제([#696](https://github.com/ohah/zntc/pull/696))를 병합했고, Hermes의 for-in이 반복마다 새 바인딩을 만들지 않아 `__copyProps`가 마지막 키만 잡던 문제를 `forEach`로 우회했습니다([#698](https://github.com/ohah/zntc/pull/698)). 여러 ESM 모듈의 `_default` 합성 변수가 충돌해 ErrorUtils 등이 덮어써지던 버그([#704](https://github.com/ohah/zntc/pull/704)), dev 모드에서 폴리필·banner가 빠지던 버그([#703](https://github.com/ohah/zntc/pull/703)), CJS 엔트리 자동 호출·hoisted var 중복·re-export default 할당 누락([#708](https://github.com/ohah/zntc/pull/708)~[#710](https://github.com/ohah/zntc/pull/710))도 수정했습니다.

ES5 클래스 변환은 `React.Component` 같은 표현식 super class([#701](https://github.com/ohah/zntc/pull/701)), 같은 이름 클래스가 여러 모듈에 있을 때 `_super` 매개변수로 부모를 격리하는 처리([#719](https://github.com/ohah/zntc/pull/719)), getter/setter의 `configurable: true`([#721](https://github.com/ohah/zntc/pull/721)), `__callSuper`와 `Reflect.construct`로 Error·Map 같은 네이티브 클래스 상속 지원([#722](https://github.com/ohah/zntc/pull/722), [#723](https://github.com/ohah/zntc/pull/723)), this를 `_this`로 바꾸는 범위 수정([#729](https://github.com/ohah/zntc/pull/729), [#730](https://github.com/ohah/zntc/pull/730))으로 보강됐습니다. dev 번들링에서 `extra_data` 재할당 뒤 낡은 슬라이스를 읽어 죽던 문제([#724](https://github.com/ohah/zntc/pull/724))와 optional chaining 변환 결과의 괄호 누락([#733](https://github.com/ohah/zntc/pull/733))도 고쳤습니다.

번들러 rename이 코드 곳곳에 반영되지 않던 문제도 정리했습니다. ES5 구조 분해 키와 shorthand 확장([#700](https://github.com/ohah/zntc/pull/700), [#712](https://github.com/ohah/zntc/pull/712)), CJS export 바인딩([#717](https://github.com/ohah/zntc/pull/717)), JSX classic 모드의 React 변수와 태그 이름, JSX 멤버 식의 왼쪽 식별자([#726](https://github.com/ohah/zntc/pull/726), [#728](https://github.com/ohah/zntc/pull/728), [#731](https://github.com/ohah/zntc/pull/731))가 대상입니다. 이 밖에 export type만 있는 CJS 모듈을 ESM으로 오판하던 버그([#713](https://github.com/ohah/zntc/pull/713)), 로더 없는 에셋의 조용한 실패를 빌드 에러로 바꾸고 RN 프리셋 에셋 확장자를 Metro 기본값 전체로 넓힌 작업([#714](https://github.com/ohah/zntc/pull/714)), JSON named export([#715](https://github.com/ohah/zntc/pull/715)), 래핑 모듈의 `export *`([#716](https://github.com/ohah/zntc/pull/716)), default와 named를 함께 쓰는 import([#718](https://github.com/ohah/zntc/pull/718)), Flow component 파라미터의 props 구조 분해 변환([#727](https://github.com/ohah/zntc/pull/727))이 들어왔습니다.

bungae는 ZTS 서브프로세스 플러그인으로 에셋 파일을 `AssetRegistry.registerAsset()` 코드로 바꾸는 RN 에셋 플러그인을 추가해 이미지 치수 추출과 @2x/@3x 변형 탐색을 넣었고, AssetRegistry를 가상 모듈로 제공하며, dev 모드에서 `process.env.NODE_ENV`를 development로 define하도록 고쳤습니다.

공개 커밋 64개, 해당일 생성 또는 병합된 PR 34개를 정리했습니다. PR 생성 33개·병합 34개는 같은 PR이 양쪽에 포함될 수 있습니다.
