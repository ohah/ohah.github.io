## 요약 (AI 작성)

agent-devtools가 이날 시작됐습니다. Zig 프로젝트로 초기화한 뒤 WebSocket 프레임 코덱, CDP 메시지 파싱과 직렬화, Chrome 프로세스 실행과 CDP 연결, CLI 진입점을 차례로 만들고, 네트워크 이벤트 수집과 `network list`, Unix 소켓으로 통신하는 데몬을 붙여 CLI에서 데몬을 거쳐 Chrome까지 이어지는 구조를 완성했습니다. 오후에는 콘솔 로그 캡처와 `--port` 기반 CDP 탐색, 웹앱 API를 역으로 정리하고 응답 JSON 스키마를 추론하는 `analyze`, `Fetch.enable` 기반 네트워크 가로채기, 흐름 녹화·재생·비교를 넣었습니다. 이어 screenshot·eval·탐색 명령, 스냅샷과 `@ref`로 요소를 가리키는 클릭·입력·스크롤 같은 페이지 조작을 추가해 agent-browser와 같은 명령 체계를 갖췄고, agent-browser와의 비교 문서와 AI 에이전트용 `SKILL.md`를 썼습니다. 밤에는 멀티스레드 구조와 agent-browser와 같은 접근성 트리, 상주 모드, 실패 시 종료 코드 1, `--debug` 모드를 더했습니다. 이 저장소는 이날 PR 없이 커밋으로만 진행됐습니다.

zntc 번들러는 namespace import를 동적으로 접근할 때 변수 선언을 만들고 이름 충돌을 점진적으로 피하도록 했으며([#442](https://github.com/ohah/zntc/pull/442), [#444](https://github.com/ohah/zntc/pull/444)), import defer·source를 default import로 파싱하던 문제와 삼항 연산자 안 화살표 함수 본문의 `:` 오파싱을 고쳤습니다([#448](https://github.com/ohah/zntc/pull/448), [#449](https://github.com/ohah/zntc/pull/449)). scope hoisting의 내부 함수 shadowing과 리네임 충돌, namespace 객체에 `default` 키워드가 그대로 나오던 문제를 고쳤고([#451](https://github.com/ohah/zntc/pull/451), [#453](https://github.com/ohah/zntc/pull/453)부터 [#455](https://github.com/ohah/zntc/pull/455)까지), Rolldown 방식의 CJS·ESM 상호 운용([#456](https://github.com/ohah/zntc/pull/456))과 `export *`에서 default를 빼는 스펙 준수 수정([#457](https://github.com/ohah/zntc/pull/457))을 넣었습니다.

오후부터는 트리 셰이킹을 export 수준 DCE([#459](https://github.com/ohah/zntc/pull/459))와 rolldown 방식의 `StmtInfo` 기반 문장 단위 셰이킹([#460](https://github.com/ohah/zntc/pull/460))으로 고도화했습니다. `exports` 조건 해석 순서를 Node.js 스펙에 맞추고([#461](https://github.com/ohah/zntc/pull/461)), arktype에서 생긴 회귀를 계기로 `export *` 경유 모듈을 보호하는 필터([#464](https://github.com/ohah/zntc/pull/464))를 넣었으며, 심볼 기반 모듈 도달성으로 svelte 번들을 78KB에서 22KB로 줄였습니다([#465](https://github.com/ohah/zntc/pull/465)). 마지막으로 CLI `--conditions`, 상수 인라인, 코드 생성 단계 DCE([#466](https://github.com/ohah/zntc/pull/466))가 병합됐습니다.

블로그 저장소에서는 맞춤법 크론이 hwpjs 개발기와 기술 스택 글을 차례로 점검해 development-2 글의 띄어쓰기를 고치고 나머지는 확인 완료로 표시했으며, 3월 26일과 27일의 오늘의 커밋 요약이 작성됐습니다.
