# 2026-09-05

## 요약 (AI 작성)

hwpjs 가 Zig 로 다시 시작한 날입니다. Rust 코드를 `legacy/` 에 보관하고 Zig 워크스페이스를 초기화한 뒤, CFB 컨테이너의 모듈러 Zig 리더를 세우고 검색·검증 계약을 통일하고 리더 경계를 반복 감사로 굳혔으며, hwp5 의 DocInfo 속성과 버전별 ID 매핑, 바이너리·폰트 리소스를 개수 검증과 함께 파싱했습니다. `@ohah/pdf` 는 문서를 잇달아 열면 앞 문서의 마스크 그림이 나오던 것, /CalRGB 를 안 옮기고 16비트 그림을 안 그리던 것, 무색 무늬(/PaintType 2)의 색을 무시하던 것, 타일 무늬 간격과 그림 키울 때 뭉개기(pdf.js 맞대기로 잡았다), 내보낸 PDF 에 모듈 이름이 새던 것(/Subtype /core.Form)을 고치고, 문서 다시 쓰기(apply)를 떼어 12,525줄을 10,859줄로 줄였습니다. zerolist 에는 ZeroList 통합과 Android 배치 최적화 검증 PR 이 열렸습니다.

maru 는 소스 컨트롤 감시자를 «실제로 심고»(RW2c) 적대적 검증 13회에서 결함 열을 잡았습니다. 편집기는 위/아래로 커서 추가(`⌥⌘↑`/`⌥⌘↓`, §3.2b)와 열/블록 선택(`⌥드래그`·`⇧⌥드래그`·`⇧⌥⌘` 방향키, §3.2a)을 얻었고, 원격 파일 트리 설계를 열어 RF1 순수 층(목록 wire 와 (host, path) root 키)을 놓았습니다. claude 진행 상태줄을 화면에서 다시 읽게 했고(`esc to interrupt` 가 사라졌다), 종류를 모르는 running 에이전트를 claude 로 그리지 않습니다.

테스트 인프라를 크게 손봤습니다 — 시간을 태우던 픽스처 넷 189초→2.7초, imports.zig 판정자의 되풀이 파싱 100초→39초, release adapter 판정자 84개를 모드당 두 바이너리로 모아 CI 컴파일 45·129회→2·4회, 세션을 닫을 때 안 읽힌 master 출력을 버려 pty teardown 4,077ms→15ms.
