## 요약 (AI 작성)

zntc는 전날 시작한 CSS-in-JS 변환을 Babel 플러그인 수준으로 끌어올렸습니다. styled-components는 클래스 필드·IIFE·중첩 제어 흐름의 return 안 styled 호출까지 인식하고([#2238](https://github.com/ohah/zntc/pull/2238), [#2239](https://github.com/ohah/zntc/pull/2239), [#2241](https://github.com/ohah/zntc/pull/2241), [#2243](https://github.com/ohah/zntc/pull/2243), [#2244](https://github.com/ohah/zntc/pull/2244)), 사용자 `.withConfig`와의 병합([#2242](https://github.com/ohah/zntc/pull/2242)), `ssr`·`minify`·`fileName`·`pure`·`namespace`·`meaninglessFileNames`·`topLevelImportPaths` 등 babel-plugin과 같은 옵션([#2240](https://github.com/ohah/zntc/pull/2240), [#2245](https://github.com/ohah/zntc/pull/2245), [#2266](https://github.com/ohah/zntc/pull/2266), [#2267](https://github.com/ohah/zntc/pull/2267), [#2269](https://github.com/ohah/zntc/pull/2269), [#2274](https://github.com/ohah/zntc/pull/2274), [#2275](https://github.com/ohah/zntc/pull/2275)), named helper import 인식([#2263](https://github.com/ohah/zntc/pull/2263))을 갖췄습니다. JSX `css` prop은 intrinsic 태그, css 태그드 템플릿, 커스텀 컴포넌트, 객체 형태, styled import 자동 주입과 프로그램 수준 호이스팅, 바인딩 충돌 감지, 동적 값 전달까지 단계별로 구현했습니다([#2276](https://github.com/ohah/zntc/pull/2276), [#2280](https://github.com/ohah/zntc/pull/2280)~[#2284](https://github.com/ohah/zntc/pull/2284), [#2288](https://github.com/ohah/zntc/pull/2288), [#2289](https://github.com/ohah/zntc/pull/2289), [#2290](https://github.com/ohah/zntc/pull/2290)). glob 매처는 picomatch 호환으로 넓혔습니다([#2287](https://github.com/ohah/zntc/pull/2287)).

emotion도 1st-party 변환을 새로 들였습니다. autoLabel([#2247](https://github.com/ohah/zntc/pull/2247))에서 시작해 `@emotion/styled` default, keyframes, styled 체인, primitives·styled-base 소스, JSX inline css와 멤버 태그, Global·injectGlobal, ClassNames render prop, 객체·배열 css prop을 인식하고([#2248](https://github.com/ohah/zntc/pull/2248), [#2249](https://github.com/ohah/zntc/pull/2249), [#2251](https://github.com/ohah/zntc/pull/2251), [#2253](https://github.com/ohah/zntc/pull/2253), [#2254](https://github.com/ohah/zntc/pull/2254), [#2256](https://github.com/ohah/zntc/pull/2256), [#2257](https://github.com/ohah/zntc/pull/2257), [#2258](https://github.com/ohah/zntc/pull/2258), [#2270](https://github.com/ohah/zntc/pull/2270)), `sourceMap`, `labelFormat`, autoLabel 모드, `importMap` 옵션을 정식 스펙대로 지원합니다([#2260](https://github.com/ohah/zntc/pull/2260), [#2261](https://github.com/ohah/zntc/pull/2261), [#2262](https://github.com/ohah/zntc/pull/2262), [#2273](https://github.com/ohah/zntc/pull/2273)). emotion v10 격리 fixture와 E2E, styled·emotion 회귀 테스트 23개도 추가했습니다([#2255](https://github.com/ohah/zntc/pull/2255), [#2291](https://github.com/ohah/zntc/pull/2291)).

다운레벨링은 광역 감사에서 나온 엣지 케이스 의미 보존 수정을 다섯 차례 병합했고([#2259](https://github.com/ohah/zntc/pull/2259), [#2264](https://github.com/ohah/zntc/pull/2264), [#2271](https://github.com/ohah/zntc/pull/2271), [#2277](https://github.com/ohah/zntc/pull/2277), [#2285](https://github.com/ohah/zntc/pull/2285)), 클래스 멤버 분류를 수집·설정·방문 단계로 나누고 codegen 전에 남은 private 문법을 검사하는 invariant를 넣었습니다([#2298](https://github.com/ohah/zntc/pull/2298), [#2309](https://github.com/ohah/zntc/pull/2309)).
