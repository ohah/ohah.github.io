# 2026-06-07

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 전날 열린 [#96](https://github.com/ohah/maru/pull/96)으로 render frame이 glyph quad를 소유하게 한 뒤, glyph 래스터 upload frame([#97](https://github.com/ohah/maru/pull/97))과 Metal의 제품 atlas 업로드 검증·샘플링([#99](https://github.com/ohah/maru/pull/99), [#100](https://github.com/ohah/maru/pull/100))으로 넘어갔습니다. 이후 Metal smoke 판정을 atlas 샘플 기준으로 바꾸고([#102](https://github.com/ohah/maru/pull/102)), shaped glyph record 어댑터([#103](https://github.com/ohah/maru/pull/103))와 renderer state의 shaped run 수용([#105](https://github.com/ohah/maru/pull/105)), font identity 레지스트리([#108](https://github.com/ohah/maru/pull/108))를 거쳐 CoreText smoke가 renderer state와 font identity를 타게 했습니다. CoreText 쪽은 font 어댑터, shaper, rasterizer, probe 경계를 차례로 분리했고([#110](https://github.com/ohah/maru/pull/110), [#112](https://github.com/ohah/maru/pull/112), [#114](https://github.com/ohah/maru/pull/114), [#115](https://github.com/ohah/maru/pull/115)), 밤에는 CoreText glyph를 Metal smoke에서 그리고 DrawList를 CoreText로 shaping해 Metal로 렌더한 뒤 스크린샷 아티팩트를 남겼습니다([#116](https://github.com/ohah/maru/pull/116)부터 [#119](https://github.com/ohah/maru/pull/119)까지). 새벽에는 실제 PTY를 붙인 앱 호스트 smoke와 Metal smoke([#120](https://github.com/ohah/maru/pull/120), [#122](https://github.com/ohah/maru/pull/122)), 스크립트 입력, 키 바인딩 입력 resolver([#124](https://github.com/ohah/maru/pull/124))와 그 라우팅, AppKit `keyDown`을 PTY smoke로 잇는 브리지와 수동 입력 모드([#126](https://github.com/ohah/maru/pull/126), [#127](https://github.com/ohah/maru/pull/127))가 들어왔고, 리뷰에서 나온 C0 제어 문자 표와 키 인코딩 문제를 고쳤습니다([#128](https://github.com/ohah/maru/pull/128)).

suji는 single-instance 락에 이어 두 번째 인스턴스의 argv를 primary로 넘기는 `second-instance` 이벤트를 Unix 소켓([#95](https://github.com/ohah/suji/pull/95))과 Windows named pipe([#96](https://github.com/ohah/suji/pull/96))로 구현했습니다. `session.setProxy`([#99](https://github.com/ohah/suji/pull/99)), 강제 파괴용 `BrowserWindow.destroy()`([#101](https://github.com/ohah/suji/pull/101)), CEF 권한 핸들러를 쓰는 `setPermissionRequestHandler`([#104](https://github.com/ohah/suji/pull/104))를 추가했고, `setSSLConfig`와 `cookies.changed`는 CEF 제약으로 보류한다고 문서에 적었습니다. 창 속성은 크기·위치와 최소·최대 크기([#106](https://github.com/ohah/suji/pull/106)), resizable 등 capability 플래그([#107](https://github.com/ohah/suji/pull/107)), movable·focusable·kiosk 등 모드 토글([#108](https://github.com/ohah/suji/pull/108))을 세 묶음으로 채웠고, 메뉴는 MenuItem의 id·visible, accelerator, role 필드([#109](https://github.com/ohah/suji/pull/109), [#110](https://github.com/ohah/suji/pull/110), [#111](https://github.com/ohah/suji/pull/111))와 `Menu.getApplicationMenu`·`getMenuItemById`([#112](https://github.com/ohah/suji/pull/112))를 더했습니다. Electron 패리티 감사 문서를 다시 맞추고, 실수로 커밋된 검증 산출물도 지웠습니다. `Menu.sendActionToFirstResponder` [#114](https://github.com/ohah/suji/pull/114)는 이날 PR이 열렸습니다.

zntc는 16개 패키지를 0.1.2로 올리는 릴리스 커밋([#4195](https://github.com/ohah/zntc/pull/4195))을 넣고, npm 퍼블리시가 실패하지 않도록 `bun.lock`을 동기화했습니다([#4196](https://github.com/ohah/zntc/pull/4196)).

공개 커밋 71개, 해당일 생성 또는 병합된 PR 55개를 정리했습니다. PR 생성 54개·병합 54개는 같은 PR이 양쪽에 포함될 수 있습니다.
