## 요약 (AI 작성)

cheolsu-proxy는 OpenAPI 스펙으로 응답을 검증하는 Contract Testing 기능([#257](https://github.com/ohah/cheolsu-proxy/pull/257))을 병합했습니다. JSON·YAML 스펙을 불러와 경로·메서드·상태 코드·스키마를 대조하는 검증 로직과 데몬 서비스, Tauri IPC 커맨드, 프런트엔드 화면을 함께 넣었고, 리뷰를 반영해 `$ref`·required·요청 body 검증과 순환 참조 깊이 제한을 추가했습니다. 화면 이름은 한국어로 "API 검증"이 됐습니다. SSE broadcast 헬퍼와 Basic auth 파싱을 정리한 리팩터링([#258](https://github.com/ohah/cheolsu-proxy/pull/258)), 설정의 Network 섹션에서 프록시 포트를 바꾸는 기능과 CLI headless 모드 관련 내용·스크립트 제거([#259](https://github.com/ohah/cheolsu-proxy/pull/259))도 병합됐습니다. 오후에는 SSL Proxying으로 명시한 도메인이 이전 핸드셰이크 실패 기록 때문에 자동 바이패스되던 문제를 고치고 인터셉트 성공 시 실패 기록을 지우도록 했으며([#261](https://github.com/ohah/cheolsu-proxy/pull/261)), MapRemote 규칙이 가리키는 비표준 포트에도 SSL 인터셉트를 자동으로 적용하고 UI에 태그를 표시했습니다([#262](https://github.com/ohah/cheolsu-proxy/pull/262)).

hwpjs는 표 셀 안 `like_letters` 이미지가 absolute로 그려지던 문제 수정([#143](https://github.com/ohah/hwpjs/pull/143))을 병합한 뒤, KS X 6101:2024 HWPX(OWPML) 표준을 소제목 단위 문서로 정리한 `hwpx-spec` 스킬([#144](https://github.com/ohah/hwpjs/pull/144)), HWPX 테스트 픽스처([#145](https://github.com/ohah/hwpjs/pull/145)), HWP 5.0과 HWPX 필드 매핑 및 `hwp-model` 아키텍처 설계 문서([#146](https://github.com/ohah/hwpjs/pull/146))를 차례로 넣었습니다. 이어 HWP·HWPX 공통 문서 모델인 `hwp-model`과 HWPX ZIP·XML 파서 `hwpx-parser` 크레이트를 추가했습니다([#147](https://github.com/ohah/hwpjs/pull/147)). 파서는 헤더 정의, 구역·표·그림, 도형·필드·캡션, OLE·글맵시·비디오 등을 다루고 단계마다 테스트를 붙였습니다. 별도 `hwp-viewer` 크레이트 PR [#148](https://github.com/ohah/hwpjs/pull/148)은 병합 없이 닫혔고, 대신 `hwp-core` viewer를 리팩터링하는 쪽으로 전략을 바꾸면서 `linesegarray` 파싱을 넣었습니다([#149](https://github.com/ohah/hwpjs/pull/149)). 기존 문서 모델을 새 Document로 옮기는 변환 모듈 [#150](https://github.com/ohah/hwpjs/pull/150)은 이날 PR이 열렸습니다.

react-native-mcp는 MCP 지침에 토큰을 아끼는 도구 선택 가이드([#112](https://github.com/ohah/react-native-mcp/pull/112))와 iOS 화면 방향을 먼저 확인하라는 안내([#113](https://github.com/ohah/react-native-mcp/pull/113))를 추가하고, `react-native-mcp-server`를 0.1.0-rc.13으로 올렸습니다. rc 버전을 npm rc 태그로 배포하도록 한 publish 워크플로 수정은 바로 되돌렸습니다. bungae는 로컬에서 Rust 수준 수정을 하기 위해 rolldown 포크를 서브모듈로 추가하고 모든 워크플로에 빌드 단계를 넣었으며([#34](https://github.com/ohah/bungae/pull/34)), CI에서는 소스맵 생성 중 디버그 빌드 단언이 패닉을 내 릴리스 빌드를 쓰도록 했습니다. `babelPlugins`를 `babel.presets`·`babel.plugins`로 바꾸는 [#35](https://github.com/ohah/bungae/pull/35)는 열린 상태입니다. 블로그 저장소(ohah.github.io)에는 맞춤법 점검 크론이 "모든 대상 파일 확인 완료" 상태만 갱신한 커밋이 30분 간격으로 쌓였고, 3월 16일 오늘의 커밋 요약이 갱신됐습니다.
