# 2026-04-20

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 minify 최적화를 본격적으로 키웠습니다. 함수·블록 안에서 쓰이지 않는 선언을 지우는 dead store 제거([#1645](https://github.com/ohah/zntc/pull/1645))와 결과값이 쓰이지 않는 식을 줄이는 unused expression simplify를 oxc 방식으로 이식했고([#1649](https://github.com/ohah/zntc/pull/1649), [#1662](https://github.com/ohah/zntc/pull/1662), [#1663](https://github.com/ohah/zntc/pull/1663)), 패스를 고정점까지 반복하는 루프([#1651](https://github.com/ohah/zntc/pull/1651)), 템플릿 리터럴 부분 rewrite([#1664](https://github.com/ohah/zntc/pull/1664)), scope hoisting된 최상위 const/let의 var 다운그레이드([#1667](https://github.com/ohah/zntc/pull/1667)), 클래스별 `#private` 이름 축약([#1668](https://github.com/ohah/zntc/pull/1668))을 더했습니다. 그 과정에서 for 루프 바인딩을 지우던 회귀([#1647](https://github.com/ohah/zntc/pull/1647)), `"use client"` 같은 directive가 쓰이지 않는 식으로 지워지던 회귀를 directive 노드 파싱으로 막은 수정([#1653](https://github.com/ohah/zntc/pull/1653)), 버려진 선언 노드를 dead store 대상으로 훑던 문제([#1677](https://github.com/ohah/zntc/pull/1677))를 고쳤습니다.

시맨틱 분석은 참조 종류를 bitset 플래그로 바꾸고 복합 대입·증감을 읽기와 쓰기로 정확히 나눴으며([#1641](https://github.com/ohah/zntc/pull/1641)~[#1643](https://github.com/ohah/zntc/pull/1643)), 스코프 단위 선언 참조와 문장 인덱스를 들였습니다([#1670](https://github.com/ohah/zntc/pull/1670), [#1671](https://github.com/ohah/zntc/pull/1671)). private 메서드·accessor의 읽기/쓰기 오진 제거([#1655](https://github.com/ohah/zntc/pull/1655)), 객체 리터럴의 private 메서드 early error([#1657](https://github.com/ohah/zntc/pull/1657)), async 화살표 함수 안 중첩 화살표 매개변수의 `await` 검사([#1659](https://github.com/ohah/zntc/pull/1659)), 블록·switch·모듈의 var와 lexical 재선언 검출([#1661](https://github.com/ohah/zntc/pull/1661))로 스펙 준수도 보강했습니다. 블록 안 let/const/class와 화살표 함수 본문 안 var/function 호이스팅, Flow component 래퍼의 ref 해석도 고쳤습니다([#1679](https://github.com/ohah/zntc/pull/1679), [#1680](https://github.com/ohah/zntc/pull/1680), [#1681](https://github.com/ohah/zntc/pull/1681)).

번들러는 transformer 재설계의 첫 단계로 emit 결과를 `CompiledModule` 값 타입으로 분리했고([#1673](https://github.com/ohah/zntc/pull/1673)), 그 결과를 캐시하는 [#1674](https://github.com/ohah/zntc/pull/1674)와 HMR alias table 소유권 수정 [#1682](https://github.com/ohah/zntc/pull/1682)는 이날 PR이 열렸습니다. bungae 실측에서 나온 HMR `changed_modules` use-after-free([#1675](https://github.com/ohah/zntc/pull/1675))와 bundle+ES5에서 `var _this`를 깨뜨리던 고아 함수 선언([#1676](https://github.com/ohah/zntc/pull/1676))도 고쳤습니다.

ohah.github.io에는 4월 7일부터 20일까지의 오늘의 커밋 요약과 `_meta.json` 날짜 정렬 수정이 올라갔고, 나머지는 맞춤법 크론의 상태 갱신 커밋입니다.
