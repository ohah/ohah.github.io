## 요약 (AI 작성)

react-wasm-table은 flex-wrap에서 격자선 행 범위를 `rowHeight`로 계산하는 [#10](https://github.com/ohah/react-wasm-table/pull/10)과 헤더를 고정하지 않고 본문과 함께 스크롤되게 한 [#11](https://github.com/ohah/react-wasm-table/pull/11)을 병합했습니다. 이어 `createColumnHelper`·`useGridTable`·다단 헤더 그룹 같은 TanStack Table 호환 API를 도입해 Grid 컴포넌트와 데모를 그 API로 옮겼고([#12](https://github.com/ohah/react-wasm-table/pull/12)), Taffy 기반 레이아웃 엔진과 열 단위 저장소 테스트, 세로 ScrollBar 컴포넌트를 더한 [#13](https://github.com/ohah/react-wasm-table/pull/13)을 병합했습니다. 100만 행 스트레스 테스트와 FPS 표시, 컨테이너 크기에 맞춘 반응형 그리드 데모도 추가했습니다([#14](https://github.com/ohah/react-wasm-table/pull/14)).

정리 작업으로 공통 타입을 `types.rs`로 모으고 중복된 저장소 모듈을 지웠으며([#15](https://github.com/ohah/react-wasm-table/pull/15)), 쓰지 않던 필터링 모듈과 `RowStyle` 컴포넌트를 없앴습니다([#16](https://github.com/ohah/react-wasm-table/pull/16)). 기능으로는 `SelectionManager`로 범위 선택과 드래그, 가장자리 자동 스크롤, 터치, 키보드 이동, TSV 복사를 넣고 캔버스에 선택 영역을 그렸으며([#17](https://github.com/ohah/react-wasm-table/pull/17)), 그리드 단위 `enableSelection`과 열 단위 선택 가능 여부 설정을 추가했습니다([#18](https://github.com/ohah/react-wasm-table/pull/18)). 헤드리스 구조로 가는 기능 로드맵 문서([#19](https://github.com/ohah/react-wasm-table/pull/19))를 쓴 뒤, WASM 초기화와 이벤트 처리 등을 훅으로 빼 `Grid.tsx`를 약 965줄에서 317줄로 줄이는 1단계 리팩터링을 병합했습니다([#20](https://github.com/ohah/react-wasm-table/pull/20)).

hwpjs는 전날 열린 모듈별 테스트 PR([#35](https://github.com/ohah/hwpjs/pull/35)부터 [#66](https://github.com/ohah/hwpjs/pull/66)까지 중 닫힌 것을 뺀 나머지)을 병합했고, Markdown 뷰어의 `ctrl_header` 하위 모듈과 utils·renderer 모듈 기본 구조 테스트([#67](https://github.com/ohah/hwpjs/pull/67)부터 [#77](https://github.com/ohah/hwpjs/pull/77)까지)를 새로 열어 같은 날 병합했습니다. 공통 모듈 테스트에서는 u16 리터럴 overflow도 고쳤고, 테스트 PR마다 `MEMORY.md`에 기록을 남겼습니다.

react-native-mcp는 E2E `compareScreenshot` 스텝에 `saveDiff`·`saveCurrent` 옵션을 넣고 `visual_compare` 도구 설명을 비주얼 리그레션 용도로 명확히 했으며([#105](https://github.com/ohah/react-native-mcp/pull/105)), 서버 버전을 0.1.0-rc.9로 올렸습니다([#106](https://github.com/ohah/react-native-mcp/pull/106)). ohah.github.io에는 2월 26일 요약과 크론 완료 표시가 올라갔습니다.
