## 요약 (AI 작성)

maru는 탭과 분할 화면의 마감 작업을 이어 갔습니다. 분할 구분선 그리기와 드래그 크기 조절([#343](https://github.com/ohah/maru/pull/343), [#344](https://github.com/ohah/maru/pull/344)), 영역별 마우스 커서([#345](https://github.com/ohah/maru/pull/345)), 사이드바 폭 조절과 새 워크스페이스 "+" 버튼([#346](https://github.com/ohah/maru/pull/346), [#347](https://github.com/ohah/maru/pull/347)), Term 탭을 pane 가장자리로 끌어 분할을 만드는 재배치와 drop 영역 강조, 떠다니는 탭 미리보기([#348](https://github.com/ohah/maru/pull/348)부터 [#350](https://github.com/ohah/maru/pull/350)까지)가 들어왔습니다. 긴 제목 말줄임, 활성 탭 제목 강조와 실제 bold 글꼴(SGR bold 포함, [#357](https://github.com/ohah/maru/pull/357)), 사이드바 글자색 테마, Cmd+1..9 워크스페이스 전환([#354](https://github.com/ohah/maru/pull/354)), 분할에서 커서 아래 pane으로 가는 휠 입력([#355](https://github.com/ohah/maru/pull/355))도 더했습니다. 키 설정은 기본 바인딩 해제([#360](https://github.com/ohah/maru/pull/360))와 셸 바이트를 보내는 매크로([#361](https://github.com/ohah/maru/pull/361)), `global:` 접두사와 Carbon 전역 단축키 등록([#363](https://github.com/ohah/maru/pull/363), [#364](https://github.com/ohah/maru/pull/364))으로 넓어졌습니다.

이어서 quick terminal을 만들었습니다. 세션 상태를 `TerminalSurface`로 추출한 뒤 오버레이 패널에 두 번째 세션을 띄우고([#365](https://github.com/ohah/maru/pull/365), [#366](https://github.com/ohah/maru/pull/366)), 슬라이드 애니메이션과 포커스를 잃으면 숨기기([#368](https://github.com/ohah/maru/pull/368)), 높이·화면·위치·가운데 배치와 페이드·가로 비율 설정, chrome full·minimal 선택, minimal 탭과 탭 표시 점, 활성 pane 테두리([#369](https://github.com/ohah/maru/pull/369)부터 [#379](https://github.com/ohah/maru/pull/379)까지)를 붙였습니다. 창을 토글로 숨기면 앱이 종료되던 버그([#367](https://github.com/ohah/maru/pull/367)), 주 창 이벤트가 엉뚱한 surface로 가던 문제([#372](https://github.com/ohah/maru/pull/372)), 연속 토글 경합([#381](https://github.com/ohah/maru/pull/381))도 고쳤습니다. 후반에는 Action 카탈로그 ABI와 `run_action`([#384](https://github.com/ohah/maru/pull/384)), NSMenu 메뉴바([#386](https://github.com/ohah/maru/pull/386)), Zig 오버레이로 그리는 커맨드 팔레트([#388](https://github.com/ohah/maru/pull/388), [#389](https://github.com/ohah/maru/pull/389)), 스크롤백 찾기 ⌘F([#391](https://github.com/ohah/maru/pull/391)), ⌘+ / ⌘- / ⌘0 런타임 폰트 크기([#392](https://github.com/ohah/maru/pull/392)), 스크롤로 들어오는 빈 줄을 현재 배경색으로 채우는 BCE([#394](https://github.com/ohah/maru/pull/394))가 들어왔고, UI 렌더 전략과 멀티 윈도우 설계안 등 계획 문서도 정리했습니다.

iris 저장소가 이날 생겼습니다. 초기 개발 환경과 CI·라벨 정책([#1](https://github.com/ohah/iris/pull/1), [#2](https://github.com/ohah/iris/pull/2)), React Native 기준 앱과 로컬 벤치마크 하네스, Hermes 기준선 산출물 추출, 빈 TurboModule 경로, RN·Android release 기준선 검증과 자동화([#3](https://github.com/ohah/iris/pull/3)부터 [#9](https://github.com/ohah/iris/pull/9)까지)를 갖췄고, Android에서 엔진별 비교 probe와 variant를 나눴습니다. 이어 Android Iris 런타임 팩토리 계약, 엔진 AAR 골격, JSI 런타임 표면과 초기화([#13](https://github.com/ohah/iris/pull/13)부터 [#16](https://github.com/ohah/iris/pull/16)까지)를 만들고, Rust HBC(Hermes 바이트코드) 파서를 연결해([#18](https://github.com/ohah/iris/pull/18), [#19](https://github.com/ohah/iris/pull/19)) 헤더, 섹션 레이아웃, 함수 메타데이터, 명령어 스트림과 피연산자, 예외 핸들러, 리터럴 버퍼, 디버그 정보, 문자열 종류 식별자까지 검증 항목을 하나씩 늘렸습니다([#37](https://github.com/ohah/iris/pull/37)까지 모두 병합).

zntc에서는 ES2025 정규식 inline modifier를 지원하지 않는 타깃에 진단을 내는 [#4264](https://github.com/ohah/zntc/pull/4264)가 이날 PR로 열렸습니다. 블로그 저장소에는 오늘의 커밋 요약과 크론이 만든 맞춤법·문구 수정 커밋이 올라갔습니다.
