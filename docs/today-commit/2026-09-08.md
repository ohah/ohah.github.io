# 2026-09-08

## 요약 (AI 작성)

hwpjs 가 ICC 역함수와 JPEG 헤더에 들어간 날입니다(68커밋). ICC 는 power level roots 를 활성 구간에서 찾고, matrix TRC 를 정확·근사 두 경로로 forward 평가하고, clipped parametric branch jump 를 분류하고, full-width rational XYZ 행렬을 뒤집고, preimage 경계와 도달 가능성을 정확히 보존하고, 정규화된 root 를 정확히 비교하고, 넓은 gamma 역을 기호로 보존합니다. JPEG 은 frame·scan 헤더와 quantization·Huffman 테이블을 파싱합니다. `@ohah/pdf` 는 표준 글꼴을 밖에서 받아 실을 수 있게 했습니다.

maru 활동 뷰는 종류를 눌러 고르고(AV4) Enter 가 본문까지 넓힙니다(BS1 — 라벨은 세션의 2.9% 다). 펼쳐도 명령이 안 보이던 것은 계약이 갚기로 한 대가를 갚는 것으로 고쳤고, AV5 적대적 검증 3회를 기록했습니다 — 증상이 같아도 고칠 곳은 둘일 수 있다. 편집기는 비교 뷰의 열을 ⌃⇧Tab 으로 넘기고 가로도 caret 을 따라가며(두 뷰 공통), 접힘이 가로 위치·상한을 안 버리고, 상태바가 비교 뷰에도 L/R 줄:열을 냅니다. 모바일은 OS 접근성 글자 크기를 따라가고(M13c) 새 출력을 소리로 알리고(M9a) 선택을 «줄 단위 동작» 으로 만들고(M9c) 저전력 모드면 그리는 주기를 반으로 합니다(M14a). PR 체크리스트에는 합류 규율이 들어갔습니다 — 각자는 초록인데 합치면 깨지는 것. file-tree 워커를 거두고 나가지 않아 CI 가 간헐적으로 누수하던 원인도 잡았습니다.
