# 2026-08-20

## 요약 (AI 작성)

에이전트 훅 축을 열고 Windows 에 파일 트리와 소스 컨트롤을 띄운 날입니다. 훅을 상태·알림·턴의 단일 소스로 두는 계약을 먼저 적고, 훅 이벤트를 나르는 채널의 순수 코어(AH1)를 세워 적대적 검증으로 굳힌 뒤, claude 의 settings.json 과 codex 에 훅을 설치하고 신뢰를 기록했습니다(AH2a·b). 게이트는 기본 꺼짐이고, 끄면 설치한 것을 지웁니다. 컨트롤 플레인은 원격 축을 SSH 채널 하나 더로 정하고(S10a), 같은 연결에 컨트롤 채널을 열고(S10b-1), ABI·펌프가 그것을 알게 하고(S10b-2), 폰이 닿을 중계 `maru control --stdio` 를 냈습니다(S10c).

Windows 는 파일 트리가 화면에 뜨고 선택 띠까지 그려졌으며(W8.2⒝·⒞), git 을 부를 캡처 러너를 CreateProcessW 와 익명 파이프로 세워 환경 상속·stdin NUL 같은 함정을 적대적으로 검증한 뒤 git 백엔드와 쓰기 경로가 Windows 에서 돌고 소스 컨트롤이 화면에 떴습니다(W8.4). 기본으로 쓰이는 PowerShell 5.1 을 실제로 띄워 봤고, 그리기 스모크는 27초에서 4초로 줄였습니다. 네이티브 편집기에서 텍스트를 고르고 복사하는 것(§4.1g)과 session-host 의 CR5 다중 runtime ledger·ordered reconnect 도 이날입니다.

작은 것들도 많았습니다 — 안드로이드 ELF 16KB 페이지 정렬, 조합 중인 한글을 편집 칸에 보이게 하고 확정을 잃지 않는 것, 빈 칸을 공백으로 셰이핑해 줄 뒤쪽 합자가 죽는 것을 막고 4글자 합자의 왼쪽 오버항을 3칸까지 허용한 것, 탭 개수를 목록 모델 없이 세어 매 프레임 378µs 를 12.8µs 로 줄인 것, 언어를 박은 문자열에 게이트를 세운 것(컴파일러가 절반만 막는다), 누른 적 없는 버튼의 뗌이 링크 Cmd+클릭을 두 번 열던 것.
