# 2026-08-28

## 요약 (AI 작성)

편집기에 구문 트리 1층이 선 날입니다 — tree-sitter 배선과 판정자(N4 §5.3). session-host 는 checkpoint 를 둘러싼 결정이 오갔습니다: 복원 중·종료 중에는 쓰지 않고(R7-0), 실패 시 Quit 을 취소하며, 두 번째 checkpoint coordinator 는 되돌렸습니다(P4 C3-1). poison 사유가 갈리면 앱을 죽이던 자리, 알림을 물어보는 값이 공짜가 아니게 됐는데 호출부가 그대로였던 것, 원격 출력에 AppKit 을 깨우는 것, foreground metadata generation 보존을 고쳤고, P4 게이트 현황을 코드·실측으로 다시 적었습니다. 상태바는 영속성이 깨진 동안 그 사실을 화면에 남깁니다.

Windows 는 에이전트 도크 검색(W8.15 의 나머지)이 들어갔고, 계획서가 "무엇이 남았나" 의 단일 출처이기를 그만둔 것을 되돌렸습니다. ssh 테스트가 CPU 를 태우는 고아를 남기던 것도 잡았습니다.
