## 요약 (AI 작성)

react-native-mcp는 iOS는 `simctl`, Android는 adb로 딥링크를 여는 `open_deeplink` 도구와 앱 생명주기 리소스·가이드를 추가하고, E2E 스모크 테스트와 iOS·Android CI 워크플로를 도입했습니다([#31](https://github.com/ohah/react-native-mcp/pull/31)). CI에서는 Release 빌드에서도 환경 변수로 MCP 연결을 허용하고, Android용 debug keystore 생성과 Hermes 컴파일러 경로, 앱 연결 대기 시간을 보강하는 수정이 이어졌습니다.

이어 YAML을 Zod로 검증해 setup·steps·teardown을 실행하고 console·junit 형식으로 결과를 내는 `@ohah/react-native-mcp-test` 패키지와 데모 스펙을 추가했습니다. 클라이언트에는 `assertNoText`·`assertCount`·`waitFor` 같은 검증과 앱 생명주기 제어, `bundleId`로 앱을 자동 실행하는 옵션이 들어갔고, 서버에는 `scroll_until_visible` 도구가 추가됐습니다. Rspress 2로 한국어·영어 사용자 문서 사이트를 만들고 GitHub Actions 배포를 붙였으며, 실제로 없는 API 안내를 걷어 내고 README를 정리했습니다([#33](https://github.com/ohah/react-native-mcp/pull/33)). E2E 셀렉터·스와이프 개선과 러너의 중복 실행 방지를 담은 [#32](https://github.com/ohah/react-native-mcp/pull/32)는 이날 열렸습니다.

ohah.github.io는 CRD development-1에 저장소 트리와 CDP 흐름도를 넣고, development-2를 배민 백로그(로컬·세션 스토리지, 쿠키)와 IndexedDB 저장·재전송 내용으로 전면 고쳤으며, 크론 작성 예정 항목에 날짜를 붙였습니다. hwpjs는 rustfmt를 적용했습니다.

공개 커밋 31개, 해당일 생성 또는 병합된 PR 3개를 정리했습니다. PR 생성 3개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
