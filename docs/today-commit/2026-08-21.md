# 2026-08-21

## 요약 (AI 작성)

훅 모드가 실제로 화면을 채우기 시작한 날입니다. 배지·대화·알림을 훅이 채우고(AH3+AH4+AH5), 배지가 거짓말하던 열넷을 자동 검증 아홉·실사용 다섯으로 닫고, Notification 으로 「입력 대기」를 판정하며 AH6 비용을 다시 쟀습니다. 폰은 컨트롤 wire 를 프레임으로 읽고(S10d-1) 세션 목록을 받아 그리고(S10d-2) 두 host 가 컨트롤 채널을 실제로 굴립니다(S10d-3). S10e 가 막힌 자리와 폰↔실서버 실측도 문서에 남겼습니다.

편집기는 비교 뷰에서도 코드를 고르고 복사하며, 복사가 CRLF 를 LF 로 뭉개던 것을 줄 끝을 뗄 때 함께 굳히는 것으로 고쳤습니다. 상태바에 커서 위치가 서고, 비교 뷰가 잡은 단어를 잃던 결함도 닫혔습니다(§2.2·§4.1g). 터미널은 수식자 붙은 특수 키를 xterm legacy 형식으로 보내 Ctrl+화살표 단어 이동이 되게 했고, 베이스는 terminfo 가 정답이라는 실측을 적었습니다.

Windows 는 번들 폰트를 열고 컬렉션에 담아(다리가 이름으로만 찾기 때문) macOS 와 같은 폰트로 그리고, 앱 수준 config(테마 색·팔레트·스크롤백·커서 모양)를 코어에 걸고, 창을 닫을 때까지 도는 터미널과 드래그 선택을 얻었습니다. 셰이핑 다리의 실측과 결정은 §2m.12·13 에 적었고, 적대적 검증이 §2e 가 이미 정한 것을 결함으로 적은 것을 바로잡았습니다. session-host 는 CR5 two-window abandon 과 CR6 recovery projection owner 를 붙였고, i18n 은 확인 버튼 기본 라벨이 comptime 에 한국어로 얼어붙어 있던 것을 고쳤습니다.
