## 요약 (AI 작성)

hwpjs는 HTML 뷰어의 표 렌더링을 이어서 고쳤습니다. 표 셀 안에 문단 텍스트와 이미지를 그리기 시작했고, 행 높이는 셀 높이 속성을 우선 쓰되 셀 안 도형 컴포넌트(선·사각형·타원·그림 등) 높이 중 가장 큰 값을 같은 행 전체에 적용하도록 바꿨습니다. 셀 왼쪽 위치를 같은 행 셀로 계산하고, 모든 행에서 열 경계를 모아 세로 테두리를 그리며, 오른쪽 끝 테두리가 빠지지 않게 했습니다. 셀 세로 정렬에 따른 텍스트 위치 계산, 문서 전체에서 공유하는 채우기 패턴 번호, 도형 안 문단의 이미지 재귀 수집, HTML 출력 디렉터리 기준 상대 이미지 경로와 `crop_rectangle`을 쓰는 이미지 높이 계산도 들어갔습니다. 튜플 대신 `TableInfo`·`ImageInfo` 구조체를 쓰도록 정리하고 쓰지 않는 모델 파일을 지웠습니다.

oxc 문서 사이트에는 VS Code 확장 디버그 빌드 설정 예시를 고친 [#706](https://github.com/oxc-project/website/pull/706)이 병합됐습니다.

공개 커밋 17개, 해당일 생성 또는 병합된 PR 1개를 정리했습니다. PR 생성 0개·병합 1개는 같은 PR이 양쪽에 포함될 수 있습니다.
