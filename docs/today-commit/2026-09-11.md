# 2026-09-11

## 요약 (AI 작성)

PR 80건이 들어간 날입니다. 편집기 폭 캐시가 편집·줄 수 변화·탭 폭 변경에도 살아남게 하고, 되돌리기가 범위를 알게 하고, 체크포인트를 프레임에 나눠 세웠습니다. 모바일은 M12 를 닫고 다른 기계로 갈아타면 화면을 처음으로 되돌리며, M3c 로 끊은 것이 되돌아오지 않게 하고 안 시킨 끊김이면 물러나며 다시 붙고 세션 목록을 «볼 때» 다시 받고 ssh 가 죽은 소켓을 keepalive 로 알아챕니다. UX 계약은 현재형으로 고쳤습니다 — 덮개는 «정해진 것» 이다(U0·U1·U2).

원격 활동은 RAV3 로 원격 pane 의 활동이 화면에 뜨고, 원격/SSH 이력 비목표를 뒤집어 무엇을 선 위로 보낼지 실측으로 정했습니다. session-host 는 handoff 크기를 태그별로 갈라 스크롤백이 주범이 아님을 알았고, input→Metal submit 을 재고, 첫 프레임의 알림 재전송을 없애고, 자식을 못 받은 빈 host 가 영영 안 죽어 업그레이드를 막던 것을 고치고, 레이아웃 조각을 host 가 «보관만» 하게 하고(A-1), CR6f 장시간 idle soak 를 제품 gate 로 고정하고, Notification Center 제품 트랜잭션을 고정했습니다.

터미널은 kitty·OSC·키보드 인코더 방어선을 전수로 훑었습니다 — kitty 여덟 중 여섯, OSC 여섯 중 둘이 그물 밖이었고, 키보드 인코더는 여섯 중 다섯이 잡혔으며 못 잡은 하나는 Caps Lock 이었습니다. 테스트는 샤드 배정을 이름 해시로 바꿨고(테스트 하나가 2,741개의 배정을 흔들었다), 스윕이 제품 소켓 뿌리 /tmp/maru-\<uid\> 를 지울 뻔한 것을 막았습니다.
