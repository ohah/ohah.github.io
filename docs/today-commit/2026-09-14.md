# 2026-09-14

## 요약 (AI 작성)

에이전트 이미지가 터미널 안에서 열리는 날입니다. 터미널의 `[Image #N]` 마커를 Cmd+클릭하면 그 자리에서 보고, 원격 전송 후 프리뷰는 wire 를 판 5 로 올려 픽셀을 저쪽에서 당겨오며(P3), 전송 전 스테이징 코어는 번호를 추측하지 않고 관찰합니다(MP1). 디코드 결과가 남의 프리뷰에 붙고 죽은 surface 가 픽셀을 들고 있던 것도 고쳤습니다. 소스 컨트롤은 충돌 파일을 «병합 모드» 로 엽니다 — 세 판을 든 편집기(S3b-1)에 이어 저녁에는 S2 의 «고르기» 줄을 병합 pane 에 되살렸습니다(S3b-3a). 세 판의 스크롤 관례는 «실측» 해서 §7 ⑥ 에 적었습니다. 에이전트 이어하기는 «그 세션의 모양» 을 되살립니다 — 권한 모드와, 끝난 뒤의 셸.

hwpjs 는 EMF 로 갔습니다 — path bracket·eof palette·mode state·logical palette·color state·pixel format descriptor·object table state·device context stack·pen/brush·16비트 poly·point drawing·mapper/miter, 그리고 WMF 의 record framing·내장 EMF payload 검증, hwp5 null chart grid string 실체화. `@ohah/pdf` 는 파일 묶음(포트폴리오)을 알려 주고, 거듭 열어도 메모리가 안 자라는지 보며, pdf.js 맞대기를 나눠 돌려 18.9초를 4.4초로 줄였습니다.

그 밖에 원격 pane 의 에이전트 탭은 «아직 지원하지 않습니다» 한 줄로 끝나고, 연결이 끊긴 원격 pane 이 «저장소를 확인할 수 없다» 고 말하던 것을 고쳤으며, 렌더러 글리프 캐시 조회가 캐시 크기만큼 훑던 것과 터미널 브라우저 스크롤이 60Hz 를 무너뜨리던 세 곳을 잡았습니다. terminal-core 는 d=a 가 화면에 보이는 배치만 지워 스크롤백 이미지를 살리고, 매체 전송 설계를 실측으로 (A)에서 (B)로 다시 골랐습니다. session-host 는 화면 스트림 바이트를 재고(고치기 전에 계측부터), 실제 cross-uid 거부와 IME 조합 픽셀의 복구 surface 결속을 검증했으며, 원격 훅 설치를 못 띄워도 굳히지 않습니다. Chrome Lab 은 넓은 창 모서리와 드롭다운 시나리오 골든을 얻었고, 아카이브 스모크는 CI 가 돌립니다 — 손으로 안 돌리면 안 도는 게이트였습니다. 블로그에는 8/18~9/14 오늘의 커밋 백필이 올라갔습니다.
