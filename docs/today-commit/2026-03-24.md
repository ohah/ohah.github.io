## 요약 (AI 작성)

zntc는 오전에 전날 연 브라우저 호환성 개선([#317](https://github.com/ohah/zntc/pull/317))을 병합하고 번들러 스모크 테스트를 넓혔습니다. Node 서브패스 external과 cheerio 처리([#319](https://github.com/ohah/zntc/pull/319)), minimatch에서 드러난 JS 모드 구조 분해 기본값 파서 버그 4건([#320](https://github.com/ohah/zntc/pull/320))을 고치면서 스모크 테스트를 101개, 브라우저 E2E를 40개로 늘렸고([#318](https://github.com/ohah/zntc/pull/318), [#321](https://github.com/ohah/zntc/pull/321)), barrel re-export 분류와 ESM external import를 esbuild 방식으로 처리하면서 zod v4 회귀를 바로잡았습니다([#322](https://github.com/ohah/zntc/pull/322)). 브라우저 스모크는 이 과정에서 107개 패키지까지 늘었습니다.

낮부터는 esbuild·SWC 출력과 비교하는 트랜스파일 적합성 테스트를 새로 넣고([#323](https://github.com/ohah/zntc/pull/323)) 9.5%에서 시작한 일치율을 끌어올렸습니다. TS 타입 파서 전면 보강([#324](https://github.com/ohah/zntc/pull/324)), 기본 쌍따옴표와 `--quotes` 옵션([#325](https://github.com/ohah/zntc/pull/325)), `import type`·`export type` 제거, 타입 단언과 JSX 제네릭 구분, 제네릭의 `>`·`<<` 토큰 분할, `declare`와 빈 namespace 제거, 키워드 공백·들여쓰기·빈 객체·JSX 서식 정리 같은 PR이 이어지며 50%를 넘었고([#345](https://github.com/ohah/zntc/pull/345)), 미사용 import 제거와 TSX 제네릭 화살표 함수 지원([#347](https://github.com/ohah/zntc/pull/347))을 거쳐 밤에는 58.8%가 됐습니다([#358](https://github.com/ohah/zntc/pull/358)).
