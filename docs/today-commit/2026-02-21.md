## 요약 (AI 작성)

hwpjs는 머리말·꼬리말·각주·미주에서 중복되던 `LIST_HEADER` 처리를 공통 함수로 묶은 [#6](https://github.com/ohah/hwpjs/pull/6)을 병합하고, 각주·미주마다 올바른 역참조 번호가 붙도록 고쳤습니다. HTML 표 출력은 캡션이 있을 때만 `htG` 래퍼를 쓰도록 fixture에 맞췄고([#9](https://github.com/ohah/hwpjs/pull/9)), 같은 문단의 절대 위치 표 순서와 `htb` 스타일, `htG` 높이까지 맞춘 [#12](https://github.com/ohah/hwpjs/pull/12)도 병합했습니다. 이 과정에서 표 위치·크기·테두리와 줄 높이를 임의의 기본값이 아니라 파싱한 값이나 스펙에서만 가져오도록 정리하고 스냅샷을 갱신했습니다.

같은 날 genpdf로 PDF 내보내기를 시작해 본문 문단, 표와 이미지를 PDF로 그리고 `toPdf` NAPI와 `to-pdf` CLI를 붙였습니다. Base64와 디코딩된 이미지 크기에 상한을 두는 DoS 방어, 테스트용 Liberation Sans 폰트 번들이 [#10](https://github.com/ohah/hwpjs/pull/10)으로 병합됐지만, `to-pdf` CLI와 일괄 PDF 옵션은 [#11](https://github.com/ohah/hwpjs/pull/11)에서 주석 처리해 나중으로 미뤘습니다. 문서 디렉터리 이름을 `docs`에서 `documents`로 바꾸고, macOS에서 Linux x64·Windows용 네이티브 바이너리를 교차 빌드하는 설정과 안내를 추가했습니다. 각주·미주 공통 처리를 뽑아내는 [#13](https://github.com/ohah/hwpjs/pull/13)은 이날 열렸습니다.

react-native-mcp는 CI E2E 기기를 지정하고 Android 에뮬레이터 해상도와 세로 방향을 고정한 [#73](https://github.com/ohah/react-native-mcp/pull/73)을 병합했고, Android `measureInWindow` 좌표를 dp로 바꾸는 보정을 넣었다가 렌더 오버레이 위치가 어긋나 되돌리고 상단 inset으로 오버레이를 보정했습니다. 단계별 대기 시간과 작업 타임아웃을 늘려 E2E 35단계를 안정화했고([#74](https://github.com/ohah/react-native-mcp/pull/74), [#75](https://github.com/ohah/react-native-mcp/pull/75)), 채택 환경을 검사하는 `doctor` 명령과 Health HTTP 서버, 호환성·제한·리스크 문서를 추가했습니다([#76](https://github.com/ohah/react-native-mcp/pull/76), [#77](https://github.com/ohah/react-native-mcp/pull/77)). `assertHasText` 스텝은 `assertText`로 합치고 React state Hook 값을 검증하는 `assert_state` 도구를 추가했습니다([#78](https://github.com/ohah/react-native-mcp/pull/78)). E2E 화면 녹화 도구와 YAML 스텝을 넣는 [#79](https://github.com/ohah/react-native-mcp/pull/79)는 이날 열렸습니다.
