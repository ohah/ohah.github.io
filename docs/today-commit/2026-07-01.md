## 요약 (AI 작성)

maru는 이날 PR 19개를 모두 main에 병합했습니다. 렌더러에서는 프레임마다 글꼴 순번이 새로 매겨져 한글 조합 중 엉뚱한 글리프가 뜨던 문제를 공유 `FontIdentityRegistry`로 고쳤고([#1121](https://github.com/ohah/maru/pull/1121)), 자간 작업 이후 pane 구분선이 굵어지던 회귀를 수정하면서 `split.divider-thickness` 설정을 추가했습니다([#1122](https://github.com/ohah/maru/pull/1122)). 커서 깜빡임은 켜고 끄는 방식에서 알파 페이드로 바뀌었고 `cursor.blink-fade-ms`(ABI v95)가 생겼습니다([#1125](https://github.com/ohah/maru/pull/1125)). 설정 화면 검색창에 IME 입력이 들어가지 않던 문제와 keybind 검증 오류를 인라인 배너로 보이게 한 수정([#1120](https://github.com/ohah/maru/pull/1120))도 들어갔습니다.

에이전트 실행 표시는 브라유 회전 점을 codex식 4칸 이퀄라이저 파형으로 바꾸고([#1123](https://github.com/ohah/maru/pull/1123)), 워크스페이스 단위로 넓혀 백그라운드 pane의 에이전트도 표시하게 했습니다([#1124](https://github.com/ohah/maru/pull/1124)). 코드 리뷰를 거치며 idle 답변 미리보기 색 오염 차단, 재렌더 조건 정밀화가 이어졌고, 탭바 표시는 파형 대신 1칸 정적 플래그(●)로 정리됐습니다. 리네임 편집 중에도 파형을 유지하고([#1127](https://github.com/ohah/maru/pull/1127)), 리네임 IME 후보창 위치를 카드 줄 수와 사이드바 헤더·스크롤에 맞췄으며, Metal scissor를 좌하단 원점으로 착각해 사이드바 스크롤 클립이 어긋나던 문제도 고쳤습니다([#1129](https://github.com/ohah/maru/pull/1129), [#1130](https://github.com/ohah/maru/pull/1130)).

에이전트 감지 쪽에서는 Claude Code가 실행 중 프로세스 이름을 버전 문자열로 바꿔 감지가 전혀 되지 않던 원인을 찾아 argv[0] 폴백을 넣었습니다([#1128](https://github.com/ohah/maru/pull/1128)). 같은 폴더의 여러 claude 세션 상태가 섞이는 문제는 먼저 `CLAUDE_CODE_SESSION_ID` 환경 변수로 매칭했다가([#1131](https://github.com/ohah/maru/pull/1131)), 에이전트 공식 훅으로 transcript 경로를 받는 훅 매핑 방식(claude·codex)으로 바꿨고([#1135](https://github.com/ohah/maru/pull/1135)), 워크스페이스 복원 시 자동 resume 세션 id도 cwd·mtime 추측 대신 훅 매핑을 쓰게 했습니다([#1138](https://github.com/ohah/maru/pull/1138)). 훅 등록이 읽기 오류를 파일 없음으로 오인해 설정을 덮어쓰던 문제 등 리뷰 지적 7건과 단위 테스트도 함께 들어갔습니다. 그 밖에 macOS의 login이 셸을 fork해 빈 터미널을 닫을 때도 실행 중 확인 창이 뜨던 문제를 OSC 133 셸 통합 기반 판정으로 고쳤고([#1137](https://github.com/ohah/maru/pull/1137)), 사이드바·탭 바 배경에도 `window.opacity`를 반영했습니다([#1133](https://github.com/ohah/maru/pull/1133)).

ohah.github.io에는 활동 요약 문서 커밋이 하나 있었습니다.

공개 커밋 33개, 해당일 생성 또는 병합된 PR 19개를 정리했습니다. PR 생성 19개·병합 19개는 같은 PR이 양쪽에 포함될 수 있습니다.
