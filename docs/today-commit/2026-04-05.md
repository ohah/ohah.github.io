> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 JSX 처리를 codegen에서 떼어 냈습니다. 리팩터링 전 동작을 스냅샷 테스트 20개로 고정한 뒤, 트랜스파일 모드와 번들 모드 모두 Transformer 패스가 JSX를 함수 호출로 낮추게 하고 codegen의 JSX 코드 약 800줄을 지웠습니다([#764](https://github.com/ohah/zntc/pull/764)). 앞서 HTML 엔티티 디코딩과 esbuild 방식 텍스트 줄 정규화 등 JSX 스펙 준수 수정([#761](https://github.com/ohah/zntc/pull/761)~[#763](https://github.com/ohah/zntc/pull/763))이 들어갔고, 분리 뒤에는 rest 요소가 JSX 분기로 잘못 가던 문제([#766](https://github.com/ohah/zntc/pull/766))와 JSX spread props의 ES5 변환 누락([#767](https://github.com/ohah/zntc/pull/767))을 고쳤습니다. 번들 모드에도 JSX 옵션을 넘기고 RN 기본값을 automatic으로 두었으며([#746](https://github.com/ohah/zntc/pull/746)), automatic 변환 때 `react/jsx-runtime` import를 자동 주입하고 그 합성 바인딩의 Span 충돌과 래핑 모듈 안 스코프 문제를 바로잡았습니다([#752](https://github.com/ohah/zntc/pull/752), [#753](https://github.com/ohah/zntc/pull/753), [#757](https://github.com/ohah/zntc/pull/757), [#759](https://github.com/ohah/zntc/pull/759)).

번들러에는 tree shaking과 함께 동작하는 번들 모드 소스맵이 생겼고([#735](https://github.com/ohah/zntc/pull/735)~[#737](https://github.com/ohah/zntc/pull/737)), 서브프로세스 플러그인의 JSON 파싱 메모리 누수를 막았습니다([#738](https://github.com/ohah/zntc/pull/738), [#739](https://github.com/ohah/zntc/pull/739)). `__esm` 모듈은 rolldown 방식으로 함수 선언을 래퍼 밖에 두는 live binding을 적용해 TDZ 문제를 풀었고([#743](https://github.com/ohah/zntc/pull/743), [#744](https://github.com/ohah/zntc/pull/744)), namespace import를 `exports_xxx`로 바꾸던 rename은 걷어 냈습니다([#747](https://github.com/ohah/zntc/pull/747)). Hermes에서 속성 재정의가 막히던 문제는 런타임 헬퍼의 `configurable: true`로 고친 뒤 react-native 플랫폼에서 자동으로 켜지는 `configurable_exports` 옵션으로 분리했고([#745](https://github.com/ohah/zntc/pull/745), [#749](https://github.com/ohah/zntc/pull/749)), tsconfig를 번들 분기 전에 읽어 번들 모드에서도 jsx·decorator·sourcemap 설정이 반영되게 했습니다([#748](https://github.com/ohah/zntc/pull/748)).

ES5 변환에서는 화살표 함수, 클래스 메서드·setter, constructor·async·generator, private method 추출 함수가 매개변수 구조 분해·rest·기본값 lowering을 거치지 않던 경로를 모두 막았고([#768](https://github.com/ohah/zntc/pull/768)~[#771](https://github.com/ohah/zntc/pull/771)), `__rest` 제외 목록에 문자열 키가 빠지던 문제([#772](https://github.com/ohah/zntc/pull/772))를 고쳤습니다. Flow component 문법의 ref 파라미터는 hermes-parser처럼 `React.forwardRef`로 감쌉니다([#773](https://github.com/ohah/zntc/pull/773)). old/new 두 AST를 하나로 합치는 리팩터링 [#775](https://github.com/ohah/zntc/pull/775)는 이날 PR이 열렸습니다.

bungae는 ExampleApp 화면이 일부만 그려지는 문제를 여러 디버그 커밋으로 추적한 끝에 App.tsx의 React default import 누락을 고치고 디버그 코드를 지웠으며, dev 모드에서 `--jsx-dev`를 넘겨 React DevTools가 컴포넌트 소스 위치를 보이게 했습니다. suji는 `@suji/node` SDK와 예제 전환 PR [#8](https://github.com/ohah/suji/pull/8)을 병합했습니다.

공개 커밋 57개, 해당일 생성 또는 병합된 PR 40개를 정리했습니다. PR 생성 39개·병합 39개는 같은 PR이 양쪽에 포함될 수 있습니다.
