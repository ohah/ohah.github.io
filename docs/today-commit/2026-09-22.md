## 요약 (AI 작성)

maru 편집기에 SSH 세션의 원격 저장과 저장 충돌 비교가 더해졌습니다. 미저장 내용의 백업·크래시 복구·이름 없는 문서 복원을 잇고, 파일 신원을 잃은 문서도 내용부터 되살리도록 했습니다. 에이전트 탭의 턴 목록은 디스크에 남겨 앱 재시작 뒤 다시 읽습니다. LSP 인레이 힌트와 문서 심볼 목록을 연결하고, 힌트가 줄바꿈과 구문 색의 열 위치를 어긋나게 하던 문제를 고쳤습니다. 같은 낱말 강조 구현도 들어왔습니다. 터미널은 DECSET 2031 / DSR 996으로 테마 변경을 구독한 앱에 알립니다.

`@ohah/pdf`는 v0.2.1과 v0.2.2를 배포했습니다. 실문서 100편에서 글자 추출·글꼴·그림을 대조하고, 퍼저가 찾아낸 예측기 경계 밖 읽기와 큰 QuadPoints의 반복 문제를 수정했습니다. hwpjs는 EMF의 호·타원·베지어·이미지·Path를 장치 좌표로 옮기고 경계선을 펼치는 기하 처리를 확장했습니다.

zntc는 async generator와 클래스 메서드의 다운레벨 변환, iterator 위임의 반환값, 반복마다 달라져야 하는 let 바인딩, 함수 이동 시 arguments 캡처를 다듬었습니다. 블로그 저장소에도 이전 날짜 기록과 개발기를 보충하고 의존성을 갱신한 작업이 있었습니다. maru의 Chromium 웹 패널은 통합 PR [#3867](https://github.com/ohah/maru/pull/3867)이 열린 진행 작업입니다.

공개 커밋 121개, 해당일 생성 또는 병합된 PR 48개를 정리했습니다. PR 생성 43개·병합 44개는 같은 PR이 양쪽에 포함될 수 있습니다.
