## 요약 (AI 작성)

hwpjs는 HTML 뷰어의 표 캡션을 집중적으로 고쳤습니다. 캡션의 라벨·번호·본문을 문단 레코드의 자동 번호 제어 문자 위치로 구조적으로 파싱하고, 줄 높이와 번호 칸 너비를 하드코딩 상수 대신 LineSegmentInfo에서 계산하도록 바꿨습니다. 문단 모양 ID를 문서에서 가져오고, 세로 캡션(왼쪽·오른쪽) 표의 위치를 `line_height`와 `line_spacing`으로 잡았으며, `vertical_align` 필드를 추가해 결합 캡션을 구분하고 위쪽 정렬 결합 캡션에도 오프셋을 적용했습니다. 캡션 너비·위치와 SVG viewBox 계산 수정, 문서 단위로 이어지는 표 번호, 표 위치 계산 단순화, 표 렌더링 모듈 분리도 이어졌고 스냅샷을 갱신했습니다.

ohah.github.io에는 댓글 컴포넌트와 Chromium 배경 문서를 추가했습니다. oxc 문서 사이트에는 VS Code 확장 디버그 빌드 설정 예시를 고치는 PR [#706](https://github.com/oxc-project/website/pull/706)을 열었습니다.

공개 커밋 17개, 해당일 생성 또는 병합된 PR 1개를 정리했습니다. PR 생성 1개·병합 0개는 같은 PR이 양쪽에 포함될 수 있습니다.
