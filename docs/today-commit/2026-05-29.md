## 요약 (AI 작성)

zntc는 오전에 이슈 단위 버그 수정을 연달아 병합했습니다. 문자열 리터럴의 `\u{}` 이스케이프 범위 초과 검사([#3988](https://github.com/ohah/zntc/pull/3988)), es5 다운레벨에서 기본값이 있는 중첩 구조 분해([#3989](https://github.com/ohah/zntc/pull/3989)), exports·imports 와일드카드를 가장 긴 접두사로 고르는 해석과 명시적 null 대상 차단([#3993](https://github.com/ohah/zntc/pull/3993), [#3994](https://github.com/ohah/zntc/pull/3994)), 플러그인 실패 진단 문자열의 데이터 경쟁([#3995](https://github.com/ohah/zntc/pull/3995))을 고쳤습니다. 진단은 `Expected X but found Y` 형식으로 렌더하고 해석되지 않은 import 제안을 중립적인 hint로 바꿨습니다([#3991](https://github.com/ohah/zntc/pull/3991), [#3992](https://github.com/ohah/zntc/pull/3992)). 모듈 쪽에서는 순수 CJS star를 가진 ESM의 namespace import를 `__toESM(require())`로 처리하고([#3996](https://github.com/ohah/zntc/pull/3996)) export*-from-CJS 멤버를 런타임에 구성하며 dev HMR에서도 빠지지 않게 했고([#4001](https://github.com/ohah/zntc/pull/4001), [#4002](https://github.com/ohah/zntc/pull/4002)), 실제로 없는 export만 `missing_export`로 보고하고([#3997](https://github.com/ohah/zntc/pull/3997)) 모호한 `export *` 충돌을 명세대로 거부하거나 undefined로 처리했습니다([#3998](https://github.com/ohah/zntc/pull/3998)).

저녁에는 Zig 0.15.2에서 0.16.0으로 옮기는 대형 마이그레이션([#4003](https://github.com/ohah/zntc/pull/4003))이 병합됐습니다. 빌드 시스템과 panic 경로부터 CLI, 번들러, dev 서버, NAPI, WASM, 테스트까지 파일 시스템·시간·스레딩 호출을 새 `std.Io` 기반으로 바꾸는 커밋 77개가 한꺼번에 main에 들어왔고, `Thread.Pool`은 `Io.Group`으로, mutex는 `Io.Mutex`나 io 없는 스핀락으로 바꿨습니다. 멀티스레드 wasm을 std 0.16이 지원하지 않아 wasm 번들러는 단일 스레드로 돌렸고, upstream 회귀를 피해 arm64-windows는 x64 호스트에서 교차 빌드하며 windows-msvc에는 advapi32를 명시적으로 링크했습니다. 후속으로 `--jobs`를 io async_limit에 연결하고([#4005](https://github.com/ohah/zntc/pull/4005)) graph·emit 작업을 범위 단위로 묶어 0.16의 작업당 오버헤드를 줄였으며([#4008](https://github.com/ohah/zntc/pull/4008)), `MpscChannel` 전송 OOM 시 멈춤이나 해제 후 사용 없이 실패하게 했습니다([#4010](https://github.com/ohah/zntc/pull/4010)).

밤에는 `export * as ns`의 내부 이름이 일반 `export *`와 잘못 모호 판정되어 zod의 `z.string`이 undefined가 되던 회귀를 고치고([#4012](https://github.com/ohah/zntc/pull/4012)), member-rewrite된 namespace의 없는 멤버 접근과 optional chain 멤버 접근이 끊어진 참조를 남기지 않게 했습니다([#4014](https://github.com/ohah/zntc/pull/4014), [#4018](https://github.com/ohah/zntc/pull/4018)). WASM 최적화 모드를 덮어쓰는 `-Dwasm-optimize`와 배포용 LTO를 켜는 `-Denable-lto` 옵션도 추가했습니다([#4016](https://github.com/ohah/zntc/pull/4016)).

suji는 IPC 지연 응답의 해제 후 사용, 슬롯 고갈, 종류 혼동, TTL 문제를 고치고([#57](https://github.com/ohah/suji/pull/57)) 리뷰 후속으로 eviction 경쟁과 타이머 누수를 없앴습니다([#59](https://github.com/ohah/suji/pull/59)). Windows ReleaseSafe의 translate-c 미사용 지역 변수 오류([#58](https://github.com/ohah/suji/pull/58))와 패키징된 앱의 scheme handler가 해제된 메모리를 써서 죽던 문제를 요청별 참조 카운트로 고쳤습니다([#61](https://github.com/ohah/suji/pull/61)). 블로그 저장소 ohah.github.io에는 5월 29일 요약 추가 커밋 1개가 있었습니다.

공개 커밋 107개, 해당일 생성 또는 병합된 PR 30개를 정리했습니다. PR 생성 30개·병합 30개는 같은 PR이 양쪽에 포함될 수 있습니다.
