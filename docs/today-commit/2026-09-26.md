## 요약 (AI 작성)

zntc는 이날 공개 커밋 100개로 작업이 가장 많았습니다. 새벽에 IIFE 접기가 반환식을 복사해 선언이 사라진 변수를 가리키던 문제와 합성 변수 이름이 사용자 변수를 가리던 문제를 고친 뒤, 오후부터 변환 패스가 쓰는 가변 심볼 편집기와 스코프 소유자 추적·재연결을 의미 분석에 더했습니다. 이어 반복문·optional catch·nullish·optional chaining·tagged template·데코레이터·런타임 헬퍼 import처럼 변환이 만든 임시 변수와 함수를 원래 심볼과 스코프에 연결했습니다. ES5 클래스 IIFE의 자기 참조, 매개변수 기본값보다 먼저 초기화해야 하는 캡처, static private 메서드·접근자, 추출된 루프의 catch 제어 흐름, TypeScript namespace와 병합 enum의 출처도 바로잡았고, Hermes 프리셋에서 async generator를 낮추도록 했습니다.

maru 편집기는 감싸는 쌍이나 다음 여는 괄호로 가는 괄호 점프([#3954](https://github.com/ohah/maru/pull/3954))를 병합하면서 다음 여는 괄호 탐색을 트리 커서 한 번 걷기로 바꿔 커밋이 밝힌 측정에서 44초 걸리던 경우를 1ms 미만으로 줄였습니다. 줄 끝 목표로 내려갈 때 큰 열 값이 넘치던 문제([#3956](https://github.com/ohah/maru/pull/3956)), 비교·병합 뷰에서 줄 번호가 본문에 밀려 사라지던 결함([#3940](https://github.com/ohah/maru/pull/3940))도 고쳤고, copyleft 레퍼런스 이름을 문서와 주석에서 걷어냈습니다. 원격 에이전트 쪽은 죽은 pane의 이벤트가 살아 있는 다른 Term에 귀속되던 문제([#3960](https://github.com/ohah/maru/pull/3960))와 orphan 경고가 옛 짝을 이번 분배 옆에 찍던 문제([#3962](https://github.com/ohah/maru/pull/3962))를 고쳤습니다.

저녁에는 랩된 줄에서 아래로 두 번 이동하면 목표 열이 0으로 무너지던 문제, 맞닿기만 한 두 선택 범위가 합쳐지던 문제, `⌘⌫`가 들여쓰기를 남기던 문제, 편집기 pane에서 커서가 깜빡이지 않던 문제, 한글 조합을 Enter로 확정한 글자가 문서에 들어가지 않던 IME 문제([#3968](https://github.com/ohah/maru/pull/3968)), 하이퍼링크를 보내지 않던 앱에 능력을 알리는 pty 수정([#3972](https://github.com/ohah/maru/pull/3972))과 `term-program` 설정([#3974](https://github.com/ohah/maru/pull/3974)) PR이 열렸습니다. 이 PR들은 다음 날 병합됐고, `Goal.line_end`를 없애려던 [#3973](https://github.com/ohah/maru/pull/3973)은 병합 없이 닫혔습니다. 괄호 색·강조·점프 판정을 통일한 [#3964](https://github.com/ohah/maru/pull/3964)도 이날 열려 다음 날 병합됐고, Markdown 소스 네이티브 이관 계약 검토안 [#3967](https://github.com/ohah/maru/pull/3967)은 미병합입니다. Chromium 웹 패널의 권한 요청 sheet(W5b1), CoreLocation 위치 전달(W5b2), 웹 알림 전달(W5c)은 기능 브랜치 `docs/web-panel-osr-backend`에 병합돼 main 반영이 아니며, main 통합 PR [#3867](https://github.com/ohah/maru/pull/3867)은 열려 있습니다.

hwpjs는 HWPX에 포함된 SVG XML 구조와 OLE 컨테이너, BMP 픽셀, 선택적으로 켜는 JPEG 픽셀 검사와 Exif 방향 보고, Adobe 4성분 JPEG와 PNG RGBA 디코딩을 HWP 컨테이너 검사에 이었습니다. 섹션·바탕쪽 텍스트 스냅샷을 문서 모음에서 비교하는 검증을 더하고, 수식·필드·매개변수 목록·단 정의·쪽 번호 제어 검사도 넓혔습니다. 새 공개 저장소 `ohah/spinon`이 첫 커밋(`initialize Boson repository`)과 함께 만들어졌습니다. 웹 문법으로 모바일과 웹 앱을 만드는 GPU 기반 UI 프레임워크를 실험하는 저장소로, 같은 JavaScript 트리를 V8과 Rust 레이아웃을 거쳐 iOS UIKit·Android 네이티브 뷰로 그리는 PoC PR [#1](https://github.com/ohah/spinon/pull/1)이 이날 열려 9월 28일 새벽에 병합됐습니다. 블로그 저장소에는 9월 22일부터 26일까지의 기록 갱신과 전수 검토 보완 커밋 두 개가 있습니다.
