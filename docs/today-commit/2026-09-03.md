# 2026-09-03

## 요약 (AI 작성)

편집기 줄 조작이 들어온 날입니다 — 줄 조작 넷과 Enter 자동 들여쓰기, `⇧⌘K`·`Tab`/`⇧Tab`(§3.9a). 편집 연산 캡처 훅으로 화면에 남는 결과를 재고, 상태바가 편집되는 문서를 「읽기 전용」이라 말하던 것을 고쳤으며, 「계약 안」 편집 보조 여섯이 닫혔습니다. `@ohah/pdf` 는 JPEG 을 푸는 값을 122ms 에서 52ms 로 줄였습니다 — 세 군데를 고쳤고, 걸림돌은 실제 바이트 잦기로 골랐습니다.

session-host 는 attestation action authority, exact draft asset 첨부·다운로드 검증·publish, published release attestation 검증, signed upgrade evidence v2, baseline product execution 과 runner workspace·child path 격리를 쌓았습니다. CI 는 공증이 릴리스를 거부한 원인 둘을 잡았습니다 — Resources 아래 감시자를 서명하지 않은 것, 떼어낸 main executable 에 건 codesign 검증. 소스 컨트롤은 원격이 바뀌면 도크가 스스로 갱신되고(RW3), S11-6 이 실기에서 처음 동작해 검증 행렬과 전달 규약을 적었습니다. `Io.Dir` 의 필드는 `.fd` 가 아니라 `.handle` 이라 main 이 깨져 있었습니다.
