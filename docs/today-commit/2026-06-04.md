## 요약 (AI 작성)

maru는 오전까지 문서와 설계 경계를 정리했습니다. Metal 우선 렌더러 결정([#25](https://github.com/ohah/maru/pull/25)), snapshot 스키마 헤더와 Trace·Event 용어 고정, 민감 키 redaction 목록 단일화와 렌더러 shaping·dirty-region 계약([#26](https://github.com/ohah/maru/pull/26)), 터미널 호환성 정책과 계약([#30](https://github.com/ohah/maru/pull/30), [#34](https://github.com/ohah/maru/pull/34)), 외부 oracle의 CI 적용 범위 명시가 들어왔고, 밤에는 폰트 렌더링 전략([#36](https://github.com/ohah/maru/pull/36))과 grapheme·ZWJ 폭, ambiguous-width, faux bold, box-drawing을 미뤄 둔 항목으로 기록했습니다([#38](https://github.com/ohah/maru/pull/38)). import 경계 검사기는 여러 줄 `@import`를 잡도록 고친 뒤([#32](https://github.com/ohah/maru/pull/32)) 토큰 단위 스캔으로 바꿔 주석 회피와 오탐을 막았습니다([#35](https://github.com/ohah/maru/pull/35)). 코드로는 나뉘어 들어온 UTF-8 입력 보존([#39](https://github.com/ohah/maru/pull/39)), 셀 폭 모델([#40](https://github.com/ohah/maru/pull/40))과 결합 문자 위치·폭 경계 수정([#41](https://github.com/ohah/maru/pull/41)), macOS openpty 세션([#42](https://github.com/ohah/maru/pull/42))이 추가됐고, CI에 아티팩트 업로드와 성능 워크플로를 붙였습니다.

suji는 프로덕션 .app을 다른 맥에서도 돌도록 다듬었습니다. 빌드 머신 경로에 의존하지 않는 self-contained 번들, suji 스킴의 `CEF_SCHEME_OPTION_LOCAL` 제거로 흰 화면 해결, 재빌드 때 CEF 프레임워크가 중첩되지 않는 idempotent 번들, 더블클릭 실행 시 번들 안 config를 읽도록 한 수정이 들어왔습니다. node 없는 백엔드에서도 쓸 수 있게 `suji.config.ts`를 없애고 정적 `suji.json`을 단일 출처로 삼았으며, `app.minimumSystemVersion`으로 최소 macOS 버전을 지정하게 했습니다. 문서 사이트는 API 레퍼런스 포팅, `llms.txt`, `suji init`의 CLAUDE·AGENTS 생성, zts 스타일 적용으로 정비했고, Lua 백엔드는 vendored Lua 5.4와 cjson, invoke·send·on outbound API를 갖췄습니다([#68](https://github.com/ohah/suji/pull/68)).

zntc는 HMR 위상 보존 Phase B로 body-only 편집 때 변경 모듈만 다시 파싱하고 나머지 edge를 재사용하게 했고, 리뷰에서 나온 TLA 강등·`requested_exports` UAF·`pkg_info_cache` 무효화 문제를 함께 고쳤습니다([#4163](https://github.com/ohah/zntc/pull/4163)). RN asset 모듈([#4164](https://github.com/ohah/zntc/pull/4164), [#4165](https://github.com/ohah/zntc/pull/4165))과 polyfill·`run_before_main`([#4166](https://github.com/ohah/zntc/pull/4166))도 보존 경로에 넣었고, 보존 게이트와 그래프 시간 분해 진단 로깅([#4169](https://github.com/ohah/zntc/pull/4169)), dev HMR 테스트의 watcher 경합 flake 제거([#4167](https://github.com/ohah/zntc/pull/4167), [#4168](https://github.com/ohah/zntc/pull/4168))가 뒤따랐습니다.

공개 커밋 40개, 해당일 생성 또는 병합된 PR 26개를 정리했습니다. PR 생성 26개·병합 26개는 같은 PR이 양쪽에 포함될 수 있습니다.
