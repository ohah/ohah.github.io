> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 거의 하루 내내 Reanimated worklet 변환을 다듬었습니다. 클로저 분석을 어느 시점의 함수 본문으로 할지가 핵심 쟁점이었습니다. 변환 전 원본 본문([#1107](https://github.com/ohah/zntc/pull/1107)), 방문 후 본문([#1127](https://github.com/ohah/zntc/pull/1127), [#1128](https://github.com/ohah/zntc/pull/1128))을 오간 끝에, ES5 헬퍼가 끼지 않은 방문 전 본문을 쓰고 codegen이 TS·Flow 노드를 걷어 내며 JS 전역 목록을 넓히는 방식으로 정리했습니다([#1134](https://github.com/ohah/zntc/pull/1134)~[#1139](https://github.com/ohah/zntc/pull/1139)). 그 사이 scope hoisting rename이 `__closure`와 worklet 해시 할당에 반영되지 않던 문제([#1111](https://github.com/ohah/zntc/pull/1111), [#1112](https://github.com/ohah/zntc/pull/1112), [#1117](https://github.com/ohah/zntc/pull/1117)), 화살표 함수 worklet에 플러그인이 호출되지 않던 문제([#1119](https://github.com/ohah/zntc/pull/1119)), 클로저 변수 이름의 use-after-free([#1132](https://github.com/ohah/zntc/pull/1132)), dev 모드 크래시를 막는 `__stackDetails`([#1133](https://github.com/ohah/zntc/pull/1133))를 고쳤습니다.

이어서 클로저 분석을 화이트리스트 대신 노드 레이아웃 기반 범용 AST walker로 바꾸고([#1162](https://github.com/ohah/zntc/pull/1162)), 중첩 함수·메서드 본문 순회, 메서드 매개변수와 지역 변수 제외, 자기 참조 제외, cover grammar 화살표 매개변수를 처리했습니다([#1155](https://github.com/ohah/zntc/pull/1155), [#1158](https://github.com/ohah/zntc/pull/1158), [#1159](https://github.com/ohah/zntc/pull/1159), [#1163](https://github.com/ohah/zntc/pull/1163), [#1165](https://github.com/ohah/zntc/pull/1165)). 알려진 함수 호출의 인자를 자동으로 worklet으로 만드는 auto-workletization([#1148](https://github.com/ohah/zntc/pull/1148)), 객체 메서드의 worklet directive([#1167](https://github.com/ohah/zntc/pull/1167)), Layout Animation SIGABRT를 일으키던 두 원인 수정([#1172](https://github.com/ohah/zntc/pull/1172))이 뒤를 이었습니다. 이어 Babel `react-native-worklets/plugin`의 테스트 169개를 기준선으로 포팅하고([#1174](https://github.com/ohah/zntc/pull/1174)), `.withCallback()` Layout Animation auto-worklet, getter/setter worklet, `__pluginVersion` 주입, `substituteWebPlatformChecks` 옵션, generator/async parity 테스트를 단계별로 병합했습니다([#1175](https://github.com/ohah/zntc/pull/1175)~[#1180](https://github.com/ohah/zntc/pull/1180)).

worklet 밖에서는 ES5 클래스 필드 초기화를 `super()` 호출 직후로 옮기고([#1146](https://github.com/ohah/zntc/pull/1146)), re-export 체인을 거치는 CJS default import를 canonical export 이름으로 해석하게 했으며([#1153](https://github.com/ohah/zntc/pull/1153)), CSS 의존성 갱신과 함께 @emotion/react·Tailwind v4 스모크 테스트를 추가했습니다([#1126](https://github.com/ohah/zntc/pull/1126)). CLAUDE.md는 329줄에서 52줄로 줄였습니다([#1123](https://github.com/ohah/zntc/pull/1123)).

bungae는 worklet 수정이 들어갈 때마다 ZTS 서브모듈을 올렸고, ZTS 네이티브 worklet 변환으로 대체된 reanimated를 Babel 플러그인 감지 대상에서 뺐습니다. RN 프리셋에 빠져 있던 `strictExecutionOrder`를 넣고, 예제 앱에 Layout Animation 등 worklet parity 데모를 추가했습니다.

공개 커밋 92개, 해당일 생성 또는 병합된 PR 62개를 정리했습니다. PR 생성 62개·병합 60개는 같은 PR이 양쪽에 포함될 수 있습니다.
