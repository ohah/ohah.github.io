## 요약 (AI 작성)

executeJS는 Node.js 런타임 작업을 이어 PR 두 개를 병합했습니다. [#28](https://github.com/ohah/executeJS/pull/28)은 Node.js 바이너리를 앱 리소스에 넣지 않고 앱 시작 때 캐시 경로에 내려받도록 바꿔, `node_downloader` 모듈을 추가하고 postinstall 다운로드 스크립트와 tauri.conf.json의 리소스 설정을 지웠습니다. 리뷰를 반영해 버전 문자열을 `NODE_VERSION` 상수로 통일하고 HTTP 응답 상태를 확인하도록 했습니다. [#29](https://github.com/ohah/executeJS/pull/29)는 oxc 파서로 require·import 문에서 패키지 이름을 뽑아 npm 패키지를 자동으로 설치하고, 플랫폼별 `node_modules` 경로를 나눴으며, ES 모듈을 지원하려고 코드를 stdin 대신 임시 `.mjs` 파일로 실행하게 했습니다.

hwpjs는 HTML 뷰어 코드를 정리했습니다. 커다란 `mod.rs`를 옵션·문서·문단·ctrl_header 모듈로 나누고 ctrl_header를 컨트롤 ID별 폴더 구조로 바꿨으며, `render_table`과 `table_position`이 따로 떼어 받던 값 대신 `CtrlHeaderData`를 직접 받도록 해 매개변수를 줄였습니다. 표 캡션은 hwplib·hwp-rs 방식대로 별도 LIST_HEADER 레코드에서 파싱하도록 고쳤고, 표 아래 테두리를 항상 그리며, 문단 세로 위치를 인덱스로 바로 찾도록 했습니다.

공개 커밋 8개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 2개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
