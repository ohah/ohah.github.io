## 요약 (AI 작성)

chrome-remote-devtools는 React Native 저장소를 DevTools에서 볼 수 있게 하는 작업을 했습니다. 먼저 MMKV v3·v4를 함께 다루는 어댑터와 CDP 메시지 처리를 갖춘 MMKV DevTools 지원을 넣고, `MMKVStorage.enable` 때 모든 인스턴스의 초기 스냅샷을 보내도록 했습니다. 예제 앱에는 v4 인스턴스 셋과 v3 레거시 인스턴스, 값을 무작위로 넣고 지우는 MMKV 테스트 화면을 추가했습니다. 이 작업은 Redux 패널 iframe 복원과 함께 [#65](https://github.com/ohah/chrome-remote-devtools/pull/65)로 병합됐고, Zustand 미들웨어가 서버 정보 속성을 잘못 읽던 문제와 Provider 상태 UI를 기본으로 숨기는 변경도 들어갔습니다.

오후에는 AsyncStorage DevTools 통합 [#66](https://github.com/ohah/chrome-remote-devtools/pull/66)을 병합했습니다. AsyncStorage 메서드를 가로채 변경을 실시간으로 감지하고, 인스턴스 하나와 여러 개를 모두 지원하며, DevTools 프런트엔드에 AsyncStorage 저장소 모델과 항목 보기를 추가했습니다. 예제 앱에는 AsyncStorage 테스트 화면을 넣고 Alert 대신 콘솔 오류를 쓰도록 단순화했으며, devtools-frontend 서브모듈과 번들 파일을 갱신했습니다.

공개 커밋 24개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 2개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
