## 요약 (AI 작성)

chrome-remote-devtools는 새벽에 [#92](https://github.com/ohah/chrome-remote-devtools/pull/92)를 병합해 React Native inspector의 콘솔·네트워크 훅을 JavaScript로 옮기고 C++ 훅을 deprecated로 표시했으며, `android`·`ios` 폴더와 podspec 이름을 `.disabled`로 바꿔 네이티브 빌드에서 뺐습니다. 예제 앱용 Metro blockList와 Host 헤더 주입 스크립트도 이때 들어갔습니다. 이어 Redux DevTools Extension 폴리필 테스트를 보강한 [#93](https://github.com/ohah/chrome-remote-devtools/pull/93), PR·리뷰 명령과 리뷰 에이전트를 추가한 [#94](https://github.com/ohah/chrome-remote-devtools/pull/94)를 병합했습니다. WebSocket 연결을 끊으면 재시도 타이머를 취소하고, `sendCDPMessage`의 `JSON.stringify` 실패를 잡도록 고쳤습니다.

저녁에는 React Native inspector의 CDP 구조를 웹 클라이언트와 같은 `cdp/domain/` 형태로 맞춘 [#95](https://github.com/ohah/chrome-remote-devtools/pull/95)를 병합했습니다. 전송 경로를 `setCDPEventSender` 하나로 모으고, 콘솔 훅의 오류 처리에서 원래 `console.error`를 써 훅이 다시 불리지 않게 했습니다. 커버리지 공백을 메우는 단위 테스트 [#97](https://github.com/ohah/chrome-remote-devtools/pull/97)은 한 번 되돌렸다가 Copilot 리뷰를 반영해 다시 넣어 병합했고, 커밋 규칙을 명령으로 옮기고 기존 PR이 있으면 수정하라는 규칙을 둔 [#98](https://github.com/ohah/chrome-remote-devtools/pull/98)도 병합했습니다.

bungae는 Bun.build 기반의 새 번들러 경로를 추가했습니다. 설정에서 `graph`와 `bun` 번들러를 고를 수 있게 하고, Bun.build에 Flow 제거·플랫폼 확장자 해석 플러그인을 붙여 IIFE로 낸 뒤 OXC(ES2015)와 SWC(ES5) 후처리로 Hermes에 맞추며, prelude에 HMRClient 등 callable 스텁을 등록했습니다. 변환기는 Hermes 파서와 캐시한 Babel을 쓰고, ExampleApp 설정을 bun 번들러로 바꿨습니다. graph 번들러는 HMRClient를 Bungae HMR 클라이언트로 바꿨습니다. OXC 런타임 헬퍼에 Hermes 호환용 null 검사를 넣고 Cursor 커밋·PR 규칙을 더한 [#18](https://github.com/ohah/bungae/pull/18), bun 번들러에 Metro 호환 에셋 처리를 넣은 [#19](https://github.com/ohah/bungae/pull/19)를 병합했습니다.

같은 날 Cursor PR 명령 파일을 추가하는 PR이 여럿 오갔습니다. executeJS의 [#30](https://github.com/ohah/executeJS/pull/30)은 main에 병합됐고, hwpjs의 [#3](https://github.com/ohah/hwpjs/pull/3)은 `copilot/align-executejs-command` 브랜치에 병합돼 main 반영은 아니며, hwpjs [#2](https://github.com/ohah/hwpjs/pull/2)는 병합 없이 닫혔습니다. cheolsu-proxy에서는 `proxy_v2_models` 변경을 되돌리는 [#52](https://github.com/ohah/cheolsu-proxy/pull/52)가 master에 병합됐습니다.

공개 커밋 46개, 해당일 생성 또는 병합된 PR 12개를 정리했습니다. PR 생성 11개·병합 11개는 같은 PR이 양쪽에 포함될 수 있습니다.
