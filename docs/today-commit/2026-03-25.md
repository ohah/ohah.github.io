## 요약 (AI 작성)

zntc는 오전부터 esbuild·SWC 대비 트랜스파일 적합성을 계속 올렸습니다. 전날 연 ASI 처리([#359](https://github.com/ohah/zntc/pull/359))를 병합하고 `useDefineForClassFields`와 `experimentalDecorators`([#360](https://github.com/ohah/zntc/pull/360)), 화살표 함수 반환 타입·매개변수 데코레이터, 함수 오버로드 시그니처 제거([#368](https://github.com/ohah/zntc/pull/368)), `import x = require()` 이름 누락 수정([#369](https://github.com/ohah/zntc/pull/369))을 넣었습니다. enum·namespace IIFE는 esbuild처럼 화살표 함수로 바꾸고([#365](https://github.com/ohah/zntc/pull/365)) namespace export 참조 치환과 `var` 중복 제거, 매개변수 리네이밍([#370](https://github.com/ohah/zntc/pull/370)부터 [#372](https://github.com/ohah/zntc/pull/372)까지)을 더해 적합성이 70.0%에 이르렀습니다. 오후에는 oxc 방식의 모듈 판별([#373](https://github.com/ohah/zntc/pull/373)), 적합성 파싱 오류 수십 건 수정([#375](https://github.com/ohah/zntc/pull/375), [#377](https://github.com/ohah/zntc/pull/377)), enum·namespace 런타임 오류 수정, TS 비중이 큰 패키지 스모크 테스트 12개 추가([#382](https://github.com/ohah/zntc/pull/382))가 이어졌습니다. 오류 13건을 묶은 [#374](https://github.com/ohah/zntc/pull/374)는 병합 없이 닫혔습니다.

저녁에는 성능과 다운레벨링으로 넘어갔습니다. 번들러에 `--experimental-decorators`와 `__decorateClass` 런타임([#384](https://github.com/ohah/zntc/pull/384)), 모듈별 스레드 병렬 파싱([#385](https://github.com/ohah/zntc/pull/385), [#386](https://github.com/ohah/zntc/pull/386))을 넣었고, 렉서의 공백 건너뛰기와 식별자 스캔을 16바이트 SIMD로 바꿨습니다([#387](https://github.com/ohah/zntc/pull/387)). 이어 `--target` 옵션과 함께 `??`·논리 할당·optional chaining([#388](https://github.com/ohah/zntc/pull/388)), `**`의 `Math.pow` 변환, class static block, optional catch binding, object spread의 `Object.assign` 변환, async/await의 generator 변환([#400](https://github.com/ohah/zntc/pull/400))까지 ES 다운레벨링을 구현했습니다. 같은 내용의 [#399](https://github.com/ohah/zntc/pull/399)는 닫고 테스트를 붙인 [#400](https://github.com/ohah/zntc/pull/400)으로 병합했습니다. 번들러 로드맵과 CLAUDE.md를 보강하고 Flow 지원 전략은 `FLOW.md`로 분리했습니다.

cheolsu-proxy는 설정 공통 래퍼 추출([#329](https://github.com/ohah/cheolsu-proxy/pull/329)), 설정 동기화에서 빠진 `block_quic` 필드 수정([#330](https://github.com/ohah/cheolsu-proxy/pull/330)), 스크립트 상태 초기 동기화와 V8 힙 제한으로 OOM 크래시를 막은 수정([#331](https://github.com/ohah/cheolsu-proxy/pull/331))을 병합했습니다. 밤에는 인증서 생성을 다듬어, leaf 인증서 유효기간을 90일로 줄이고 CA 만료 임박 시 자동 재생성과 키·인증서 매칭 검증, `moka`를 이용한 동시 생성 쏠림(thundering herd) 방지를 넣었고([#332](https://github.com/ohah/cheolsu-proxy/pull/332)), 생성 메트릭·타임아웃·와일드카드 캐시와 ALPN 미러링 공통화를 더했습니다([#333](https://github.com/ohah/cheolsu-proxy/pull/333)).

블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋과 함께, 빠졌던 3월 24일·26일 커밋 보충과 ZTS 월간 오픈소스 개발기 추가, 최초 세션 대화와 작업 강도 분석을 넣은 ZTS·Cheolsu Proxy 개발기 보강이 올라왔습니다.
