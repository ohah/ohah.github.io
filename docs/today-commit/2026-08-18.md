# 2026-08-18

## 요약 (AI 작성)

SSH 클라이언트를 직접 세운 날입니다. session 채널 열기·pty-req·shell·데이터·종료(S7)에서 출발해 받는 쪽 흐름 제어로 대량 출력이 멈추지 않게 하고(S7b), 잡 메시지에 답하고(S7c), 재키잉으로 한 시간 넘는 세션이 끊기지 않게 한 뒤(S7d), 일회용 sshd 를 띄워 8MiB 를 왕복하는 실서버 하네스(S8)로 증명했습니다. 이어 세션 상태기계를 도구에서 승격해 모바일과 같은 것을 쓰게 하고(S9-1), SSH 세션을 C ABI 로 내어 핸들·배압·난수를 host 가 들게 했으며(S9-2), 안드로이드에서는 소켓 펌프와 포그라운드 서비스로 배경에서도 살게 했습니다(S9-3a·b).

편집기는 성능을 팠습니다. 랩 계수가 매 프레임 돌고 4,096줄에서 잘리던 것을 접두합 캐시로 바꾸고, 폭을 라이브로 끄는 드래그가 16fps 이던 것을 저하 동작으로 내리고, 놓는 순간의 62ms 를 프레임에 나눠 점진 계수로 만들었습니다(§2.1). 비교 뷰를 네이티브로 여는 기본 경로 전환(N1.5)과 세로·가로 스크롤바 드래그, 합자가 잘려 `//` 가 `/` 로 보이던 결함도 이날입니다. 탐색기는 언어별 파일 아이콘, git 이 무시하는 항목 흐리기, 단일 자식 디렉터리 접기, 헤더의 새로 고침·전체 접기 버튼을 얻었고, 소스 컨트롤 도크는 fetch 를 직접 실행하고(P6a) push·pull 을 터미널에 넣어 주며(P6b) ahead/behind 기준을 기본 브랜치로 옮겼습니다 — `@{u}` 는 작업 브랜치에서 늘 0 이었습니다.

Windows 는 경로와 사용자 config 배선(W7.5)이 들어갔고, 파일 패널의 에이전트 탭이 턴 타임라인을 그리기 시작했습니다(P5). i18n 적대적 검증이 뜻이 뒤집힌 번역·미끄러지는 선택·스레드 경합 다섯을 잡았고, 리베이스 규율("팁에서 고치면 히스토리가 죽는다")과 커밋된 머지 충돌 마커를 막는 게이트가 문서·CI 에 들어갔습니다.
