## 요약 (AI 작성)

maru 파일 패널에는 Markdown 라이브 프리뷰가 새로 들어왔고, 이날 maru PR 16개는 모두 main에 병합됐습니다. 계약 문서([#1452](https://github.com/ohah/maru/pull/1452))를 먼저 쓴 뒤 프리뷰 기반([#1454](https://github.com/ohah/maru/pull/1454)), 라이브 프리뷰 worker([#1456](https://github.com/ohah/maru/pull/1456)), Mermaid helper 기반([#1457](https://github.com/ohah/maru/pull/1457))을 올렸고, 마지막에 Markdown 라이브 편집을 기본으로 켜면서 macOS 세션 회귀 범위와 Mod 단축키의 플랫폼 차이를 테스트에 반영했습니다([#1460](https://github.com/ohah/maru/pull/1460)). 도크 쪽은 빈 도크 진입점을 복원하고([#1445](https://github.com/ohah/maru/pull/1445)), 탭 드래그 계약 문서([#1446](https://github.com/ohah/maru/pull/1446))에 이어 탭 드래그와 포커스 왕복을 구현했으며([#1450](https://github.com/ohah/maru/pull/1450)), pane 외곽 포커스 경계를 정의하고 보더로 표시했습니다([#1458](https://github.com/ohah/maru/pull/1458), [#1459](https://github.com/ohah/maru/pull/1459)).

에이전트 쪽은 터미널 관측 상태 모델을 문서로 정의하고([#1447](https://github.com/ohah/maru/pull/1447)) 판정 로직을 구현했으며([#1448](https://github.com/ohah/maru/pull/1448)), 포그라운드 그룹과 화면 상태 판정을 보강했습니다([#1453](https://github.com/ohah/maru/pull/1453)). 훅과 세션 복원 경로를 정리하면서 cleanup의 원자적 생성 경로를 고쳤고([#1449](https://github.com/ohah/maru/pull/1449)), 상태 관측과 훅 정리의 안전성도 높였습니다([#1451](https://github.com/ohah/maru/pull/1451)). 워크스페이스는 마지막 pane을 다른 워크스페이스에 합칠 때 빈 원본 워크스페이스를 지우고 pane과 surface를 재시작 없이 옮기도록 해, 단독 pane도 합칠 수 있게 됐습니다([#1455](https://github.com/ohah/maru/pull/1455)).

zntc는 `--preserve-modules` 결함 수정을 이어 가며, 건마다 리뷰 지적을 별도 커밋으로 반영했습니다. React Native 다운레벨 class 헬퍼 이중 선언([#4578](https://github.com/ohah/zntc/pull/4578)), 동명 `export default` 중복 선언 SyntaxError([#4581](https://github.com/ohah/zntc/pull/4581)), CJS default-only 모듈(`module.exports = X`) interop([#4582](https://github.com/ohah/zntc/pull/4582)), minify 시 default import 참조 발산([#4583](https://github.com/ohah/zntc/pull/4583)), CJS 순환에서 function export가 undefined로 잡히던 #4532 증상 4([#4584](https://github.com/ohah/zntc/pull/4584))를 고쳤습니다. 여러 entry가 공유하는 run-before-main 모듈이 common 청크로 갈 때의 결합 형식([#4585](https://github.com/ohah/zntc/pull/4585))과 `--minify`에서 그 wrapper 이름이 어긋나던 문제([#4588](https://github.com/ohah/zntc/pull/4588))도 수정한 뒤 v0.1.4를 릴리스했고([#4589](https://github.com/ohah/zntc/pull/4589)), 릴리스 잡의 `bun.lock` 동기화 push가 pre-push 훅에서 막히던 문제를 고쳤습니다([#4590](https://github.com/ohah/zntc/pull/4590)). ohah.github.io에는 메타데이터 동기화와 문서 커밋 16개가 있었습니다.
