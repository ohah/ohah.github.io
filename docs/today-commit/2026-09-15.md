# 2026-09-15

## 요약 (AI 작성)

성능을 진단으로 판 날입니다. 리더가 청크 경계마다 메인에게 코어 락 차례를 넘겨 불공정 mutex 기아로 11~20Hz 로 떨어지던 폭포를 55Hz 로 올렸고, 빈 출력 신호는 코어 락 없이 지나가게 해 전체 잠금의 60% 를 없앴으며(P4-3 진단, §12.9), kitty 이미지 base64·zlib 해제와 f=100 PNG 디코드를 리더가 락 밖에서 하게 해 브라우저 프레임마다 메인이 서던 3~8ms 와 2.9MB PNG 의 락 보유 16~17ms 를 1ms 아래로 내렸습니다. CoreText 는 grid run 캐시로 CTLine 생성을 건너뛰어 split 3 pane 스크롤이 19.5Hz 에서 56Hz 가 됐고, CTLine 비용의 정체(합자 6배·폴백 캐스케이드 run당 약 110µs)는 진단만 하고 착수는 보류했습니다(§10.9). 데몬 할당자의 스택 포획을 꺼 host CPU 를 50% 에서 14% 로 내렸고, host 메모리 누수와 재접속 창 크래시, 죽은 host 의 1.0GB rollback 사본을 daemon 시작에 거두는 것도 이날입니다.

병합 편집기는 세 판의 «대응표» 를 세워 Result 를 따라 굴리고(S3b-M), 고르기 줄을 «판» 으로 옮기고(S3b-3c), 세 판에 caret 이 서며(S3b-3b), 헤더 밴드의 ↓·↑ 와 F7/⇧F7 로 파일 안 다음/이전 충돌 구간을 오갑니다(S5). selection 이 없으면 IME 조합도 받지 않게 해 조합 글자가 Result 첫 줄에 뜨던 자리를 막았습니다. 소스 컨트롤은 마커가 없어진 충돌 행에 «+» 를 되돌리고(S4) 「모두 스테이지」가 마커가 남은 충돌 파일을 비켜 갑니다(S4b). 에이전트 아카이브는 이어하기가 «모델» 도 되살리고 카드의 `<synthetic>` 을 걷었습니다. tmux 안 터미널 브라우저가 화면을 박스 문자로 덮던 것은 세 겹의 원인이었고, 같은 id 재전송 동안 옛 이미지를 완료까지 보여 줍니다.

hwpjs 는 EMF 를 넓혔습니다 — image color management·extended flood fill·bit block transfer·layout mode·alpha blend·parallelogram block transfer·comment envelope, 그리고 EMF+ object·comment 검증과 SETLINKEDUFIS·SETLAYOUT 확장 수용. `@ohah/pdf` 는 겉모습 없는 글상자 주석(/FreeText)과 겉모습 없는 주석을 규격의 기본 모양으로 그립니다. 테스트는 벽시계 단언을 전수 조사해 시간 대신 차례·모양으로 바꿨습니다.
