## 요약 (AI 작성)

maru 파일 패널은 편집 모드 방향을 바꿨습니다. [#1709](https://github.com/ohah/maru/pull/1709)에서 백로그로 두었던 라이브 프리뷰를 폐기로 확정하고 네이티브와 웹 양쪽 구현을 걷어낸 뒤, 읽기·리치·소스 세 모드 가운데 셋째로 리치 편집 모드를 들였습니다. TipTap 3 기반 툴바 편집기를 붙여 네이티브 모드 체계에 `rich`로 편입했고, 이미지 등이 왕복 중 사라지던 데이터 파괴와 리치 편집 결과가 읽기 프리뷰에 반영되지 않던 문제를 고쳤습니다. 마우스 말고는 mode를 바꿀 경로가 없던 문제를 풀어 스모크를 두 모드 왕복으로 재구성했고, macOS app smoke를 전용 HOME으로 격리하고 터미널 테마에서 파생되는 syntax 색을 4층으로 검증했으며, `macos-app-build`가 실행 가능한 앱 번들을 만들도록 고치고 리뷰 결함 13건을 반영했습니다.

[#1710](https://github.com/ohah/maru/pull/1710)에서는 파일 패널에서 고른 부분을 옆 터미널의 에이전트 CLI로 보내는 send-selection 기능을 설계하고, 개행 실행 위험 등을 다루는 페이로드 조립·안전 계약을 순수 모듈로 두었습니다. 같은 PR에서 콘텐츠 영역 UI 스택을 React·Tailwind·shadcn으로 정하고 빌드 기반을 세웠습니다. 문서는 탐색기를 `file-explorer.md`로 분리하고([#1700](https://github.com/ohah/maru/pull/1700)), 폐기된 도크 구현 서술을 걷어냈으며([#1699](https://github.com/ohah/maru/pull/1699)), 구현이 끝난 절의 상태 표기를 코드와 맞추고 PR 라벨 규율을 명문화했습니다([#1697](https://github.com/ohah/maru/pull/1697)).

session-host는 외부 RX 경로의 권위와 소유권을 닫는 작업을 이어 갔습니다. non-adopted verdict를 같은 prepare 호출에서 확정하고([#1693](https://github.com/ohah/maru/pull/1693)), owner lifecycle gate 순서를 재설계했으며([#1694](https://github.com/ohah/maru/pull/1694)), teardown 권위를 callback 전에 동결하는 설계와 구현([#1695](https://github.com/ohah/maru/pull/1695), [#1696](https://github.com/ohah/maru/pull/1696)), owner event projection 계약과 구현([#1698](https://github.com/ohah/maru/pull/1698), [#1701](https://github.com/ohah/maru/pull/1701))이 병합됐습니다. 이어 RX provenance 계약과 바인딩([#1702](https://github.com/ohah/maru/pull/1702), [#1704](https://github.com/ohah/maru/pull/1704)), bounded demux 계약([#1705](https://github.com/ohah/maru/pull/1705)), sealed external RX 분류기([#1706](https://github.com/ohah/maru/pull/1706)), buffered RX turn 계약과 권위 봉인([#1707](https://github.com/ohah/maru/pull/1707), [#1708](https://github.com/ohah/maru/pull/1708)), atomic live RX ledger batch([#1711](https://github.com/ohah/maru/pull/1711)), persistent buffered live owner([#1712](https://github.com/ohah/maru/pull/1712)), classified RX intent scratch([#1713](https://github.com/ohah/maru/pull/1713)), aggregate ledger commit과 destination ownership 봉인([#1714](https://github.com/ohah/maru/pull/1714), [#1716](https://github.com/ohah/maru/pull/1716))까지 이어졌습니다. host-backed Term에서 ⌘F 하이라이트가 화면 좌표와 어긋나 이전 표시가 남던 문제도 고쳤습니다([#1703](https://github.com/ohah/maru/pull/1703)).

zntc는 `splitting:false`에서 동적 `import()`가 인라인도 청크 분리도 진단도 없이 원문 그대로 나가던 문제를 단일 권위 지점에서 인라인을 강제해 막았고([#4597](https://github.com/ohah/zntc/pull/4597)), JSX namespace 멤버가 합성 import span 오염으로 미선언 식별자가 되던 문제를 고치는 PR [#4601](https://github.com/ohah/zntc/pull/4601)이 열렸습니다. 외부 기여로는 2025년 10월에 올렸던 microsoft/vscode의 file-found Badge 세로 정렬 수정 [#273098](https://github.com/microsoft/vscode/pull/273098)이 이날 병합됐습니다.

공개 커밋 45개, 해당일 생성 또는 병합된 PR 26개를 정리했습니다. PR 생성 25개·병합 25개는 같은 PR이 양쪽에 포함될 수 있습니다.
