## 요약 (AI 작성)

zntc는 0.1.0 공개를 앞두고 문서와 배포 준비에 많은 시간을 썼습니다. 퍼블리시 대상 16개 패키지에 저자·저장소·키워드·Node 엔진 메타데이터와 LICENSE를 넣고 오류 코드 문서를 한국어·영어 양쪽으로 생성하는 0.1.0 준비 커밋([#3058](https://github.com/ohah/zntc/pull/3058))과 lockstep 버전 전략 문서([#3060](https://github.com/ohah/zntc/pull/3060))가 병합됐습니다. 실제 퍼블리시나 태그 기록은 이날 목록에 없습니다. 문서 사이트에는 번들 성능 벤치마크 차트([#2992](https://github.com/ohah/zntc/pull/2992))와 10·1000·5000 모듈 재측정, native-transforms 가이드, JS·NAPI 플러그인 개발 가이드([#3019](https://github.com/ohah/zntc/pull/3019)), 로드맵·Electron 가이드, React Native·Expo 레시피, `zntc-init` 모드별 가이드, HTTPS dev server·Web Worker 가이드가 추가됐고, 한국어 문서 종결어미를 합쇼체로 통일했습니다([#3020](https://github.com/ohah/zntc/pull/3020)). 문서에만 있고 CLI에는 없던 `--dev`·`--polyfill`·`--watch-folder` 등 7개 플래그는 실제 CLI에 연결했습니다([#3080](https://github.com/ohah/zntc/pull/3080)).

기능으로는 Vite plugin-react와 같은 경로 필터를 react-refresh에 넣었고([#3003](https://github.com/ohah/zntc/pull/3003)), `index.html` 안의 EJS 스타일 `ZNTC_*` 환경 변수 토큰 치환([#3010](https://github.com/ohah/zntc/pull/3010)), MetafileAnalyzer의 Treemap·Import graph 시각화([#3009](https://github.com/ohah/zntc/pull/3009)), `zntc-init`의 vite·rspack overlay와 web scaffold 모드([#3018](https://github.com/ohah/zntc/pull/3018)), vite plugin의 virtual module ID와 쿼리 파라미터 sub-import([#3023](https://github.com/ohah/zntc/pull/3023)), esbuild와 같은 모양의 `OutputFile`([#3035](https://github.com/ohah/zntc/pull/3035)), `jsx: 'preserve'` 모드([#3057](https://github.com/ohah/zntc/pull/3057)), `--external:pkg` 별칭([#2995](https://github.com/ohah/zntc/pull/2995))이 추가됐습니다. e2e에는 라이브러리 39개를 9개 시나리오의 작은 앱으로 묶어 검증하는 호환성 매트릭스가 생겼습니다([#3065](https://github.com/ohah/zntc/pull/3065)). 소스맵 `names` 배열 발행([#2989](https://github.com/ohah/zntc/pull/2989))과 전날 열린 가이드 보강 PR도 이날 병합됐습니다.

수정 사항은 manualChunks vendor 청크의 namespace가 entry preamble로 새던 문제([#2991](https://github.com/ohah/zntc/pull/2991)), UMD·AMD globals 매핑 회귀([#2994](https://github.com/ohah/zntc/pull/2994), [#3001](https://github.com/ohah/zntc/pull/3001)), Node에서 WASM `init()` 기본 호출이 깨지던 문제([#3006](https://github.com/ohah/zntc/pull/3006)), writer-edge 판정이 함수 본문 안의 쓰기까지 잡던 회귀([#3016](https://github.com/ohah/zntc/pull/3016)), vite 4 이상 hook 객체 호환([#3017](https://github.com/ohah/zntc/pull/3017)), import specifier 문자열 이스케이프([#3029](https://github.com/ohah/zntc/pull/3029)), CSS 번들 같은 asset 출력이 dist에 써지지 않던 문제([#3030](https://github.com/ohah/zntc/pull/3030)), return·throw 뒤 ASI 위험([#3059](https://github.com/ohah/zntc/pull/3059)) 등입니다. JSX 런타임은 linker의 synthetic 우회를 없애고 transformer가 정식 AST 노드를 만들게 한 뒤 헬퍼 스코프를 격리했으며([#3067](https://github.com/ohah/zntc/pull/3067), [#3071](https://github.com/ohah/zntc/pull/3071)), 이어 `ImportBinding.isSynthetic`을 `is_helper`로 완전히 대체했습니다([#3084](https://github.com/ohah/zntc/pull/3084)). 성능 쪽은 디렉터리 단위 realpath 캐시와 새 빌드의 fstat 생략([#3039](https://github.com/ohah/zntc/pull/3039), [#3050](https://github.com/ohah/zntc/pull/3050))이 들어갔고, tree-shake 대형 테스트 파일도 주제별로 나눴습니다.

블로그 저장소 ohah.github.io에는 zntc 개발기 3-15부터 3-17까지(4월 24일부터 5월 12일 범위)를 추가하고 배경 타임라인을 늘린 뒤 커밋 수 수치를 정정한 커밋, 오늘의 커밋 `_meta.json` 누락 항목 보충, 요약 갱신과 맞춤법 교정, 크론 점검 표시 커밋이 있었습니다.

공개 커밋 109개, 해당일 생성 또는 병합된 PR 85개를 정리했습니다. PR 생성 82개·병합 85개는 같은 PR이 양쪽에 포함될 수 있습니다.
