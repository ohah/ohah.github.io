## 요약 (AI 작성)

maru는 한글 조합 중 글자가 셸이 그린 자동완성 고스트를 옆으로 밀어 화면에 남기던 문제를, 조합 중 글자를 삽입형 대신 오버레이로 그려 고스트를 가리는 방식으로 고쳤고, 오버레이가 넓은 글자를 반만 덮을 때의 경계도 정리했습니다([#1105](https://github.com/ohah/maru/pull/1105)). 사이드바 카드는 맨 앞 칸을 동작·활성 표시(·, *) 전용으로 두고 고정 핀 📌을 이름 줄 오른쪽 끝으로 옮겼습니다([#1107](https://github.com/ohah/maru/pull/1107)). 같은 내용의 앞선 PR [#1106](https://github.com/ohah/maru/pull/1106)은 병합되지 않고 닫혔습니다. JetBrains Mono에 더해 Fira Code·Cascadia Code·Hack을 라이선스 문서와 함께 번들했고([#1108](https://github.com/ohah/maru/pull/1108)), 세팅의 `font.family`를 ←→로 번들 폰트를 고르고 직접 입력도 할 수 있는 피커로 바꿨습니다([#1109](https://github.com/ohah/maru/pull/1109)).

공개 커밋 5개, 해당일 생성 또는 병합된 PR 5개를 정리했습니다. PR 생성 5개·병합 4개는 같은 PR이 양쪽에 포함될 수 있습니다.
