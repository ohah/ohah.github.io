## 요약 (AI 작성)

react-wasm-table은 이날도 PR 12개를 병합했습니다. 왼쪽·오른쪽 열 고정과 영역별로 잘라 그리는 고정 열 렌더링([#30](https://github.com/ohah/react-wasm-table/pull/30)), TSV·CSV·HTML 복사와 `Cmd+V` 붙여넣기 콜백, WASM 보기 인덱스를 ref로 넘기는 지연 행 모델([#31](https://github.com/ohah/react-wasm-table/pull/31)), 헤더를 끌어 열 순서를 바꾸는 드래그 앤 드롭과 위·아래 행 고정([#32](https://github.com/ohah/react-wasm-table/pull/32))을 차례로 넣었습니다. 열 순서가 바뀌어도 셀을 찾을 수 있게 문자열 테이블은 열 ID로 조회하도록 바꿨습니다.

셀 안 레이아웃 쪽은 캔버스용 `Flex`·`Text`·`Badge` 컴포넌트와 데모 페이지를 추가하고([#33](https://github.com/ohah/react-wasm-table/pull/33)), 패딩·테두리·배경을 갖는 `Box`와 `Stack` 컴포넌트, Rust Taffy로 셀 안 Flex·Box·Stack 배치를 계산하는 `compute_composite_layout`을 넣었습니다([#34](https://github.com/ohah/react-wasm-table/pull/34)). 셀 렌더러는 컴포넌트별 파일로 나눴고([#35](https://github.com/ohah/react-wasm-table/pull/35)), 내장 렌더러에 stack을 등록했으며([#38](https://github.com/ohah/react-wasm-table/pull/38)), 마지막에 렌더러 디렉터리 구조를 다시 정리했습니다([#40](https://github.com/ohah/react-wasm-table/pull/40)). 클릭 위치를 판별하는 컨텍스트 메뉴 이벤트도 추가했습니다([#36](https://github.com/ohah/react-wasm-table/pull/36)).

API 면에서는 `useReactTable`·`flexRender`와 `Table`·`Thead`·`Tbody` 구조를 해석하는 `parseTableChildren` 등 TanStack 스타일 Table API를 공개하고([#37](https://github.com/ohah/react-wasm-table/pull/37)), `InstructionBuilder`를 없애 렌더 루프가 `cellDef`로 셀을 그리게 하면서 TanStack 데모 섹션을 추가했습니다([#39](https://github.com/ohah/react-wasm-table/pull/39)). 보이는 범위만 담는 가상 행 모델과 내보내기용 `getTotalRowModel`, 브라우저 스크롤 높이 한계를 피하려고 스크롤바를 1천만 px로 제한하는 수정은 [#41](https://github.com/ohah/react-wasm-table/pull/41)로 들어왔습니다. e2e 워크플로는 임시로 껐습니다.

ssh-agent-web 저장소가 이날 시작됐습니다. PTY를 띄워 `/terminal`과 `/terminal/agok` 경로로 제공하는 Bun WebSocket 터미널 서버와, xterm으로 접속하는 반응형 React 웹 앱, SSH 포트 포워딩 사용법을 담은 README로 구성했습니다. cheolsu-proxy는 pnpm과 prettier를 bun과 oxfmt·oxlint로 바꾸고 mise 설정과 `AGENTS.md`를 추가했으며([#53](https://github.com/ohah/cheolsu-proxy/pull/53), [#54](https://github.com/ohah/cheolsu-proxy/pull/54)), 문서 폴더를 `document`로 옮기고 Rspress 2.0.3과 SSG로 CI를 고친 뒤([#55](https://github.com/ohah/cheolsu-proxy/pull/55)) Pages 배포 워크플로를 되살렸습니다([#56](https://github.com/ohah/cheolsu-proxy/pull/56)). react-native-mcp는 모노레포 루트에서 `init`을 실행하면 작업 공간 안의 RN 앱을 찾아 설정하고 패키지를 `package.json`에 추가하도록 했습니다([#107](https://github.com/ohah/react-native-mcp/pull/107)).
