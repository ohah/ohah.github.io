## 요약 (AI 작성)

maru는 이날 PR 19개를 모두 main에 병합했습니다. SSH 원격에서 Sync를 쓰는 TUI의 색·셀렉터가 깨지는 미해결 문제를 좁히려고 `.sync` 로거에 리더 측 BSU 카운터를 더하고([#1154](https://github.com/ohah/maru/pull/1154)), SSH가 시퀀스를 쪼개 파서가 오파싱한다는 가설을 헤드리스 테스트로 반증한 뒤 로그 분석기를 추가했으며([#1155](https://github.com/ohah/maru/pull/1155)), 분석기의 오분류 8건을 고치고 게이트 이유를 로그에 실측하게 했습니다([#1156](https://github.com/ohah/maru/pull/1156)). 다른 탭의 에이전트 스피너가 멈추거나 느려지던 문제는 tick 단계별 시간 계측([#1157](https://github.com/ohah/maru/pull/1157))으로 원인을 가른 뒤, 연속 출력 중 스피너 진행이 굶던 경로를 분리하고([#1158](https://github.com/ohah/maru/pull/1158)) 위상을 실제 경과 시간 기반으로 바꿔 고쳤습니다([#1159](https://github.com/ohah/maru/pull/1159)).

같은 문제의 근본인 tick당 잦은 코어 lock 경합을 줄이기 위해 렌더 read 스냅샷 통합 설계(Phase 4)를 문서로 정리하고([#1160](https://github.com/ohah/maru/pull/1160)), 제목·cwd가 바뀐 Term만 lock하는 title generation([#1161](https://github.com/ohah/maru/pull/1161))과 활성 코어의 sync·blink 상태를 한 번의 lock으로 읽는 `CoreSnapshot`([#1163](https://github.com/ohah/maru/pull/1163))을 넣었습니다. 에이전트 세션 매핑은 가리키던 transcript가 지워지면 스스로 정리하고 상태를 리셋하게 했고([#1164](https://github.com/ohah/maru/pull/1164)), 여러 maru 인스턴스가 공유하는 매핑 디렉터리를 시작 시 통째로 지워 다른 창의 상태줄이 사라지던 문제는 오래된 항목만 정리하는 방식으로 바꿨습니다([#1165](https://github.com/ohah/maru/pull/1165)).

설정 화면은 크게 바뀌었습니다. ←는 섹션 목록, →는 폼으로 포커스를 옮기는 방향키 영역 모델, 숫자 값의 입력 박스, enum·폰트·테마 프리셋의 드롭다운 팝업과 ↑↓ 라이브 미리보기·Esc 원복이 들어가고 죽은 슬라이더 코드는 삭제됐습니다([#1169](https://github.com/ohah/maru/pull/1169)). 이 과정에서 미리보기 취소가 커스텀 폰트·테마를 덮어쓰거나 파일에까지 반영하던 데이터 손실을 리뷰로 잡아 고쳤고, 검색 중 열린 드롭다운이 ↑↓를 놓치던 버그 수정과 검색 중 팔레트 셀 이동이 이어졌습니다([#1171](https://github.com/ohah/maru/pull/1171), [#1172](https://github.com/ohah/maru/pull/1172)). 그 밖에 dark-pink 테마 프리셋([#1162](https://github.com/ohah/maru/pull/1162))과 테마별 탭 accent 색([#1166](https://github.com/ohah/maru/pull/1166))이 추가됐고, 퀵 터미널 설정이 첫 토글 때 굳어 버리던 문제와 멀티모니터 주 디스플레이 판정을 고쳤습니다([#1168](https://github.com/ohah/maru/pull/1168)).

ohah.github.io에는 오늘의 커밋 요약 문서 커밋 2개가 있었습니다.

공개 커밋 34개, 해당일 생성 또는 병합된 PR 19개를 정리했습니다. PR 생성 19개·병합 19개는 같은 PR이 양쪽에 포함될 수 있습니다.
