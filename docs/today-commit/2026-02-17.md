## 요약 (AI 작성)

react-native-mcp는 E2E를 Bun 스모크 테스트에서 YAML 러너만 쓰는 방식으로 옮겼습니다. 앱이 서버보다 먼저 떠 연결이 끊기던 순서 문제를 바로잡고, 같은 `bundleId`의 중복 실행을 건너뛰며, `--no-auto-launch` 옵션과 전체 35단계 `all-steps` YAML, 앱 빌드 캐시를 추가했습니다. 문서 사이트는 testing·mcp 섹션으로 재구성하고 로고를 바꿨으며, 이를 묶은 [#32](https://github.com/ohah/react-native-mcp/pull/32)를 병합했습니다. `cdp-interceptor`는 이날 제거했습니다.

셀렉터에는 `:first`·`:last`·`:display-name`을 넣었다가 인덱스 문법을 CSS와 비슷한 `:nth-of-type`·`:first-of-type`·`:last-of-type`으로 바꿨고, 스와이프는 `duration`과 퍼센트 거리를 지원하게 했습니다. iOS 가로 모드에서 좌표를 바꿔 idb에 넘기는 방향별 변환과 탭·스와이프의 뷰포트 클램핑([#34](https://github.com/ohah/react-native-mcp/pull/34)), 앱과 서버 사이 30초 ping과 60초 무응답 연결 정리, 실패한 스텝 뒤의 건너뛴 스텝이 통과로 집계되던 `RunResult` 수정([#35](https://github.com/ohah/react-native-mcp/pull/35))을 병합했습니다. 라벨 없는 누름 요소 등을 찾는 `accessibility_audit`([#36](https://github.com/ohah/react-native-mcp/pull/36)), 컴포넌트 상태를 보는 `inspect_state`·`get_state_changes`([#37](https://github.com/ohah/react-native-mcp/pull/37))도 추가했습니다.

ohah.github.io에서는 맞춤법 크론 가이드를 추가하고, 크론이 홈과 월간 오픈소스 첫 페이지, Craby·Chromium 배경 글, CRD 배경과 development 문서들을 차례로 점검해 오탈자를 고쳤습니다. 2월 17일 요약도 올렸습니다.

공개 커밋 73개, 해당일 생성 또는 병합된 PR 5개를 정리했습니다. PR 생성 4개·병합 5개는 같은 PR이 양쪽에 포함될 수 있습니다.
