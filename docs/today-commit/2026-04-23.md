# 2026-04-23

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 Expo Router에 필요한 `require.context`를 단계별로 구현했습니다. AST에서 호출을 찾아 리터럴 인자를 평가하고([#1770](https://github.com/ohah/zntc/pull/1770)), 정규식 매칭은 호스트 런타임에 맡기는 플러그인 hook과 그래프 처리([#1772](https://github.com/ohah/zntc/pull/1772)), 이를 JS 플러그인 `onResolveContext`로 여는 NAPI 브리지([#1773](https://github.com/ohah/zntc/pull/1773)), `process.env.X` 인자를 define 표로 평가하는 처리([#1774](https://github.com/ohah/zntc/pull/1774))를 거쳐, Metro의 sync 모드를 따라 webpackContext IIFE로 출력합니다([#1775](https://github.com/ohah/zntc/pull/1775)). `__esm` 래핑 모듈에서도 이 IIFE가 나오도록 import record를 넘기는 수정([#1777](https://github.com/ohah/zntc/pull/1777))이 뒤따랐고, 매칭 결과를 그래프 의존성으로 넣는 다음 단계 [#1778](https://github.com/ohah/zntc/pull/1778)은 닫혔습니다. TS 객체 타입 리터럴의 계산된 프로퍼티 키를 index signature와 구분하도록 TS 공식 파서 로직을 옮겼고([#1768](https://github.com/ohah/zntc/pull/1768)), 식별자가 아닌 JSX 속성 이름은 문자열 키로 낮춥니다([#1776](https://github.com/ohah/zntc/pull/1776)).

번들러 내부에서는 ModuleGraph의 모듈 저장소 접근을 단계 태그가 붙은 accessor로 감싸고 `[]Module` 슬라이스 API를 없앤 뒤, 저장소를 `std.SegmentedList`로 바꿔 worker 경합에서도 주소가 안정되게 했습니다([#1780](https://github.com/ohah/zntc/pull/1780)~[#1784](https://github.com/ohah/zntc/pull/1784)). 이렇게 정한 ModuleGraph 불변식은 문서로 남겼습니다([#1785](https://github.com/ohah/zntc/pull/1785)).

bungae는 `onResolveContext` 플러그인과 Expo Router define 항목으로 `require.context`를 지원하고([#70](https://github.com/ohah/bungae/pull/70)), Expo 예제를 `bungae:start:expo`로 실행하게 설정하면서 dev 서버 포트를 ExampleApp과 같은 8081로 맞췄습니다([#71](https://github.com/ohah/bungae/pull/71), [#72](https://github.com/ohah/bungae/pull/72)). ohah.github.io에는 맞춤법 크론이 cheolsu-proxy 개발기와 craby 문서 등의 맞춤법을 고친 커밋과 4월 21일 오늘의 커밋 메타 갱신이 올라왔습니다.

공개 커밋 50개, 해당일 생성 또는 병합된 PR 18개를 정리했습니다. PR 생성 18개·병합 17개는 같은 PR이 양쪽에 포함될 수 있습니다.
