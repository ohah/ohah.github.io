## 요약 (AI 작성)

chrome-remote-devtools는 TypeScript WebSocket 서버를 Rust로 옮겨 Tauri 앱에 넣는 [#70](https://github.com/ohah/chrome-remote-devtools/pull/70)을 병합했습니다. `crates/server` 크레이트에 axum 기반 HTTP 엔드포인트, 로그 수준과 CDP 메서드 필터를 갖춘 로깅, 압축 해제를 포함한 WebSocket 메시지 라우팅, Redux 스토어 상태를 캐시하는 React Native Inspector 연결 관리를 구현했습니다. DevTools가 연결되면 저장된 Storage·SessionReplay 이벤트를 다시 요청하고, 개발 모드에서만 동작하는 `/client.js` 엔드포인트를 두었습니다. rustls와 OpenSSL로 TLS를 지원했다가 OpenSSL을 빼고 rustls만 남겼고, `bun dev` 스크립트와 Tauri 앱이 Rust 서버를 쓰도록 바꾸면서 TypeScript 서버에는 deprecated 표시를 달았습니다. React Native inspector의 WebSocket 경로도 `/remote/debug/inspector/device`로 바꿨습니다.

이어 947줄짜리 `socket_server.rs`를 메시지 처리·클라이언트·DevTools 처리 모듈로 나누고 타입 파일을 재정리한 [#71](https://github.com/ohah/chrome-remote-devtools/pull/71)을 병합했습니다. 저녁에는 inspector UI를 정리한 [#72](https://github.com/ohah/chrome-remote-devtools/pull/72)를 병합했습니다. 웹과 React Native로 나뉘었던 라우트를 하나로 합치고 필터 체크박스로 클라이언트를 고르게 했으며, 아이콘을 lucide-react로 바꾸고 shadcn/ui Button·Tooltip을 들였습니다. DevTools iframe마다 무작위 인스턴스 접두사를 붙여 localStorage를 분리하고, 탭 표시 토글을 추가했으며, Tauri 창 최소 크기를 1024x768로 정했습니다.

공개 커밋 36개, 해당일 생성 또는 병합된 PR 3개를 정리했습니다. PR 생성 3개·병합 3개는 같은 PR이 양쪽에 포함될 수 있습니다.
