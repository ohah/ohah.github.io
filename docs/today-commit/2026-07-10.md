# 2026-07-10

## 요약 (AI 작성)

Phase 5 — 브라우저 제어 코어와 `maru-app://` 신뢰 서빙 — 을 통째로 끝낸 날입니다. 5a 에서 `browser.*` 스키마·디스패치·authz 를 헤드리스로 세운 뒤, 5c-1 경로 샌드박스와 CSP 를 L2 순수 보안 코어로 놓고 5c-2 를 a(realpath 로 symlink 탈출을 막는 asset resolve 보안 코어) → b(C-ABI export 로 Swift 핸들러 브리지) → c(`WKURLSchemeHandler` + 트러스트 분기) 순으로 쌓았습니다. 신뢰 웹 브리지도 5b-1 디스패치 코어(`control_bridge`) 위에 5b-2 Swift 배선(isolated world + origin 검증 + 격리 E2E)을 얹었고, 5d 에서 실 `WKWebView` API 로 `browser.*` 제어 코어와 fixture E2E(BrowserControl)를 완성했습니다. 그 사이 10·11·12차 `/code-review max` 가 짚은 결함(active_term remap 회귀와 CSP doc-sync, 신뢰 서빙 경로 6건, 브리지·서빙·fixture 5건)을 차례로 반영했습니다.

같은 날 인앱 브라우저 UI(7e)도 첫 삽을 떴습니다. 7e-0 에서 ephemeral `WKWebsiteDataStore` 로 untrusted 데이터를 격리하고, 7e-1a 로 Swift KVO → Zig per-surface 저장을 잇는 nav 상태 파이프라인을 놓은 뒤, 7e-1b 읽기전용 주소창 밴드를 Zig GPU 셀로 렌더했습니다. 이어 7e-2a 로 주소창 편집 모드의 Zig 코어(상태·스킴 정책·라우팅·렌더)를 만들고, 7e-2b Swift 배선(포커스 전이 + navigate)이 PR 로 머지되면서 실제 브라우징이 동작하기 시작했습니다.

웹 Term 쪽 마무리와 버그 수정도 함께 있었습니다. 4e 9차 리뷰 결함 9건(web Term 공유 소비자 kind 분기)을 정리하고 4e-5 로 웹 브라우저 탭 생성을 command 화(`new_web_tab`, env 훅 승격)했습니다. 웹 패널 divider 는 seam 노출 회귀를 고치면서 시각 gap 과 grab 폭을 분리해 hitTest 가 통과하도록 손봤고, hover resize 커서 미표시는 알려진 한계로 문서에 남겼습니다. 그 밖에 `read_error` 를 검증 없이 종료로 처리해 살아 있는 셸을 죽이고 좌측 탭이 닫히던 pty 버그를 잡았습니다. 블로그 저장소에는 monthly-opensource 의 electron-mcp-server 문서 갱신이 있었습니다.
