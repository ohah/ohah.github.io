## 요약 (AI 작성)

hwpjs는 렌더링 수정 PR 여덟 개를 main에 병합했습니다. 쪽 단위·글상자·표 셀·인라인 콘텐츠를 아우르는 다단 렌더링([#94](https://github.com/ohah/hwpjs/pull/94))과 도형 위치 정보를 호출 경로로 넘겨 절대 위치와 내용을 바로 그리는 수정([#96](https://github.com/ohah/hwpjs/pull/96))으로 시작해, 번호 문단의 `NumberType` 파싱과 HTML 표시([#98](https://github.com/ohah/hwpjs/pull/98)), Wingdings PUA 글머리표 매핑과 폭·여백 수정([#99](https://github.com/ohah/hwpjs/pull/99))이 들어왔습니다. 저녁에는 `DrawingObjectCommon`을 파싱해 도형의 채우기·선을 그리고([#101](https://github.com/ohah/hwpjs/pull/101)), 쪽 번호 위치 레코드에서 번호 필드가 빠져 기호·접두·접미가 밀려 읽히던 문제를 고쳤습니다([#102](https://github.com/ohah/hwpjs/pull/102)).

이어 다단 구역 사이의 쪽 나눔을 `column_divide_type`의 쪽 플래그로 판단하고 단 구분선을 그리며, 표 셀 다단의 높이·행 위치와 이중 아래 테두리, 인라인 도형·표 위치를 바로잡았습니다([#103](https://github.com/ohah/hwpjs/pull/103)). 들여쓰기·내어쓰기의 `padding-left`를 `outdent`가 아닌 `ParaShape.indent`로 계산하도록 바꾸고 분석 문서와 스냅숏을 갱신했습니다([#104](https://github.com/ohah/hwpjs/pull/104)). [#95](https://github.com/ohah/hwpjs/pull/95)와 [#97](https://github.com/ohah/hwpjs/pull/97)은 병합 없이 닫혔습니다.

react-wasm-table은 twoslash 예제를 오류 없이 돌리는 문서 수정([#56](https://github.com/ohah/react-wasm-table/pull/56))을 병합한 뒤, 캔버스 컴포넌트에 `onClick`·`onDoubleClick` 같은 DOM식 이벤트 핸들러를 붙이고 Color·Tag·Rating·Chip·Link 렌더러를 정식 목록에 올렸습니다([#57](https://github.com/ohah/react-wasm-table/pull/57)). 낡은 계획 문서 정리([#58](https://github.com/ohah/react-wasm-table/pull/58)), `drawImage`로 그리는 Image 컴포넌트([#59](https://github.com/ohah/react-wasm-table/pull/59)), CSS transition 속성을 쓰는 Switch 토글 애니메이션([#60](https://github.com/ohah/react-wasm-table/pull/60))도 병합됐습니다.

ohah.github.io에는 크론의 `CRON_CRD_WRITE.md` 상태 갱신 커밋이 15개 남았고, 그중 `docs/index.mdx` 점검 표시와 이날 활동 요약 추가가 포함됩니다.

공개 커밋 44개, 해당일 생성 또는 병합된 PR 15개를 정리했습니다. PR 생성 13개·병합 13개는 같은 PR이 양쪽에 포함될 수 있습니다.
