## 요약 (AI 작성)

react-native-mcp는 하루 동안 PR 아홉 개를 병합하며 도구를 크게 늘렸습니다. Fiber 트리에서 `onPress`와 텍스트를 찾아 누르는 `click_by_label`·`click`·`list_clickables`와 `get_debugger_status`를 추가하고 데모 앱을 넓혔으며([#12](https://github.com/ohah/react-native-mcp/pull/12)), 앱 세션 요청·응답 구조와 `take_snapshot`·`list_text_nodes`를 넣었습니다([#13](https://github.com/ohah/react-native-mcp/pull/13)). Babel로 ScrollView ref를 주입하는 `scroll`과 `list_clickable_text_content`, 앱 연결 트러블슈팅 문서가 [#15](https://github.com/ohah/react-native-mcp/pull/15)로 들어왔고, 릴리스 빌드에서 DevTools hook이 없을 때 직접 설치하는 런타임 개선과 npm 배포 워크플로 정리는 [#16](https://github.com/ohah/react-native-mcp/pull/16)으로 병합됐습니다.

Metro transformer 대신 쓸 수 있는 Babel 플러그인·프리셋을 추가하고([#17](https://github.com/ohah/react-native-mcp/pull/17)), Metro CDP에 직접 연결해 `deviceId`·`platform`으로 여러 기기를 구분하게 했으며, testID가 문자열이 아닌 표현식이어도 핸들러를 등록하도록 고쳤습니다([#18](https://github.com/ohah/react-native-mcp/pull/18), [#19](https://github.com/ohah/react-native-mcp/pull/19)). WebSocket 서버는 여러 연결을 받아 `ios-1`·`android-1` 같은 ID를 붙이고, 앞서 지웠던 Fiber 도우미와 DevTools hook 주입을 되살렸습니다([#20](https://github.com/ohah/react-native-mcp/pull/20)). Fiber 트리용 CSS 유사 셀렉터인 `query_selector`·`query_selector_all`, `long_press`·`type_text`·`assert` 도구와 Input·Press 데모 화면도 추가했습니다([#22](https://github.com/ohah/react-native-mcp/pull/22)). 한편 `get_metro_url`과 CDP 이벤트 HTTP 조회는 제거했고, 콘솔·네트워크 도구는 주석으로 비활성화해 두었다가 이를 다시 등록하는 [#23](https://github.com/ohah/react-native-mcp/pull/23)이 이날 열렸습니다. E2E 테스트 러너 계획 문서도 추가했습니다.

hwpjs는 `PARA_TEXT` 처리와 단순 레코드 파싱을 도우미 함수로 뽑아냈고, `parse_cell_list` 같은 쓰이지 않는 함수와 `dead_code` 허용 표시를 정리했습니다. ohah.github.io는 CRD 기술 스택 문서의 가독성과 맞춤법을 다듬고 2월 14일 요약을 추가했습니다.

공개 커밋 64개, 해당일 생성 또는 병합된 PR 10개를 정리했습니다. PR 생성 10개·병합 9개는 같은 PR이 양쪽에 포함될 수 있습니다.
