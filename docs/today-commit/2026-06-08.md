> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 오전에 frame loop smoke 계약([#129](https://github.com/ohah/maru/pull/129))과 live PTY frame loop smoke([#130](https://github.com/ohah/maru/pull/130))를 만들고 Metal smoke를 이 경로로 옮겼습니다. live PTY 세션 소유권을 한곳으로 모은 뒤([#134](https://github.com/ohah/maru/pull/134)) 닫기를 detach 경계, 앱 호스트, 레지스트리를 거치도록 정리했고([#135](https://github.com/ohah/maru/pull/135), [#137](https://github.com/ohah/maru/pull/137), [#138](https://github.com/ohah/maru/pull/138)), 대화형 shell smoke([#140](https://github.com/ohah/maru/pull/140), [#141](https://github.com/ohah/maru/pull/141))와 닫기 시점의 자식 프로세스 회수([#142](https://github.com/ohah/maru/pull/142)), Metal 창에서의 PTY 닫기와 `keyDown` 캡처 테스트를 더했습니다. 오후에는 macOS Swift 앱 호스트 경계([#148](https://github.com/ohah/maru/pull/148))와 dev shell, dev session 런타임 연결과 이벤트 라우팅([#149](https://github.com/ohah/maru/pull/149)부터 [#151](https://github.com/ohah/maru/pull/151)까지)을 세웠고, 리뷰에서 나온 세션 종료 신호와 이벤트별 치명적 종료 문제를 고쳤습니다([#152](https://github.com/ohah/maru/pull/152)). 저녁에는 dev session이 실제 CoreText glyph frame을 그리고([#155](https://github.com/ohah/maru/pull/155)) 이를 Metal frame ABI로 노출한 뒤([#156](https://github.com/ohah/maru/pull/156)), 셀 셰이더를 공유하는 제품 Metal 렌더러([#158](https://github.com/ohah/maru/pull/158))와 Swift Metal 터미널 뷰([#159](https://github.com/ohah/maru/pull/159))까지 연결했습니다. 이어서 렌더러 경계 보강과 idle 호출 생략([#160](https://github.com/ohah/maru/pull/160), [#161](https://github.com/ohah/maru/pull/161)), 고정 픽셀 크기 셀 배치([#162](https://github.com/ohah/maru/pull/162)), SGR·커서·지우기 VT escape 해석([#163](https://github.com/ohah/maru/pull/163)), resize 때 화면 내용 보존([#164](https://github.com/ohah/maru/pull/164))이 들어왔습니다.

suji는 Electron 패리티 항목을 카테고리별로 마무리했습니다. 전날 열린 `Menu.sendActionToFirstResponder` [#114](https://github.com/ohah/suji/pull/114)를 병합하고 MenuItem 아이콘·`Menu.insert`·메뉴 열림/닫힘 이벤트([#115](https://github.com/ohah/suji/pull/115))로 Menu를 닫았습니다. nativeTheme·nativeImage getter, globalShortcut `registerAll`과 일시 중지, ipc `handleOnce`·`removeAllListeners`, clipboard 북마크·찾기 텍스트·다중 쓰기, tray `getBounds`, notification 그룹과 `Notification` 클래스, powerMonitor 종료·배터리 이벤트, screen 디스플레이 변경 이벤트([#117](https://github.com/ohah/suji/pull/117)부터 [#124](https://github.com/ohah/suji/pull/124)까지)가 들어왔습니다. 이어 WebContentsView 클래스([#125](https://github.com/ohah/suji/pull/125)), webContents `stop`·`insertCSS`([#126](https://github.com/ohah/suji/pull/126)), 다운로드 경로와 `will-download`([#127](https://github.com/ohah/suji/pull/127)), webRequest 응답 헤더와 요청 헤더 설정([#128](https://github.com/ohah/suji/pull/128), [#131](https://github.com/ohah/suji/pull/131)), `before-quit` 이벤트([#129](https://github.com/ohah/suji/pull/129)), 기본 프로토콜 클라이언트 등록([#130](https://github.com/ohah/suji/pull/130)), `setWindowOpenHandler`([#132](https://github.com/ohah/suji/pull/132))를 추가했습니다. SDK wire 계약 테스트와 `before-quit` e2e를 보강했고, 리뷰에서 `before-quit` 때 메인 창이 닫히지 않던 문제 등 5건을 고쳤습니다([#135](https://github.com/ohah/suji/pull/135)).

zntc는 0.1.2 퍼블리시 뒤 생긴 `bun.lock` 차이를 맞추고, 배포되는 7개 패키지에 영어 기본 README와 한국어 링크를 넣었습니다([#4197](https://github.com/ohah/zntc/pull/4197)). 블로그 저장소에는 이날 오늘의 커밋 요약 커밋이 올라갔습니다.

공개 커밋 61개, 해당일 생성 또는 병합된 PR 59개를 정리했습니다. PR 생성 58개·병합 59개는 같은 PR이 양쪽에 포함될 수 있습니다.
