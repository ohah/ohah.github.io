## 요약 (AI 작성)

maru는 스크롤바와 찾기 기능을 다듬으며 시작했습니다. 스크롤바 thumb 드래그([#593](https://github.com/ohah/maru/pull/593)), 굵기·hover 강조·idle fade와 비활성 pane 표시, pane별 독립 fade([#599](https://github.com/ohah/maru/pull/599), [#600](https://github.com/ohah/maru/pull/600), [#603](https://github.com/ohah/maru/pull/603))가 들어왔고, Option+드래그 블록 선택([#594](https://github.com/ohah/maru/pull/594)), 오버레이 없이 다음·이전 매치로 가는 ⌘G / ⌘⇧G([#595](https://github.com/ohah/maru/pull/595)), Latin-1·그리스·키릴 문자 case folding([#601](https://github.com/ohah/maru/pull/601)), alt screen에서 maru 찾기 끄기([#604](https://github.com/ohah/maru/pull/604))를 더했습니다. 메뉴바에 Services·Open Config·Find 항목을 넣고([#596](https://github.com/ohah/maru/pull/596)), 폰트 크기 단계와 절대 크기 지정을 설정으로 열었습니다([#597](https://github.com/ohah/maru/pull/597), [#598](https://github.com/ohah/maru/pull/598)).

오후에는 폰트에 의존하지 않고 직접 그리는 합성 glyph를 넓혔습니다. Block Elements와 box-drawing, 둥근 모서리 arc([#606](https://github.com/ohah/maru/pull/606)부터 [#608](https://github.com/ohah/maru/pull/608)까지)를 넣었는데 보더가 보이지 않는 문제가 생겨, 폰트에 glyph가 없어도 그리고 네이티브 셰이퍼와 GlyphRunList 진입 게이트가 합성 glyph를 버리지 않도록 고쳤습니다([#609](https://github.com/ohah/maru/pull/609), [#610](https://github.com/ohah/maru/pull/610), [#611](https://github.com/ohah/maru/pull/611)). 로고가 흰색으로 보이던 회귀를 추적하려 진단 로그와 토글을 넣었다가 오래된 빌드 탓으로 확인하고 제거했습니다([#614](https://github.com/ohah/maru/pull/614)). 이어 heavy·dashed, double, 혼합 굵기, 대각선, single·double 혼합으로 box-drawing 블록 전체를 채웠고([#615](https://github.com/ohah/maru/pull/615)부터 [#619](https://github.com/ohah/maru/pull/619)까지), Powerline separator([#620](https://github.com/ohah/maru/pull/620)), Braille([#625](https://github.com/ohah/maru/pull/625)), shade, Legacy Computing 모자이크·wedge·smooth mosaic·대각 stroke·hatch, 대각 corner 삼각형, Powerline-extra 사다리꼴([#626](https://github.com/ohah/maru/pull/626)부터 [#634](https://github.com/ohah/maru/pull/634)까지)이 뒤를 이었습니다. 리뷰 후속으로 cache key를 codepoint로 통일하고 공유 픽셀 프리미티브와 dispatch를 정리했습니다([#621](https://github.com/ohah/maru/pull/621), [#623](https://github.com/ohah/maru/pull/623), [#635](https://github.com/ohah/maru/pull/635)).

밤부터는 워크스페이스·Pane·Term에 사용자 지정 이름을 붙이는 기능을 설계 문서([#636](https://github.com/ohah/maru/pull/636))와 함께 구현했습니다. 이름 모델과 영속([#637](https://github.com/ohah/maru/pull/637)), 탭 바의 pane 라벨, 인라인 rename 편집기와 키 액션·커맨드 팔레트([#639](https://github.com/ohah/maru/pull/639)), 더블클릭과 Zig 오버레이 우클릭 메뉴로 시작하기([#641](https://github.com/ohah/maru/pull/641), [#642](https://github.com/ohah/maru/pull/642)), 편집기 caret 깜빡임과 IME 후보창 위치가 들어왔고 리뷰 지적 8건을 고쳤습니다([#644](https://github.com/ohah/maru/pull/644)). 셸을 처음부터 실제 창 크기로 띄워 zsh 첫 프롬프트의 % 잔상을 없앴고([#645](https://github.com/ohah/maru/pull/645)), 코드 전반의 "dev" 이름을 app으로 바꿨으며([#647](https://github.com/ohah/maru/pull/647)), 창 padding([#648](https://github.com/ohah/maru/pull/648)), 사이드바의 git 브랜치 표시([#650](https://github.com/ohah/maru/pull/650)), 우클릭 메뉴의 워크스페이스 고정·배경색([#651](https://github.com/ohah/maru/pull/651)), claude·codex 에이전트 세션 표시([#652](https://github.com/ohah/maru/pull/652))를 추가했습니다.

suji는 웹뷰가 `suji://app/__localfile__` 경로로 로컬 파일을 Range 요청과 함께 받을 수 있게 하고 `allowFileAccess` 옵션과 sqlite `busy_timeout`을 넣었습니다. 영상 전용 `suji-video://` 스킴과 그 CSP·CORS 설정을 추가했고, backends 아래 Mach-O를 재귀적으로 서명해 공증을 통과하게 했습니다. 블로그 저장소에는 오늘의 커밋 요약과 크론 교정 커밋이 올라갔습니다.
