## 요약 (AI 작성)

zntc는 소스 타입 정리로 하루를 시작했습니다. JS 계열 source type을 `ModuleType`으로 통일하고([#2321](https://github.com/ohah/zntc/pull/2321)), 파서의 `is_ts`와 `reject_ts_syntax_in_js`를 `SourceMode` enum으로 합쳤으며([#2322](https://github.com/ohah/zntc/pull/2322)), es2017 대상에서 for-await-of를 다운레벨하도록 고쳤습니다([#2323](https://github.com/ohah/zntc/pull/2323)). 이어 CLI 옵션을 차례로 붙여 `--packages=external`([#2344](https://github.com/ohah/zntc/pull/2344)), `--drop-labels`([#2345](https://github.com/ohah/zntc/pull/2345)), pure call DCE 힌트([#2346](https://github.com/ohah/zntc/pull/2346)), 소스맵 매핑 보정과 함께 `--line-limit` 줄바꿈([#2347](https://github.com/ohah/zntc/pull/2347)), allow-overwrite([#2349](https://github.com/ohah/zntc/pull/2349)), `--tsconfig-raw`([#2350](https://github.com/ohah/zntc/pull/2350))를 지원했습니다. tsconfig는 raw 값과 jsx 병합을 Zig 한 곳에서 처리하도록 옮기고([#2356](https://github.com/ohah/zntc/pull/2356)) NAPI transpile의 자동 탐색을 연결했으며, NAPI에 잘못된 `jsx` 옵션을 주면 조용히 classic으로 떨어지지 않고 오류를 던지게 바꿨습니다([#2370](https://github.com/ohah/zntc/pull/2370)). 플러그인 `closeBundle`을 `watch()`에 연결하는 watch lifecycle hook([#2326](https://github.com/ohah/zntc/pull/2326))과 현재 CLI·config 기준의 문서 정합성 보정([#2328](https://github.com/ohah/zntc/pull/2328))도 들어갔습니다.

같은 날 zntc에는 React Native 컴포넌트 codegen이 새로 쌓였습니다. 스키마 자료구조([#2357](https://github.com/ohah/zntc/pull/2357)), 타입 별칭·인터페이스 인덱서([#2361](https://github.com/ohah/zntc/pull/2361)), `ComponentShape`를 만드는 schema_builder([#2372](https://github.com/ohah/zntc/pull/2372))와 이를 JS 문자열로 내는 view_config_emitter([#2374](https://github.com/ohah/zntc/pull/2374)), 검증기와 ZTS 오류 코드 1400-1499([#2376](https://github.com/ohah/zntc/pull/2376))를 거쳐 codegen 플러그인을 파이프라인과 RN preset에 연결했습니다([#2377](https://github.com/ohah/zntc/pull/2377)). 이후 `codegenTransform` NAPI 옵션을 노출하고([#2378](https://github.com/ohah/zntc/pull/2378)) `WithDefault`, `Array`·`ReadonlyArray`, Flow nullable, `UnsafeMixed`, union, `DirectEventHandler`·`BubblingEventHandler` 인식을 하나씩 더했으며, 파일명 접미사 대신 AST 수준 감지로 대상을 고르게 했습니다([#2391](https://github.com/ohah/zntc/pull/2391)). 파서는 TS property signature와 Flow 객체 본문 멤버를 보존하게 됐고([#2365](https://github.com/ohah/zntc/pull/2365), [#2369](https://github.com/ohah/zntc/pull/2369)), 타입 전용 export 선언이 프로그램에서 빠져 codegen 타입 인덱스가 놓치던 문제를 고쳤습니다([#2384](https://github.com/ohah/zntc/pull/2384)). 저녁에는 Flow enum 문법 인식과 변환([#2405](https://github.com/ohah/zntc/pull/2405), [#2406](https://github.com/ohah/zntc/pull/2406))이 들어왔습니다.

그 밖에 zntc는 binding-lite semantic 경로([#2389](https://github.com/ohah/zntc/pull/2389)), `module_specifier_map` cherry-pick 분할과 `moduleSpecifierMap` NAPI 옵션([#2394](https://github.com/ohah/zntc/pull/2394), [#2395](https://github.com/ohah/zntc/pull/2395))을 추가했습니다. build/watch deinit에서 typed entries·alias·fallback·loader_overrides를 해제하지 않던 문제([#2399](https://github.com/ohah/zntc/pull/2399), [#2400](https://github.com/ohah/zntc/pull/2400), [#2408](https://github.com/ohah/zntc/pull/2408)), es2015 generator 변환의 switch 문 접근 UB([#2404](https://github.com/ohah/zntc/pull/2404)), fs.watch 오류로 dev 서버가 멈추던 문제([#2387](https://github.com/ohah/zntc/pull/2387))도 고쳤고, dev 서버 테스트는 빈 포트를 동적으로 잡도록 바꿨습니다([#2373](https://github.com/ohah/zntc/pull/2373)).

bungae는 `BUNGAE_CODEGEN_NATIVE` 토글로 네이티브 codegen 플러그인을 켜는 경로를 만든 뒤 하이브리드 모드로 바꾸고 `BUNGAE_CODEGEN_FALLBACK=js` 탈출구를 두었습니다([#74](https://github.com/ohah/bungae/pull/74), [#75](https://github.com/ohah/bungae/pull/75), [#76](https://github.com/ohah/bungae/pull/76)). babel decorators와 root-import 플러그인을 ZTS 네이티브로 매핑하고([#77](https://github.com/ohah/bungae/pull/77)) `BUNGAE_BABEL_NATIVE`·`BUNGAE_BABEL_FALLBACK` 토글([#82](https://github.com/ohah/bungae/pull/82))과 공용 `parseToggleEnv` 헬퍼([#83](https://github.com/ohah/bungae/pull/83))로 정리했으며, CI의 서브모듈 체크아웃 수정, 예제 앱의 lodash-es 전환, zts 서브모듈 갱신도 병합했습니다. suji는 Electron과 같은 형태의 `session.cookies` set/get/remove API를 추가했습니다. 외부 저장소 warpdotdev/warp에는 한국어 IME에서 마지막 음절이 사라지는 문제를 고치는 PR [#9713](https://github.com/warpdotdev/warp/pull/9713)을 열었지만 병합되지 않고 닫혔습니다. 블로그 저장소 ohah.github.io의 커밋 18개는 크론이 `CRON_CRD_WRITE.md` 점검 완료를 표시한 커밋 17개와 요약 갱신 커밋 1개입니다.
