## 요약 (AI 작성)

zntc는 클래스 다운레벨링의 남은 구멍을 메웠습니다. ES5 클래스의 계산된 getter/setter 키 평가와 private getter/setter lowering([#1525](https://github.com/ohah/zntc/pull/1525), [#1526](https://github.com/ohah/zntc/pull/1526)), private·계산된 키 `accessor`의 ES5 구현과 static private accessor·복합 대입([#1527](https://github.com/ohah/zntc/pull/1527), [#1528](https://github.com/ohah/zntc/pull/1528)), Stage 3 데코레이터와 accessor의 ES5 처리([#1539](https://github.com/ohah/zntc/pull/1539), [#1540](https://github.com/ohah/zntc/pull/1540)), `@decorator export default class` 보존([#1541](https://github.com/ohah/zntc/pull/1541))이 병합됐습니다. 번들러는 axios 스모크 실패를 계기로 package.json `browser` 필드의 문자열 remap, bare module 키와 순환 감지를 지원하고([#1529](https://github.com/ohah/zntc/pull/1529), [#1531](https://github.com/ohah/zntc/pull/1531)), ESM 래퍼 함수 호이스팅의 중복 var 선언을 없앴습니다([#1532](https://github.com/ohah/zntc/pull/1532)).

tsconfig 지원을 크게 넓혔습니다. `verbatimModuleSyntax`([#1544](https://github.com/ohah/zntc/pull/1544)), NAPI/WASM의 `tsconfigPath`([#1545](https://github.com/ohah/zntc/pull/1545)), CLI `--tsconfig-path`([#1547](https://github.com/ohah/zntc/pull/1547)), `paths`/`baseUrl`과 `--alias` 병합([#1548](https://github.com/ohah/zntc/pull/1548))을 넣은 뒤 `paths`를 TS 공식 스펙대로 어디에나 오는 wildcard와 다중 후보로 다시 설계했고([#1549](https://github.com/ohah/zntc/pull/1549)), 상위 디렉터리 자동 발견을 붙였습니다([#1550](https://github.com/ohah/zntc/pull/1550)).

번들 크기 쪽에서는 tree shaker가 가짜 used_exports로 코드를 남기던 누수를 고치고([#1555](https://github.com/ohah/zntc/pull/1555)), reference_count 신호를 없애고 BFS를 fixpoint 안으로 합치는 재설계를 마쳤으며([#1559](https://github.com/ohah/zntc/pull/1559)~[#1563](https://github.com/ohah/zntc/pull/1563)), `globalThis.process?.env` 같은 방어적 접근도 define에 매칭되게 했습니다([#1556](https://github.com/ohah/zntc/pull/1556)). 상수 폴딩과 dead branch 제거는 `--minify` 없이도 돌게 했고([#1565](https://github.com/ohah/zntc/pull/1565)), `!0`/`!1`, `void 0` 같은 peephole 축약([#1557](https://github.com/ohah/zntc/pull/1557), [#1566](https://github.com/ohah/zntc/pull/1566)), ES2015 이상에서 화살표 IIFE 래퍼([#1583](https://github.com/ohah/zntc/pull/1583)), mangling 제외 범위를 공개 API 경계로 줄이기([#1584](https://github.com/ohah/zntc/pull/1584)), 합성 `_default`의 mangling([#1590](https://github.com/ohah/zntc/pull/1590)), 참조되지 않는 클래스 식 이름 익명화([#1594](https://github.com/ohah/zntc/pull/1594))가 이어졌습니다. 이 과정에서 드러난 `!!x` 축약의 타입 가드 누락([#1578](https://github.com/ohah/zntc/pull/1578)), for 초기화절 중복 세미콜론([#1568](https://github.com/ohah/zntc/pull/1568)), 단일 모듈 번들에 `_default$1`이 붙던 문제([#1599](https://github.com/ohah/zntc/pull/1599))도 고쳤고, AST의 매직 오프셋과 플래그 비트를 상수와 구조체로 바꾸는 정리가 여러 PR로 들어갔습니다([#1534](https://github.com/ohah/zntc/pull/1534), [#1570](https://github.com/ohah/zntc/pull/1570), [#1573](https://github.com/ohah/zntc/pull/1573) 등).

bungae는 예제 앱을 RN 0.85.1로 올리고 표시 이름을 Bungae로 바꿨으며, Expo SDK 55 Router 예제 BungaeExpo를 추가했습니다. `@react-native/babel-plugin-codegen`으로 네이티브 view config를 인라인하고, RN 0.85 업그레이드 뒤 드러난 Rozenite monkey-patch 누락과 `.ts` codegen 파서 불일치를 고쳤으며, 예제 앱을 iPhone·iPad 유니버설로 만들어 iPadOS 26 창 모드 실행 문제를 해결했습니다. ohah.github.io에는 맞춤법 크론의 상태 갱신 커밋이 이어졌습니다.
