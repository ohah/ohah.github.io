## 요약 (AI 작성)

zntc는 전날 열린 core-js 런타임 폴리필 지원([#2517](https://github.com/ohah/zntc/pull/2517))을 병합하며 하루를 시작했습니다. 폴리필 대상은 rspack 기준에 맞추고 es5 캡처를 정리했으며, 이어 모듈 그래프를 보고 필요한 폴리필을 감지하는 방식([#2521](https://github.com/ohah/zntc/pull/2521))과 수집기 hot path 자료구조 정리([#2528](https://github.com/ohah/zntc/pull/2528))가 들어갔습니다. NAPI plan 객체는 TS와 Zig 양쪽 키가 맞는지 검증하도록 캡슐화했고, fallback 옵션과 Node 폴리필 예시, core-js 옵션 문서도 추가했습니다([#2534](https://github.com/ohah/zntc/pull/2534), [#2535](https://github.com/ohah/zntc/pull/2535)). 문서 배포는 docs 변경이 있을 때만 돌도록 CI를 좁혔습니다([#2536](https://github.com/ohah/zntc/pull/2536)).

RN codegen은 RN 버전별 스냅샷 스위트 디렉터리를 만든 뒤([#2519](https://github.com/ohah/zntc/pull/2519)) 0.78부터 0.84까지 버전마다 RN core 스펙 3개씩 매트릭스를 채웠습니다([#2520](https://github.com/ohah/zntc/pull/2520), [#2527](https://github.com/ohah/zntc/pull/2527), [#2533](https://github.com/ohah/zntc/pull/2533) 등). runtime contract의 핵심 값 검증([#2522](https://github.com/ohah/zntc/pull/2522)), `paperComponentName` 옵션 처리([#2523](https://github.com/ohah/zntc/pull/2523)), 타입 수준 함수 파라미터 이름 보존([#2525](https://github.com/ohah/zntc/pull/2525)), `codegenNativeCommands`를 `dispatchCommand` 래퍼로 내보내는 기능([#2526](https://github.com/ohah/zntc/pull/2526))도 추가했습니다. 같은 제목의 앞선 PR [#2524](https://github.com/ohah/zntc/pull/2524)는 닫고 다시 올렸습니다. dev 서버에는 브라우저 오류 overlay가 들어왔고([#2537](https://github.com/ohah/zntc/pull/2537)), 로드맵 문서에 dev server 통일 트랙과 TLS 라이브러리로 BoringSSL을 쓰기로 한 결정을 적었습니다.

오후부터 밤까지는 tree-shaking 성능을 다뤘습니다. 하위 단계, const 사전 패스, fixpoint BFS 시간을 따로 재는 프로파일 계측을 넣고([#2541](https://github.com/ohah/zntc/pull/2541), [#2542](https://github.com/ohah/zntc/pull/2542), [#2546](https://github.com/ohah/zntc/pull/2546)), 숫자 상수 전파 큐 중복 제거와 배치화, namespace re-export 소비자 인덱스와 소스 조회 캐시, opaque namespace seed 확산 회피, post-link rename 재계산 생략, import record 문장 조회와 const fact export 조회 캐시, fixpoint seed 유지와 re-export 스캔 후보 축소, require 레코드가 없을 때 스캔 생략, numeric postpass 재동기화 축소를 차례로 병합했습니다([#2543](https://github.com/ohah/zntc/pull/2543)부터 [#2558](https://github.com/ohah/zntc/pull/2558)까지). 벤치마크는 CI에서 다른 도구와 번들 성능을 비교하도록 바꿨습니다([#2550](https://github.com/ohah/zntc/pull/2550)).
