# 2026-07-23

## 요약 (AI 작성)

전날 올린 영속 세션의 남은 패리티와 회귀를 정리한 날입니다. IME 조합 표시가 영속 터미널과 구 host 양쪽에서 깨져 있던 것을 복구하고, host-backed 마우스 리포팅(휠·클릭·드래그·우클릭)과 붙여넣기의 bracketed-paste 패리티를 맞췄습니다. 영속 세션 쪽은 메타데이터 동기화와 호스트 실행 인자를 되살리고 수명주기·복원 계약을 보강했으며, 원격 snapshot 이 실제 draw 경로에서 렌더되는지 검증하는 테스트(#1)를 추가하고 크기 fallback 주석의 오류도 바로잡았습니다.

UI 쪽은 알림·컨텍스트 메뉴 위로 포커스 테두리가 뜨던 것을 억제하고, ⌘+/− 폰트 줌을 파일 패널 콘텐츠에도 적용했습니다. 파일 패널에서는 mermaid 의 터미널 팔레트 렌더를 완성하고 소스 편집기 폴리시를 다듬었습니다.
