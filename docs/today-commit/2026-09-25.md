## 요약 (AI 작성)

maru 편집기는 새벽에 들여쓰기 안내선([#3922](https://github.com/ohah/maru/pull/3922))과 구문 접힘 승격이 해제된 줄 표를 그리던 문제의 수정([#3933](https://github.com/ohah/maru/pull/3933))을 병합했습니다. 안내선은 파일에서 들여쓰기 간격을 추정하고, Markdown·Python의 offSide 규칙과 Go의 탭 기본값을 반영했으며, 긴 공백 구간에서 활성 안내선이 줄마다 끝까지 훑던 비용을 줄였습니다. 낮에는 언어별 규칙과 증분 괄호 목록을 쓰는 괄호 쌍 색([#3946](https://github.com/ohah/maru/pull/3946)), 선택 영역의 공백·탭을 기본으로 하는 다섯 가지 공백 표시 모드([#3951](https://github.com/ohah/maru/pull/3951))가 들어왔습니다. 여러 커서를 한자리에 모으면 글자가 커서 수만큼 입력되던 문제, 줄바꿈된 줄에서 ⌘← / ⌘→가 화면 행이 아닌 논리 줄로 가던 문제도 고쳤습니다.

앱 쪽은 탭을 갈아 끼우는 복원에서 해제된 Term을 읽던 문제([#3945](https://github.com/ohah/maru/pull/3945))와 사이드카가 죽은 pane 이름을 계속 보내 지운 행이 되살아나던 문제를 고쳤고, 판정자 이름 정리는 원장을 0으로 비우며 마무리됐습니다. 감싸는 쌍이나 다음 여는 괄호로 가는 괄호 점프 [#3954](https://github.com/ohah/maru/pull/3954), 비교·병합 뷰에서 줄 번호가 사라지던 결함 수정 [#3940](https://github.com/ohah/maru/pull/3940), 실패한 host의 재교체 정책 문서 [#3942](https://github.com/ohah/maru/pull/3942)는 이날 PR이 열렸습니다. Chromium 웹 패널은 키보드·한글 입력 라우팅(W4c), 설정으로 엔진 켜기(W4d①), 앱 안 입력 시험기(W4d②), JS 대화상자·떠나기 확인·파일 선택 sheet(W5a)를 `docs/web-panel-osr-backend` 기능 브랜치에 병합했으며, main 반영은 아닙니다.

zntc는 새벽에 minify 이름 줄이기를 변환 뒤 재분석한 코드로 하도록 바꾸고([#4775](https://github.com/ohah/zntc/pull/4775)), 그 회귀로 export·import·클래스 식 이름이 바뀌던 문제를 고쳤습니다. 이어 식별자 생성 함수를 대상별로 나누고 심볼을 전달하는 작업, 블록 스코핑 이름 스택을 심볼 표로 바꿔 완전히 지우는 작업, 식별자 직접 생성을 막는 CI 감사까지 이어졌습니다. 배열·객체 rest와 es5 구조 분해, namespace export 선언, namespace 멤버 문장 탐색, 클래스 밖으로 옮긴 static 초기값의 this·super, 별칭을 통한 쓰기까지 지우던 member-augment 제거, 링크 뒤 재분석에서 export default 리네임이 사라지던 문제도 수정했습니다.

hwpjs는 HWPX 표 여백·셀 구역·행과 셀 구조, 문단 줄 세그먼트, 바탕쪽의 텍스트·바이너리·표·스타일·차트 참조와 다단계 차트 레이블을 검사했고, 오전부터 섹션 쪽 크기·쪽 테두리·주석 모양, 채우기 브러시와 그림 이미지의 OPF 연결 및 페이로드, WMF·TIFF·PCX 그림 구조 검사를 추가했습니다. HWP5에서는 요약 정보 사전 진단, PCX·WMF BinData 검사, PNG 끝의 0 패딩과 PNG로 선언된 JPEG 진단을 넣었습니다. 이 검사들은 해당 포맷의 완전한 렌더링 지원을 뜻하지 않습니다.
