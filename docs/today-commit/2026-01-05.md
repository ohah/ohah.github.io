## 요약 (AI 작성)

chrome-remote-devtools는 React Native에서 Redux DevTools Extension을 쓸 수 있게 하는 [#58](https://github.com/ohah/chrome-remote-devtools/pull/58)을 병합했습니다. inspector에 `__REDUX_DEVTOOLS_EXTENSION__`과 `__REDUX_DEVTOOLS_EXTENSION_COMPOSE__`를 구현해 Redux Toolkit과 Zustand devtools 미들웨어를 지원하고, 순환 의존을 피하려고 서버 정보와 CDP 메시지 전송을 별도 파일로 나눴습니다. 모듈을 불러오면 서버에 자동 연결하는 방식을 넣었다가 프로덕션 빌드 호환성을 이유로 되돌려 App 컴포넌트의 `useEffect`에서 연결하게 했고, Zustand 전용 감지 로직을 지웠습니다. 훅 활성 상태를 확인하는 `isConsoleHookEnabled`·`isNetworkHookEnabled`와 서버 정보를 동적으로 읽는 유틸리티도 추가했습니다.

React Native 예제 앱에는 React Navigation 하단·상단 탭 구조를 만들고 Redux와 Zustand 각각의 카운터·할 일·장바구니 화면과 스토어를 추가했습니다. 프로덕션에서도 Redux DevTools가 켜지도록 `devTools: true`를 지정하고, 스토어 생성 전 확장 존재 여부를 확인해 화면에 상태를 표시했으며, 하단 탭 아이콘이 보이지 않던 vector-icons 설정과 Android 설정을 고쳤습니다. 확장 초기화 확인 코드는 공통 유틸리티로 뽑고, inspector 패키지의 `sideEffects`와 자동 초기화 동작을 문서화했습니다.
