## 요약 (AI 작성)

react-native-mcp는 이날 PR 16개를 병합했습니다. 런타임 소스를 TypeScript로 나눠 tsdown으로 `runtime.js`를 번들하게 바꾸고([#38](https://github.com/ohah/react-native-mcp/pull/38), [#39](https://github.com/ohah/react-native-mcp/pull/39)), 서버와 패키지 빌드도 tsdown으로 통일했습니다. 빌드 시 `REACT_NATIVE_MCP_ENABLED`가 없으면 transformer와 Babel을 적용하지 않아 번들에 MCP 코드가 들어가지 않게 했고([#45](https://github.com/ohah/react-native-mcp/pull/45)), Release 빌드에서 쓸 수 있도록 Babel 플러그인이 활성화 플래그를 주입하게 했습니다([#49](https://github.com/ohah/react-native-mcp/pull/49)). 프로젝트를 감지해 Babel과 MCP 설정을 만들어 주는 `init` CLI도 추가했습니다([#47](https://github.com/ohah/react-native-mcp/pull/47)).

E2E YAML에는 `back`·`home`·`hideKeyboard`·`longPress`·`addMedia`·`assertHasText`·`clearText`·`doubleTap`·`assertValue` 스텝이 추가됐고, `repeat`·`runFlow`·`if`/`when`·`retry` 흐름 제어([#41](https://github.com/ohah/react-native-mcp/pull/41)), HTML·Slack·GitHub PR 리포터([#40](https://github.com/ohah/react-native-mcp/pull/40)), fetch·XHR을 가로채는 네트워크 모킹([#43](https://github.com/ohah/react-native-mcp/pull/43)), 앱 데이터 초기화·위치 설정·복사와 붙여넣기([#48](https://github.com/ohah/react-native-mcp/pull/48))가 차례로 들어왔습니다. 화면 밖 요소를 탭하면 명시적 오류를 내고 Android 상태 바 높이와 기기별 배율을 반영하는 좌표 보정([#46](https://github.com/ohah/react-native-mcp/pull/46)), Expo 검증 가이드와 iOS CI의 idb 설치([#44](https://github.com/ohah/react-native-mcp/pull/44))도 병합했습니다.

후반에는 초기 컨텍스트를 줄이려고 도구 설명과 리소스를 대폭 줄이고 앱 생명주기 리소스를 없애면서 비주얼 리그레션 도구를 추가했으며([#50](https://github.com/ohah/react-native-mcp/pull/50)), 리렌더를 기록하는 `start_render_profile`·`get_render_report`를 넣었습니다([#51](https://github.com/ohah/react-native-mcp/pull/51)). 쓰지 않는 CDP interceptor 안내를 문서에서 지웠고([#42](https://github.com/ohah/react-native-mcp/pull/42)), E2E 문서를 개편해 steps 레퍼런스와 cookbook·도구별 문서를 추가했으며([#52](https://github.com/ohah/react-native-mcp/pull/52)), Rspress 문서의 제목과 SEO 메타를 보강했습니다([#53](https://github.com/ohah/react-native-mcp/pull/53)).

ohah.github.io에서는 맞춤법 크론이 CRD development-7·8·9와 기술 스택 문서, hwpjs 배경·개발 문서를 점검해 띄어쓰기와 섞여 들어간 한자 표기 등을 고쳤습니다.
