## 요약 (AI 작성)

zntc 번들러는 오전에 트리 셰이킹을 진행했습니다. 쓰이지 않는 export를 모듈 단위로 지우는 1단계([#238](https://github.com/ohah/zntc/pull/238))에 이어, 호출·new 노드의 플래그를 `extra_data`로 옮겨 `@__PURE__` 주석을 담고([#239](https://github.com/ohah/zntc/pull/239)), `package.json`의 `sideEffects`와 순수성 분석을 적용했으며([#240](https://github.com/ohah/zntc/pull/240)), esbuild·rolldown처럼 순수 모듈을 자동 판정하게 했습니다([#241](https://github.com/ohah/zntc/pull/241)). `@__NO_SIDE_EFFECTS__`는 `@__PURE__`와 분리해 호출 지점에 반영하고 모듈 간으로 전파했습니다([#242](https://github.com/ohah/zntc/pull/242), [#243](https://github.com/ohah/zntc/pull/243), [#245](https://github.com/ohah/zntc/pull/245)). JSX 자기 닫는 태그가 `>`를 먼저 소비해 형제 요소를 깨뜨리던 렉서 버그도 고쳤습니다([#244](https://github.com/ohah/zntc/pull/244)).

오후에는 CJS 모듈 감지와 `require()` 스캔, `__commonJS` 래핑, `__toESM` 브리지로 CJS 상호 운용을 넣고([#248](https://github.com/ohah/zntc/pull/248)부터 [#250](https://github.com/ohah/zntc/pull/250)까지) Top-Level Await 감지와 전파를 추가했습니다([#251](https://github.com/ohah/zntc/pull/251)). 이어 코드 분할을 청크 그래프 타입, 청크 간 의존성 추적, 다중 파일 emitter와 CLI `--splitting`, 심볼 단위 청크 간 import·export와 동적 import 경로 재작성, 청크별 scope hoisting, content hash와 import 중복 제거 순으로 구현했습니다([#252](https://github.com/ohah/zntc/pull/252)부터 [#258](https://github.com/ohah/zntc/pull/258)까지).

저녁부터는 Bun 모노레포와 통합·E2E 테스트 환경, oxlint·oxfmt 설정([#259](https://github.com/ohah/zntc/pull/259))을 갖추고 개발 서버와 HMR을 만들었습니다. 정적 파일 서버, 실시간 번들 서빙, WebSocket HMR 채널, 파일 감시와 전체 새로고침, 모듈 그래프 전체 감시, 에러 오버레이까지 6단계([#260](https://github.com/ohah/zntc/pull/260)부터 [#267](https://github.com/ohah/zntc/pull/267)까지)와 SPA 폴백([#269](https://github.com/ohah/zntc/pull/269))을 병합했고, TS non-null 단언 체이닝 파싱도 고쳤습니다([#265](https://github.com/ohah/zntc/pull/265)). 이후 `import.meta.hot`용 모듈 래핑 dev 번들과 HMR 런타임([#270](https://github.com/ohah/zntc/pull/270)), 바뀐 모듈만 보내는 업데이트([#271](https://github.com/ohah/zntc/pull/271)), dev 번들 소스맵 서빙([#272](https://github.com/ohah/zntc/pull/272)), React Fast Refresh의 `$RefreshReg$`·`$RefreshSig$` 주입과 런타임 통합([#273](https://github.com/ohah/zntc/pull/273), [#274](https://github.com/ohah/zntc/pull/274), [#276](https://github.com/ohah/zntc/pull/276)), 새로고침 없는 CSS 핫 리로드([#275](https://github.com/ohah/zntc/pull/275))가 들어왔습니다. esbuild·SWC·oxc·webpack·rspack·rolldown과 비교하는 벤치마크 스위트 [#277](https://github.com/ohah/zntc/pull/277)은 이날 PR이 열렸습니다.

cheolsu-proxy는 네트워크 테이블을 TanStack Table로 옮기면서 요청 시각 컬럼, 디바이스 종류와 로컬·원격 클라이언트 표시, 쿼리 필터 편집기 개선, 트래픽 분석의 Invalid Date와 다른 형식으로 복사 버그 수정, pre-commit 훅을 함께 넣었습니다([#318](https://github.com/ohah/cheolsu-proxy/pull/318)). 컨텍스트 메뉴의 규칙 추가 옵션 확장과 다이얼로그 패턴 통일([#319](https://github.com/ohah/cheolsu-proxy/pull/319)), Quick Settings의 Block QUIC(Alt-Svc 제거) 옵션([#320](https://github.com/ohah/cheolsu-proxy/pull/320))도 병합됐습니다. 블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋(hwpjs 개발기 5편 확인 포함)과 3월 22일 오늘의 커밋 요약 작성이 올라왔습니다.
