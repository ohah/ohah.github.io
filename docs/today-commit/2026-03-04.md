## 요약 (AI 작성)

react-wasm-table은 PR 아홉 개를 main에 병합했습니다. Switch 애니메이션과 함께 Checkbox·Input 캔버스 컴포넌트, 그리고 Taffy 레이아웃 좌표로 캔버스 위에 실제 입력 요소를 띄우는 DOM 오버레이를 넣었고, 한글 조합 입력 처리와 Tab 이동도 붙였습니다([#61](https://github.com/ohah/react-wasm-table/pull/61)). ProgressBar 클릭·드래그 편집([#62](https://github.com/ohah/react-wasm-table/pull/62)), grid 패키지 커버리지를 98.73%로 올린 테스트 보강([#63](https://github.com/ohah/react-wasm-table/pull/63)), 복합 레이아웃 렌더러의 JS 폴백을 없애고 WASM 경로만 쓰게 한 정리([#64](https://github.com/ohah/react-wasm-table/pull/64))가 이어졌습니다. 컬럼 크기 조절 때 글자를 압축하지 않고 잘라내는 수정([#65](https://github.com/ohah/react-wasm-table/pull/65))과 크기 조절 손잡이 위 커서 수정([#66](https://github.com/ohah/react-wasm-table/pull/66)), WASM `lib.rs`를 `types.rs`·`convert.rs`로 나누고 자체 DOM 폴리필을 `@happy-dom/global-registrator`로 바꾼 작업([#67](https://github.com/ohah/react-wasm-table/pull/67))도 병합됐습니다. 이어 캔버스로 직접 그리는 Checkbox·Radio와 Label 컴포넌트([#68](https://github.com/ohah/react-wasm-table/pull/68)), Icon·Select 컴포넌트와 Input의 숫자 입력 속성([#69](https://github.com/ohah/react-wasm-table/pull/69))이 들어왔습니다.

hwpjs는 표 셀·글상자 안 문단 글머리표([#105](https://github.com/ohah/hwpjs/pull/105)), 한컴 뷰어 출력 구조에 맞춘 쪽 안 각주 배치와 미주 전용 쪽([#106](https://github.com/ohah/hwpjs/pull/106)), 머리말·꼬리말의 쪽 번호와 아래 정렬([#107](https://github.com/ohah/hwpjs/pull/107)), CharShape 음영 색의 `background-color` 출력([#108](https://github.com/ohah/hwpjs/pull/108))을 병합했습니다. 차트·하이퍼링크 픽스처([#110](https://github.com/ohah/hwpjs/pull/110))와 하이퍼링크 onclick 렌더링([#111](https://github.com/ohah/hwpjs/pull/111))에 이어, 모든 패키지 버전을 0.1.0-rc.7로 올리고 Node·WebAssembly·React Native 빌드를 갱신한 릴리스 커밋([#112](https://github.com/ohah/hwpjs/pull/112))이 들어왔습니다. 이 커밋에서 NAPI와 React Native의 `toPdf` 바인딩은 비활성화됐습니다. 마크다운 뷰어의 하이퍼링크·개요·번호 매기기 리뷰 반영([#113](https://github.com/ohah/hwpjs/pull/113))도 병합됐습니다.

cheolsu-proxy는 예전 요약에서 빠졌던 저장소로, 이날 구조를 크게 바꿨습니다. 3월 2일에 연 [#60](https://github.com/ohah/cheolsu-proxy/pull/60)을 병합해 `--daemon` 플래그로 Tauri 없이 도는 데몬 모드, Unix 도메인 소켓 기반 클라이언트, GUI와 CLI가 모두 데몬 클라이언트로 동작하는 구조를 넣었고, 이어 프록시·데몬 핵심 로직을 독립 `proxy_daemon` 크레이트로 옮겨 Tauri 래퍼를 줄였습니다([#61](https://github.com/ohah/cheolsu-proxy/pull/61)). 프런트엔드는 Radix UI를 Base UI로 옮기고 번들러를 rspack에서 Vite 7(Rolldown)로 바꾸며 react-resizable-panels v4에 맞췄고, 데몬 소켓이 준비되기 전에 연결하던 경쟁 조건도 고쳤습니다([#62](https://github.com/ohah/cheolsu-proxy/pull/62), [#63](https://github.com/ohah/cheolsu-proxy/pull/63)).
