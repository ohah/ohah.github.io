## 요약 (AI 작성)

react-native-mcp는 도구 설명을 한 문장 중심으로 줄이고 npm 배포 워크플로를 서버 패키지 전용으로 단순화하며 E2E 대기 시간을 두 배로 늘린 [#88](https://github.com/ohah/react-native-mcp/pull/88)을 병합했습니다. iOS 가로 모드에서 비주얼 비교의 잘라 낼 영역을 세로 스크린샷 좌표로 바꾸고 VS Code 확장을 0.1.1로 올렸으며([#89](https://github.com/ohah/react-native-mcp/pull/89)), 스크린샷을 기기 방향에 맞게 회전하게 했습니다([#91](https://github.com/ohah/react-native-mcp/pull/91)). 런타임은 서버가 없을 때 WebSocket 생성이 실패해도 재연결을 예약하게 하고([#94](https://github.com/ohah/react-native-mcp/pull/94)), 서버 종료 때 연결을 정상적으로 닫아 TCP RST로 앱이 죽지 않게 했습니다([#96](https://github.com/ohah/react-native-mcp/pull/96)). 서버 패키지 버전은 이날 0.1.0-rc.2부터 rc.6까지 차례로 올렸습니다([#92](https://github.com/ohah/react-native-mcp/pull/92), [#93](https://github.com/ohah/react-native-mcp/pull/93), [#95](https://github.com/ohah/react-native-mcp/pull/95)).

문서 쪽은 영문 기본 경로와 도메인을 통일하고([#90](https://github.com/ohah/react-native-mcp/pull/90)), 아키텍처 다이어그램을 Mermaid로 바꿨으며([#97](https://github.com/ohah/react-native-mcp/pull/97)), `docs` 폴더를 architecture·guides·references 등으로 나눴습니다([#98](https://github.com/ohah/react-native-mcp/pull/98)). 도구 레퍼런스와 홈 화면 링크, 사이드바의 아키텍처 항목도 바로잡았습니다([#99](https://github.com/ohah/react-native-mcp/pull/99), [#100](https://github.com/ohah/react-native-mcp/pull/100), [#101](https://github.com/ohah/react-native-mcp/pull/101)).

hwpjs는 밑줄 종류가 글자 위일 때 취소선으로 그리고, Playwright로 fixture와 생성 HTML의 이미지를 비교하는 문서 스냅샷 E2E를 추가한 [#17](https://github.com/ohah/hwpjs/pull/17)을 병합했습니다. 캡션 없는 인라인 표의 위치를 0으로 두어 1쪽 배치를 fixture에 맞췄고([#18](https://github.com/ohah/hwpjs/pull/18)), 표가 쪽을 넘긴 뒤 다시 그릴 때의 좌표와 셀 이미지를 반영한 표 높이도 고쳤습니다. Linux 교차 빌드와 릴리스 스크립트를 손본 뒤 패키지 버전을 0.1.0-rc.5로 올리고 빌드 산출물을 커밋했습니다. `AGENTS.md`는 100줄 안팎의 목차로 줄였고([#20](https://github.com/ohah/hwpjs/pull/20)), 테스트 코드는 별도 브랜치 PR로만 올린다는 heartbeat 규칙([#19](https://github.com/ohah/hwpjs/pull/19))에 따라 document 모듈, Markdown 뷰어, 본문·개요 처리 단위 테스트를 각각 병합했습니다([#21](https://github.com/ohah/hwpjs/pull/21), [#22](https://github.com/ohah/hwpjs/pull/22), [#23](https://github.com/ohah/hwpjs/pull/23)). 테스트 컴파일 오류를 고치는 [#24](https://github.com/ohah/hwpjs/pull/24)는 이날 열렸습니다.

ohah.github.io에는 2월 23일 요약과 매일 크론 실행 규칙을 명시한 `AGENTS.md` 수정이 올라갔습니다.

공개 커밋 43개, 해당일 생성 또는 병합된 PR 22개를 정리했습니다. PR 생성 20개·병합 21개는 같은 PR이 양쪽에 포함될 수 있습니다.
