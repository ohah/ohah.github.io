## 요약 (AI 작성)

zntc는 데코레이터 변환 수정으로 하루를 열었습니다. es2021에서 experimental decorators를 쓸 때 class private 멤버를 다운레벨하고([#3679](https://github.com/ohah/zntc/pull/3679)), private 멤버와 함께 쓴 field decorator가 조용히 사라지던 회귀를 고쳤습니다([#3681](https://github.com/ohah/zntc/pull/3681)). private method 안의 `super.x`가 SyntaxError를 내던 문제의 수정 [#3722](https://github.com/ohah/zntc/pull/3722)도 이날 열렸습니다. CLI에는 `--intro:js`·`--outro:js`와 JSON config 노출, splitting 모드의 wrapper 안쪽 emit을 추가했습니다([#3682](https://github.com/ohah/zntc/pull/3682)).

번들러 출력 파일 이름 체계는 크게 바뀌었습니다. 코드 분할에서 여러 chunk가 같은 CSS를 쓰면 복제하고, 같은 stem의 CSS 경로 충돌을 분할 여부와 관계없이 자동으로 구분하게 한 뒤([#3685](https://github.com/ohah/zntc/pull/3685), [#3686](https://github.com/ohah/zntc/pull/3686), [#3687](https://github.com/ohah/zntc/pull/3687)), entry·chunk 이름 패턴에 `[dir]` 토큰을 지원하고 `Chunk.name_dir` 필드와 정규화 함수, CSS 이름 규칙, chunk 간 상대 import 경로, Module Federation manifest 경로 분리를 차례로 붙였습니다([#3688](https://github.com/ohah/zntc/pull/3688), [#3689](https://github.com/ohah/zntc/pull/3689), [#3697](https://github.com/ohah/zntc/pull/3697), [#3698](https://github.com/ohah/zntc/pull/3698)). 그 결과 `entryNames`·`cssNames`의 기본값을 `[dir]/[name]`으로 바꾸는 호환성 변경([#3699](https://github.com/ohah/zntc/pull/3699))이 들어갔고, RFC와 마이그레이션 가이드([#3702](https://github.com/ohah/zntc/pull/3702))를 함께 냈습니다. 리뷰 후속으로 dynamic chunk의 `chunkNames` 적용 등 Rollup 동작 맞춤([#3717](https://github.com/ohah/zntc/pull/3717))과 `renderChunk` 플러그인에 넘기는 chunk 이름을 실제 파일 이름과 맞추는 수정([#3719](https://github.com/ohah/zntc/pull/3719))이 이어졌습니다.

오후부터는 NAPI 메모리 문제를 집중적으로 다뤘습니다. 문자열 getter와 잘린 결과의 allocator 크기 불일치([#3691](https://github.com/ohah/zntc/pull/3691)), `loader_overrides` 누수와 plugin bridge의 범위 밖 쓰기, `Bundler.init`의 ResolveCache 누수, manual chunks 이름 누수, `shrinkSlice` OOM 경로 누수를 고쳤고, 디버그 빌드용 누수 탐지기([#3695](https://github.com/ohah/zntc/pull/3695))를 넣은 뒤 Node worker_threads 경쟁과 atexit 시점 해제 후 사용 문제를 다듬었습니다([#3707](https://github.com/ohah/zntc/pull/3707), [#3713](https://github.com/ohah/zntc/pull/3713)). 측정 가이드 문서와 main push·nightly로 도는 NAPI 누수 게이트 워크플로([#3715](https://github.com/ohah/zntc/pull/3715))도 추가했습니다. watch 증분 빌드에서 `entry_dir`이 갱신되지 않던 문제와 사용자가 지정한 `project_root`를 덮어쓰던 문제도 고쳤습니다([#3704](https://github.com/ohah/zntc/pull/3704), [#3708](https://github.com/ohah/zntc/pull/3708)). 블로그 저장소 ohah.github.io의 커밋 8개는 크론의 문서 점검 표시와 요약 갱신 커밋입니다.

공개 커밋 50개, 해당일 생성 또는 병합된 PR 42개를 정리했습니다. PR 생성 42개·병합 40개는 같은 PR이 양쪽에 포함될 수 있습니다.
