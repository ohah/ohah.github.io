# 2026-09-01

## 요약 (AI 작성)

`@ohah/pdf` 가 메모리를 잡은 날입니다 — 안 쓰는 자리는 안 잡아 바닥 메모리가 112MB 에서 38MB 로, 맨 위 표는 옮기지 않고 뒤로 늘리고, 빽빽한 쪽이 통째로 백지로 나오던 것과 출력 자리가 꽉 차면 쪽 표를 뭉개던 것을 고쳤습니다. 레거시 전수조사가 낸 다섯 중 둘은 파일을 망가뜨리고 있었고, 환경이 깨진 자리 열세 가지를 두들기다 셋을 더 고쳤습니다.

maru session-host 는 릴리스 인증을 촘촘히 쌓았습니다 — GitHub tag chain 검증, 현재 릴리스 인증, manifest pathname 을 private 증명 입력으로 고정, 제품 권위 결속, evidence signer, evidence 를 인증 manifest 에 결속, asset private file 실체화, asset attest, frozen compatibility 관측, release executable authority, 그리고 authority·release·manifest deadline 공유. 편집기는 찾기가 대소문자와 낱말을 가리고(`⌥⌘C`·`⌥⌘W`, §5.1) 비교 뷰 막대에도 검색 마커가 찍힙니다.

원격 축은 구멍을 메웠습니다 — 보고자 없는 원격 pane 이 로컬로 판정되던 링크 구멍(B→A), 원격 폴더줄이 훅이 알려 준 작업 디렉터리를 쓰는 것, 종료 안내가 원격 경로를 로컬처럼 적던 것, 컨트롤 플레인 DTO 가 `cwd_host` 로 어느 기계의 경로인지 알리는 것. Windows 는 `Ctrl+Shift+C` 가 복사가 아니게 돼 있었는데 `⌥⌘C` 하나 때문이었습니다.
