## 요약 (AI 작성)

이날 공개 활동은 거의 전부 zntc였고, 그중 가장 큰 줄기는 큰 파일을 잘게 나누는 리팩터링이었습니다. 오전에 CLI·config·`import.meta.glob`·browserslist·build 등 대형 테스트 파일을 나눈 데 이어([#2773](https://github.com/ohah/zntc/pull/2773)–[#2778](https://github.com/ohah/zntc/pull/2778)), NAPI 공통 헬퍼·옵션 파싱·plugin bridge·watch bridge, graph의 에셋·synthetic import·glob·파싱·순환·import 해석·빌드 흐름, transformer의 enum·regex·import/export·decorator·class 헬퍼와 node dispatch, codegen의 모듈·문장·식 출력, ES2015 class 변환, emitter·linker·tree shaker·minify·CLI 옵션 파서까지 기능 변화 없이 모듈을 쪼개는 PR이 하루 종일 연달아 병합됐습니다.

배포 준비 작업도 함께 들어왔습니다. 내부 패키지끼리 dist 대신 src를 바로 쓰는 `source` exports 조건을 도입하고 vite-plugin을 dist 빌드로 바꿔 퍼블리시할 수 있게 했으며([#2791](https://github.com/ohah/zntc/pull/2791)), TS Project References를 세 단계로 연결하고([#2805](https://github.com/ohah/zntc/pull/2805), [#2806](https://github.com/ohah/zntc/pull/2806), [#2807](https://github.com/ohah/zntc/pull/2807)) `isolatedDeclarations`를 켰습니다([#2819](https://github.com/ohah/zntc/pull/2819)). CI에는 tarball 내용을 보는 publish smoke test, publint, sherif, 실제 npm install 검증, 의존성 버전 일관성 검사가 추가됐고, 기본은 dry-run이고 `--publish`와 확인 입력이 있어야 실제로 퍼블리시하는 `release.ts`([#2818](https://github.com/ohah/zntc/pull/2818))와 changesets 도입([#2833](https://github.com/ohah/zntc/pull/2833))이 이어졌습니다. 이날 실제 퍼블리시 기록은 없습니다. core·wasm·vite-plugin-zntc·web 패키지 README도 보강했습니다([#2829](https://github.com/ohah/zntc/pull/2829)).

새 패키지 `@zntc/rspack-loader`가 추가됐습니다([#2840](https://github.com/ohah/zntc/pull/2840)). Rspack과 webpack 5에서 swc-loader·esbuild-loader 자리에 쓰는 loader로, 양쪽 통합 테스트를 갖췄고 뒤이어 import/require별 exports 타입을 나눴습니다([#2887](https://github.com/ohah/zntc/pull/2887)). 이 작업 중 발견된 문제로 `.js`·`.jsx`도 ESM으로 파싱하도록 바꿔 date-fns 4.x 파일 252개가 모두 통과하게 했고([#2853](https://github.com/ohah/zntc/pull/2853)), 번들러 경로의 회귀를 막기 위해 이 규칙을 CLI·transpile 경로로만 한정했습니다. `.cjs`는 script 모드로 맞췄습니다([#2859](https://github.com/ohah/zntc/pull/2859)).

버그 수정으로는 사용자가 `__extends` 같은 런타임 헬퍼 이름을 최상위에 선언하면 헬퍼 호출이 사용자 바인딩에 묶이던 문제를 심볼에 묶인 참조로 고쳤고([#2877](https://github.com/ohah/zntc/pull/2877)), RN ES5 번들에서 헬퍼 이름이 `$1` 접미사로 바뀌어 `__extends$1 is not defined`가 나던 문제를 고쳤습니다([#2814](https://github.com/ohah/zntc/pull/2814), [#2866](https://github.com/ohah/zntc/pull/2866)). for-of 블록 스코프 캡처 보존과 `_loop` 클로저의 async 표시 전파([#2793](https://github.com/ohah/zntc/pull/2793), [#2796](https://github.com/ohah/zntc/pull/2796)), HMR 메시지 상수 동결([#2861](https://github.com/ohah/zntc/pull/2861)), watch 루프의 `mtime_map` 누수([#2884](https://github.com/ohah/zntc/pull/2884)), `forwardClientLogs` 깊은 복사 누수([#2894](https://github.com/ohah/zntc/pull/2894))도 수정했고, Expo 예제에는 Rozenite DevTools를 적용했습니다([#2835](https://github.com/ohah/zntc/pull/2835)). 블로그 저장소 ohah.github.io의 커밋 11개는 크론이 남긴 `CRON_CRD_WRITE.md` 점검 표시와 메타·요약 갱신입니다.
