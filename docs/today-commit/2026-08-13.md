# 2026-08-13

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru의 편집기를 하나의 Term 종류로 승격한 날입니다. 프레임 조립을 chrome 컴포넌트로 올린 뒤([#2144](https://github.com/ohah/maru/pull/2144)), `SurfaceKind`에 `editor`를 더해 타입 자리를 만들고 `kind == .web`으로 뭉뚱그려 있던 8곳을 분류했으며, 편집기 Term을 만들어 파일을 붙이고 훅이 파일을 편집기 Term으로 열어 렌더 블록까지 잇게 했습니다. 사이드바 아이콘에서 편집기가 빠져 있던 것도 채웠습니다. 렌더 쪽에서는 배경 quad가 자기 본문을 덮고 있던 것을 layer 3에서 2로 고치면서 합성 층에 이름을 줘 Lab과 제품이 갈리던 자리를 없앴고, 배경이 텍스트를 덮는 것을 Lab 게이트가 잡게 했습니다([#2158](https://github.com/ohah/maru/pull/2158)). 편집기 배경은 `terminal_bg` 토큰으로 터미널과 같은 색을 쓰되 창 투명도는 그 역할에만 걸고, 본문에는 창 padding을 적용하지 않게 정리했습니다.

터미널에서는 wrap 이음의 유령 공백 문제를 뿌리부터 팠습니다. 안 쓴 칸과 쓴 공백을 구분하는 것에서 시작해 soft-wrap 이음이 wrap 채움을 내용으로 삼지 않게 하고, BCE로 칠한 화면에서도 같은 규칙이 서게 했으며, 중립 렌더 계층도 안 쓴 칸을 빈 칸으로 보게 맞췄습니다([#2156](https://github.com/ohah/maru/pull/2156)). 화면을 지워도 스크롤백에서 줄이 계속 이어지던 문제도 잡아, 홈에서의 ED 0·ED 1과 0행을 비우거나 덮는 연산도 스크롤백 wrap을 끊게 했습니다([#2153](https://github.com/ohah/maru/pull/2153)). 넓힌 뒤 커서 줄 복사의 패딩 공백을 다루던 [#2155](https://github.com/ohah/maru/pull/2155)는 병합 없이 닫혔습니다. 폰트는 셰이핑을 run 단위로 묶고 합자를 설정으로 뺐습니다([#2151](https://github.com/ohah/maru/pull/2151)). 사이드바는 토글 행의 파형 중복 그리기, 에이전트 행 상태 마커 위치, 카드 호버 밴드가 상태바를 덮던 문제를 고쳤습니다([#2157](https://github.com/ohah/maru/pull/2157)).

모바일 작업은 `deploy/mobile` 브랜치에서 이어졌고 main 반영은 아닙니다. 전날 열린 iOS `UITextInput` 전환 [#2131](https://github.com/ohah/maru/pull/2131), 커서 [#2133](https://github.com/ohah/maru/pull/2133), 렌더 루프 수정 [#2138](https://github.com/ohah/maru/pull/2138)이 그 브랜치에 병합됐고, 스크롤([#2142](https://github.com/ohah/maru/pull/2142)), 길게 눌러 잡는 선택([#2148](https://github.com/ohah/maru/pull/2148)), 복사([#2152](https://github.com/ohah/maru/pull/2152)), 보조 키바([#2146](https://github.com/ohah/maru/pull/2146)), 이모지 컬러 아틀라스([#2159](https://github.com/ohah/maru/pull/2159))와 셸 따옴표·`--` 플래그 입력, 선택 중 화면 흐름 수정이 같은 브랜치에 들어갔습니다. 번들 폰트에 없는 기호를 채우는 [#2165](https://github.com/ohah/maru/pull/2165)는 이날 열렸습니다.

session-host는 전날 열린 CR0b incident artifact 영속화 [#2140](https://github.com/ohah/maru/pull/2140)을 병합하고, incident writer를 부트스트랩했으며([#2143](https://github.com/ohah/maru/pull/2143)), incident process 권위를 격리하고 크로스플랫폼 경계를 맞췄습니다. managed client publication도 봉인했습니다([#2149](https://github.com/ohah/maru/pull/2149)). 앱 종료 단계를 계측하고 정리 전에 창을 내리는 [#2139](https://github.com/ohah/maru/pull/2139)도 병합됐습니다. 로컬 셸이 OSC 7 authority를 비워 자기 세션을 원격으로 오판하던 SSH 문제 [#2163](https://github.com/ohah/maru/pull/2163)과 CR0b incident publication 기반 [#2164](https://github.com/ohah/maru/pull/2164)는 이날 PR이 열렸습니다.
