# 2026-08-24

## 요약 (AI 작성)

편집 버퍼를 persistent rope 와 delta 로 세우고 selection 을 같은 연산에서 밀게 한 날입니다(§3.0·§3.3). `@maru/*` 는 마커와 장식(여러 매치 동시 칠하기), 앱이 자기 패턴을 주입하는 링크 규칙, 캔버스가 못 하는 접근성·터치를 DOM 이 맡는 구조를 얻었고, 장식이 무한 렌더 루프를 만들어 유휴 1638fps 였던 것을 2fps 로, 워커 모드에서 open() 직후 22ms 흐리던 것을 잡았습니다.

에이전트 훅은 신원에 host 소유 자리를 만들고(계약이 GUI 만 알고 있었다) host 가 자기 신원으로 훅 경로를 채우며 훅 로그 칸을 만들고 치우고 GUI 가 그것을 읽게 해, host-backed 터미널이 훅 모드로 살게 됐습니다. 훅을 턴 경계 트리거로 삼고(AT1) 턴 제목을 링에 싣습니다(AT2). maru 를 두 개 띄우면 같은 훅 로그를 물던 것과 업그레이드 뒤 뜬 자식만 신원을 못 받던 것도 고쳤습니다.

Windows 는 도크에 파일 트리가 뜨고(아틀라스를 나눠 쓴다) 입력이 갈리고 디바이더로 도크 폭이 바뀌고 도크가 파일 트리↔소스 컨트롤을 갈아 끼우며, 창이 사이드바 띠까지 셋으로 갈리고 프레임리스 창·테마 색·아이콘·헤더 아이콘 줄이 섰습니다. 탐색기는 CIM §9 조건을 항목별로 닫고 Chrome Lab 시나리오와 시각 골든을 얻었으며, 밀려난 세션이 조용히 사라지던 것에 신원 자취를 남기고, 공개 attach 루프를 실제 TTY 에 연결하고 localhost SSH 로 번들 attach 를 검증했습니다.
