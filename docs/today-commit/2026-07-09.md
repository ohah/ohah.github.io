## 요약 (AI 작성)

maru는 웹 패널 Phase 4를 이어 가며 PR 6개를 모두 main에 병합했습니다. 4d에서는 웹뷰를 포커스 가능하게 바꾸고 웹과 모달 사이 입력·IME responder 전환을 배선하되, 기존 터미널 IME 경로는 건드리지 않고 `MARU_WEB_PANEL` 훅 뒤에 격리했습니다([#1260](https://github.com/ohah/maru/pull/1260)). 리뷰에서 웹 포커스 중 Cmd+Q·H·M 같은 메뉴 단축키가 먹지 않던 문제와 오래된 rect를 쓰던 문제 등 결함 7건이 나와 고쳤습니다([#1262](https://github.com/ohah/maru/pull/1262)). 기획 문서에는 웹 Term 통합(4e)과 브라우저 chrome UI(7e)를 명시 슬라이스로 추가했습니다([#1261](https://github.com/ohah/maru/pull/1261)).

이어 웹 surface를 탭 안의 Term으로 다루는 4e를 세 단계로 올렸습니다. 4e-1은 union과 sentinel로 web Term을 트리에 넣되 렌더와 ABI는 바꾸지 않았고([#1263](https://github.com/ohah/maru/pull/1263)), 4e-2는 web Term이 활성일 때 터미널 렌더가 sentinel 코어를 참조하지 않도록 막아 본문을 비웠습니다([#1264](https://github.com/ohah/maru/pull/1264)). 4e-3은 web Term마다 WKWebView를 두고 자기 pane 위치에 고정해, 다른 pane에 포커스해도 웹뷰가 따라다니지 않게 했습니다([#1265](https://github.com/ohah/maru/pull/1265)). 다크 모드에서 `about:blank`가 흰색이 아닌 시스템 배경으로 그려져 터미널과 구분되지 않던 원인도 이때 함께 고쳤습니다.

공개 커밋 7개, 해당일 생성 또는 병합된 PR 6개를 정리했습니다. PR 생성 6개·병합 6개는 같은 PR이 양쪽에 포함될 수 있습니다.
