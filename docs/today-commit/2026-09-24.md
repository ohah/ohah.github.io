## 요약 (AI 작성)

maru 편집기는 자정 무렵 sticky scroll을 병합했습니다([#3899](https://github.com/ohah/maru/pull/3899)). 화면 맨 위 줄이 속한 스코프의 머리줄을 본문 위에 고정하고, 비교 뷰로 바꾸면 옛 머리줄이 클릭을 가로채던 결함과 같은 낱말 강조가 막대를 자르던 결함도 함께 고쳤습니다. 오후에는 현재 줄 강조와 짝 괄호 강조가 들어왔고, 괄호 점프도 같은 판정을 쓰게 됐습니다([#3911](https://github.com/ohah/maru/pull/3911)). 들여쓰기 안내선 [#3922](https://github.com/ohah/maru/pull/3922)와 구문 접힘 승격 중 해제된 줄 표를 그리던 문제의 수정 [#3933](https://github.com/ohah/maru/pull/3933)은 이날 PR만 열렸습니다.

렌더러는 안 보이는 탭의 출력이 사이드바만 갱신하고 사이드바가 그대로면 아무것도 올리지 않게 했으며(커밋 기준 활성 32세션 조건에서 앱 CPU −31%), 안 보이는 탭의 kitty 애니메이션이 화면을 다시 그리게 하지 않도록 했습니다. 재부팅 부활은 keep-alive를 끈 칸에서도 에이전트 대화를 잇고, 코드 리뷰에서 나온 두 번 부활·대화 파일 탐색·spawn 실패 처리를 반영했습니다. 밑줄·한글이 들어간 경로에서 사이드바 대화 줄이 비던 문제, 죽은 tmux pane 행이 남던 문제도 고쳤습니다. CI는 ReleaseFast 잡 상한을 45분으로 올리고 AppKit 스모크 잡 셋을 하나로 합쳤고, 재접속 계열을 중심으로 판정자 이름 정리가 계속됐습니다.

Chromium 웹 패널은 sidecar 제어 채널 codec(W1a), CEF sidecar 뼈대(W1b), 실제 브라우저 실행(W1c), 픽셀 링(W2), WKWebView 로그인 유지(W3a), 앱의 sidecar 실행(W3b), Metal 표시(W3c), 마우스·키·IME 입력(W4a), 포인터 라우팅(W4b) PR이 병합됐습니다. 모두 `docs/web-panel-osr-backend`와 그 하위 기능 브랜치에 들어간 것이며, main 통합 PR [#3867](https://github.com/ohah/maru/pull/3867)은 열려 있습니다.

hwpjs는 새벽에 HWPX 섹션 텍스트 스트리밍, 문단·런 경계, 섹션·헤더 XML 트리 색인과 지원하지 않는 네임스페이스 거부를 넣었고, 오전부터는 선언된 모든 XML 파트와 패키지 바이트 검사, 설정 값, 바탕쪽, 런의 변경 추적 속성과 인라인 태그, 조건부 분기에 따른 바이너리·차트·텍스트·스타일 참조 선택, 표 격자·셀 크기·여백·테두리 참조 검사로 범위를 넓혔습니다. zntc는 네이티브 node 결과와 타깃별 번들 결과를 비교하는 다운레벨 런타임 오라클 스위트를 추가하고, for-of·for-in·for-await를 공통 AST 풀이로 옮기는 3단계 리팩터링과 심볼 ID 누락 검사기, es5 경로의 심볼 전달 수정을 이어갔습니다. es5 상태 기계의 catch 파라미터 스코프, 루프 캡처의 반복별 바인딩, 구조 분해 대입의 rest도 고쳤고, minify 이름 줄이기를 다시 분석한 뒤 하도록 바꾸는 [#4775](https://github.com/ohah/zntc/pull/4775)가 열렸습니다.
