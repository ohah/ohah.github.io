## 요약 (AI 작성)

electron-mcp-server는 메인 프로세스의 `ipcMain` 이벤트와 `http.request`·`https.request` 네트워크 요청을 감시하는 도구와 데모 테스트를 추가해 병합했습니다([#17](https://github.com/ohah/electron-mcp-server/pull/17)). 이어 메인·렌더러 전용 도구를 없애고 `list_console_messages`와 `list_network_requests`에 `targetType` 옵션을 두는 식으로 통합했으며, 저장 개수 상한과 mutex를 넣는 리뷰 반영 뒤 v0.1.0-rc.3 준비 커밋을 올렸습니다.

gif2mp4는 MP4 묶기를 내부 Rust WASM 모듈로 바꾸는 커밋을 거쳤다가, 최종적으로 `mp4-muxer` 라이브러리만 쓰도록 통일하고 자체 mux를 제거했습니다. `v*` 태그를 푸시하면 `@gif2mp4/core`를 npm에 배포하는 워크플로를 추가한 [#9](https://github.com/ohah/gif2mp4/pull/9)가 병합됐고, Playwright trace 옵션과 Clippy 경고도 고쳤습니다.

공개 커밋 7개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 1개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
