## 요약 (AI 작성)

react-native-mcp는 콘솔 수집과 XHR·fetch 캡처를 런타임에 넣어 `list_console_messages`·`list_network_requests`를 다시 등록한 [#23](https://github.com/ohah/react-native-mcp/pull/23)을 병합했습니다. 데모 앱에는 RNGH와 Reanimated를 쓰는 Gesture 탭을 추가해 testID가 있는 요소와 없는 요소를 모두 시험하게 했고([#24](https://github.com/ohah/react-native-mcp/pull/24)), 드래그·핀치·회전·밀어서 삭제·당겨서 새로고침 같은 제스처 시험 UI를 넣으면서 하단 탭을 7개에서 5개로 합쳤습니다([#27](https://github.com/ohah/react-native-mcp/pull/27)). Android 앱 아이콘은 iOS와 같게 맞췄습니다([#25](https://github.com/ohah/react-native-mcp/pull/25)). `take_screenshot`은 AI 비전 처리 시간을 줄이려고 기본값을 720p·JPEG 80%로 정했습니다([#26](https://github.com/ohah/react-native-mcp/pull/26)).

런타임에는 화면 정보를 주는 `getScreenInfo`와 testID로 요소 위치를 재는 `measureView`를 추가하고, 확장 제스처 지원 단계를 설계 문서에 정리했습니다([#28](https://github.com/ohah/react-native-mcp/pull/28)). iOS용 idb 도구와 공용 `run_command`·`switch_keyboard`, 설치 가이드를 넣었고([#29](https://github.com/ohah/react-native-mcp/pull/29)), Android용 adb 도구도 추가한 뒤 둘을 `platform` 인자로 나누는 `tap`·`swipe`·`input_text` 같은 플랫폼 중립 도구로 합쳤습니다([#30](https://github.com/ohah/react-native-mcp/pull/30)). 이에 맞춰 `click`·`click_by_label`·`scroll` 등 기존 상호작용 도구를 `query_selector`로 좌표를 얻은 뒤 `tap`하는 방식으로 바꾸고, 데모 앱은 탭 대신 질문과 과제를 단계별로 넘기는 Q&A 형식으로 재구성했습니다. `webview_evaluate_script`의 결과 피드백과 WebView `onMessage` 자동 주입, `key` prop 기반 동적 testID, Hermes에서 `URL.origin`이 없을 때의 대체 처리도 들어갔고, 서버 버전은 0.1.0001-rc.1로 바꿨습니다.

ohah.github.io에는 CRD 개발 과정 문서가 여러 편 채워졌습니다. 순차 작성용 크론 가이드를 추가한 뒤 CDP 클라이언트와 WebSocket 릴레이 서버(development-1), Redux DevTools 패널과 MMKV·AsyncStorage 보드(development-2), React Native 연동과 TurboModule(development-4, 5), 네이티브 걷어 내기(development-7), 커스텀 패널(development-8), 마무리(development-9), 배민 구현 따라 하기(3-1) 글이 올라갔습니다. hwpjs는 `pagination.rs`의 Clippy 경고와 `ImageInfo`의 쓰이지 않는 필드를 정리했습니다.

공개 커밋 66개, 해당일 생성 또는 병합된 PR 8개를 정리했습니다. PR 생성 7개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
