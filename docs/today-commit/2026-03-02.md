## 요약 (AI 작성)

react-wasm-table은 PR 여덟 개를 main에 병합했습니다. 테마·컬럼·셀 단계로 테두리를 덮어쓰는 테두리 스타일 기능을 넣으면서 기본 테두리를 없음으로 바꿨고([#48](https://github.com/ohah/react-wasm-table/pull/48)), WASM과 JS의 행 번호를 헤더 0부터 시작하는 하나의 체계로 합쳤습니다. 컬럼 끌어 옮기기를 헤더 오른쪽 손잡이 영역으로 제한하고 선택 영역에 헤더 셀을 포함하는 수정([#49](https://github.com/ohah/react-wasm-table/pull/49)), 데모 WASM 바이너리 갱신([#50](https://github.com/ohah/react-wasm-table/pull/50)), 그룹 헤더 위치를 TS에서 계산하는 다단 컬럼 헤더 렌더링과 히트 테스트([#51](https://github.com/ohah/react-wasm-table/pull/51))가 이어졌습니다.

오후에는 셀 편집을 진행했습니다. `TableMeta`의 `updateData`로 값을 반영하고 `editTrigger`, 편집 가능한 셀의 텍스트 커서, Tab 이동을 붙였으며([#52](https://github.com/ohah/react-wasm-table/pull/52)), `EditorManager`를 상태 관리만 맡도록 바꾸고 포털로 그리는 Text·Number·Select 기본 에디터, `editCell` 렌더 prop, 입력하면 바로 편집하는 기능, 스크롤 시 취소를 추가했습니다([#53](https://github.com/ohah/react-wasm-table/pull/53), [#54](https://github.com/ohah/react-wasm-table/pull/54)). 마지막으로 `totalCount`·`onFetchMore`·`fetchAhead`를 쓰는 무한 스크롤과 WASM 컬럼 저장소에 새 행만 덧붙이는 증분 추가, TanStack 스트리밍 데모를 병합했고, `Table`이 기본 페이지 크기 10을 늘 넘겨 모든 데모가 10행으로 잘리던 문제도 고쳤습니다([#55](https://github.com/ohah/react-wasm-table/pull/55)). twoslash 예제 오류를 없애는 문서 PR [#56](https://github.com/ohah/react-wasm-table/pull/56)은 이날 열렸습니다.

hwpjs는 전날 열린 표 셀·글상자 다단 렌더링 [#89](https://github.com/ohah/hwpjs/pull/89)를 병합했습니다. 이 과정에서 다단의 줄 높이·위치와 둘째 단 텍스트를 바로잡고, 도형 캡션에 자동 번호를 그리며 본문 기본 줄 간격을 캡션에도 적용했습니다. markdown 뷰어 테스트 [#84](https://github.com/ohah/hwpjs/pull/84)·[#87](https://github.com/ohah/hwpjs/pull/87)·[#90](https://github.com/ohah/hwpjs/pull/90)과 `shape_component` 자식 변환 테스트 [#92](https://github.com/ohah/hwpjs/pull/92), `para_text` 테스트와 경계 사례 수정 [#93](https://github.com/ohah/hwpjs/pull/93)도 들어왔고, `to_pdf` FFI가 `Result`가 아닌 `Vec` 바이트를 돌려주도록 고쳤습니다. 쪽 단위·글상자·표 셀·인라인 콘텐츠를 아우르는 다단 렌더링 PR [#94](https://github.com/ohah/hwpjs/pull/94)가 열렸고, [#91](https://github.com/ohah/hwpjs/pull/91)은 닫혔습니다.

cheolsu-proxy는 헤드리스 CLI 모드 PR [#59](https://github.com/ohah/cheolsu-proxy/pull/59)를 닫고, GUI와 CLI가 함께 쓰는 프록시 데몬을 분리하는 [#60](https://github.com/ohah/cheolsu-proxy/pull/60)을 열었습니다. ohah.github.io에는 크론이 `CRON_CRD_WRITE.md`에 "검사할 mdx 없음"을 반복 기록한 커밋이 15개 쌓였습니다.
