## 요약 (AI 작성)

zntc는 이날 ES5 타깃 다운레벨링을 거의 하루 만에 쌓아 올렸습니다. `__async` 런타임 헬퍼 자동 주입([#401](https://github.com/ohah/zntc/pull/401))과 CLAUDE.md를 BUNDLER·PLUGINS·HMR 문서로 나누는 정리([#402](https://github.com/ohah/zntc/pull/402))에 이어, ES5 타깃과 런타임 헬퍼 구조를 깔고([#404](https://github.com/ohah/zntc/pull/404)) 템플릿 리터럴, 단축·계산된 프로퍼티, 기본값·rest 매개변수, spread, 화살표 함수, for-of, 구조 분해, `let`·`const`, 클래스를 차례로 ES5 코드로 바꾸는 PR을 병합했습니다([#405](https://github.com/ohah/zntc/pull/405)부터 [#414](https://github.com/ohah/zntc/pull/414)까지). generator는 상태 머신으로 바꾸고 변수 호이스팅, `yield*`, try 블록 안의 yield, 레이블 continue와 switch 안의 yield까지 다뤘으며([#416](https://github.com/ohah/zntc/pull/416)부터 [#422](https://github.com/ohah/zntc/pull/422)까지), 클래스의 extends·super·getter와 setter, `#field`를 WeakMap으로 바꾸는 private 멤버 변환도 넣었습니다. 저녁에는 다운레벨링 스모크·유닛·통합 테스트를 더하고([#424](https://github.com/ohah/zntc/pull/424)부터 [#426](https://github.com/ohah/zntc/pull/426)까지) private field가 여럿인 클래스의 패닉을 고쳤습니다([#427](https://github.com/ohah/zntc/pull/427)).

번들러 쪽은 namespace import의 프로퍼티 추적과 문장 단위 트리 셰이킹을 넣고([#428](https://github.com/ohah/zntc/pull/428), [#429](https://github.com/ohah/zntc/pull/429)), generator 무한 루프와 async 변환 오류를 고치면서 번들 크기 비교 대시보드를 추가했습니다([#430](https://github.com/ohah/zntc/pull/430)). 밤에는 generator 죽은 코드 제거([#433](https://github.com/ohah/zntc/pull/433)), ES2018 object rest와 private field 증감 연산([#434](https://github.com/ohah/zntc/pull/434)), `useDefineForClassFields=false`의 static 필드([#435](https://github.com/ohah/zntc/pull/435)), 매개변수 데코레이터와 ES5 타깃 데코레이터([#438](https://github.com/ohah/zntc/pull/438))를 병합했고, TSC 적합성 테스트를 데코레이터 73개, 다운레벨링 230개, ES6·클래스·enum·generator 등 1,877개 추가했습니다([#439](https://github.com/ohah/zntc/pull/439), [#440](https://github.com/ohah/zntc/pull/440)). 서브패스 `package.json` 해석과 `module` 필드의 ESM 파싱 수정([#441](https://github.com/ohah/zntc/pull/441))도 들어왔습니다.

bungae에는 zts 기반 번들러 뼈대와 이전 계획을 담은 [#39](https://github.com/ohah/bungae/pull/39)가 열렸고 병합되지 않았습니다. 블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋과 3월 26일 오늘의 커밋 요약 작성이 올라왔습니다.
