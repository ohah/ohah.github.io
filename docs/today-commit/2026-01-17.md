## 요약 (AI 작성)

chrome-remote-devtools는 서버 종료 상태 추적과 React Native Inspector 재연결을 다룬 [#83](https://github.com/ohah/chrome-remote-devtools/pull/83)을 병합했습니다. 서버에 `ShutdownStatus`를 두어 종료가 끝났는지 추적하고, Tauri 명령이 이 상태를 돌려주면 inspector가 Reactotron 토글 툴팁에 보여 주도록 했습니다. React Native inspector는 Android·iOS에서 지수 백오프로 자동 재연결하고 앱이 포그라운드로 돌아오면 다시 연결하며, 서버는 같은 `deviceId`와 `appName`의 기존 연결을 재사용해 sender만 바꿉니다. Reactotron 클라이언트 판별을 URL의 `reactotron://` 접두사로 고쳤고, iOS WebSocket 오류 처리의 EXC_BAD_ACCESS, Objective-C++ 컴파일 오류, 로그 형식 문자열 불일치를 바로잡았습니다. Android 에뮬레이터 감지는 `ro.kernel.qemu` 속성을 읽도록 바꾸고 `Runtime.exec()` 대신 SystemProperties 리플렉션을 썼으며, inspector에서는 웹·React Native 토글과 탭 닫기 기능을 지웠습니다.

새 저장소 bungae를 만들었습니다. React Native용 번들러 핵심 패키지와 CLI를 추가하고, Android·iOS 네이티브 프로젝트를 갖춘 ExampleApp, lint·test·build GitHub Actions 워크플로, Claude·Cursor용 개발 문서와 규칙을 넣었습니다. macOS 빌드 실패를 피하려고 Ruby 버전을 3.3으로 올리고, Android 빌드에 필요한 `@react-native/gradle-plugin`·`@react-native/codegen`을 추가했습니다.

ohah.github.io에는 hwpjs 개발기에 NAPI-RS 배포와 Craby 배포 섹션을 추가하고 WASM 빌드 위치와 Buffer 폴리필 시행착오를 보강하면서 개발기 6·7·8편을 정리했습니다. Craby 문서에는 기여 배경 섹션을 새로 쓰고, 흐름도 링크 색을 다크·라이트 테마 모두에서 보이게 바꿨습니다. hwpjs는 Node 패키지의 0.1.0-rc.4 빌드 산출물을 갱신했습니다.
