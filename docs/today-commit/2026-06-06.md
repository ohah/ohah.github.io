> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 macOS 렌더링 경로를 smoke 테스트로 한 단계씩 쌓았습니다. 전날 열린 Metal smoke [#63](https://github.com/ohah/maru/pull/63)을 병합한 뒤 placeholder 셀 그리기와 readback 검증([#65](https://github.com/ohah/maru/pull/65), [#66](https://github.com/ohah/maru/pull/66))을 붙였고, CoreText shaping smoke([#67](https://github.com/ohah/maru/pull/67))에서 나온 glyph를 atlas 키로 넘기고 래스터·texture·text smoke([#69](https://github.com/ohah/maru/pull/69), [#71](https://github.com/ohah/maru/pull/71), [#72](https://github.com/ohah/maru/pull/72))와 스크린샷 캡처까지 이어 갔습니다. glyph frame 계약([#74](https://github.com/ohah/maru/pull/74))을 세워 CoreText smoke와 앱 호스트가 이를 거치게 했고, appearance 설정 해석([#77](https://github.com/ohah/maru/pull/77))과 공용 `color.Rgb` 분리([#78](https://github.com/ohah/maru/pull/78))로 해석된 폰트·테마 색을 smoke에 적용했습니다. 창 backing scale에 맞춘 probe 준비([#88](https://github.com/ohah/maru/pull/88)), font size·device scale 상하한 고정, RenderFrame 통계 직렬화 단일화([#92](https://github.com/ohah/maru/pull/92), [#93](https://github.com/ohah/maru/pull/93)), atlas 슬롯 배치([#91](https://github.com/ohah/maru/pull/91), [#94](https://github.com/ohah/maru/pull/94)), glyph quad UV frame([#95](https://github.com/ohah/maru/pull/95))이 뒤를 이었고, 런타임·외부 프로파일러 전략 문서([#85](https://github.com/ohah/maru/pull/85))와 PR metadata 체크 중복 실행 정리([#70](https://github.com/ohah/maru/pull/70))도 들어왔습니다. render frame이 glyph quad를 소유하게 하는 [#96](https://github.com/ohah/maru/pull/96)은 이날 PR이 열렸습니다.

suji는 Electron API 맞추기를 이어 갔습니다. BrowserWindow에 `focus`·`isNormal`([#81](https://github.com/ohah/suji/pull/81)), bounds·size·position 조회([#82](https://github.com/ohah/suji/pull/82)), 가시성·포커스·always-on-top([#83](https://github.com/ohah/suji/pull/83)), 전체 창과 포커스 창 조회([#84](https://github.com/ohah/suji/pull/84)), 콘텐츠 영역 bounds([#92](https://github.com/ohah/suji/pull/92))를 더했고, Rust·Go SDK에도 창 생명주기·상태 메서드 21종을 넣었습니다([#85](https://github.com/ohah/suji/pull/85), [#86](https://github.com/ohah/suji/pull/86)). `screen.getDisplayMatching`은 JS SDK로 추가한 뒤 코어 명령으로 옮겨 6개 언어에서 쓰게 했고([#89](https://github.com/ohah/suji/pull/89)), `powerMonitor.isOnBatteryPower`·`nativeTheme.themeSource`·`Notification.removeAll`([#91](https://github.com/ohah/suji/pull/91))과 그 Linux 빌드 수정([#93](https://github.com/ohah/suji/pull/93)), single-instance 락([#94](https://github.com/ohah/suji/pull/94))도 들어왔습니다. `suji init`은 multi 스캐폴딩에 lua·python 백엔드를 추가하고([#79](https://github.com/ohah/suji/pull/79)) CLI의 python 스캐폴딩 e2e를 갖췄습니다.

zntc는 dev HMR과 cold 빌드 성능을 다듬었습니다. `computeRenames`의 중첩 바인딩 판정을 모듈별로 캐시하고([#4186](https://github.com/ohah/zntc/pull/4186)), 보존 경로에서 import·re-export 분석을 변경 모듈과 importer로 한정했으며([#4190](https://github.com/ohah/zntc/pull/4190)), 위상이 같으면 renumber를 건너뛰게 했습니다([#4192](https://github.com/ohah/zntc/pull/4192)). RN dev HMR의 watch 디바운스 기본값을 50ms에서 16ms로 낮추고([#4193](https://github.com/ohah/zntc/pull/4193)), dev cold 빌드가 병렬 scan을 타도록 바꿨습니다([#4194](https://github.com/ohah/zntc/pull/4194)). 포맷 체크 실패를 계기로 저장소에 자동 포매팅 pre-commit 훅을 두고([#4188](https://github.com/ohah/zntc/pull/4188)) 그 안전성도 보강했습니다([#4191](https://github.com/ohah/zntc/pull/4191)).

공개 커밋 77개, 해당일 생성 또는 병합된 PR 60개를 정리했습니다. PR 생성 59개·병합 59개는 같은 PR이 양쪽에 포함될 수 있습니다.
