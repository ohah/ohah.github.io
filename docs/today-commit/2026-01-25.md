## 요약 (AI 작성)

bungae는 React Native 번들용 실험적 트리 셰이킹 [#11](https://github.com/ohah/bungae/pull/11)을 병합했습니다. 쓰이지 않는 export와 모듈을 지우고 package.json의 `sideEffects` 필드를 따르며, Babel이 CommonJS로 바꾼 `exports.foo` 대입과 `Object.defineProperty` 형태의 export도 제거 대상으로 다룹니다. 트리 셰이킹 모듈은 타입·export 추출 등 작은 파일로 나눴고, 순환 의존을 다시 방문할 때 무한 재귀에 빠지던 문제와 `exports['foo']` 같은 계산된 속성 이름을 처리하지 못하던 문제를 고쳤습니다. `IMPLEMENTATION_STATUS.md`에는 트리 셰이킹을 실험적 완료로 표시했습니다.

저녁에는 Metro 호환 터미널 단축키와 빌드 진행률 표시를 담은 [#12](https://github.com/ohah/bungae/pull/12)를 병합했습니다. 개발 서버에서 r·d·j·i·a·c 키 입력을 받고, 진행률은 Metro의 `onDependencyAdd`·`onDependencyAdded` 방식으로 세도록 바꿨으며, 두 기능의 테스트를 추가했습니다. 불완전한 `build.ts`를 지우고 소스 맵과 에셋 추출을 갖춘 `build/index.ts`로 통일했고, 리뷰 지적과 타입·lint 오류를 정리했습니다.

공개 커밋 16개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 2개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
