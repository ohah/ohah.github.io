# 2026-07-04

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 사이드바 워크스페이스 그룹 기능을 SG1부터 SG5까지 한꺼번에 밀어붙였고, 관련 PR은 모두 main에 병합됐습니다. 그룹 소속을 따로 저장하지 않고 탭 순서의 `group_start` 마커에서 파생하는 데이터·직렬화 토대와 chrome `Row` union(SG1·SG2, [#1173](https://github.com/ohah/maru/pull/1173))에서 출발해, 가변 높이 hit-test와 `projectRows` 그룹 헤더 투영(SG3a·SG3b, [#1174](https://github.com/ohah/maru/pull/1174)), 카드 glyph·tint·스크롤 높이를 행 누적 위치로 맞춘 수정([#1175](https://github.com/ohah/maru/pull/1175), [#1176](https://github.com/ohah/maru/pull/1176)), 그룹 만들기·헤더 렌더·접기(SG3c, [#1177](https://github.com/ohah/maru/pull/1177))로 골격을 세웠습니다.

이어 카드를 드래그해 그룹에 넣고 빼는 조작(SG4, [#1178](https://github.com/ohah/maru/pull/1178)), 헤더를 잡아 그룹을 통째로 옮기는 드래그(SG5-1, [#1180](https://github.com/ohah/maru/pull/1180)), 헤더 밴드와 소속 카드 막대에 공통으로 쓰는 그룹 색(SG5-2, [#1181](https://github.com/ohah/maru/pull/1181)), 중첩 그룹과 형제 그룹 액션(SG5-3, [#1182](https://github.com/ohah/maru/pull/1182)), 드래그로 중첩 깊이를 바꾸는 조작(SG5-4, [#1184](https://github.com/ohah/maru/pull/1184))이 붙었습니다. 사용자 피드백에 따라 헤더 높이를 두 배로 늘리고 기본 밴드를 없애며 "그룹에서 빼기"를 넣었고([#1185](https://github.com/ohah/maru/pull/1185)), 그룹 헤더 우클릭 메뉴의 해제 후 참조(UAF)를 포함한 코드 리뷰 지적 15건을 고쳤습니다([#1186](https://github.com/ohah/maru/pull/1186)). IME 쪽에서는 줄 중간 한글 조합이 커서 자리 글자를 덮어 보이던 문제 때문에 preedit을 삽입형 미리보기로 되돌리고, dim 인라인 고스트만 오버레이 예외로 두었습니다([#1179](https://github.com/ohah/maru/pull/1179), [#1183](https://github.com/ohah/maru/pull/1183)).

markdown-editor에는 Tauri 2·React 19·CodeMirror 6·unified 스택의 설계 문서 세트(ADR 6개, 아키텍처, 성능 예산, 테스트 전략, 구현 계획)와 에이전트 가이드가 올라왔습니다. 이어 git 훅으로 린트·테스트를 강제하고 macOS 우선의 최소 CI를 구성했으며([#1](https://github.com/ohah/markdown-editor/pull/1)), 문서 중복을 단일 출처 원칙으로 정리하고([#2](https://github.com/ohah/markdown-editor/pull/2)), mise로 개발 환경을 통일하며 도구 버전을 고정했습니다([#3](https://github.com/ohah/markdown-editor/pull/3)). 기획 범위와 마크다운 정책 정리([#5](https://github.com/ohah/markdown-editor/pull/5)), mise 전환 때 놓친 명령 참조 6곳 수정([#6](https://github.com/ohah/markdown-editor/pull/6))도 병합됐고, 같은 주제의 codex PR [#4](https://github.com/ohah/markdown-editor/pull/4)는 병합 없이 닫혔습니다.

ohah.github.io에는 포맷 정리 커밋 하나가 있었습니다.

공개 커밋 41개, 해당일 생성 또는 병합된 PR 20개를 정리했습니다. PR 생성 20개·병합 19개는 같은 PR이 양쪽에 포함될 수 있습니다.
