# 2026-04-03

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 전날 도입한 `__esm` 래퍼를 실제 React Native 번들에서 돌리며 드러난 결함을 잡았습니다. `__esm` 모듈의 CJS export 출력 억제([#658](https://github.com/ohah/zntc/pull/658)), `__export()`를 래퍼 안으로 옮긴 수정([#659](https://github.com/ohah/zntc/pull/659)), namespace import를 `exports_xxx`로 바꾸는 rename([#660](https://github.com/ohah/zntc/pull/660)), export default의 `_default` 미정의([#662](https://github.com/ohah/zntc/pull/662)), import 변수 호이스팅([#668](https://github.com/ohah/zntc/pull/668)), rolldown 방식의 엄격한 실행 순서([#669](https://github.com/ohah/zntc/pull/669)), CJS default import의 `__toESM` 래핑([#670](https://github.com/ohah/zntc/pull/670)), 래핑 모듈을 scope hoisting 모듈보다 먼저 내보내는 정렬([#674](https://github.com/ohah/zntc/pull/674)) 등이 이어졌습니다. 번들 rename이 ES5 클래스 변환과 optional chaining 복제 노드에 반영되지 않던 symbol_id 전파 누락([#676](https://github.com/ohah/zntc/pull/676)~[#678](https://github.com/ohah/zntc/pull/678)), Flow 타입 캐스트 안 식의 symbol_id 누락([#667](https://github.com/ohah/zntc/pull/667)), 제네릭 `new` 식이 이중 호출로 출력되던 파서 버그([#672](https://github.com/ohah/zntc/pull/672))도 고쳤습니다.

Metro 호환 기능으로는 `--platform=react-native`에서 ESM 모듈을 require 시점에 실행하는 지연 로딩([#682](https://github.com/ohah/zntc/pull/682)), 폴리필과 초기화 모듈을 넣는 `--polyfill`·`--run-before-main`([#683](https://github.com/ohah/zntc/pull/683), [#686](https://github.com/ohah/zntc/pull/686)), RN 전역 이름과 모듈 변수 충돌을 막는 `--global-identifier`([#689](https://github.com/ohah/zntc/pull/689))를 추가했고, dev 모드에서는 `__DEV__`를 true로 둡니다([#663](https://github.com/ohah/zntc/pull/663)). I/O 없는 독립 `transpile` 모듈을 분리해 폴리필의 Flow 구문을 걷어 내게 했으며([#685](https://github.com/ohah/zntc/pull/685)), ES5 클래스 다운레벨링은 Hermes 이름 충돌을 피하려고 SWC와 같은 IIFE 패턴으로 바꿨습니다([#691](https://github.com/ohah/zntc/pull/691), [#693](https://github.com/ohah/zntc/pull/693)). `__esm` 래퍼 안 클래스 선언 호이스팅 수정 [#694](https://github.com/ohah/zntc/pull/694)는 이날 PR이 열렸습니다.

bungae는 연동 대상 표기를 zts로 바꾸고, ZTS의 새 옵션으로 RN 폴리필과 InitializeCore를 넘겨 Metro와 같은 초기화 순서를 맞췄습니다([#41](https://github.com/ohah/bungae/pull/41)). Hermes에 `global`이 없어 생기는 에러를 banner prelude로 막고, 바이너리 경로 탐색과 전역 식별자 예약도 붙였습니다. suji는 libnode 다운로드 URL을 자체 릴리스로 고정하고([#5](https://github.com/ohah/suji/pull/5)), Node.js 백엔드의 크로스 호출과 async invoke([#6](https://github.com/ohah/suji/pull/6)), 문서 동기화와 `suji.json` JSON Schema([#7](https://github.com/ohah/suji/pull/7))를 병합했으며, `@suji/node` SDK PR [#8](https://github.com/ohah/suji/pull/8)을 열었습니다. ohah.github.io에는 맞춤법 크론이 수정 없이 검사만 남긴 커밋이 있습니다.

공개 커밋 57개, 해당일 생성 또는 병합된 PR 41개를 정리했습니다. PR 생성 41개·병합 38개는 같은 PR이 양쪽에 포함될 수 있습니다.
