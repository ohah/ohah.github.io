# 2026-04-02

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 ES5 다운레벨링 결함을 몰아서 고쳤습니다. ES5 타깃에서 async/await를 generator를 거치지 않고 바로 상태 기계로 바꾸고([#605](https://github.com/ohah/zntc/pull/605)), 상태 기계 안의 구조 분해 var 호이스팅([#606](https://github.com/ohah/zntc/pull/606)), 조건식·표현식 안의 yield/await 추출([#607](https://github.com/ohah/zntc/pull/607), [#608](https://github.com/ohah/zntc/pull/608)), 클래스 async 메서드([#609](https://github.com/ohah/zntc/pull/609)), generator for-of([#627](https://github.com/ohah/zntc/pull/627)), finally 없는 try/catch에서 return await 값이 사라지던 문제([#615](https://github.com/ohah/zntc/pull/615)), catch 파라미터 호이스팅 누락([#618](https://github.com/ohah/zntc/pull/618))을 차례로 수정했습니다. export default class의 빈 출력([#603](https://github.com/ohah/zntc/pull/603))과 computed key 표기([#604](https://github.com/ohah/zntc/pull/604))도 바로잡았고, ES2022 private method를 WeakSet 기반으로 다운레벨링하는 기능([#640](https://github.com/ohah/zntc/pull/640))을 넣었습니다.

React Native 번들 호환도 크게 진척됐습니다. Metro의 플랫폼 확장자 규칙에 맞춘 `--rn-platform=ios|android`([#616](https://github.com/ohah/zntc/pull/616))를 추가했고, Flow 파싱을 `import typeof`·generic arrow·static variance·const generic·match 식 등으로 넓혀 resolve 모듈 수를 449개에서 577개로 늘렸으며([#617](https://github.com/ohah/zntc/pull/617), [#620](https://github.com/ohah/zntc/pull/620)~[#624](https://github.com/ohah/zntc/pull/624)), Flow match 식은 if-else IIFE로 변환합니다([#631](https://github.com/ohah/zntc/pull/631)). RN ExampleApp 번들을 hermesc로 컴파일해 보는 검증 테스트와 CI job([#629](https://github.com/ohah/zntc/pull/629), [#651](https://github.com/ohah/zntc/pull/651))을 두고, CJS import 별칭 변환, JSX 멤버 태그와 텍스트 줄바꿈, CJS preamble 변수 충돌, export default 자기 참조 재선언을 고쳐 hermesc 에러를 0으로 만들었습니다([#636](https://github.com/ohah/zntc/pull/636), [#637](https://github.com/ohah/zntc/pull/637)).

번들러는 esbuild·rolldown과 같은 `WrapKind.esm`과 `__esm` 래퍼를 도입해([#646](https://github.com/ohah/zntc/pull/646)) require로 소비되는 ESM 모듈의 live binding과 지연 초기화를 지원하고, CJS 모듈이 scope hoisting된 ESM을 import할 때까지 require 미변환을 없앴습니다([#647](https://github.com/ohah/zntc/pull/647), [#648](https://github.com/ohah/zntc/pull/648)). `__esm` 안의 함수 선언 호이스팅은 넣었다가 실행 순서 문제로 걷어 내고 `init_xxx()` 호출 주입으로 정리했으며([#653](https://github.com/ohah/zntc/pull/653)~[#655](https://github.com/ohah/zntc/pull/655)), react-native 플랫폼에서 `__DEV__`를 자동 define하도록 했습니다([#656](https://github.com/ohah/zntc/pull/656), [#657](https://github.com/ohah/zntc/pull/657)).

suji는 이날 PR 네 개를 main에 병합했습니다. `suji://` 사용자 정의 프로토콜과 webview.h 제거·CI 추가([#1](https://github.com/ohah/suji/pull/1)), macOS·Linux 크로스 플랫폼 빌드([#2](https://github.com/ohah/suji/pull/2)), 파일 감시와 dylib 재적재 기반 백엔드 핫 리로드([#3](https://github.com/ohah/suji/pull/3)), libnode를 임베드한 Node.js 백엔드([#4](https://github.com/ohah/suji/pull/4))입니다.

공개 커밋 60개, 해당일 생성 또는 병합된 PR 55개를 정리했습니다. PR 생성 55개·병합 55개는 같은 PR이 양쪽에 포함될 수 있습니다.
