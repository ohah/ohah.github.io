## 요약 (AI 작성)

chrome-remote-devtools는 React Native 인스펙터가 다시 연결될 때 같은 deviceId면 이전 clientId를 재사용하도록 서버를 바꾸고([#100](https://github.com/ohah/chrome-remote-devtools/pull/100)), 앱 쪽에서는 AsyncStorage에 안정적인 deviceId를 두어 재연결 시 DevTools iframe이 다시 로드되지 않게 했습니다. 콘솔·네트워크 훅은 `Object.defineProperty(s)`로 설치·복원하도록 바꾸고 테스트를 붙였으며, WebSocket 연결 중 끊김 경쟁 상태도 처리했습니다([#101](https://github.com/ohah/chrome-remote-devtools/pull/101)). 이어 devtools-frontend 서브모듈에 React DevTools Components·Profiler 패널을 넣어 React Native 클라이언트에서만 보이게 하고, `Runtime.evaluate` 반환값과 `Runtime.addBinding`·`bindingCalled`를 구현해 렌더링되도록 했습니다([#102](https://github.com/ohah/chrome-remote-devtools/pull/102)).

같은 저장소에서 Tauri 인스펙터의 DevTools iframe에 모든 권한을 허용해 클립보드 복사와 Copy object, 우클릭 메뉴가 동작하게 했고([#103](https://github.com/ohah/chrome-remote-devtools/pull/103)), Safari/WebKit에서 콘솔 객체가 클릭으로 펼쳐지지 않던 문제도 고쳤습니다. 디버그 빌드 전용 Tauri MCP Bridge 플러그인과 작업 공간 MCP 설정·`setup-mcp` 스크립트([#104](https://github.com/ohah/chrome-remote-devtools/pull/104)), Maestro와 Tauri MCP로 RN 동작을 검증하는 Cursor skill 문서([#105](https://github.com/ohah/chrome-remote-devtools/pull/105))도 병합했습니다.

gif2mp4는 이날 첫 커밋으로 시작했습니다. Rust로 GIF를 디코드하고 WebCodecs로 인코딩해 `mp4-muxer`로 묶는 구조이며, oxlint·oxfmt·rustfmt·clippy 린트와 WASM 빌드 검증 워크플로를 추가했습니다([#1](https://github.com/ohah/gif2mp4/pull/1)). Rspress 문서를 한국어·영어로 나누고 사용 예시 페이지를 붙였고([#2](https://github.com/ohah/gif2mp4/pull/2)), 커밋·PR·리뷰 커맨드 규칙 문서도 정리했습니다.

공개 커밋 34개, 해당일 생성 또는 병합된 PR 8개를 정리했습니다. PR 생성 8개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
