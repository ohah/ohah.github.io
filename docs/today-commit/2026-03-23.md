> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 전날 연 벤치마크 스위트([#277](https://github.com/ohah/zntc/pull/277))를 병합하며 단계별 파이프라인 프로파일링과 Bun을 포함한 7개 도구 비교를 넣었고, `.ts` 같은 파일을 자동으로 ESM 모듈 모드로 처리해 트랜스파일을 18배 빠르게 했습니다([#278](https://github.com/ohah/zntc/pull/278)). 변수 이름을 줄이는 identifier mangling을 단일 파일과 번들 모드에 넣은 뒤([#279](https://github.com/ohah/zntc/pull/279), [#280](https://github.com/ohah/zntc/pull/280)), lodash-es·preact·date-fns·uuid·zod 다섯 패키지를 번들링하는 실제 프로젝트 스모크 테스트를 시작했습니다([#281](https://github.com/ohah/zntc/pull/281)).

이후 하루 대부분은 스모크 테스트가 드러낸 문제를 고치는 데 쓰였습니다. namespace import를 esbuild 방식으로 `ns.prop` 직접 치환하고 `export * as ns`를 지원해 zod를 통과시켰고([#288](https://github.com/ohah/zntc/pull/288), [#290](https://github.com/ohah/zntc/pull/290)), contextual keyword를 식별자로 허용하는 파서 수정([#291](https://github.com/ohah/zntc/pull/291)), `sideEffects` 글롭 패턴([#293](https://github.com/ohah/zntc/pull/293)), CJS 내부 `require()` 번들링과 JSON 모듈, `node_modules`의 `.js`를 CJS로 간주하는 처리 등 CJS 상호 운용 개선([#295](https://github.com/ohah/zntc/pull/295))이 이어졌습니다. axios·Redux Toolkit·express·superjson·zustand·effect·yargs에서 나온 버그를 고치고([#296](https://github.com/ohah/zntc/pull/296), [#297](https://github.com/ohah/zntc/pull/297), [#300](https://github.com/ohah/zntc/pull/300)), 2단계 선언 방식으로 전방 참조를 해결했으며([#301](https://github.com/ohah/zntc/pull/301)), 스모크 테스트 결과를 PR 댓글로 남기는 CI([#303](https://github.com/ohah/zntc/pull/303))와 scope hoisting 충돌 회피의 전역 이름 자동 수집([#304](https://github.com/ohah/zntc/pull/304))을 넣었습니다. 스모크 테스트는 vue·svelte·solid·three·react-dom·d3·hono 등을 더해 47개로 늘었습니다([#305](https://github.com/ohah/zntc/pull/305), [#311](https://github.com/ohah/zntc/pull/311)).

밤에는 `--platform=node`에서 `package.json` exports의 node 조건 사용([#307](https://github.com/ohah/zntc/pull/307)), barrel re-export의 export 체인 추적([#308](https://github.com/ohah/zntc/pull/308)), TS contextual keyword 30개를 식별자로 통합한 렉서 정리([#309](https://github.com/ohah/zntc/pull/309))를 병합했습니다. export default 함수 이름의 contextual keyword 인식을 고치려던 [#306](https://github.com/ohah/zntc/pull/306)은 병합 없이 닫혔습니다. CLI `--define:KEY=VALUE`([#312](https://github.com/ohah/zntc/pull/312)), CJS 트리 셰이킹과 메모리 누수 수정([#313](https://github.com/ohah/zntc/pull/313)), CJS 모듈의 `export *` 지원과 esbuild·rolldown 호환 `__toESM`([#314](https://github.com/ohah/zntc/pull/314))이 들어왔고, Playwright 브라우저 E2E를 31개까지 늘렸습니다([#315](https://github.com/ohah/zntc/pull/315), [#316](https://github.com/ohah/zntc/pull/316)). 발견한 문제는 `ISSUES.md`로 정리하기 시작했습니다. 브라우저 호환성을 위한 `import.meta` polyfill 등의 [#317](https://github.com/ohah/zntc/pull/317)은 이날 PR이 열렸습니다.

cheolsu-proxy는 Store 로직을 `OpsStore`로 합쳐 CLI와 MCP 사이 중복을 없앴습니다([#321](https://github.com/ohah/cheolsu-proxy/pull/321)). 블로그 저장소에는 맞춤법 크론의 상태 갱신 커밋과 3월 23일 오늘의 커밋 요약 작성이 올라왔습니다.
