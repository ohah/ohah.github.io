## 요약 (AI 작성)

chrome-remote-devtools는 React Native inspector의 콘솔 객체 처리를 웹 클라이언트와 맞춘 [#99](https://github.com/ohah/chrome-remote-devtools/pull/99)를 병합했습니다. CDP `objectId`를 발급·조회·해제하는 객체 저장소를 두고, `Runtime.getProperties`와 `Runtime.releaseObject`를 처리해 DevTools 콘솔에서 객체를 펼쳐 볼 수 있게 했습니다. 리뷰를 반영해 서버 정보가 있으면 objectId가 없어도 빈 결과로 응답하게 했고, 저장소 크기 상한을 두었으며, `executionContextCreated` 성공 로그를 지웠습니다. 객체 저장소, 속성 조회, CDP 메시지 처리기 단위 테스트도 추가했습니다.
