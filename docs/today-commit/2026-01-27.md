## 요약 (AI 작성)

bungae는 소스 맵과 Metro 호환성 PR 세 개를 병합했습니다. [#14](https://github.com/ohah/bungae/pull/14)는 Chrome DevTools 무시 목록 기능을 위한 `x_google_ignoreList`를 구현하고, Metro와 같은 줄 수 계산을 썼으며, 초기화 코드인 prelude는 디버깅할 수 있도록 무시 목록에서 뺐습니다. 모듈 매개변수 이름을 Metro처럼 `_$$_REQUIRE`·`_dependencyMap`으로 바꾸고 AST 수준에서 define으로 감쌌으며, 개발 서버는 `jsc-safe-url`로 sourceURL을 만들도록 했습니다. 변환기에는 `babel-plugin-transform-define`으로 `__DEV__`를 치환하고 minify 플러그인으로 죽은 코드를 지우는 단계를 넣었고, 변환된 AST에 `any` 대신 BabelAST 타입을 썼습니다.

구현 현황 문서를 실제 코드에 맞춰 Phase 2와 Phase 3 완료로 고친 [#15](https://github.com/ohah/bungae/pull/15)에 이어, DevTools의 `console.log` 위치가 정확히 나오도록 한 [#16](https://github.com/ohah/bungae/pull/16)을 병합했습니다. 비동기 SourceMapConsumer 대신 `vlq` 패키지로 매핑을 직접 해석하고, prepend 모듈 매핑을 고쳤으며, 모듈 이름은 항상 상대 경로로 내고 `sourcePaths` 옵션을 빌드 파이프라인 전체로 넘기도록 했습니다. prepend 모듈에도 `shouldAddToIgnoreList`를 적용했습니다.

chrome-remote-devtools에는 Rust 서버가 `Network.responseReceived` 이벤트의 응답 본문을 저장해 `Network.getResponseBody`에 답하도록 하는 PR [#89](https://github.com/ohah/chrome-remote-devtools/pull/89)를 열었습니다.

공개 커밋 17개, 해당일 생성 또는 병합된 PR 4개를 정리했습니다. PR 생성 4개·병합 3개는 같은 PR이 양쪽에 포함될 수 있습니다.
