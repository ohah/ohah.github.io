# 2026-08-25

## 요약 (AI 작성)

Windows 가 앱 모양을 갖추고 접근성 축이 열린 날입니다. 사이드바 카드와 헤더 아이콘이 눌리고, ＋ 가 세션을 만들고 카드가 전환하며, 도크와 사이드바가 굴러가고(앞부분이 아니라 창이다), 하단 상태표시줄이 섰습니다(W8.9). 헤더 아이콘 줄은 창 버튼과 같은 띠에 놓았습니다. 접근성은 서술자 계약을 먼저 열고(생산자까지, 읽는 쪽은 아직 없다) 스냅숏·ABI v172·Swift 어댑터로 host 에 연결했습니다.

에이전트 쪽은 턴이 만진 파일을 직접 캡처해 ✎ 가 내 것과 남의 것을 가르게 했고(AT3), 「턴이 끝나는 그 순간」을 지키지 않아 사본·세션·셸 수가 어긋나던 것을 잡았습니다. codex 훅이 하나도 안 돌고 있던 것(낡은 신뢰 값)과 방금 승인한 사람에게 「승인하라」고 말하던 것을 고쳤고, codex 오류 턴은 세트를 늘려도 못 닫는다는 실측을 박았습니다. session-host 는 checkpoint coordinator 를 넣고 incremental checkpoint 구동 계약을 적었으며, host 를 못 띄웠는데 4초를 기다리던 자리를 닫았습니다.

Lab 은 pane 합성 축을 열어 도크가 상태바를 덮지 않는지 골든이 보게 했고, 픽스처가 /tmp 에 남긴 2만 개를 거뒀습니다. 모바일은 긴 안내가 잘리는 대신 접히고, 글자 폭을 한 함수로 모았습니다.
