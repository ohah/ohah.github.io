# 2026-05-08

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 전날 열린 RN의 기본 Babel 변환 패스 회피 수정([#2700](https://github.com/ohah/zntc/pull/2700))을 병합하고, init 오버레이 병합 때 의도치 않게 되돌려진 `parse_arena` heap 포인터 전환과 dev_mode 증분 재빌드 최적화를 다시 적용했습니다([#2701](https://github.com/ohah/zntc/pull/2701)). 이어 `unwrapNapi` 제네릭 헬퍼로 NAPI 언랩 반복 코드를 합치고([#2702](https://github.com/ohah/zntc/pull/2702)), playground에서 codeSplitting·preserveModules를 켜면 형식을 ESM으로 자동 전환하게 했으며([#2703](https://github.com/ohah/zntc/pull/2703)), import scanner의 호출식 처리를 callee 태그별 분기로 바꿨습니다([#2704](https://github.com/ohah/zntc/pull/2704)).

플러그인 쪽은 실패를 diagnostic으로 드러내고([#2705](https://github.com/ohah/zntc/pull/2705)), 플러그인 transform이 낸 sourcemap을 최종 sourcemap에 합성하며([#2706](https://github.com/ohah/zntc/pull/2706)), `buildSync`에서 동기 JS 플러그인을 지원하게 했습니다([#2708](https://github.com/ohah/zntc/pull/2708)). 그 뒤 TLS 채널을 `HookContext` out-param으로 바꾸고, async·sync dispatcher를 generator로 합쳐 lifecycle 채널을 하나로 줄였으며, `NapiPlugin`·`NapiSyncPlugin`의 hook별 어댑터를 comptime 제네릭으로 통합했습니다([#2709](https://github.com/ohah/zntc/pull/2709), [#2710](https://github.com/ohah/zntc/pull/2710), [#2712](https://github.com/ohah/zntc/pull/2712)). RN dev server 터미널은 bungae와 같은 로고 배너·단축키 표·핫키 피드백을 갖추고 `v` 키로 콘솔 로그를 켜고 끌 수 있게 됐고([#2707](https://github.com/ohah/zntc/pull/2707)), RN HMR 로딩 토스트도 고쳤습니다([#2711](https://github.com/ohah/zntc/pull/2711)).

semantic에서는 catch 블록 안 함수 재선언 검사([#2714](https://github.com/ohah/zntc/pull/2714))를 main에 병합했습니다. 그 위에 쌓은 계산된 constructor 키 제외, 계산된 중복 `__proto__` 키 무시, test262 실패 시 CI를 실패시키는 PR([#2715](https://github.com/ohah/zntc/pull/2715), [#2716](https://github.com/ohah/zntc/pull/2716), [#2717](https://github.com/ohah/zntc/pull/2717))은 각각 아래 PR의 브랜치로 병합됐습니다. 이 과정에서 중첩 블록 함수 선언이 rename과 어긋나 ReferenceError가 나던 회귀를 var_scope 심볼을 블록 스코프에 alias로 등록해 고쳤고, 중첩 블록 함수를 올바른 종류로 미리 선언하도록 했습니다([#2719](https://github.com/ohah/zntc/pull/2719)).

오후부터 밤까지는 거대한 테스트 파일을 쪼개는 작업이 이어졌습니다. core와 CLI 테스트 스위트를 나눈 [#2718](https://github.com/ohah/zntc/pull/2718)을 시작으로 app builder, watch, HMR, 플러그인, sourcemap, browserslist, 옵션 조합, vite 플러그인, 공통 헬퍼 등과 CLI의 bundle·tsconfig·config·dev server·transpile·serve 테스트를 주제별 파일로 옮기는 PR을 한 시간에 몇 개씩 병합했습니다([#2720](https://github.com/ohah/zntc/pull/2720)부터 [#2772](https://github.com/ohah/zntc/pull/2772)까지). 그 사이에 연 test262의 OS별 차이 추적용 [#2724](https://github.com/ohah/zntc/pull/2724)는 닫았고, 마지막 [#2773](https://github.com/ohah/zntc/pull/2773)은 이날 열려 5월 9일에 병합됐습니다. 블로그 저장소 ohah.github.io의 커밋 16개는 크론의 `CRON_CRD_WRITE.md` 점검 기록 15개와 요약 추가 1개입니다.
