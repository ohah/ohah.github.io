## 요약 (AI 작성)

electron-mcp-server는 CDP `Tracing`으로 성능 트레이스를 시작·종료해 trace JSON을 gzip으로 저장하는 성능 트레이스·인사이트 도구를 구현하고([#11](https://github.com/ohah/electron-mcp-server/pull/11)), 공통 `withCdpWs` 추출과 `performance_start_trace` 경쟁 상태 방지 같은 리뷰 반영을 거쳤습니다. 콘솔 도구 `list_console_messages`·`get_console_message`도 Chrome DevTools MCP 스펙에 맞춰 페이지네이션·유형 필터·상시 수집을 지원하게 하고, 목록 응답을 `msgid=N [level] text` 한 줄 형식으로 바꿨습니다.

배포 쪽은 npm publish 설정과 provenance를 쓰는 publish 워크플로를 추가하고 버전을 0.1.0-rc.1로 잡았으며([#12](https://github.com/ohah/electron-mcp-server/pull/12)), `npx` 실행 시 ajv 등 의존성 해석 오류가 나지 않도록 MCP SDK·ws를 하나의 dist로 번들하고 런타임 의존성을 비운 0.1.0-rc.2로 고쳤습니다([#13](https://github.com/ohah/electron-mcp-server/pull/13)). README를 영문·한글판으로 나누고 MIT 라이선스를 추가했습니다([#14](https://github.com/ohah/electron-mcp-server/pull/14)).

마지막으로 렌더러가 없을 때도 메인 프로세스에만 연결하는 콘솔 수집, 9229·9230 두 포트 연결, 메인 프로세스 리소스 사용량, Profiler·HeapProfiler 지원을 묶은 [#15](https://github.com/ohah/electron-mcp-server/pull/15)를 병합했습니다. 메인 프로세스 `Runtime.evaluate`에서 `require('os')`를 쓰도록 `includeCommandLineAPI`를 켰고, 도구 설명과 응답 메시지는 영어로 통일했습니다.

공개 커밋 20개, 해당일 생성 또는 병합된 PR 5개를 정리했습니다. PR 생성 5개·병합 5개는 같은 PR이 양쪽에 포함될 수 있습니다.
