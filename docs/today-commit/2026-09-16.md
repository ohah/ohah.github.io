# 2026-09-16

## 요약 (AI 작성)

편집기에 미니맵과 진단 층이 선 날입니다. 본문 오른쪽에 2px/1px 색 블록 스트립과 비례 스크롤·슬라이더·클릭/드래그 굴리기(N5a), 비교 뷰 막대의 변경 위치 마커와 미니맵 검색 행 강조(N5b, §6.2), 그리고 tree-sitter 구문 오류를 첫 출처로 하는 진단 층 — gutter 글리프·지그재그 밑줄·막대/미니맵 마커·F8/⇧F8(§5.4). 병합 모드는 세 판의 가로를 Result 의 것으로 통일하고 가로 휠이 안 듣던 결함을 잡았습니다(S6). 모바일은 삼성 자동완성이 «되잡은» 글자를 다시 보내 텍스트가 겹치던 것을 고치고, 세션 알림을 누르면 앱으로 돌아오며 상태바에 심볼이 뜹니다.

zntc 는 해석 못 한 import 를 포맷에 맞게 방출하고(ESM 에 `require()` 금지) return/throw/yield 앞 줄 주석의 ASI 를 고쳤습니다(#4651). hwpjs 는 EMF+ path·brush 객체를 파싱합니다.
