## 요약 (AI 작성)

chrome-remote-devtools는 React Native inspector를 JSI·네이티브 모듈 의존에서 JavaScript 계층으로 옮기기 시작했습니다. [#90](https://github.com/ohah/chrome-remote-devtools/pull/90)으로 네이티브 TurboModule 설치와 JS 쪽 네이티브 모듈 로딩을 지우고, 서버에 연결하는 JavaScript WebSocket 클라이언트와 새 JS 전용 `index.ts`를 두었으며, 기존 진입점은 `index.deprecated.ts`로 남겼습니다. 배포 파일도 JS만 포함하게 줄이고 Provider에서 JSI 상태 UI를 뺐습니다. MMKV 보기에서 빈 문자열을 유효한 값으로 다뤄 초기값과 변경 이벤트가 어긋나지 않게 했고, WebSocket 클라이언트 테스트를 추가하면서 연결이 끊긴 뒤에는 sender가 아무 일도 하지 않고 Redux·MMKV·AsyncStorage sender는 연결된 뒤에만 설정되도록 다듬었습니다.

개발 도구 설정도 손봤습니다. 커밋 규칙과 lint 필수화, PR 생성·Copilot 리뷰 반영용 Cursor 명령, React Native Inspector·DevTools 프런트엔드·Redux 등 11개 영역의 Cursor 하위 에이전트 규칙을 추가해 [#91](https://github.com/ohah/chrome-remote-devtools/pull/91)로 병합했고, mise에 gh를 넣고 PR은 영어로 쓰도록 정했습니다. 저녁에는 inspector를 JS 전용으로 만들고 네이티브 빌드를 끄는 PR [#92](https://github.com/ohah/chrome-remote-devtools/pull/92)를 열었습니다.

공개 커밋 13개, 해당일 생성 또는 병합된 PR 3개를 정리했습니다. PR 생성 3개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
