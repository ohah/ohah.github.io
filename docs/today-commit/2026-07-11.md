# 2026-07-11

## 요약 (AI 작성)

인앱 브라우저를 사용 가능한 물건으로 마감한 날입니다. 7e-3 에서 주소창의 back/forward/reload 버튼을 붙여 브라우저 골격을 완성하고, 7e-4 로 버튼 폴리시와 ⌘←/→/R 단축키를 더했습니다. 주소창 편집은 별도 입력 경로 대신 공유 `OverlayInput` 으로 리팩터해 IME 조합 표시를 얻고 중복을 없앴으며(사용자 지적 반영), `inputFocus` 에 `.addr_edit` 을 추가해 평문 타이핑이 새던 문제를 고쳤습니다. 이어 7f 로 새 창·팝업을 흡수해 — 7f-0 Swift-first web term 등록 ABI, 7f-1 `WKUIDelegate.createWebViewWith` adopt, 7f-2 위험 스킴 차단 정책 게이트 — 팝업이 앱 밖으로 새지 않게 했습니다. 손 테스트에서 나온 ⌘R 미동작, 링크 이동 시 주소창 미갱신, 탭 닫기 확인, 주소창 클릭-어웨이 포커스, 모달이 웹 패널에 가려 ⌘Q 확인이 Enter 를 못 받던 문제도 함께 정리했습니다.

포커스는 4g 로 한 축을 통합했습니다. 흩어져 있던 포커스 패치들을 웹↔터미널 포커스 동기 불변식으로 묶어(4g-0 활성 web surface getter → 4g-1 `reconcileWebFocus` → 4g-2 정리 검토 결론 → 4g-3 override 단일 출처) 설계 문서와 함께 정착시켰고, 렌더러 슬라이스로 탭·pane 드래그 시각물을 `WKWebView` 위 최상위 오버레이 레이어로 올렸습니다.

컨트롤 플레인은 라이브 `browser.*` 배선(5e)이 주제였습니다. §9.2·§9.3 을 doc-first 로 먼저 쓴 뒤 §5-async deferred marshal(in-flight 레지스트리)을 선행으로 깔고, 5e-1 `dispatchBrowser` 가 skeleton 대신 `BrowserOp` 를 반환하도록 바꾼 다음 5e-2a 라우팅, 5e-2b-1 Zig L4 marshal(op 큐·defer·take/complete ABI), 5e-2b-2 소켓 라이브 제어 E2E 까지 이었습니다. 1e-core 로 capability nonce 를 라이브 auth 경로에 배선해 browser/write/lifecycle 공통 토대도 마련했습니다. 13~17차 `/code-review max` 결함을 계속 흡수했고, 탭 전환 시 sync 게이트 오투영으로 화면이 사라지던 버그와 스모크의 web 패널 삐져나옴을 고쳤으며, 설정에는 네비 전체 리셋과 변경 행별 ↺ 를 제공하는 기본값 리셋 UX(CS-4-8)를 추가했습니다.
