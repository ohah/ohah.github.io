> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru 인앱 브라우저는 주소창 편집을 Swift에 배선해 클릭, URL 입력, Enter로 페이지를 여는 7e-2b([#1291](https://github.com/ohah/maru/pull/1291))와 back·forward·reload 버튼을 붙인 7e-3([#1292](https://github.com/ohah/maru/pull/1292))으로 기본 골격을 갖췄습니다. 7e-4는 버튼 hover 커서·하이라이트와 ⌘←/→/R 단축키를 더하고, 손 테스트에서 나온 ⌘R 미동작, 링크 이동 시 주소창 미갱신, web 패널을 보던 중 뜬 종료 확인 창이 Enter를 받지 못하던 문제를 함께 고쳤습니다([#1293](https://github.com/ohah/maru/pull/1293)). 주소창 편집은 별도 고정 버퍼 대신 find·palette와 같은 공유 `OverlayInput`을 쓰도록 바꿔 IME 조합 표시를 얻었고, `inputFocus`에 `.addr_edit`이 빠져 평문 타이핑이 새던 문제도 고쳤습니다.

새 창·팝업은 Swift 쪽에서 먼저 web Term을 등록하는 ABI(7f-0, [#1295](https://github.com/ohah/maru/pull/1295)), `WKUIDelegate.createWebViewWith`로 팝업을 새 브라우저 탭에 여는 처리(7f-1, [#1296](https://github.com/ohah/maru/pull/1296)), 위험 스킴을 막는 팝업 URL 정책(7f-2, [#1298](https://github.com/ohah/maru/pull/1298))으로 들어왔습니다. 마지막 창을 ⌘W나 빨간 버튼으로 닫으면 확인 없이 종료되던 문제는 Cmd+Q 종료 확인으로 합쳤고([#1297](https://github.com/ohah/maru/pull/1297)), 13차 리뷰 결함 11건과 브라우저 탭 닫기 확인·잘못된 주소 유지·주소창 클릭-어웨이 포커스 수정이 [#1300](https://github.com/ohah/maru/pull/1300)으로 병합됐습니다. 반복되던 포커스 버그는 4g로 묶어, 설계 문서([#1301](https://github.com/ohah/maru/pull/1301))와 활성 web surface getter(4g-0, [#1302](https://github.com/ohah/maru/pull/1302)), `reconcileWebFocus` 불변식(4g-1, [#1303](https://github.com/ohah/maru/pull/1303)), 정리 검토(4g-2, [#1304](https://github.com/ohah/maru/pull/1304)), override 단일 출처화(4g-3, [#1306](https://github.com/ohah/maru/pull/1306))까지 진행했습니다. 탭·pane 드래그 시각물은 WKWebView에 가리지 않도록 최상위 오버레이 레이어로 옮겼습니다([#1307](https://github.com/ohah/maru/pull/1307)).

컨트롤 플레인은 에이전트 브라우저 제어를 라이브로 연결했습니다. §9.2·§9.3 설계 문서([#1308](https://github.com/ohah/maru/pull/1308), [#1313](https://github.com/ohah/maru/pull/1313))를 먼저 쓰고, capability nonce를 라이브 auth 경로에 배선한 1e-core([#1309](https://github.com/ohah/maru/pull/1309)), 응답이 나중에 오는 메서드를 위한 in-flight 레지스트리([#1312](https://github.com/ohah/maru/pull/1312)), `dispatchBrowser`가 `BrowserOp`를 돌려주게 한 5e-1([#1314](https://github.com/ohah/maru/pull/1314))과 라우팅 5e-2a([#1315](https://github.com/ohah/maru/pull/1315)), Zig 쪽 op 큐 marshal 5e-2b-1([#1320](https://github.com/ohah/maru/pull/1320)), 소켓에서 실제 WKWebView를 구동하는 E2E 5e-2b-2([#1322](https://github.com/ohah/maru/pull/1322))까지 병합됐습니다. 15차부터 17차 리뷰 결함([#1311](https://github.com/ohah/maru/pull/1311), [#1319](https://github.com/ohah/maru/pull/1319), [#1325](https://github.com/ohah/maru/pull/1325))도 이어서 고쳤고, 누적 리뷰용 PR 4개([#1299](https://github.com/ohah/maru/pull/1299), [#1305](https://github.com/ohah/maru/pull/1305), [#1310](https://github.com/ohah/maru/pull/1310), [#1316](https://github.com/ohah/maru/pull/1316))는 병합 없이 닫혔습니다.

그 밖에 탭 전환 시 DECSET 2026 동기화 게이트가 잘못 투영돼 화면이 사라지던 버그를 고치고 문서에 반영했으며([#1317](https://github.com/ohah/maru/pull/1317), [#1318](https://github.com/ohah/maru/pull/1318), [#1321](https://github.com/ohah/maru/pull/1321)), 스모크 테스트에서 web 패널이 창 밖으로 삐져나오던 문제를 고쳤습니다([#1324](https://github.com/ohah/maru/pull/1324)). 설정 화면에는 네비 하단 전체 초기화와 바뀐 행마다 ↺를 두는 기본값 리셋 UX(CS-4-8)가 추가됐습니다([#1323](https://github.com/ohah/maru/pull/1323)).

공개 커밋 39개, 해당일 생성 또는 병합된 PR 35개를 정리했습니다. PR 생성 34개·병합 31개는 같은 PR이 양쪽에 포함될 수 있습니다.
