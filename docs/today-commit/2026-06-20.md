## 요약 (AI 작성)

maru는 원격·터미널 식별 작업을 이어 갔습니다. `maru ssh`의 호스트별 설치 캐시([#713](https://github.com/ohah/maru/pull/713)), terminfo 없이 캡을 질의하는 XTGETTCAP([#714](https://github.com/ohah/maru/pull/714)), `maru install-cli`([#716](https://github.com/ohah/maru/pull/716)), 버튼 없는 마우스 이동을 알리는 DECSET 1003([#717](https://github.com/ohah/maru/pull/717))이 들어왔고, 기본 TERM을 내장 terminfo를 자동 캐시하는 `xterm-maru`로 바꾸고([#719](https://github.com/ohah/maru/pull/719)) bracketed paste·OSC 52·커서 모양·focus 캡을 추가했습니다([#722](https://github.com/ohah/maru/pull/722)). OSC 52 클립보드 쓰기는 사용자 결정에 따라 기본 허용으로 바꿨고([#718](https://github.com/ohah/maru/pull/718)), 통합 zsh에서 평범한 ssh를 `maru ssh`로 돌리는 opt-in 옵션, ssh가 비정상 종료된 뒤 남은 입력 모드 복구([#729](https://github.com/ohah/maru/pull/729)), 일반 ssh에서는 TERM을 xterm-256color로 낮추는 기본값도 더했습니다. 스레딩 3단계로는 코어 변경을 I/O 스레드에 맡기는 `CoreCommandQueue`([#723](https://github.com/ohah/maru/pull/723))를 만들고 IME preedit, focus·config, scroll·선택·마우스 리포트를 차례로 위임해([#725](https://github.com/ohah/maru/pull/725), [#728](https://github.com/ohah/maru/pull/728)) 재진입 데드락을 구조적으로 없앴으며, 측정으로 더블 버퍼가 필요 없다는 결론과 리뷰 통과를 문서에 남겼습니다.

오후부터는 창 chrome을 다시 짰습니다. 사이드바 상단에 검색바와 view options·새 워크스페이스 아이콘을 둔 헤더([#738](https://github.com/ohah/maru/pull/738)), 이름·브랜치·폴더로 카드를 거르는 검색([#741](https://github.com/ohah/maru/pull/741)), 브랜치·폴더 표시 토글 메뉴([#745](https://github.com/ohah/maru/pull/745)), 사이드바 접기 토글([#749](https://github.com/ohah/maru/pull/749))과 타이틀바 띠, 헤더 영역 창 드래그·더블클릭 확대가 들어왔고, 에이전트 세션 카드 색을 상태 기반으로 바꿨습니다. 실행 중인 명령이 있는 터미널이나 창을 닫기 전에 확인 모달을 띄우고([#755](https://github.com/ohah/maru/pull/755), [#757](https://github.com/ohah/maru/pull/757)), 이 대화상자를 테두리 패널과 accent 버튼, Y·N 단축키, 화살표 포커스 이동을 갖춘 재사용 컴포넌트로 다시 만들었습니다([#768](https://github.com/ohah/maru/pull/768)). 시작·새 surface의 작업 디렉터리 설정([#746](https://github.com/ohah/maru/pull/746)), Shift+Enter·IME Enter 개행 옵션([#742](https://github.com/ohah/maru/pull/742)), EAW Ambiguous 폭 선택 `text.ambiguous-width`([#767](https://github.com/ohah/maru/pull/767)), ⌘F 오버레이의 pane 우상단 배치도 추가했습니다. 렌더링은 glyph 가로 배치를 advance 기준으로 바꿔 숫자 겹침을 고치고, 밑줄을 절반 두께로 얇게 하며, 셀보다 넓은 동그라미 번호를 축소하거나 두 칸으로 그리게 했습니다. IME 확정 경로의 데드락과 탭 전환 시 잘못된 surface로 가던 입력도 고쳤습니다. 모달 버튼 클릭 [#781](https://github.com/ohah/maru/pull/781)과 접기 토글 정렬 [#782](https://github.com/ohah/maru/pull/782)는 이날 PR이 열렸습니다.

zntc는 디스크 캐시(이슈 #4438) 리뷰 후속([#4448](https://github.com/ohah/zntc/pull/4448)) 뒤 그래프에 캐시 키 캡처, store 호출, 캐시된 AST로 재구성하는 load 경로, 캐시를 켜도 결과가 같은 load hit 배선을 연결하고([#4449](https://github.com/ohah/zntc/pull/4449)부터 [#4452](https://github.com/ohah/zntc/pull/4452)까지) `--disk-cache`·`--cache-dir` CLI opt-in([#4453](https://github.com/ohah/zntc/pull/4453))을 병합했습니다. npm 쪽 노출 [#4454](https://github.com/ohah/zntc/pull/4454)는 이날 PR이 열렸습니다. suji는 코어·보안과 플랫폼·CEF 전수 조사에서 찾은 버그를 고치고 리뷰에서 나온 회귀까지 바로잡은 [#176](https://github.com/ohah/suji/pull/176)을 병합했습니다.
