## 요약 (AI 작성)

bungae는 React Native 예제 앱을 실제로 띄우기 위한 수정을 이어 갔습니다. 이미지 파일을 AssetRegistry 모듈로 만드는 에셋 처리와 HMRClient 등록 수정을 넣고, 개발 서버가 `/assets/...`·`/node_modules/...` 경로의 에셋 요청을 Metro처럼 처리하게 했습니다. 릴리스 빌드에서는 `__DEV__` 조건 블록 안의 에셋과 `openURLInBrowser` 같은 개발 도구 모듈을 빼고, 개발 서버에 `/open-url` 엔드포인트를 추가했습니다. 전역에 `__BUNGAE_BUNDLER__`·`__BUNGAE_VERSION__` 식별자를 주입하고, SIGINT·SIGTERM을 받으면 WebSocket 연결을 닫고 서버를 멈추도록 했습니다.

Windows 빌드 문제와 Android 에뮬레이터 접근, Windows용 Hermes 컴파일러 경로 설정도 고쳤고, InitializeCore 테스트 실패와 Babel 플러그인 경로 해석, 그래프 번들러의 의존성 해석을 손봤습니다. 커밋 메시지를 영어로 쓰는 규칙을 에이전트 문서에 넣었고, 저녁에는 에셋 감지용 디버그 코드를 지운 [#4](https://github.com/ohah/bungae/pull/4)를 병합했습니다.
