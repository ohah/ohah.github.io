> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 rollup 호환 플러그인 컨텍스트를 하루 동안 넓혔습니다. `this.warn`·`this.error`([#3642](https://github.com/ohah/zntc/pull/3642)), `ModuleInfo.meta`와 자기 모듈 한정 `this.getModuleInfo`([#3643](https://github.com/ohah/zntc/pull/3643)), external 판정을 포함한 `this.resolve`([#3644](https://github.com/ohah/zntc/pull/3644))를 넣고, `resolveId`·`load`의 this 바인딩 누락과 watch warning 누수도 함께 고쳤습니다. 이어 `this.emitFile`로 에셋을 모으고 `this.getFileName`과 이름만 준 에셋 emit을 지원했으며([#3650](https://github.com/ohah/zntc/pull/3650), [#3652](https://github.com/ohah/zntc/pull/3652)), `vitePlugin()`에도 같은 기능을 맞췄습니다([#3654](https://github.com/ohah/zntc/pull/3654)). `type: chunk` emit은 설계 RFC([#3657](https://github.com/ohah/zntc/pull/3657)) 뒤 이미 그래프에 있는 모듈을 별도 chunk로 내는 경우와 새 모듈을 chunk로 내는 경우([#3659](https://github.com/ohah/zntc/pull/3659), [#3661](https://github.com/ohah/zntc/pull/3661)), chunk 참조의 파일 이름 조회, 상대·bare specifier 해석, 명시한 `fileName` 그대로 출력([#3668](https://github.com/ohah/zntc/pull/3668))까지 이어졌습니다. 같은 범위를 다른 방식으로 올린 [#3662](https://github.com/ohah/zntc/pull/3662)는 닫았습니다.

후속 이슈에서는 `resolveId`·`transform` 훅의 `ModuleInfo.meta` 병합([#3666](https://github.com/ohah/zntc/pull/3666)), `syntheticNamedExports`와 그 re-export 전달([#3667](https://github.com/ohah/zntc/pull/3667), [#3669](https://github.com/ohah/zntc/pull/3669)), `implicitlyLoadedAfterOneOf` 관계 배선과 chunk 비트 축약([#3670](https://github.com/ohah/zntc/pull/3670), [#3671](https://github.com/ohah/zntc/pull/3671))을 구현했고, watch 증분 빌드에서 새로 emit된 chunk 모듈이 재파싱 목록에서 빠지던 문제를 고쳐 e2e 회귀 가드를 붙였습니다([#3673](https://github.com/ohah/zntc/pull/3673)).

이 밖에 `--minify`가 esbuild처럼 식별자 mangling을 함께 켜도록 바꾸고([#3651](https://github.com/ohah/zntc/pull/3651)), whitespace minify 때 RN polyfill 내용도 줄이며 polyfill 변환 결과의 메모리 누수를 막았습니다([#3653](https://github.com/ohah/zntc/pull/3653), [#3656](https://github.com/ohah/zntc/pull/3656)). dev 서버는 sass partial이 바뀌면 `@import`한 루트 scss를 다시 컴파일하도록 역의존을 추적하고([#3675](https://github.com/ohah/zntc/pull/3675)), innerGraph dead-store DCE를 제어 흐름 블록 안으로 넓혔으며([#3677](https://github.com/ohah/zntc/pull/3677)), 렉서의 한 줄·여러 줄 주석 스캔에 SIMD를 적용했습니다([#3678](https://github.com/ohah/zntc/pull/3678)). RN 예제에는 Re.pack 벤치마크 설정을 추가했고([#3645](https://github.com/ohah/zntc/pull/3645)), 백로그는 측정 결과에 따라 stale 항목을 두 차례 정리했습니다. 블로그 저장소 ohah.github.io의 커밋 7개는 크론의 문서 점검 표시와 요약 갱신 커밋입니다.

공개 커밋 43개, 해당일 생성 또는 병합된 PR 33개를 정리했습니다. PR 생성 33개·병합 32개는 같은 PR이 양쪽에 포함될 수 있습니다.
