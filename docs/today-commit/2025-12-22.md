## 요약 (AI 작성)

chrome-remote-devtools는 iframe 예제 E2E 테스트([#8](https://github.com/ohah/chrome-remote-devtools/pull/8))를 병합했습니다. 페이지 로드, 클라이언트 연결, DevTools iframe 표시, 콘솔·네트워크 패널 동작을 검사하며, Copilot 리뷰를 반영해 타입과 대기 방식을 다듬었습니다. 통합 테스트와 E2E 테스트의 webServer 설정을 나눠 통합 테스트 타임아웃을 고쳤고, JUnit 결과를 PR 댓글로 올리는 CI 단계를 추가한 뒤 권한·`comment_mode`·check run 설정을 여러 차례 고쳤습니다.

저녁에는 로컬 스토리지 감지를 켜고 스토리지 도메인을 정리한 [#9](https://github.com/ohah/chrome-remote-devtools/pull/9)를 병합했습니다. DevTools URL의 `v8only` 매개변수를 빼 Target 유형이 NODE가 아닌 FRAME이 되게 해 DOM 기능을 쓸 수 있게 했고, DOMStorage가 이벤트를 두 번 보내던 문제를 StorageObserver 한 경로로 정리했습니다. 스토리지 도메인 파일을 `storage/` 폴더로 옮기고, DevTools가 다시 연결될 때 iframe이 불필요하게 새로 고쳐지지 않도록 WebSocket ID를 고정했으며, 쓰지 않는 Runtime 메서드를 지우고 스토리지 도메인 통합 테스트를 추가했습니다.

외부 저장소 leegeunhyeok/craby에서는 ArrayBuffer를 `Vec<u8>`로 바꿀 때 Vec 길이가 0으로 남던 코드 생성 버그 수정 [#78](https://github.com/leegeunhyeok/craby/pull/78)이 병합됐습니다.

공개 커밋 18개, 해당일 생성 또는 병합된 PR 3개를 정리했습니다. PR 생성 1개·병합 3개는 같은 PR이 양쪽에 포함될 수 있습니다.
