## 요약 (AI 작성)

maru는 `core.zig` 분해를 마무리했습니다. 스크롤백 저장과 재배치([#943](https://github.com/ohah/maru/pull/943))로 screen 쪽 이전을 끝낸 뒤 커서 이동, erase·insert·delete, scroll과 줄 이동, alt screen과 커서 저장, 출력 핫패스, resize·reflow, snapshot 합성을 `screen.zig`로, SGR·모드 dispatch와 CSI 상태 기계, write 상태 기계를 `parser.zig`로 옮겨 분해를 완결했고([#956](https://github.com/ohah/maru/pull/956)), 이어 선택·검색·URL 감지를 `selection.zig`([#964](https://github.com/ohah/maru/pull/964)), kitty graphics를 `kitty.zig`([#968](https://github.com/ohah/maru/pull/968)), 입력 이벤트 인코딩을 `input_report.zig`([#971](https://github.com/ohah/maru/pull/971))로 분리했습니다. `Screen` 구조체를 만들어 활성 grid와 스크롤백, 커서, DECSC 슬롯을 화면에 귀속시키고 alt screen을 구조체 swap으로 바꿨으며([#977](https://github.com/ohah/maru/pull/977)), RIS가 저장 슬롯도 초기화하게 했습니다. 단계마다 코드 리뷰 후속 정리가 함께 들어왔습니다.

같은 날 한글 NFD 자모 grapheme cluster 렌더링을 설계 문서와 함께 구현했습니다. UAX#29 규칙으로 한글 cluster를 나누는 순수 함수(HG1, [#972](https://github.com/ohah/maru/pull/972))와 셀 하나에 여러 코드포인트를 무손실로 저장하는 `grapheme_store`, 다중 combining·키캡 누적을 넣은 뒤 CoreText 셰이퍼에 cluster 전체를 넘기고([#985](https://github.com/ohah/maru/pull/985)) 기존 `Cell.combining`과 단일 combining 우회 코드를 없앴으며([#988](https://github.com/ohah/maru/pull/988)), recorded oracle fixture([#989](https://github.com/ohah/maru/pull/989))와 저장소 중복 제거, emoji ZWJ 시퀀스 통합([#997](https://github.com/ohah/maru/pull/997))으로 이어졌습니다. 스크롤백은 행별 ring에서 page와 pool 저장([#990](https://github.com/ohah/maru/pull/990)), 가변 폭과 끝 공백 잘라 내기, mmap `page_allocator` backing([#1001](https://github.com/ohah/maru/pull/1001))으로 바꿨고, 활성 grid까지 합치는 full B 방식은 구조적 충돌로 불가하다고 결론을 문서에 남겼습니다([#1005](https://github.com/ohah/maru/pull/1005)).

이 밖에 다른 맥에서 '손상'으로 뜨지 않도록 .app 자체를 공증·staple하고([#974](https://github.com/ohah/maru/pull/974)), rich quad 역감마 지수를 2.4로 바로잡았으며, atlas가 가득 차면 키우도록 해 ─ 문자가 ?로 깨지던 문제를 고쳤습니다([#1007](https://github.com/ohah/maru/pull/1007)). 알림은 접힘 상태에서도 종을 유지하고 빨간 원형 배지와 패널 헤더·빈 상태 디자인을 더했으며, 백그라운드 pane과 가로 탭에서도 알림을 보내고 발신 Term으로 이동하게 했습니다([#1012](https://github.com/ohah/maru/pull/1012)). 세팅 토글이 런타임 폰트 줌을 초기화하던 문제의 [#1014](https://github.com/ohah/maru/pull/1014)는 이날 PR이 열렸습니다.

zntc는 integration 잡별 path 필터와 draft PR 건너뛰기([#4462](https://github.com/ohah/zntc/pull/4462)), PR에서는 매트릭스를 줄이고 main push에서만 전체를 돌리는 방식([#4463](https://github.com/ohah/zntc/pull/4463))으로 CI를 가볍게 했고, 디스크 캐시 감사 후속으로 진단 누락·`.d.ts` 키·`import.meta` 문제와 견고성 항목, 버전별 GC를 처리했습니다([#4464](https://github.com/ohah/zntc/pull/4464), [#4465](https://github.com/ohah/zntc/pull/4465)).
