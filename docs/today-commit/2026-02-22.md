## 요약 (AI 작성)

hwpjs는 각주·미주 처리 공통화를 담은 [#13](https://github.com/ohah/hwpjs/pull/13)을 병합하고, HTML 뷰어 스냅샷의 기준이 될 fixture HTML·CSS와 `.hwp`, 참고 이미지를 추가·갱신했습니다([#14](https://github.com/ohah/hwpjs/pull/14)). 이어 문서 요약 정보의 제목을 HTML `title`로 쓰는 등 fixture와 스냅샷을 비교하는 1단계 작업과 차이 분석 노트를 [#15](https://github.com/ohah/hwpjs/pull/15)로 병합했고, 리뷰 워크플로 설정 파일도 추가했습니다([#16](https://github.com/ohah/hwpjs/pull/16)). HTML 뷰어에는 각주·미주, 머리말·꼬리말, 구역·단 정의 내용 렌더링과 문단 안 굵게·기울임·밑줄 글자 모양 적용, HTML·Markdown 개요 번호 출력이 들어갔습니다. 취소선과 문서 스냅샷 E2E를 담은 [#17](https://github.com/ohah/hwpjs/pull/17)은 이날 열렸습니다.

react-native-mcp는 iOS는 idb, Android는 `adb screenrecord`로 화면을 녹화하는 `start_video_recording`·`stop_video_recording` 도구와 YAML `startRecording`·`stopRecording` 스텝을 병합했습니다([#79](https://github.com/ohah/react-native-mcp/pull/79)). 앱 연결 없이 쓰는 `list_apps`·`terminate_app`·`get_screen_size`·`get_orientation`·`set_orientation` 도구를 추가해 전체 도구 수를 47개로 늘렸고([#83](https://github.com/ohah/react-native-mcp/pull/83)), 문서 사이트의 빠진 항목을 채웠습니다([#86](https://github.com/ohah/react-native-mcp/pull/86)).

나머지는 E2E 안정화였습니다. Android 첫 탭 실패를 줄이려고 초기 렌더를 기다리게 하고([#80](https://github.com/ohah/react-native-mcp/pull/80)), 상태 바·내비게이션 바·caption bar inset을 읽어 탭과 오버레이 좌표를 보정했으며([#82](https://github.com/ohah/react-native-mcp/pull/82)), iOS 시뮬레이터를 세로 방향으로 고정했습니다([#84](https://github.com/ohah/react-native-mcp/pull/84)). 탭은 짧은 swipe로 바꾸거나 iOS 타임아웃 때 재시도하는 등 여러 방식을 거쳐 Android `input tap`과 10초 타임아웃으로 단순화했고, 전체 스텝 대기 시간을 늘리고 Android 제스처 드래그를 안정화한 [#85](https://github.com/ohah/react-native-mcp/pull/85)를 병합했습니다. 같은 대기 시간 조정을 담았던 #87은 병합 없이 닫혔고, MCP 도구 설명과 E2E·배포·문서를 정리하는 [#88](https://github.com/ohah/react-native-mcp/pull/88)은 이날 열렸습니다. ohah.github.io에는 2월 22일 요약이 올라갔습니다.

공개 커밋 58개, 해당일 생성 또는 병합된 PR 14개를 정리했습니다. PR 생성 12개·병합 11개는 같은 PR이 양쪽에 포함될 수 있습니다.
