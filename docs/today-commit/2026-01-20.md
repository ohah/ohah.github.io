## 요약 (AI 작성)

bungae는 Metro 호환 변환 파이프라인과 Phase 1 보완을 담은 [#3](https://github.com/ohah/bungae/pull/3)을 병합했습니다. 의존성 그래프 빌드와 `build()`·`serve()` 함수를 구현하고, require 경로를 dependencyMap 조회로 바꾸는 직렬화기와 빌드·그래프 스냅샷 통합 테스트를 추가했습니다. 직렬화기에는 `modulesOnly`, `inlineSourceMap` 뼈대, `shouldAddToIgnoreList` 같은 Metro 호환 옵션을 넣고, InitializeCore 탐지·실행 순서 테스트와 비교용 Metro 번들 파일을 두었습니다. 변환기는 Babel과 Hermes 파서로 Flow 타입을 걷어 내는 Metro 순서 파이프라인을 처음에 OXC 기반으로 만들었다가, 같은 날 OXC 의존성을 빼고 SWC로 옮겼으며 문서와 테스트도 그에 맞췄습니다. 쓰지 않는 Babel 설정 옵션을 지우고 CLI를 정리했으며, 마지막으로 그래프 기반 번들러 진입점을 추가하고 예제 앱의 iOS·Android 빌드가 Bungae 번들을 쓰도록 설정했습니다.

chrome-remote-devtools는 Tauri 빌드에 `client.js`를 리소스로 묶고 개발 모드에서 프로젝트 루트를 찾는 방식을 고친 [#87](https://github.com/ohah/chrome-remote-devtools/pull/87)을 병합했습니다. 이어 React Native inspector 패키지 구조를 정리한 [#88](https://github.com/ohah/chrome-remote-devtools/pull/88)을 병합했습니다. 타입을 `types.ts`로 모으고 타입 전용 import를 고쳤으며, 빌드 산출물을 npm 패키지에서 빼고 podspec 버전을 package.json과 같은 0.1.0-rc.1로 맞췄고, npm 배포 워크플로의 불필요한 검증 단계를 덜어 냈습니다.

공개 커밋 55개, 해당일 생성 또는 병합된 PR 3개를 정리했습니다. PR 생성 2개·병합 3개는 같은 PR이 양쪽에 포함될 수 있습니다.
