> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 셸 통합부터 시작했습니다. 전날 열린 OSC 133 semantic prompt 파싱 [#286](https://github.com/ohah/maru/pull/286)을 병합하고, zsh가 프롬프트·입력·출력 경계 표시를 내보내게 했으며([#287](https://github.com/ohah/maru/pull/287)), 이 태그를 reflow와 스크롤백 재배치에서도 유지하고([#288](https://github.com/ohah/maru/pull/288)), Cmd+↑·↓ 프롬프트 점프([#289](https://github.com/ohah/maru/pull/289))와 명령 성공·실패를 초록·빨강 막대로 보여 주는 gutter 표시([#290](https://github.com/ohah/maru/pull/290))를 더했습니다. OSC 7 현재 디렉터리 보고([#296](https://github.com/ohah/maru/pull/296))와 OSC 0·2 제목을 쓰는 창 제목([#297](https://github.com/ohah/maru/pull/297)), 셸 의미 이벤트 스트림과 `maru.trace.v1` 기록기([#299](https://github.com/ohah/maru/pull/299), [#300](https://github.com/ohah/maru/pull/300))도 들어왔습니다. `input.page-keys` 기본값을 scroll로 바꾸고([#293](https://github.com/ohah/maru/pull/293)), 특수 키 앞에서 IME 조합을 확정하도록 고쳤으며([#294](https://github.com/ohah/maru/pull/294)), 표준이 없는 터미널 동작은 사실상 기준과 결정을 문서로 남기라는 규칙도 추가했습니다.

오후부터는 8단계 탭과 분할 화면을 진행했습니다. DevSession이 활성 surface를 거치게 하고 surface를 힙에 고정한 뒤 탭 상태를 `Tab` 구조체와 동적 목록으로 옮겨([#301](https://github.com/ohah/maru/pull/301)부터 [#305](https://github.com/ohah/maru/pull/305)까지) 여러 탭의 PTY drain과 Cmd+T 새 탭([#306](https://github.com/ohah/maru/pull/306), [#307](https://github.com/ohah/maru/pull/307))을 동작시켰습니다. cmux식 세로 사이드바로 방향을 정한 설계 문서([#308](https://github.com/ohah/maru/pull/308)) 뒤에 사이드바 레이아웃과 하이라이트, 테마 색, 큰 탭 슬롯, 공유 atlas 두 번째 패스로 그리는 탭 제목, 클릭 전환과 호버, Cmd+W 닫기, 호버 X, Cmd+Shift+] / [ 순환, 드래그 재정렬([#309](https://github.com/ohah/maru/pull/309)부터 [#320](https://github.com/ohah/maru/pull/320)까지)이 차례로 들어왔습니다. 분할은 `SplitTree` 모델과 재귀 레이아웃([#321](https://github.com/ohah/maru/pull/321))에서 출발해 panel별 렌더 origin, N개 frame 병합, Cmd+D 분할([#326](https://github.com/ohah/maru/pull/326)), panel 포커스와 Cmd+Option+화살표 이동, 트리를 접는 panel 닫기([#329](https://github.com/ohah/maru/pull/329))로 이어졌습니다. 이후 pane 하나가 여러 Term을 가로 탭으로 담는 구조([#330](https://github.com/ohah/maru/pull/330), [#331](https://github.com/ohah/maru/pull/331))로 바꾸고 pane별 탭 바와 제목, 클릭 전환, 호버 X 닫기, pane 안팎 드래그 이동, "+" 버튼([#332](https://github.com/ohah/maru/pull/332)부터 [#341](https://github.com/ohah/maru/pull/341)까지)을 붙였으며, 셸이 끝나면 Term과 pane을 자동으로 정리하는 기능([#342](https://github.com/ohah/maru/pull/342))까지 병합됐습니다. 사용자 설정 키바인딩이 실제 키 처리에 전달되지 않던 문제도 고쳤습니다([#334](https://github.com/ohah/maru/pull/334)).

zntc는 전날 열린 [#4262](https://github.com/ohah/zntc/pull/4262)로 default 파라미터를 지원하는 타깃에서 rest 파라미터를 그대로 두게 했고, 중첩된 object rest 할당 대상을 es2017에서 낮추는 수정([#4263](https://github.com/ohah/zntc/pull/4263))을 병합했습니다. 블로그 저장소에는 오늘의 커밋 요약과 크론이 만든 교정 커밋이 올라갔습니다.

공개 커밋 63개, 해당일 생성 또는 병합된 PR 59개를 정리했습니다. PR 생성 57개·병합 59개는 같은 PR이 양쪽에 포함될 수 있습니다.
