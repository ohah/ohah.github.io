## 요약 (AI 작성)

maru는 감사에서 나온 터미널 결함부터 고쳤습니다. 콜론 SGR 하위 파라미터가 별도 SGR로 새던 문제, 스크롤 바닥에서 autowrap이 soft-wrap 플래그를 잃던 문제, kitty query가 구현하지 않은 플래그를 광고하던 문제([#535](https://github.com/ohah/maru/pull/535)부터 [#537](https://github.com/ohah/maru/pull/537)까지), 탭 문자가 지나는 셀을 덮어쓰던 문제, SGR-Pixels 마우스 좌표, kitty Ctrl+Shift 조합의 코드포인트([#544](https://github.com/ohah/maru/pull/544))를 바로잡고 ABI 크기·오프셋 가드를 보강했습니다. 이어 ICH·DCH([#545](https://github.com/ohah/maru/pull/545))와 origin mode DECOM([#546](https://github.com/ohah/maru/pull/546))을 넣었습니다.

kitty graphics는 placement 코어([#547](https://github.com/ohah/maru/pull/547))에서 시작해 이미지 노출과 GPU 이미지 환산, ABI 채널과 업로드 계획, textured quad와 텍스처 캐시를 쓰는 Metal 렌더([#551](https://github.com/ohah/maru/pull/551))까지 연결했고, chunked 전송·zlib 압축·PNG 디코드([#552](https://github.com/ohah/maru/pull/552)부터 [#554](https://github.com/ohah/maru/pull/554)까지), 세분화된 delete와 LRU·텍스처 eviction([#555](https://github.com/ohah/maru/pull/555)부터 [#557](https://github.com/ohah/maru/pull/557)까지)을 더했습니다. 리뷰 후속으로 placement 자원 정리, chunk 도중 독립 명령 처리, 큰 단일 전송을 위한 APC 버퍼 동적화, 자동 크기 이미지의 커서 이동([#570](https://github.com/ohah/maru/pull/570))을 넣었고, 이미지 파이프라인 벤치로 추가 캐시가 필요 없다는 결론을 냈습니다. brew 진행 표시가 줄마다 쌓이던 문제는 CSI s·u 커서 저장·복원으로 고쳤습니다([#566](https://github.com/ohah/maru/pull/566)).

후반은 VT 기능 공백을 G 시리즈로 메웠습니다. 취소선·윗줄·흐림 SGR([#558](https://github.com/ohah/maru/pull/558)부터 [#560](https://github.com/ohah/maru/pull/560)까지)과 장식선 overlay 통합, OSC 10·11 색 질의와 설정([#573](https://github.com/ohah/maru/pull/573), [#577](https://github.com/ohah/maru/pull/577)), OSC 52 클립보드([#574](https://github.com/ohah/maru/pull/574), [#575](https://github.com/ohah/maru/pull/575)), OSC 4·104 256색 팔레트([#576](https://github.com/ohah/maru/pull/576)), OSC 9·777 데스크톱 알림([#578](https://github.com/ohah/maru/pull/578), [#579](https://github.com/ohah/maru/pull/579)), DEC 라인 드로잉 charset, 동적 탭스톱, 벨·NEL, REP·IRM·SU·SD 등 소형 항목 묶음([#583](https://github.com/ohah/maru/pull/583)), 화면 반전 DECSCNM, 깜빡임·숨김·이중 밑줄·밑줄 색 SGR([#585](https://github.com/ohah/maru/pull/585)), DCS 상태 기계와 DECRQSS([#586](https://github.com/ohah/maru/pull/586)), keypad 모드와 numpad SS3 인코딩([#588](https://github.com/ohah/maru/pull/588), [#591](https://github.com/ohah/maru/pull/591))이 들어왔습니다. 활성 pane 오른쪽 스크롤바([#589](https://github.com/ohah/maru/pull/589)), 이중 밑줄 렌더([#590](https://github.com/ohah/maru/pull/590)), 설정으로 켜는 blink 애니메이션([#592](https://github.com/ohah/maru/pull/592))도 병합됐습니다.

zntc는 전날 열린 `--rn-version` [#4437](https://github.com/ohah/zntc/pull/4437)을 병합해 RN 문서 기준으로 버전별 다운레벨 타깃을 고를 수 있게 하고 지원 범위와 출력 크기 벤치를 문서화했습니다. 이어 디스크 캐시(이슈 #4438)를 단계별로 쌓아 AST 직렬화 codec([#4439](https://github.com/ohah/zntc/pull/4439)), semantic 정보와 HashMap 직렬화([#4440](https://github.com/ohah/zntc/pull/4440), [#4441](https://github.com/ohah/zntc/pull/4441)), source·AST·semantic을 한 엔트리로 묶는 module codec([#4442](https://github.com/ohah/zntc/pull/4442)), atomic write와 샤딩을 하는 IO 레이어([#4444](https://github.com/ohah/zntc/pull/4444)), 보수·정밀 무효화 키([#4445](https://github.com/ohah/zntc/pull/4445)), 디스크 모듈 store([#4446](https://github.com/ohah/zntc/pull/4446)), git SHA 기반 `compiler_build_id` 주입([#4447](https://github.com/ohah/zntc/pull/4447))을 병합했습니다. 블로그 저장소에는 오늘의 커밋 요약과 크론 맞춤법 커밋이 올라갔습니다.
