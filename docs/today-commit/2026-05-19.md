## 요약 (AI 작성)

zntc는 Flow 타입 제거(strip) 출력이 깨지는 사례를 하나씩 고쳤습니다. 함수 타입의 `this` 파라미터([#3526](https://github.com/ohah/zntc/pull/3526)), `%checks` 추론 술어 화살표 함수([#3528](https://github.com/ohah/zntc/pull/3528)), 객체 타입의 `proto` modifier, `declare namespace`, bigint 기반 enum, `renders` 타입 연산자, component 파라미터의 `as` 로컬 바인딩, const와 variance가 섞인 타입 파라미터 순서([#3535](https://github.com/ohah/zntc/pull/3535), [#3537](https://github.com/ohah/zntc/pull/3537), [#3538](https://github.com/ohah/zntc/pull/3538), [#3539](https://github.com/ohah/zntc/pull/3539), [#3540](https://github.com/ohah/zntc/pull/3540), [#3541](https://github.com/ohah/zntc/pull/3541))를 처리했고, 오후에는 `@@name`·`[[name]]` 내부 슬롯, 객체 타입의 generic call property, 중첩된 화살표 반환 타입, `interface`·`of` 식별자, inline interface의 extends 목록, `import type`의 예약어 로컬 이름, generic 호출 오판([#3545](https://github.com/ohah/zntc/pull/3545), [#3551](https://github.com/ohah/zntc/pull/3551))까지 이어졌습니다. 잘못된 enum 입력에서 codegen이 범위 밖 접근으로 패닉하던 문제도 오류 처리로 바꿨습니다([#3543](https://github.com/ohah/zntc/pull/3543)).

그 밖에 CLI에서 config 병합 시 값이 조용히 무시되던 버그 10건을 고치고 drift 가드를 넣었으며([#3524](https://github.com/ohah/zntc/pull/3524)), 누락된 CLI 플래그 11개를 레퍼런스에 보완했습니다([#3520](https://github.com/ohah/zntc/pull/3520)). RN에서는 비인라인 CJS import 이름 충돌 수정([#3519](https://github.com/ohah/zntc/pull/3519))이 병합됐고, 불안정한 `babel.config.js` 자동 감지·로딩을 껐습니다([#3558](https://github.com/ohah/zntc/pull/3558)). minify에서 shorthand 키 참조가 남아 있는데 const 선언을 지워 axios가 ReferenceError를 내던 문제도 고쳤습니다([#3560](https://github.com/ohah/zntc/pull/3560)). CI는 Zig 빌드 캐시 키를 나눠 job 간 충돌을 없애고 stale 회귀 가드를 strict로 바꿨으며, e2e는 dev·preview 서버 대기를 readiness 폴링으로 바꿨습니다([#3529](https://github.com/ohah/zntc/pull/3529), [#3531](https://github.com/ohah/zntc/pull/3531), [#3532](https://github.com/ohah/zntc/pull/3532)). 문서 사이트는 Astro·Starlight를 올리고 지구라트 로고를 배선했고([#3552](https://github.com/ohah/zntc/pull/3552)), 개발 서버 배너도 지구라트 ASCII 로고로 바꿔 몇 차례 다듬었습니다([#3553](https://github.com/ohah/zntc/pull/3553)). 로고 시안 비교 PR [#3530](https://github.com/ohah/zntc/pull/3530)은 닫혔고, ESM re-export getter 수정 [#3542](https://github.com/ohah/zntc/pull/3542)와 Electron용 타깃별 config 예제 [#3563](https://github.com/ohah/zntc/pull/3563)은 이날 PR이 열렸습니다.

suji는 `nativeImage`의 경로 읽기를 fs 게이트로 묶어 전날 캡처 경로 보완과 대칭을 맞추고, EventBus OOM 회귀 테스트와 로드맵 전수조사를 했습니다. Astro Starlight 기반 GitHub Pages 문서 사이트와 배포 워크플로를 만들었고, Electron 토큰과 맞춘 `globalShortcut` 미디어 키 API를 추가했습니다. CLI는 `suji init --frontend`로 react·vue·svelte·solid·preact·vanilla를 고르게 했다가, create-vite에 맡기던 방식을 버리고 Tauri처럼 번들된 프론트엔드 템플릿을 쓰도록 바꿨습니다.

블로그 저장소 ohah.github.io에는 zts 개발기 development-18(5/13부터 5/19까지, minify 격차와 Module Federation)을 추가하고 5월 오늘의 커밋 목록의 링크와 누락 요약을 보정했습니다. 나머지 커밋은 크론의 문서 점검 표시와 요약 갱신입니다.

공개 커밋 61개, 해당일 생성 또는 병합된 PR 40개를 정리했습니다. PR 생성 39개·병합 37개는 같은 PR이 양쪽에 포함될 수 있습니다.
