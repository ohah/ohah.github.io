## 요약 (AI 작성)

cheolsu-proxy는 이날도 PR 열세 개를 main에 병합하며 기능을 크게 늘렸습니다. 전날 연 MCP 서버 [#79](https://github.com/ohah/cheolsu-proxy/pull/79)가 `cheolsu-proxy-mcp` 크레이트로 들어와 AI 어시스턴트가 트래픽을 조회하고 인터셉트 규칙을 바꾸면 Tauri UI에도 반영되게 했고, CONNECT 터널을 거치는 업스트림 프록시 체이닝과 설정 페이지([#80](https://github.com/ohah/cheolsu-proxy/pull/80))가 뒤를 이었습니다. 기능 비교 문서 갱신과 설정 페이지 사이드바 수정([#81](https://github.com/ohah/cheolsu-proxy/pull/81)), Lingui 기반 영어·한국어 다국어 지원과 번역 누락을 검사하는 CI([#82](https://github.com/ohah/cheolsu-proxy/pull/82)), 데몬 단계의 서버 리플레이([#83](https://github.com/ohah/cheolsu-proxy/pull/83))도 병합됐습니다.

오후에는 ratatui 기반 TUI 크레이트를 새로 만들어 Network·WebSocket·Rules·Settings 탭과 데몬 연결을 구현하고, TUI를 사이드카로 등록해 데스크톱 앱에서 터미널 명령을 설치·제거하는 기능을 넣었습니다([#84](https://github.com/ohah/cheolsu-proxy/pull/84)). 이어 선택 색상과 키 힌트, 자동 스크롤, cURL 복사와 리플레이 단축키, 전체 화면 네트워크 상세를 다듬었고([#85](https://github.com/ohah/cheolsu-proxy/pull/85), [#86](https://github.com/ohah/cheolsu-proxy/pull/86)), `tauri-ui` 디렉터리를 `desktop`으로 바꿨으며([#87](https://github.com/ohah/cheolsu-proxy/pull/87)), TUI 설정 탭에 업스트림 프록시 폼을 추가했습니다([#88](https://github.com/ohah/cheolsu-proxy/pull/88)).

저녁에는 deno_core 기반 TypeScript·JavaScript 스크립팅 엔진을 프록시 파이프라인에 붙여 스크립트 핫 리로드와 `console.log` 캡처, MCP의 스크립트 로드 도구, 데스크톱의 Monaco 스크립트 편집 페이지와 TUI 스크립트 탭을 넣었습니다([#89](https://github.com/ohah/cheolsu-proxy/pull/89)). 같은 흐름에서 HTTP 헤더 한도를 늘려 431 오류를 해결했습니다. 데스크톱과 TUI의 HAR 내보내기([#90](https://github.com/ohah/cheolsu-proxy/pull/90)), 리뷰 반영과 함께 Tauri Updater 플러그인과 GitHub Actions 릴리스 워크플로 추가([#91](https://github.com/ohah/cheolsu-proxy/pull/91))가 병합됐고, 데스크톱 앱 단일 인스턴스 PR [#92](https://github.com/ohah/cheolsu-proxy/pull/92)는 이날 열려 다음 날 병합됐습니다.
