> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru는 파일 패널(전역 도크) 작업을 새로 시작해 FP1부터 FP6까지 모두 main에 병합했습니다. `.md`·`.html` 뷰어와 CodeMirror 6 편집기를 오른쪽이나 아래 도크에 두는 설계 문서([#1418](https://github.com/ohah/maru/pull/1418))를 신설하고, 모드명을 "읽기 / 소스 편집"으로 고친 뒤([#1419](https://github.com/ohah/maru/pull/1419)) 웹 스택을 vanilla TS와 remark/rehype로 확정했습니다([#1420](https://github.com/ohah/maru/pull/1420)). 구현은 `SplitTree` 기반 도크 모델과 workspace 영속(FP1, [#1421](https://github.com/ohah/maru/pull/1421)), Bun·zntc 기반 렌더러 패키지와 sanitizer·SRI·라이선스 감사 게이트(FP2, [#1423](https://github.com/ohah/maru/pull/1423)), 도크 기하와 터미널 영역을 같은 rect로 맞춘 슬롯 배관(FP3, [#1424](https://github.com/ohah/maru/pull/1424)), 파일 크기·asset 수 한도를 둔 격리 뷰어 브리지(FP4, [#1425](https://github.com/ohah/maru/pull/1425)), Cmd+O와 터미널 파일 링크로 여는 라우팅(FP5, [#1426](https://github.com/ohah/maru/pull/1426)), CodeMirror 6 소스 편집과 원자적 저장(FP6, [#1427](https://github.com/ohah/maru/pull/1427)) 순으로 진행됐습니다. FP2는 리뷰를 거치며 Mermaid SVG의 외부 URL과 라이선스 감사 우회를 막고 잘못된 SVG escape를 fail-closed로 처리했으며, FP1에는 같은 경로의 항목을 도크 전체에서 하나만 두는 불변식이 더해졌습니다.

컨트롤 플레인에서는 browser 메서드의 params 파싱이 인가 게이트보다 앞에 있어 파싱 결과가 단서로 새던 문제와, `exec`·`screenshot`이 서버 오류를 감추던 문제를 고쳤습니다([#1422](https://github.com/ohah/maru/pull/1422)). 설정 화면의 항목별 리셋 ↺는 행 맨 오른쪽으로 옮기고 아이콘을 키웠고([#1417](https://github.com/ohah/maru/pull/1417)), 주소창 marked-text 프로토콜 후속 항목을 문서로 상세화했습니다([#1416](https://github.com/ohah/maru/pull/1416)).

zntc는 manualChunks가 user entry를 다른 청크로 옮기지 않도록 바꾼 [#4554](https://github.com/ohah/zntc/pull/4554)를 병합했습니다. iife·umd·amd 출력에서 `run_before_main` 모듈을 entry 청크에 함께 두어 SyntaxError를 없앴고([#4556](https://github.com/ohah/zntc/pull/4556)), 다른 모듈의 const 값을 구워 넣은 모듈을 증분 캐시에서 빼 stale 산출물을 막았습니다([#4558](https://github.com/ohah/zntc/pull/4558)). `--preserve-modules`(ESM)에서 동명 심볼이 붕괴하던 문제는 파일 간 네이밍 인프라를 켜서 고쳤고([#4559](https://github.com/ohah/zntc/pull/4559)), `import * as ns` 멤버가 바인딩되지 않던 문제([#4561](https://github.com/ohah/zntc/pull/4561))와 `--splitting`에서 namespace 멤버의 크로스-청크 등록이 빠지던 문제([#4562](https://github.com/ohah/zntc/pull/4562))도 수정했습니다. ohah.github.io에는 메타데이터 동기화 커밋이 하나 있었습니다.

공개 커밋 24개, 해당일 생성 또는 병합된 PR 18개를 정리했습니다. PR 생성 17개·병합 18개는 같은 PR이 양쪽에 포함될 수 있습니다.
