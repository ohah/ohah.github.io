## 요약 (AI 작성)

executeJS는 코드 실행 런타임을 Deno에서 Node.js로 바꿨습니다([#27](https://github.com/ohah/executeJS/pull/27)). Deno Core 대신 Node.js 서브프로세스로 JavaScript를 실행하고, Node.js 바이너리 자동 다운로드 스크립트를 추가했으며, `lint_code` 기능과 `deno-runtime`·`hello-world` 크레이트를 제거했습니다. 다운로드 함수가 리다이렉트나 에러 때 파일 스트림을 닫지 않던 리소스 누수를 고쳤고, GitHub Actions의 Linux 환경처럼 지원하지 않는 플랫폼에서는 postinstall 스크립트가 조용히 끝나도록 했습니다.

hwpjs는 HTML 뷰어의 표 렌더링을 손봤습니다. `row_size`가 1일 때 CtrlHeader 높이로 행 높이를 계산하고, `offset_x`·`offset_y`를 부호 있는 SHWPUNIT으로 파싱하도록 바꿨습니다. `table.rs`를 상수·크기·위치·기하·셀·SVG 모듈로 나누고 쓰지 않는 레거시 문서 변환기를 지웠으며, 픽스처를 `crates/hwp-core/tests/fixtures`로 옮겼습니다. table2·표 캡션 테스트 픽스처와 스냅샷, HTML 뷰어 테스트 규칙 문서도 추가했습니다.

공개 커밋 16개, 해당일 생성 또는 병합된 PR 1개를 정리했습니다. PR 생성 1개·병합 1개는 같은 PR이 양쪽에 포함될 수 있습니다.
