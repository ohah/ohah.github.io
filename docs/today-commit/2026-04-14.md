# 2026-04-14

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 호환성 기반을 넓히는 작업으로 시작했습니다. kangax compat-table 실측값으로 `compat.zig`를 검증·생성하는 스크립트([#1268](https://github.com/ohah/zntc/pull/1268)), 번들의 `__async` 중복 주입 수정과 browserslist 지원([#1269](https://github.com/ohah/zntc/pull/1269), [#1270](https://github.com/ohah/zntc/pull/1270)), `.d.ts` 생성([#1271](https://github.com/ohah/zntc/pull/1271))을 병합했고, bungae처럼 로컬 경로로 쓰는 쪽에서 설치가 깨지지 않게 browserslist를 optional 의존성으로 돌렸습니다([#1273](https://github.com/ohah/zntc/pull/1273)). private 클래스 다운레벨링은 constructor 중복 출력, standalone 메서드 함수 안 `this.#field`, class 보존 경로의 static `#field`와 static block 누락을 고치고([#1276](https://github.com/ohah/zntc/pull/1276)~[#1281](https://github.com/ohah/zntc/pull/1281)), `#x in obj` brand check 다운레벨링을 추가했습니다([#1284](https://github.com/ohah/zntc/pull/1284)).

React Native는 `--platform=react-native`가 Hermes 미지원 기능 표를 강제로 적용하게 한 뒤([#1285](https://github.com/ohah/zntc/pull/1285)), 화살표 함수와 let/const 다운레벨을 차례로 더하고 결국 RN 프리셋을 ES5 매트릭스로 넓혔습니다([#1300](https://github.com/ohah/zntc/pull/1300), [#1301](https://github.com/ohah/zntc/pull/1301), [#1304](https://github.com/ohah/zntc/pull/1304)). 그 과정에서 for-of/for-in 구조 분해에 `void 0` 초기화가 붙던 문제([#1303](https://github.com/ohah/zntc/pull/1303)), `__generator`의 `sent()`가 throw를 다시 던지지 않아 rejected Promise가 값으로 풀리던 문제([#1307](https://github.com/ohah/zntc/pull/1307)), re-export getter가 canonical 로컬 이름을 쓰지 않던 문제([#1313](https://github.com/ohah/zntc/pull/1313)), `__esm` 안 호이스팅 함수의 소스맵 매핑([#1316](https://github.com/ohah/zntc/pull/1316)), `--minify` CLI 크래시를 낸 arena 해제 순서([#1289](https://github.com/ohah/zntc/pull/1289))를 고쳤습니다. webpack UMD 번들의 복구 가능한 파서 에러로 모듈을 건너뛰던 문제도 바로잡고([#1293](https://github.com/ohah/zntc/pull/1293)), 앞서 넣은 require 참조 보호는 중복 안전망이라 되돌렸습니다([#1294](https://github.com/ohah/zntc/pull/1294)).

AST와 번들러 내부도 크게 손봤습니다. 화살표 함수 매개변수를 `formal_parameters` 노드로 정규화하고([#1287](https://github.com/ohah/zntc/pull/1287)), 이를 함수·메서드 전체로 넓혀 매개변수 레이아웃과 헬퍼 시그니처를 `NodeList`로 통일했으며([#1324](https://github.com/ohah/zntc/pull/1324), [#1326](https://github.com/ohah/zntc/pull/1326), [#1327](https://github.com/ohah/zntc/pull/1327)), 변수 선언 종류를 매직 넘버에서 enum으로 바꿨습니다([#1318](https://github.com/ohah/zntc/pull/1318)). barrel 모듈의 default re-export가 같은 이름의 named export를 덮던 문제는 직접 커밋한 수정을 되돌린 뒤, 번들러 전용 심볼 테이블을 도입하는 단계적 리팩터링 안에서 다뤘습니다. 심볼 테이블 타입([#1329](https://github.com/ohah/zntc/pull/1329)), 바인딩의 심볼 필드([#1330](https://github.com/ohah/zntc/pull/1330)), 심볼 기반 `_default` getter([#1331](https://github.com/ohah/zntc/pull/1331)), 문자열 기반 re-export 체인 해석 제거([#1332](https://github.com/ohah/zntc/pull/1332)), CJS emit 분리([#1334](https://github.com/ohah/zntc/pull/1334)), 심볼 참조 횟수 수집([#1336](https://github.com/ohah/zntc/pull/1336))까지 병합됐고, 합성 default를 시맨틱 공간으로 옮기는 PoC [#1339](https://github.com/ohah/zntc/pull/1339)는 이날 PR이 열렸습니다.

bungae는 Metro와 같은 `transformer.babelTransformerPath` 설정과 Babel 플러그인 자동 감지를 추가하고, 비동기 transformer 처리와 터미널 raw 모드 복구를 고쳤습니다.

공개 커밋 75개, 해당일 생성 또는 병합된 PR 48개를 정리했습니다. PR 생성 46개·병합 47개는 같은 PR이 양쪽에 포함될 수 있습니다.
