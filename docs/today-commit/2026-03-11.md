## 요약 (AI 작성)

cheolsu-proxy는 PR 스무 개를 모두 main에 병합했습니다. 오전에는 TLS를 다듬었습니다. 인증서 정보 표시와 도메인별 클라이언트 인증서를 넣은 mTLS 고급 기능([#179](https://github.com/ohah/cheolsu-proxy/pull/179)), 커스텀 CA 인증서 임포트와 PKCS12 지원([#180](https://github.com/ohah/cheolsu-proxy/pull/180)), 인증서 생성 개선과 TLS 이벤트 훅 구조([#181](https://github.com/ohah/cheolsu-proxy/pull/181)), 도메인별 TLS 버전·암호화 스위트 설정([#182](https://github.com/ohah/cheolsu-proxy/pull/182))이 들어왔고, 백그라운드 인증서 스니핑을 쓰는 Eager·Lazy 연결 전략과 이를 실행 중에 바꾸는 설정 UI([#183](https://github.com/ohah/cheolsu-proxy/pull/183))가 이어졌습니다.

낮에는 Rust 백엔드가 중개하는 방식으로 트레이 패널 기능을 되살렸고([#184](https://github.com/ohah/cheolsu-proxy/pull/184)), CONNECT 터널 요청 표시 토글([#185](https://github.com/ohah/cheolsu-proxy/pull/185)), SSE 스트리밍 캡처·gRPC 디코딩·연결 모니터링([#186](https://github.com/ohah/cheolsu-proxy/pull/186))을 병합했습니다. 설정 페이지는 사이드바 내비게이션과 하나의 저장 버튼으로 바꾸고 React Hook Form으로 옮겼으며, Select 값이 화면에 반영되지 않던 문제를 고치면서 빠른 설정도 저장 버튼에 묶었습니다([#187](https://github.com/ohah/cheolsu-proxy/pull/187), [#188](https://github.com/ohah/cheolsu-proxy/pull/188)). SSL Proxying에 블랙리스트·화이트리스트 모드를 두고 프록시 연결 때 데몬과 설정을 맞췄습니다([#189](https://github.com/ohah/cheolsu-proxy/pull/189)).

저녁에는 모든 스토어의 저장소를 localStorage에서 tauri-plugin-store로 옮기고 프록시 시작 때 Rust가 저장 파일을 직접 읽어 설정을 맞추게 했으며([#190](https://github.com/ohah/cheolsu-proxy/pull/190)), 로그 파일 삭제 기능을 더했습니다([#191](https://github.com/ohah/cheolsu-proxy/pull/191)). 이후 규칙 스토어 팩토리와 제네릭 `RuleListPage` 추출, 설정 페이지 하위 컴포넌트 분리([#192](https://github.com/ohah/cheolsu-proxy/pull/192), [#193](https://github.com/ohah/cheolsu-proxy/pull/193), [#194](https://github.com/ohah/cheolsu-proxy/pull/194))로 프런트엔드 중복을 줄였고, 데몬 쪽에서는 헤더 정리 헬퍼 추출, 인터셉트 마커 헤더 제거, 요청·응답 인터셉트 중복 정리, `handler.rs` 모듈 분리를 마쳤습니다([#195](https://github.com/ohah/cheolsu-proxy/pull/195)부터 [#198](https://github.com/ohah/cheolsu-proxy/pull/198)).

ohah.github.io에서는 크론이 craby 배경 문서의 오타를 고쳤고, 나머지는 이날 요약 갱신과 점검 상태 기록이었습니다.
