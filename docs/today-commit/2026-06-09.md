maru는 dev shell이 실제 터미널처럼 보이도록 렌더링을 다듬는 데서 시작했습니다. 셀 전경색과 SGR 배경색 칠하기([#165](https://github.com/ohah/maru/pull/165), [#172](https://github.com/ohah/maru/pull/172)), 공통 baseline 정렬([#166](https://github.com/ohah/maru/pull/166)), 실제 폰트 메트릭과 Retina HiDPI, 번들 폰트([#167](https://github.com/ohah/maru/pull/167))가 들어왔고, idle tick에서 CoreText shaping을 건너뛰며([#171](https://github.com/ohah/maru/pull/171)) grid 계산을 Swift에서 Zig로 옮겼습니다([#170](https://github.com/ohah/maru/pull/170), [#173](https://github.com/ohah/maru/pull/173)). 터미널 코어에는 DECAWM autowrap([#175](https://github.com/ohah/maru/pull/175)), 콜론 형식 확장색 SGR([#169](https://github.com/ohah/maru/pull/169)), 반전 블록 커서([#182](https://github.com/ohah/maru/pull/182))가 추가됐습니다. resize reflow는 한 번 넣었다가([#184](https://github.com/ohah/maru/pull/184)) Ghostty libghostty-vt 비교 oracle([#187](https://github.com/ohah/maru/pull/187))을 만든 뒤 되돌리고([#188](https://github.com/ohah/maru/pull/188)), 스크롤백 ring buffer와 뷰포트, 렌더, 휠·Shift+PageUp/Down 입력([#190](https://github.com/ohah/maru/pull/190)부터 [#193](https://github.com/ohah/maru/pull/193)까지)을 먼저 깐 다음 soft-wrap 추적과 활성 화면 reflow([#194](https://github.com/ohah/maru/pull/194), [#195](https://github.com/ohah/maru/pull/195))로 다시 들어왔습니다. 라이브에서 좁은 폭의 프롬프트가 겹치던 문제는 DSR·CPR 응답 경로([#196](https://github.com/ohah/maru/pull/196)), 드래그 끝에 한 번만 resize 적용([#198](https://github.com/ohah/maru/pull/198)), `TERM=xterm-256color` 지정([#199](https://github.com/ohah/maru/pull/199)), 커서가 있는 줄은 reflow하지 않는 방식([#200](https://github.com/ohah/maru/pull/200))으로 정리했습니다. PR에서도 성능 예산을 돌리도록 CI를 바꿨습니다([#189](https://github.com/ohah/maru/pull/189)).

후반에는 TUI 지원을 넣었습니다. scroll region(DECSTBM, [#206](https://github.com/ohah/maru/pull/206)), alternate screen([#207](https://github.com/ohah/maru/pull/207)), application cursor keys([#208](https://github.com/ohah/maru/pull/208)), alt screen에서 휠을 화살표로 바꾸는 alternate scroll([#209](https://github.com/ohah/maru/pull/209)), IL·DL과 커서 표시·reverse video([#212](https://github.com/ohah/maru/pull/212)), DECSC·DECRC와 DA1([#214](https://github.com/ohah/maru/pull/214))이 들어왔고, glyph가 많은 출력에서 atlas 좌표가 바닥나 글자가 깨지던 문제를 atlas 재활용으로 고쳤습니다([#213](https://github.com/ohah/maru/pull/213), [#217](https://github.com/ohah/maru/pull/217)). 누적 리뷰 반영([#215](https://github.com/ohah/maru/pull/215)부터 [#219](https://github.com/ohah/maru/pull/219)까지) 뒤에는 resize 때 스크롤백 행 재배치([#220](https://github.com/ohah/maru/pull/220))와 스크롤 위치 고정([#221](https://github.com/ohah/maru/pull/221)), DECSCUSR 커서 모양([#222](https://github.com/ohah/maru/pull/222)), 마우스 선택과 Cmd+C 복사([#223](https://github.com/ohah/maru/pull/223)), 더블·트리플 클릭 선택([#224](https://github.com/ohah/maru/pull/224)), bracketed paste를 지원하는 Cmd+V([#225](https://github.com/ohah/maru/pull/225))까지 병합됐습니다. Cmd+클릭으로 URL을 여는 [#226](https://github.com/ohah/maru/pull/226)은 이날 PR이 열렸습니다.
