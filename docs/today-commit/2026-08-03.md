## 요약 (AI 작성)

maru의 세션 도크 텍스트 렌더링을 시스템 UI 수준으로 끌어올린 날입니다. cached pixel glyph text 토대([#1812](https://github.com/ohah/maru/pull/1812))와 리뷰용 폰트 스펙시먼([#1816](https://github.com/ohah/maru/pull/1816))을 먼저 놓고, typography 계약을 고정한 뒤([#1828](https://github.com/ohah/maru/pull/1828)) text role을 전파했습니다([#1830](https://github.com/ohah/maru/pull/1830)). 이어 system UI chrome text shaper를 추가하고 system UI 글리프를 public font API로 rasterize하게 바꿨으며, measured dock text와 icon lowering을 분리해 frame에 연결하고 renderer에 measured chrome glyph slot 보존과 rich text raster 크기 오버라이드를 뒀습니다. text worker를 분리하고 시스템 text worker 경계를 이식 가능하게 만들어 도크를 비동기 system text로 안정화했고([#1832](https://github.com/ohah/maru/pull/1832)), Retina 도크 text 정렬과 icon-only text lowering은 테스트로 고정했습니다.

도크 크롬 자체도 다듬었습니다. 액션을 Button으로 분리하고([#1833](https://github.com/ohah/maru/pull/1833)) 라벨과 그룹을 측정해 간격을 토큰화했으며([#1836](https://github.com/ohah/maru/pull/1836)), role line box로 컨트롤을 정렬하고 유틸리티 아이콘을 가운데에 맞췄습니다. refresh 아이콘에 고정 슬롯과 인셋을 주고, 폭과 목록 밀도([#1819](https://github.com/ohah/maru/pull/1819)), 시각 계층([#1826](https://github.com/ohah/maru/pull/1826)), 시각 대비와 경계 대비, 헤더 경계, chrome 기하 bound를 차례로 보정했습니다. 기능으로는 세션 상세를 인라인으로 펼치고([#1825](https://github.com/ohah/maru/pull/1825)), 오래된 아카이브 스캔을 취소하며([#1820](https://github.com/ohah/maru/pull/1820)), 터미널 재개 액션 문구를 명확히 했고, 레거시 archive 탭 수명주기를 제거했습니다([#1841](https://github.com/ohah/maru/pull/1841)). AppKit 아카이브 액션 검증, archive detail 상태 캡처, 상세 close/reopen E2E, 확장 스크롤 앵커, 폰트 배율별 도크 기하 테스트가 이를 받쳤습니다.

session-host는 ended purge를 트랜잭션으로 완성했습니다. 계획을 권위 없는 projection으로 분리하고([#1806](https://github.com/ohah/maru/pull/1806)) commit 트랜잭션을 정의한 뒤([#1807](https://github.com/ohah/maru/pull/1807)) quarantine 부트스트랩, commit 권위 준비, finalization 권위 2단계 고정, Client substrate 완성([#1837](https://github.com/ohah/maru/pull/1837)), 오케스트레이션 마무리([#1842](https://github.com/ohah/maru/pull/1842))까지 이었습니다. `ClientSlot` teardown에 동시성 fence를 넣고([#1814](https://github.com/ohah/maru/pull/1814)), Client 생성 정책을 문서로 정한 뒤 caller closure·guard 정책·receiver 정책을 테스트로 강제했으며, generation input facade와 capability facade([#1851](https://github.com/ohah/maru/pull/1851))를 추가했습니다. CI는 session-host 게이트를 병렬 job으로 나누고([#1810](https://github.com/ohah/maru/pull/1810)) 변경 영역별로 job을 돌리게 했으며([#1822](https://github.com/ohah/maru/pull/1822)), 적대적 검증에서 찾은 changed-area 게이트 우회도 막았습니다.

파일 패널은 읽기 모드에 새던 빈 요소를 없애고 통과시킨 태그에 모습을 줬습니다([#1839](https://github.com/ohah/maru/pull/1839)). 읽기 링크 열기를 사용자가 실제로 누른 클릭으로 제한하는 [#1840](https://github.com/ohah/maru/pull/1840)은 이날 PR이 열렸습니다. ohah.github.io에는 크론이 남긴 CRD 점검 요약 커밋이 하나 들어갔습니다.

공개 커밋 83개, 해당일 생성 또는 병합된 PR 46개를 정리했습니다. PR 생성 46개·병합 44개는 같은 PR이 양쪽에 포함될 수 있습니다.
