## 요약 (AI 작성)

zntc의 worklet 변환은 Babel 플러그인과의 parity를 마무리했습니다. 파일 단위 `'worklet'` directive([#1181](https://github.com/ohah/zntc/pull/1181)), implicit context·globals·CJS dehoist를 담은 Phase 6 마지막 묶음([#1184](https://github.com/ohah/zntc/pull/1184))에 이어 `__classFactory`로 parity 테스트 169개를 모두 통과했고([#1185](https://github.com/ohah/zntc/pull/1185)), context object factory와 플러그인이 바꾼 클래스의 ES5 lowering, Babel식 익명 이름을 넣었습니다([#1187](https://github.com/ohah/zntc/pull/1187), [#1188](https://github.com/ohah/zntc/pull/1188)). 실제 앱에서 드러난 문제로는 사용자 `react-native-worklets` 버전을 `__pluginVersion`에 넣기([#1186](https://github.com/ohah/zntc/pull/1186)), worklet 본문 안 `--define` 치환 억제([#1194](https://github.com/ohah/zntc/pull/1194)), object hook 프로퍼티 자동 worklet화([#1202](https://github.com/ohah/zntc/pull/1202)), `__stackDetails` 형식과 `__initData.code`의 shorthand 구조 분해([#1203](https://github.com/ohah/zntc/pull/1203), [#1205](https://github.com/ohah/zntc/pull/1205))가 있었고, 빈 `sourceMap` 필드가 UI 런타임 초기화를 깨뜨려 다시 뺐습니다([#1206](https://github.com/ohah/zntc/pull/1206)). 드래그 제스처 실패의 근본 원인은 package.json `sideEffects` 설정이 자동 순수성 판정에 덮이던 tree shaking 문제였습니다([#1207](https://github.com/ohah/zntc/pull/1207)).

구조 면에서는 AST 플러그인에 Babel식 visitor hook을 도입하고([#1182](https://github.com/ohah/zntc/pull/1182)), worklet과 refresh의 런타임 상태를 `PluginState`로 분리해 그 규칙을 D097로 기록했으며([#1196](https://github.com/ohah/zntc/pull/1196)~[#1199](https://github.com/ohah/zntc/pull/1199)), 클로저 분석 캐시를 하나로 합쳤습니다([#1213](https://github.com/ohah/zntc/pull/1213)). dev 서버에는 빌드 이벤트를 흘리는 SSE 엔드포인트([#1216](https://github.com/ohah/zntc/pull/1216)), `/reset-cache` Control API([#1217](https://github.com/ohah/zntc/pull/1217)), LLM 에이전트용 MCP JSON-RPC 서버([#1218](https://github.com/ohah/zntc/pull/1218)), graceful shutdown([#1222](https://github.com/ohah/zntc/pull/1222))이 붙었습니다. HMR 성능 이슈 #1223에 대응해 이벤트 기반 watcher와 50ms debounce, 내용 해시 캐시, 재파싱 모듈 목록과 단계별 소요 시간 노출을 병합했습니다([#1227](https://github.com/ohah/zntc/pull/1227), [#1231](https://github.com/ohah/zntc/pull/1231), [#1232](https://github.com/ohah/zntc/pull/1232)).

소스맵은 Metro 호환 `x_facebook_sources` function map 수집과 RN 프리셋 자동 활성화([#1251](https://github.com/ohah/zntc/pull/1251), [#1252](https://github.com/ohah/zntc/pull/1252)), HMR용 모듈별 독립 소스맵([#1253](https://github.com/ohah/zntc/pull/1253)), 폴리필을 소스로 등록하는 prologue 매핑 수정([#1225](https://github.com/ohah/zntc/pull/1225))이 들어왔습니다. 이 밖에 `"use client"`/`"use server"` directive 보존과 다중 엔트리 CLI([#1242](https://github.com/ohah/zntc/pull/1242)), import attributes 등 AST 스키마 보강([#1246](https://github.com/ohah/zntc/pull/1246)), ES2022 미만 private field 다운레벨링([#1254](https://github.com/ohah/zntc/pull/1254)), direct eval/with 스코프의 mangling 차단([#1263](https://github.com/ohah/zntc/pull/1263)), dynamic import 대상 모듈의 export 보존([#1264](https://github.com/ohah/zntc/pull/1264)), Windows NAPI 링크([#1255](https://github.com/ohah/zntc/pull/1255))가 병합됐습니다. CLI 레퍼런스와 가이드, 루트 ROADMAP을 현재 구현에 맞춰 갱신하고 Babel 이관 가이드를 썼습니다([#1234](https://github.com/ohah/zntc/pull/1234), [#1238](https://github.com/ohah/zntc/pull/1238)~[#1241](https://github.com/ohah/zntc/pull/1241)). compat-table 기반 생성기([#1268](https://github.com/ohah/zntc/pull/1268))와 browserslist 지원([#1269](https://github.com/ohah/zntc/pull/1269))은 이날 PR이 열렸습니다.

bungae는 예제 앱에 worklet 전 단계 데모와 Reanimated 데모 다섯 개, ScrollView 안에서도 동작하는 독립 DragDemo를 넣고, 설치된 `react-native-worklets` 버전을 감지해 `__pluginVersion`에 넘기도록 했습니다. 위 zntc 수정을 따라 서브모듈을 여러 번 올렸고, iOS 26 iPad에서 전체 화면을 강제하는 설정을 다시 손봤습니다.
