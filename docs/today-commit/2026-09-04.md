# 2026-09-04

## 요약 (AI 작성)

원격 감시를 정직하게 만든 날입니다. macOS 원격은 «감시하는 척» 하고 있었습니다 — 못 하면 못 한다고 말하게 하고(RW6), 폴링 설계를 쓰고(RW7), 한도에서 포기 대신 폴링으로 내려가며(RW7d), 폴링 다이제스트가 «화면의 숫자» 까지 보게 했습니다. filter 는 «닫으면 안 되는» 문이라 선을 그었습니다. 편집기 Term 은 자기 키 컨텍스트를 얻어 전역에 못 넣던 chord 를 그 Term 안에서 세우고, `⌘D` 를 확정 자리로 옮겼습니다(비교 뷰에서는 전역으로).

모바일은 U2 전환 손짓을 «덮개» 로 정하고 돌아온 세션이 빈 화면부터 다시 쌓지 않게 했습니다(U2a). session-host 는 쓸 수 있는 backend 가 있으면 래치를 풀고(붙어 있는데도 원격으로 안 열렸다), baseline app authority·preparation 을 orchestrate 하고, candidate prerequisite transaction·product·publication product·trusted source directory 를 세웠습니다. 5초 마감을 확정하고 근거를 적었고(옛 문장은 결정이 아니었다), 셸 단계가 게이트를 조용히 깨는 것을 원장으로 막았으며, 같은 버전을 두 번 빌드하면 마지막 한 줄이 릴리스를 죽이던 CI 도 고쳤습니다. `@ohah/pdf` 는 Type3 글리프 스트림을 쪽 단위로 들고 있게 했습니다.
