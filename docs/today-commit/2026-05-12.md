## 요약 (AI 작성)

zntc는 JSX 설정 처리부터 손봤습니다. `zntc build`·`dev`가 JSX 런타임 설정을 app 빌드에 넘기게 하고([#3088](https://github.com/ohah/zntc/pull/3088)), classic JSX factory를 named import로 가져올 때 import가 지워지던 문제를 고쳤으며([#3089](https://github.com/ohah/zntc/pull/3089)), 파일별 `@jsx`·`@jsxFrag`·`@jsxRuntime`·`@jsxImportSource` pragma 주석을 지원하고 문서화했습니다([#3090](https://github.com/ohah/zntc/pull/3090), [#3091](https://github.com/ohah/zntc/pull/3091)). automatic 런타임에서 `@jsx` pragma가 무시될 때는 경고를 내도록 했습니다([#3092](https://github.com/ohah/zntc/pull/3092)). PUBLISH.md에 release.yml 흐름·롤백·체크리스트를 보강했고([#3093](https://github.com/ohah/zntc/pull/3093)), core-js 런타임 폴리필 가이드도 추가했습니다([#3113](https://github.com/ohah/zntc/pull/3113)).

낮에는 minify 출력 크기를 줄이는 codegen 개선이 이어졌습니다. 이항 `+`·`-` 주변 공백 제거, `const`를 `let`으로 낮추기, 매개변수 하나인 화살표 함수 괄호 제거, 문장 하나뿐인 블록의 중괄호 제거, if-else-return과 else-if 체인을 삼항 return으로 바꾸기, if를 논리·삼항 식으로 바꾸기, 한 번만 쓰는 식별자 별칭 인라인([#3101](https://github.com/ohah/zntc/pull/3101)–[#3120](https://github.com/ohah/zntc/pull/3120)) 등이 하나씩 병합됐고, 그 과정에서 생긴 entry export 뒤 줄바꿈 누락 회귀도 바로 고쳤습니다([#3108](https://github.com/ohah/zntc/pull/3108)). RN 번들에 `0xaa` 쓰레기 값이 섞이던 synthetic 이름 dangling 문제([#3104](https://github.com/ohah/zntc/pull/3104)), RN 번들의 `RuntimeKind` 보존과 Hermes 다운레벨 경계 사례([#3117](https://github.com/ohah/zntc/pull/3117), [#3126](https://github.com/ohah/zntc/pull/3126)), dev 빌드 오류 뒤 증분 재빌드가 overlay를 잘못 지우던 문제([#3099](https://github.com/ohah/zntc/pull/3099))도 수정했습니다.

저녁에는 resolver와 번들러 성능을 다뤘습니다. 프로파일 타이머 집계를 스레드 안전하게 고치고 `metadata`·`resolve.resolver` 단계를 세분했으며, 잠금 밖에서 readdir하는 `DirEntryCache`([#3122](https://github.com/ohah/zntc/pull/3122)), 디렉터리별 package.json 파싱 캐시([#3130](https://github.com/ohah/zntc/pull/3130)), 16개로 샤딩한 resolve 결과 캐시([#3131](https://github.com/ohah/zntc/pull/3131)), 디렉터리 캐시로 확장자 후보 탐색([#3132](https://github.com/ohah/zntc/pull/3132)), 평범한 node_modules 모듈의 transformer pre-pass 생략([#3124](https://github.com/ohah/zntc/pull/3124))이 들어갔습니다. 모듈 분류 히스토그램은 `ZNTC_MODULE_STATS`로 시작했다가 `ZNTC_DEBUG` 카테고리로 합쳤습니다([#3143](https://github.com/ohah/zntc/pull/3143)). lazy-barrel 판정은 헬퍼로 다운레벨된 모듈을 제외하고 `export *` 원본에는 namespace 전체를 요청하며 순수 re-export barrel만 지연하도록 좁혀, deferred record에 raw require가 남던 문제를 해결했습니다([#3135](https://github.com/ohah/zntc/pull/3135), [#3137](https://github.com/ohah/zntc/pull/3137), [#3138](https://github.com/ohah/zntc/pull/3138)). RN 번들 디버깅 이슈를 정리하는 [#3141](https://github.com/ohah/zntc/pull/3141)은 이날 열렸습니다.

블로그 저장소 ohah.github.io의 커밋 6개는 크론의 맞춤법 점검 표시와 `development-3.mdx` 띄어쓰기 수정, 요약 갱신입니다.

공개 커밋 50개, 해당일 생성 또는 병합된 PR 42개를 정리했습니다. PR 생성 42개·병합 41개는 같은 PR이 양쪽에 포함될 수 있습니다.
