# 2026-06-27

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

iris는 strict HBC 인터프리터의 핫패스를 이어서 깎았습니다. 전역 읽기의 문자열 디코드 지연([#113](https://github.com/ohah/iris/pull/113)), Uint8Array length와 숫자 인덱스 쓰기, 관계형·JLess·JLessLong 숫자 점프, 전역·객체 프로퍼티 캐시 적중 시 인덱스 직접 읽기와 숫자 쓰기 단축, 숫자 add와 write register 직접 처리([#130](https://github.com/ohah/iris/pull/130)), 배열 `GetByVal` 숫자 읽기, Math intrinsic 캐시 조회와 `Call2` native Math 직접 처리, 객체 `GetById`의 prototype 조회 생략([#136](https://github.com/ohah/iris/pull/136)), JSON payload lazy parse layout과 compact layout 검증 단축이 들어왔습니다. strict HBC 타이밍 프로파일러([#139](https://github.com/ohah/iris/pull/139))를 붙인 뒤 이를 근거로 JSON length와 객체 property index 병목을 줄였고([#140](https://github.com/ohah/iris/pull/140), [#141](https://github.com/ohah/iris/pull/141)), 이날 연 iris PR 29개는 모두 병합됐습니다.

maru는 전날 열린 [#1072](https://github.com/ohah/maru/pull/1072)로 위로 스크롤한 채 synchronized output을 쓰는 TUI를 빠르게 스크롤하면 화면이 멈추던 문제를 고쳤고, 기본값 리셋 후 뜨는 토스트가 마우스·키보드 입력을 막던 회귀를 토스트를 닫으며 입력을 소비하는 방식으로 정리했습니다([#1073](https://github.com/ohah/maru/pull/1073)). 사이드바 카드의 브랜치·폴더 아이콘을 키우고 경로 줄에 폴더 아이콘을 더했으며([#1074](https://github.com/ohah/maru/pull/1074)), 합성 아이콘이 Nerd Fonts v3의 PUA 영역을 가로채지 않도록 등록된 codepoint만 처리하게 했습니다([#1075](https://github.com/ohah/maru/pull/1075), [#1076](https://github.com/ohah/maru/pull/1076)). chrome 기본 테마를 rich로 바꾸고 세팅 슬라이더에 값을 표시하며 폰트 크기 단계를 1pt로 고정했고([#1077](https://github.com/ohah/maru/pull/1077)), Cmd+Q·메뉴·Dock 종료에도 항상 확인 모달을 띄우게 했습니다([#1078](https://github.com/ohah/maru/pull/1078)). 활성 탭은 본문 색으로 도려낸 connected 모양과 앰버 언더바를 기본으로 하고([#1079](https://github.com/ohah/maru/pull/1079)), `chrome.tab-style`로 connected·underline·pill 중에서 고를 수 있게 했습니다([#1080](https://github.com/ohah/maru/pull/1080), [#1081](https://github.com/ohah/maru/pull/1081)).

공개 커밋 44개, 해당일 생성 또는 병합된 PR 39개를 정리했습니다. PR 생성 38개·병합 39개는 같은 PR이 양쪽에 포함될 수 있습니다.
