> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 오전에 전날의 tree-shaking·번들러 성능 작업을 마무리했습니다. 직접 export seed 빠른 경로([#2559](https://github.com/ohah/zntc/pull/2559)), const-materialize 캐시 무효화 범위 축소와 `ConstPassPolicy` enum 정리([#2561](https://github.com/ohah/zntc/pull/2561), [#2562](https://github.com/ohah/zntc/pull/2562)), 작은 graph 배치에서 스레드 풀 시작 생략([#2565](https://github.com/ohah/zntc/pull/2565)), 소스 디렉터리 핸들 캐시([#2570](https://github.com/ohah/zntc/pull/2570))가 들어갔고, 벤치마크는 wall 측정과 프로파일 진단을 나누고 resolve·graph read·prepass 단계를 따로 보이게 했으며 xlarge 번들 fixture를 추가했습니다([#2563](https://github.com/ohah/zntc/pull/2563), [#2564](https://github.com/ohah/zntc/pull/2564), [#2568](https://github.com/ohah/zntc/pull/2568), [#2571](https://github.com/ohah/zntc/pull/2571)). 사용자에게 보이는 옵션·플래그·API 문서 누락과 오래된 JSDoc도 일괄 보강했습니다([#2566](https://github.com/ohah/zntc/pull/2566), [#2567](https://github.com/ohah/zntc/pull/2567)).

오후에는 패키지 분리를 11단계로 진행했습니다. `@zts/web`과 `@zts/server` 패키지를 비공개로 만들고 zts 자체 빌드로 빌드하게 한 뒤([#2572](https://github.com/ohah/zntc/pull/2572), [#2573](https://github.com/ohah/zntc/pull/2573)), `@zts/server`에 HMR·WebSocket·watcher를 구현하고([#2574](https://github.com/ohah/zntc/pull/2574)) HMR 클라이언트 런타임, CSS 스캐너, loader, PostCSS, Sass, CSS Modules 파이프라인을 `@zts/web`으로 옮겼습니다([#2577](https://github.com/ohah/zntc/pull/2577), [#2580](https://github.com/ohah/zntc/pull/2580), [#2582](https://github.com/ohah/zntc/pull/2582)부터 [#2585](https://github.com/ohah/zntc/pull/2585)까지). 이후 core의 HMR 채널, CSS 파이프라인 중복, app dev 컨트롤러를 새 패키지로 넘기고([#2587](https://github.com/ohah/zntc/pull/2587), [#2588](https://github.com/ohah/zntc/pull/2588), [#2589](https://github.com/ohah/zntc/pull/2589)) 분리 문서를 썼습니다([#2592](https://github.com/ohah/zntc/pull/2592)). 이 과정에서 ESM 출력에 `export *` 재export가 빠지던 번들러 버그를 찾아 고쳤고([#2578](https://github.com/ohah/zntc/pull/2578)), CLI·E2E 테스트 전에 새 패키지를 빌드하고 `@zts/core` 타입 선언을 내보내도록 CI를 손봤습니다([#2586](https://github.com/ohah/zntc/pull/2586), [#2593](https://github.com/ohah/zntc/pull/2593), [#2596](https://github.com/ohah/zntc/pull/2596)).

저녁부터는 `@zts/react-native` 패키지를 세웠습니다. 서버 프로토콜에 RN HMR 메시지를 추가하고([#2598](https://github.com/ohah/zntc/pull/2598)) RN 런타임과 Metro HMR 어댑터, asset·babel·codegen·require-context 플러그인 팩토리, RN preset을 만든 뒤([#2600](https://github.com/ohah/zntc/pull/2600)부터 [#2603](https://github.com/ohah/zntc/pull/2603)까지) `zts bundle --platform=react-native`를 연결했습니다([#2604](https://github.com/ohah/zntc/pull/2604)). 이어 RN dev server를 HTTP 기본 라우트, asset, bundle·map 라우트와 sourcemap 캐시, HMR 연결, symbolicate, cli-server-api·dev-middleware 연동, 터미널 단축키, 단일 WS upgrade 체인 순서로 쌓고([#2606](https://github.com/ohah/zntc/pull/2606)부터 [#2614](https://github.com/ohah/zntc/pull/2614)까지) `zts dev --platform=react-native`로 묶었습니다([#2615](https://github.com/ohah/zntc/pull/2615)). 예제 앱은 `examples/react-native-bare`(RN 0.85)와 `examples/react-native-expo`(Expo 55, RN 0.83)로 옮겼고, RN dev server 가이드([#2618](https://github.com/ohah/zntc/pull/2618)), 테스트 범위 점검과 버그 수정, bungae와 같은 index 페이지와 HMR 수신 처리([#2621](https://github.com/ohah/zntc/pull/2621)), `zts.config.ts`의 RN 영역 인식과 Metro 스타일 터미널 UI([#2625](https://github.com/ohah/zntc/pull/2625), [#2626](https://github.com/ohah/zntc/pull/2626)), babel 플러그인을 프로젝트 기준으로 찾도록 한 수정([#2627](https://github.com/ohah/zntc/pull/2627))이 이어졌습니다. 이날 열린 oxfmt 0.48 업그레이드 [#2628](https://github.com/ohah/zntc/pull/2628)와 `zts.config.ts`의 transformer·serializer·server 영역 매핑 [#2630](https://github.com/ohah/zntc/pull/2630)은 5월 6일에 병합됐습니다.
