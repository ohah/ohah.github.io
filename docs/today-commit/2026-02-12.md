## 요약 (AI 작성)

hwpjs는 포맷·린트 대상에서 `dist`·`legacy`·`npm` 디렉터리를 빼고([#4](https://github.com/ohah/hwpjs/pull/4)), HWP 5.0 스펙 문서를 하위 절 단위 파일로 나눈 Cursor skill을 추가했습니다([#5](https://github.com/ohah/hwpjs/pull/5)). 공유 라이브러리와 래퍼 구조를 설명하는 아키텍처 문서와 커밋 규칙, 리팩터링 뒤 스냅샷·출력이 바뀌면 안 된다는 refactoring-expert 규칙, Rust 코드를 바꾸면 커밋 전에 테스트를 돌리라는 규칙도 문서로 정리했습니다.

코드 쪽은 `hwp-core`와 `hwpjs` 크레이트에 rustfmt를 적용하고 Clippy 경고를 줄이는 정리가 대부분이었습니다. 쓰이지 않는 함수·상수·트레이트 메서드를 지우고 불필요한 `HwpError` 변환을 걷어 냈으며, 빈 페이지에서 표가 넘칠 때 쪽 나눔을 하지 않도록 고쳤습니다. Node CLI·벤치마크·wasi-worker와 Node·React Native 예제도 갱신했습니다.

lodash-v2는 빌드를 깨뜨리던 중복 코드 블록을 지웠습니다. ohah.github.io는 오늘의 커밋에 2026년 1월 전체와 2월 1일부터 8일까지를 채우고 AI 요약을 붙였으며, 커밋·PR이 없는 날은 파일을 만들지 않도록 생성 스크립트를 고치고 제목·날짜 frontmatter 표기를 다듬었습니다.

공개 커밋 37개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 2개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
