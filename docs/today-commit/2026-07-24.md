# 2026-07-24

## 요약 (AI 작성)

실행 중인 host 를 무중단으로 갈아끼우는 live-upgrade 를 설계부터 검증까지 밀어붙인 날입니다. U0 계약을 고정한 뒤 U1·U2 기반을 구현하고, 업그레이드 타깃 inode 고정과 staged target preflight, handoff 권위 저장과 attempt 기록, 승인·호스트별 업그레이드 권위 연결로 트랜잭션을 강화했습니다. 실패 대비도 같은 비중으로 다뤄, rollback self-image 권위와 rollback image staging·host pool 연결을 넣고 same-PID host exec rollback 과 연속 upgrade rollback 을 검증했으며, upgrade commit 경계와 N-1 호환 경계를 fail-close 로 닫고 복원 경합과 host pool lease 경계를 정리했습니다. 복원 경로 역시 restore 진입 권위 고정, 복원 그래프 커밋 권위, restore 활성화 권위와 제품 restore activation 연결로 권위를 한 줄로 세웠습니다.

터미널 링크 감지를 host-backed 세션에 되살린 것도 이날입니다. 설계를 확정하고 원격 OSC 8 미전달 사실을 반영해 정정한 뒤, 링크 span 에 감지 종류 태그와 뷰포트 수집기를 붙이고 screen wire 에 `link_spans` record 를 추가해 host 가 뷰포트 링크를 계산·적재하면 client 가 조립해 렌더 스냅샷에 노출하도록 했습니다. 그 위에 Cmd+hover 밑줄과 원격 Cmd+클릭 링크 열기를 host RPC 로 배선하고 로컬 회귀 가드를 추가했으며, RPC 응답 파싱은 strict 디코더 하나로 통일하고 `link_at` 은 전용 디코더로 분리했습니다.

에이전트 관측(agent observer)도 한 축 진행했습니다. 화면 region·게이트·완료 알림 설계를 문서로 쓰고 region·게이트 엔진을 구현한 뒤, claude 의 실제 신호를 실측해 판정을 정정하고 근거를 문서에 고정했으며 게이트 판정을 경화했습니다. 그 밖에 host-backed 일반 key 가 host 의 DECKPAM·kitty 모드로 인코딩되도록 고치고, 재접속 직후 관측이 없을 때도 스크롤이 동작하게 하며, core command 패리티와 구 host 원격 복사 호환을 맞췄습니다. 문서 위생으로는 광고된 config 키가 실재하는지 검사하는 게이트를 추가하고, 알림 config 3키가 미구현임을 명시했습니다.
