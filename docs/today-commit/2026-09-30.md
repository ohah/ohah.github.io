# 2026-09-30

> 한국 시간(KST) 기준으로 하루를 나눴습니다. 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 조회: 2026-10-06 KST. 공개 저장소에서 조회한 활동만 포함합니다.

## 요약 (AI 작성)

maru는 session host 업그레이드가 수렴하지 않던 문제를 정리했습니다. 업그레이드 스캔은 첫 prepare 뒤 결과와 무관하게 끝나서, 교체가 늘 실패하는 host 하나가 나머지 옛 host의 교체를 막았습니다. [#4023](https://github.com/ohah/maru/pull/4023)은 결과에 따라 다음 후보로 넘어가고 매니페스트 게시 시각 순으로 시도하게 했습니다. 교체가 실패해도 새 host를 띄우지 않고 살아 있는 호환 host를 재사용해 「host 하나」 원칙을 지키게 하는 [#4030](https://github.com/ohah/maru/pull/4030)은 이날 밤 열려 자정 직후 병합됐습니다. 재연결 직전 강제 resize가 host의 옛 격자를 다시 박던 문제와, 관문이 버린 mutation을 이유와 함께 남기는 진단은 [#4017](https://github.com/ohah/maru/pull/4017)에 담겼습니다. 자정 직후에는 전날 밤 열린 [#4014](https://github.com/ohah/maru/pull/4014)가 병합돼, 업그레이드 handoff 실패·host 자연 종료·spawn 재시도에서 로그가 없거나 틀리던 세 자리를 보완했습니다.

CI 쪽은 main push에서만 도는 잡이 실패하면 이슈 하나로 알리는 워크플로를 추가했습니다([#4028](https://github.com/ohah/maru/pull/4028)). 9/27부터 9/30까지 main push 51번 중 22번이 그 잡에서 실패했고, PR에서는 드러나지 않아 22시간 가까이 빨간 채 이어진 구간도 있었습니다. [#4017](https://github.com/ohah/maru/pull/4017) 뒤 깨진 크기 pin을 실측값으로 맞춘 [#4025](https://github.com/ohah/maru/pull/4025), exec 업그레이드 테스트의 목표 이미지를 ReleaseFast로 바꾼 [#4024](https://github.com/ohah/maru/pull/4024), macOS 전용 게이트를 별도 잡으로 떼어 병렬로 돌리는 [#4020](https://github.com/ohah/maru/pull/4020)도 병합됐습니다. CI(ubuntu)에는 처음부터 등록되지 않던 macOS 전용 동작 테스트 17개를 check-boundaries에서 Debug로만 돌게 한 [#4019](https://github.com/ohah/maru/pull/4019)는 로컬 macOS 스텝 수를 줄이는 변경입니다. 샤드 러너가 무시 상태로 물려받은 SIGINT·SIGQUIT를 되돌리고 C2 상대 스레드의 read에 기한을 거는 [#4029](https://github.com/ohah/maru/pull/4029)는 이날 열려 다음 날 병합됐습니다.

편집기는 전날 열린 인접 검색 강조 op 병합 [#4010](https://github.com/ohah/maru/pull/4010)을 병합하고, 비교 뷰 좌우의 찾기 상태와 입력 포커스를 분리했습니다([#4027](https://github.com/ohah/maru/pull/4027)). 전체 프레임 op writer의 비용·실패 경계 검증 [#4016](https://github.com/ohah/maru/pull/4016)과 초기 성장 실패에서 현재 검색을 보존하는 [#4021](https://github.com/ohah/maru/pull/4021)은 테스트 전용 B2 writer 범위이며 제품 저장소 정책은 바꾸지 않았습니다. 편집기 잔여 작업 정리 문서 [#4022](https://github.com/ohah/maru/pull/4022)도 병합됐습니다. Chromium 웹 패널은 W7a2 [#4015](https://github.com/ohah/maru/pull/4015)와 후속 [#4018](https://github.com/ohah/maru/pull/4018), 안내 문구 정리 [#4026](https://github.com/ohah/maru/pull/4026), `maru-chromium` Homebrew formula를 다룬 W7b [#4031](https://github.com/ohah/maru/pull/4031)이 모두 기능 브랜치 `docs/web-panel-osr-backend`에 병합돼 main 반영은 아닙니다.

spinon은 R06 스레드·소유권 위험 표 [#14](https://github.com/ohah/spinon/pull/14)와, Chromium식 우선순위 큐를 갖춘 V8 세션 우선순위 스케줄러 기반 [#15](https://github.com/ohah/spinon/pull/15), R06 근거 링크의 문서 빌드 오류 수정 [#16](https://github.com/ohah/spinon/pull/16)을 병합했습니다. Taffy 레이아웃 모듈 [#17](https://github.com/ohah/spinon/pull/17)은 이날 열려 다음 날 병합됐습니다. hwpjs는 HWP5 편집을 위한 스타일 참조 보존과 일반 텍스트 교체 시제품을 추가하고, 레코드 하위 트리 경계에서 문단 소유를 닫도록 고쳤습니다.

공개 커밋 41개, 해당일 생성 또는 병합된 PR 23개를 정리했습니다. PR 생성 20개·병합 20개는 같은 PR이 양쪽에 포함될 수 있습니다.
