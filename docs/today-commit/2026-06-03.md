## 요약 (AI 작성)

maru 저장소의 첫 커밋과 첫 PR들이 올라온 날입니다. 터미널 전략 노트와 한국어 번역, Zig 개발 환경 부트스트랩([#2](https://github.com/ohah/maru/pull/2)), 헤드리스 E2E 스캐폴드([#3](https://github.com/ohah/maru/pull/3)), 에이전트 규칙과 프로젝트 구조 문서가 들어왔고, 기록된 터미널 출력과 비교하는 oracle POC([#6](https://github.com/ohah/maru/pull/6)), 구조화된 검증 snapshot, 스트레스 테스트 계층([#11](https://github.com/ohah/maru/pull/11)), 성능 예산 하네스([#12](https://github.com/ohah/maru/pull/12))로 검증 틀을 잡았습니다. 클린룸 터미널 코어 정책, 구현 전 계약, 전역 단축키 충돌 규칙, 구현 계획, 입력 매크로를 문서로 정했고, 저녁에는 GitHub Actions check 게이트와 외부 oracle, import 경계 검사·포맷 게이트, LICENSE를 추가했습니다([#18](https://github.com/ohah/maru/pull/18)). 이후 `TerminalSession`·Pane을 `Surface`로 이름을 통일하고 PR 규칙을 체크리스트 하나로 모았으며([#20](https://github.com/ohah/maru/pull/20)), 의존성·커밋·클린룸 인용 정책 추가와 문서 감사, `Surface`·`SurfaceRuntime` 분리 반영, 런타임 trace와 렌더러 결정 문서([#24](https://github.com/ohah/maru/pull/24))까지 이날 24개 PR이 모두 main에 병합됐습니다.

zntc는 코드젠 precedence 전환(이슈 #4042)을 이어 갔습니다. 연산자와 member·call·new 등 자식에 level·flags를 배선하고([#4152](https://github.com/ohah/zntc/pull/4152)), 연산자 괄호 재유도를 켠 뒤([#4153](https://github.com/ohah/zntc/pull/4153)) paren 노드에 의존하지 않도록 `emitParen`을 투명화하고 statement-start 마킹을 도입했습니다([#4154](https://github.com/ohah/zntc/pull/4154)). 코드 리뷰로 찾은 엣지 케이스 수정, IIFE 자동 괄호, 트랜스포머의 `makeParenExpr` 합성 제거([#4156](https://github.com/ohah/zntc/pull/4156))와 optional chain 판정 중복 정리([#4158](https://github.com/ohah/zntc/pull/4158))가 뒤따랐습니다. React Native에서는 `__zntc_modules` 레지스트리에서 react-refresh 런타임을 찾게 해 Fast Refresh와 Refreshing 배너를 살렸고([#4155](https://github.com/ohah/zntc/pull/4155)), Bun으로 띄운 RN dev 서버의 HMR WebSocket도 복구했습니다([#4157](https://github.com/ohah/zntc/pull/4157)). 8067모듈 RN 앱 기준 HMR 성능 작업으로 캐시 적중 모듈의 방출 생략([#4159](https://github.com/ohah/zntc/pull/4159)), `rename_table` 보존으로 `computeRenames` 생략([#4161](https://github.com/ohah/zntc/pull/4161)), 그래프 위상 보존 인프라 Phase A([#4162](https://github.com/ohah/zntc/pull/4162))가 병합됐습니다.

suji는 CEF에서 히스토리가 없으면 Cmd+[ / ]와 Cmd+W를 앱 DOM으로 넘기게 했고, macOS 배포 문제를 연달아 고쳤습니다. codesign이 거부하던 entitlements plist의 XML 주석 제거, CEF 프레임워크 내부 dylib 서명 누락, `--dmg --notarize` 때 dmg 자체의 서명·공증·staple, 빌드 호스트보다 낮은 macOS에서 실행되도록 minos 고정, node를 쓰지 않는 앱이 죽지 않도록 libnode weak-link, Info.plist의 `LSMinimumSystemVersion` 명시가 들어왔습니다.

공개 커밋 62개, 해당일 생성 또는 병합된 PR 35개를 정리했습니다. PR 생성 35개·병합 35개는 같은 PR이 양쪽에 포함될 수 있습니다.
