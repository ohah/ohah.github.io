## 요약 (AI 작성)

chrome-remote-devtools는 Reactotron 클라이언트를 CDP로 연결하는 [#81](https://github.com/ohah/chrome-remote-devtools/pull/81)을 병합했습니다. Reactotron 서버 포트를 기본값인 9090으로 바꾸고, 8080과 9090 서버가 `RwLock`으로 감싼 SocketServer 인스턴스 하나를 공유해 실행 중에 Reactotron 서버를 켜고 끌 수 있게 했습니다. Reactotron 클라이언트를 원격 DevTools 클라이언트로 등록하는 브리지와, Reactotron의 콘솔·네트워크 이벤트를 `Runtime.consoleAPICalled` 같은 CDP 이벤트로 바꾸는 CDP 브리지를 만들었으며, 최소 프레임 트리로 `Page.enable`·`Page.getResourceTree`에 응답하도록 했습니다. 874줄이 된 `cdp_bridge.rs`는 정규화·콘솔 등 모듈로 나눴고, inspector에는 `reactotron` 클라이언트 유형과 필터를 추가했습니다. 테스트 설정에 빠진 필드와 clippy 경고, 리뷰 지적도 정리했습니다.

이어 Redux·MMKVStorage·AsyncStorageStorage 같은 React Native 전용 CDP 도메인 문서와 아키텍처 문서 갱신을 담은 [#82](https://github.com/ohah/chrome-remote-devtools/pull/82)를 병합했고, 빠른 시작 안내에 `bun run dev:server`가 cargo 명령을 감싼 것이라는 설명을 더했습니다.
