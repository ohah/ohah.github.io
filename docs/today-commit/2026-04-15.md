## 요약 (AI 작성)

zntc는 전날 시작한 번들러 심볼 리팩터링을 끝까지 밀었습니다. 합성 default와 래핑 모듈의 init/exports 심볼을 시맨틱 심볼 공간에 등록하고([#1339](https://github.com/ohah/zntc/pull/1339), [#1341](https://github.com/ohah/zntc/pull/1341)), 번들러 전용 SymbolTable을 별칭만 담는 AliasTable로 줄였습니다([#1342](https://github.com/ohah/zntc/pull/1342)~[#1344](https://github.com/ohah/zntc/pull/1344)). 이어 import·export 바인딩이 문자열 이름 대신 심볼 참조를 쓰도록 바꾸고, linker의 `canonical_names` 문자열 맵을 없애 `Symbol.canonical_name` 필드로 옮겼으며, `local_name` 조회 사이트를 여러 묶음으로 나눠 이전했습니다. 이 과정이 PR 30여 개([#1345](https://github.com/ohah/zntc/pull/1345)부터 [#1374](https://github.com/ohah/zntc/pull/1374)까지)로 병합됐고, 아키텍처 문서도 갱신했습니다([#1378](https://github.com/ohah/zntc/pull/1378)). barrel의 `export { default as X } from` 재수출에서 소스 모듈 래핑이 빠지던 버그([#1375](https://github.com/ohah/zntc/pull/1375))도 함께 고쳤습니다.

ES5 다운레벨링에서 Hermes 실패 패턴을 계속 잡았습니다. for-await-of의 var 초기화와 ES5 미만 lowering([#1380](https://github.com/ohah/zntc/pull/1380), [#1390](https://github.com/ohah/zntc/pull/1390)), for-of 본문 구조 분해([#1391](https://github.com/ohah/zntc/pull/1391)), 객체 메서드 shorthand([#1392](https://github.com/ohah/zntc/pull/1392)), for-in let/const의 TDZ 초기화([#1393](https://github.com/ohah/zntc/pull/1393)), top-level await를 async IIFE로 감싸기([#1394](https://github.com/ohah/zntc/pull/1394)), 정규식 dotAll·named capture([#1395](https://github.com/ohah/zntc/pull/1395)), 중괄호 유니코드 이스케이프의 surrogate pair 변환([#1396](https://github.com/ohah/zntc/pull/1396))입니다. 이후 공유 타깃 비트 레이아웃을 `compat.zig`와 맞췄고([#1400](https://github.com/ohah/zntc/pull/1400)), 합성 노드 span을 소스에서 직접 읽어 범위를 벗어나던 문제를 transformer·codegen·semantic·번들러 전반에서 `getText`로 바꿔 막았습니다([#1405](https://github.com/ohah/zntc/pull/1405), [#1412](https://github.com/ohah/zntc/pull/1412)). panic이 나면 신고 안내를 띄우는 Bun 스타일 crash report도 추가했습니다([#1409](https://github.com/ohah/zntc/pull/1409)).

Metro 호환 기능으로는 그래프 밖 경로를 감시하는 `watchFolders`([#1414](https://github.com/ohah/zntc/pull/1414)), 일반 해석이 실패할 때만 쓰는 resolve `fallback`([#1416](https://github.com/ohah/zntc/pull/1416)), RN 전용 AssetRegistry 출력과 @2x/@3x 변형 자동 감지([#1417](https://github.com/ohah/zntc/pull/1417), [#1418](https://github.com/ohah/zntc/pull/1418)), resolver `blockList`([#1419](https://github.com/ohah/zntc/pull/1419))를 넣었고, TS 타입에 빠져 있던 `strictExecutionOrder` 등 BuildOptions 세 개를 채웠습니다([#1415](https://github.com/ohah/zntc/pull/1415)).

bungae는 Hermes에서 실패하던 ES5 패턴 11종을 담은 스트레스 케이스를 예제 앱에 넣었다가 async 함수와 계산된 객체 키로 좁혔고([#57](https://github.com/ohah/bungae/pull/57)), Rozenite를 위한 `server.enhanceMiddleware`, `rewriteRequestUrl`, `symbolicator.customizeFrame` 등 Metro 설정 hook과 `watchFolders` 전달을 연결했습니다. 설정 스키마와 dev 서버 문서도 실제 구현에 맞춰 다시 썼습니다. ohah.github.io에는 4월 8일부터 15일까지의 오늘의 커밋 페이지가 추가됐습니다.

공개 커밋 90개, 해당일 생성 또는 병합된 PR 64개를 정리했습니다. PR 생성 63개·병합 64개는 같은 PR이 양쪽에 포함될 수 있습니다.
