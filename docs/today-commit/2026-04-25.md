## 요약 (AI 작성)

zntc는 브라우저에서 번들러를 돌리는 작업을 하루 만에 Playground까지 끌고 갔습니다. 번들러가 `std.fs`를 직접 부르던 곳을 FileSystem 추상화로 감싸 graph·resolver·package.json 읽기를 옮기고([#1915](https://github.com/ohah/zntc/pull/1915), [#1917](https://github.com/ohah/zntc/pull/1917), [#1918](https://github.com/ohah/zntc/pull/1918), [#1923](https://github.com/ohah/zntc/pull/1923)), 해석 결과를 `ResolvedModule` union으로 통일했습니다([#1925](https://github.com/ohah/zntc/pull/1925), [#1931](https://github.com/ohah/zntc/pull/1931) 등). 이어 호스트 JS 콜백에 위임하는 VirtualFS([#1935](https://github.com/ohah/zntc/pull/1935)), wasm-bundler 빌드 타깃([#1937](https://github.com/ohah/zntc/pull/1937)), JS VirtualFileSystem과 COOP/COEP 설정([#1939](https://github.com/ohah/zntc/pull/1939)), 실제 `Bundler.bundle()`을 부르는 WASM `build()`([#1946](https://github.com/ohah/zntc/pull/1946))를 병합했고, 크기 측정 결과에 따라 transpile 전용과 번들러 바이너리를 나누기로 문서화했습니다([#1947](https://github.com/ohah/zntc/pull/1947)). Playground에는 여러 파일을 입력하는 bundler 페이지([#1948](https://github.com/ohah/zntc/pull/1948))가 생겨 format·platform·minify 옵션, 청크 뷰어와 코드 분할, external과 preset, UMD/AMD, Share 버튼, transpile 옵션 전체가 차례로 붙었습니다([#1951](https://github.com/ohah/zntc/pull/1951), [#1953](https://github.com/ohah/zntc/pull/1953), [#1954](https://github.com/ohah/zntc/pull/1954), [#1957](https://github.com/ohah/zntc/pull/1957), [#1958](https://github.com/ohah/zntc/pull/1958)). 옵션 조합 회귀 검증 스크립트를 CI에 넣고([#1966](https://github.com/ohah/zntc/pull/1966)), WASM 번들러 에러를 표준 진단 형식으로 맞췄습니다([#1967](https://github.com/ohah/zntc/pull/1967)).

번들러 기능으로는 `inlineDynamicImports`의 런타임 registry([#1861](https://github.com/ohah/zntc/pull/1861)), external 모듈을 그래프의 phantom 모듈로 등록하는 Rollup parity([#1863](https://github.com/ohah/zntc/pull/1863), [#1865](https://github.com/ohah/zntc/pull/1865)), `manualChunks` meta의 `hasModuleSideEffects`·`code` 등 Rollup ModuleInfo 필드 확장([#1867](https://github.com/ohah/zntc/pull/1867), [#1876](https://github.com/ohah/zntc/pull/1876), [#1879](https://github.com/ohah/zntc/pull/1879))이 들어왔습니다. iOS 26.4 Hermes 부팅 실패에 대응해 RN 프리셋에 엔트리 에러 가드를 넣고 콘솔 에러 무시 패턴을 별도 옵션으로 나눴으며([#1864](https://github.com/ohah/zntc/pull/1864), [#1878](https://github.com/ohah/zntc/pull/1878)), 번들 성능 회귀 가드를 CI에 붙였습니다([#1873](https://github.com/ohah/zntc/pull/1873), [#1875](https://github.com/ohah/zntc/pull/1875)).

ES5 async 다운레벨링에서는 if 안 await가 상태 기계에서 자기 자신으로 도는 문제([#1888](https://github.com/ohah/zntc/pull/1888)), 복합 대입과 for-await-of var 호이스팅([#1904](https://github.com/ohah/zntc/pull/1904)), async 함수의 this 바인딩과 `yield*` iterable 래핑([#1914](https://github.com/ohah/zntc/pull/1914)), async generator의 `__asyncGenerator` 변환([#1919](https://github.com/ohah/zntc/pull/1919))을 고치고 번들러 통합·Hermes 런타임 회귀 테스트를 더했습니다([#1916](https://github.com/ohah/zntc/pull/1916)). `export * as ns` 재수출이 자기 재귀하던 문제의 namespace 변수 호이스팅([#1936](https://github.com/ohah/zntc/pull/1936))과 fallback disabled 결과 무시([#1945](https://github.com/ohah/zntc/pull/1945))도 수정했습니다.

bungae는 ZTS의 엔트리 에러 가드와 Expo 전용 콘솔 에러 패턴을 연결하고, `withExpo()` 래퍼와 무설정 감지, `bungae init`을 추가했습니다. 위 async 수정들을 따라 서브모듈을 여러 번 올렸고, Astro Starlight 문서 사이트와 GitHub Pages CI를 새로 만들었습니다. ohah.github.io에는 4월 24·25일 오늘의 커밋 요약이 올라왔습니다.

공개 커밋 105개, 해당일 생성 또는 병합된 PR 69개를 정리했습니다. PR 생성 69개·병합 69개는 같은 PR이 양쪽에 포함될 수 있습니다.
