## 요약 (AI 작성)

zntc는 이날 Vite식 앱 빌더와 styled-components 변환이라는 두 기능을 새로 들였습니다. 앱 빌더([#2200](https://github.com/ohah/zntc/pull/2200))는 HTML 진입점을 다루며 dev 모드 PostCSS CSS HMR([#2208](https://github.com/ohah/zntc/pull/2208), [#2214](https://github.com/ohah/zntc/pull/2214)), 남은 Vite parity 범위([#2218](https://github.com/ohah/zntc/pull/2218)), CSS Modules와 Sass 파이프라인([#2225](https://github.com/ohah/zntc/pull/2225), [#2226](https://github.com/ohah/zntc/pull/2226)), HTTPS SPA fallback 미리보기 테스트([#2230](https://github.com/ohah/zntc/pull/2230))를 갖췄고, Playwright E2E와 증분 dev 파이프라인 정리가 함께 들어갔습니다. 웹 예제 앱과 `compiler` 설정 네임스페이스를 추가한 뒤([#2227](https://github.com/ohah/zntc/pull/2227)) styled-components 변환을 1st-party로 구현해 displayName 주입, `withConfig` 표준 출력, SSR용 componentId 해시를 넣고, `.attrs` 체인·객체 프로퍼티·대입·조건식·논리식과 TS/Flow cast 안의 styled 호출까지 인식하며 사용자가 직접 쓴 `.withConfig`는 보존합니다([#2228](https://github.com/ohah/zntc/pull/2228)~[#2237](https://github.com/ohah/zntc/pull/2237)). 클래스 필드 패턴을 다루는 [#2238](https://github.com/ohah/zntc/pull/2238)은 이날 PR이 열렸습니다.

번들러 옵션으로는 `output.exports`의 auto/named/default/none과 충돌 진단([#2177](https://github.com/ohah/zntc/pull/2177)), lifecycle hook([#2179](https://github.com/ohah/zntc/pull/2179)), 내장 로더 검증과 onLoad의 로더 override 전달, Uint8Array·Buffer 내용 지원([#2180](https://github.com/ohah/zntc/pull/2180), [#2181](https://github.com/ohah/zntc/pull/2181)), `--inline-dynamic-imports` 플래그와 `zts.config.json`의 manualChunks 매핑([#2185](https://github.com/ohah/zntc/pull/2185), [#2186](https://github.com/ohah/zntc/pull/2186))이 들어왔고, 옵션 DTO 이름을 `ConfigOptionsDto`로 바꾸며 공용 필드 적용을 헬퍼로 묶었습니다([#2182](https://github.com/ohah/zntc/pull/2182)~[#2184](https://github.com/ohah/zntc/pull/2184)). 문서에는 NAPI/JS API 레퍼런스와 `@zts/core` 아키텍처 다이어그램이 추가됐습니다([#2191](https://github.com/ohah/zntc/pull/2191)).

버그 수정으로는 mime-types에서 드러난 CJS 동적 exports 접근 시 prune 비활성화([#2178](https://github.com/ohah/zntc/pull/2178)), string enum의 reverse mapping 제거([#2199](https://github.com/ohah/zntc/pull/2199)), 이름 있는 클래스 식의 내부 이름 보존과 JSX factory 식별자의 symbol_id 전파([#2201](https://github.com/ohah/zntc/pull/2201), [#2204](https://github.com/ohah/zntc/pull/2204)), 블록 스코프 let의 TDZ 보존([#2205](https://github.com/ohah/zntc/pull/2205)), 순환 모듈의 const/let/class live binding([#2206](https://github.com/ohah/zntc/pull/2206)), 단일 파일 출력의 dynamic import lazy 래핑([#2212](https://github.com/ohah/zntc/pull/2212), [#2215](https://github.com/ohah/zntc/pull/2215), [#2216](https://github.com/ohah/zntc/pull/2216)), 소스맵 footer와 specifier·enum 매핑([#2219](https://github.com/ohah/zntc/pull/2219), [#2220](https://github.com/ohah/zntc/pull/2220), [#2221](https://github.com/ohah/zntc/pull/2221)), 파생 클래스 parameter property의 `super()` 뒤 출력([#2222](https://github.com/ohah/zntc/pull/2222))이 있었습니다. 광역 fuzz 라운드에서 나온 fixture는 회귀 테스트로 남겼습니다([#2223](https://github.com/ohah/zntc/pull/2223)).
