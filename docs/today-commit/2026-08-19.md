# 2026-08-19

## 요약 (AI 작성)

모바일 SSH 를 기기에서 끝까지 잇는 날입니다. iOS host 가 같은 펌프로 붙고 유예 뒤 정직하게 끊으며(S9-3c), 기기에서 키를 만들어 그 키로 실서버에 붙어 증명하고(S9c-1), 안드로이드는 개인키를 Keystore 로 봉인해 키 파일 경로를 없앴습니다(S9c-3). 공개키를 보여 주고 복사하는 화면(S9c-4), 서버 목록에서 골라 붙고 등록·수정·삭제하는 화면(S9b-2b), 접속 정보를 config 가 들게 하고 ssh.conf 를 제거한 것(S9b-2a), 비밀번호 인증과 none 으로 방법 목록을 묻는 경로, 처음 붙는 서버의 지문 승인(S9b-3)까지 붙였습니다.

편집기는 텍스트 파일을 네이티브 편집기로 여는 것을 기본으로 전환하고, 선택의 좌표계를 먼저 정한 뒤(§4.1g — 방향이 둘이고 성질이 다르다) 행마다 조각 시작을 싣고 픽셀을 원본 byte 로 옮기고 이어진 조각에도 글자 강조가 서게 했습니다. pane 상태바 셋(저하·읽기 전용·줄바꿈)도 냈습니다. chrome 은 tui 룩과 `chrome.preset` 을 제거해 rich 하나로 좁혔고, 소스 컨트롤은 비교 기준을 고르고 workspace 에 기억하며(P7a·b) 히스토리 ref 칩을 `+N` 으로 접고 미푸시가 있으면 브랜치 이름 뒤에 점을 켭니다.

Windows 는 크로스 타깃 게이트가 중립 표면을 실제로 보게 하고(W8.0), 파일 트리 백엔드와 데이터 경로가 Windows 에서 끝까지 흐르게 했으며(W8.1·W8.2⒜), `shell.args` 기본값을 OS 별로 갈라 PowerShell 을 pwsh·powershell 로 나눴습니다(W8.1b·c). 가드가 무엇을 지키는지 돌연변이로 가른 적대적 검증, CLI help 를 영어로 옮긴 것(계약이 금지한 것이 코드에 있었다), 그리고 "규율의 값싼 절반만 돌고 확인했다고 적었다"는 자기 정정과 중간 커밋도 경계 게이트를 통과하는지 보는 CI 가 이날 들어갔습니다.
