## 요약 (AI 작성)

zntc는 전날 열린 RN 런타임 회귀 수정 [#3156](https://github.com/ohah/zntc/pull/3156)을 병합했습니다. 비동기 다운레벨에서 지연 분기를 보존하고, 루프 클로저 호출의 this를 지키며, `module.exports`에 `defineProperty`를 쓰는 모듈을 CJS로 감지하고, RN 로그 전달을 Metro와 맞추고, RN codegen의 nullable 이벤트 핸들러 분류와 이벤트 속성 감싸기를 고친 내용입니다. Rozenite serializer 폴리필 지원([#3172](https://github.com/ohah/zntc/pull/3172))과 Rozenite·Metro 설정 문서, RN 런타임 지원 범위 문서([#3188](https://github.com/ohah/zntc/pull/3188), [#3191](https://github.com/ohah/zntc/pull/3191)), Metro `resolver.platforms`를 검증하는 `extra.platforms`([#3183](https://github.com/ohah/zntc/pull/3183))도 들어왔고, 콜드 빌드 성능 측정용 `react-native-large` 예제를 추가했습니다([#3160](https://github.com/ohah/zntc/pull/3160)).

하루의 대부분은 TypeScript·Flow 파서 정합성 작업이었습니다. 문맥 키워드를 Flow 함수 타입·TS 매개변수 프로퍼티·타입 서술어 이름으로 받아들이고, 기본값이나 끝 쉼표가 있는 화살표 함수의 타입 판별, 인터페이스 getter/setter 시그니처, non-null 단언 대입 대상, 모든 숫자 리터럴 타입, 타입 없는 `this` 매개변수, get·set·async라는 이름의 메서드를 처리하게 했습니다. `.d.ts`와 `declare global`을 ambient로 다루고 `.d.ts` 변환 결과를 빈 출력으로 내며([#3176](https://github.com/ohah/zntc/pull/3176), [#3182](https://github.com/ohah/zntc/pull/3182)), TS 파일을 암묵적 strict 모듈로 취급하되 script 모드에서는 `await`를 식별자로 허용했습니다([#3180](https://github.com/ohah/zntc/pull/3180), [#3186](https://github.com/ohah/zntc/pull/3186)). 자동 type-only export 제거는 선언 병합과 최상위 declare 바인딩을 존중하게 됐습니다([#3173](https://github.com/ohah/zntc/pull/3173), [#3177](https://github.com/ohah/zntc/pull/3177)). 리터럴 왼쪽 피연산자에서 제네릭 인자 추측이 지수적으로 늘어나 멈추던 문제도 고쳤습니다([#3192](https://github.com/ohah/zntc/pull/3192), [#3193](https://github.com/ohah/zntc/pull/3193)).

이런 수정을 체계적으로 찾기 위해 TSC conformance 감사 스크립트를 추가하고([#3187](https://github.com/ohah/zntc/pull/3187)), 판정 오라클이 TSC matrix baseline과 TS18xxx·TS17xxx 같은 구문 오류 코드, `@strict:false` 지시를 인식하도록 이어서 다듬었습니다. tsc 통합 테스트에서 실패를 조용히 건너뛰던 `expectPass` 경로도 없앴습니다([#3181](https://github.com/ohah/zntc/pull/3181)). 그 밖에 linker는 namespace 멤버 초기화 감싸기를 dev 모드로 한정하고 export마다 반복하던 작업을 루프 밖으로 옮겼으며([#3163](https://github.com/ohah/zntc/pull/3163), [#3169](https://github.com/ohah/zntc/pull/3169)), resolver의 `preserveSymlinks`는 esbuild 방식의 식별과 새 `resolveSymlinkSiblings` 대체 경로로 나눴습니다([#3174](https://github.com/ohah/zntc/pull/3174)).

블로그 저장소 ohah.github.io의 커밋 19개는 대부분 크론이 남긴 `CRON_CRD_WRITE.md` 점검 기록이고, zts 개발기 `development-1.mdx` 문구 수정과 요약 갱신이 섞여 있습니다.
