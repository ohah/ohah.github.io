> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

maru 파일 패널은 FP7 프로젝트 트리([#1428](https://github.com/ohah/maru/pull/1428))와 FP8 도크 분할 UI([#1429](https://github.com/ohah/maru/pull/1429))로 기능 단계를 마치고, 이날 PR 18개가 모두 main에 병합됐습니다. 프로젝트 트리는 natural sort, lazy 디렉터리, 여러 루트, 최근 MRU를 지원하고, 분할 UI는 그룹별 탭·포커스·분할선 리사이즈와 workspace 직렬화 v2를 더했습니다. 이어 탭·breadcrumb·탐색기 구획을 디자인 구조에 맞추고([#1430](https://github.com/ohah/maru/pull/1430)), 도크 드래그를 WKWebView가 따라오는 라이브 리사이즈로 바꿨으며([#1431](https://github.com/ohah/maru/pull/1431)), 도크 바깥 클릭을 삼키던 입력 라우팅과 탐색기 리사이즈를 보강했습니다([#1432](https://github.com/ohah/maru/pull/1432)). 도크 divider·resize 리뷰 결함([#1433](https://github.com/ohah/maru/pull/1433)), 접기 토글 시각과 트리 상단 정렬([#1435](https://github.com/ohah/maru/pull/1435)), 우상단 토글 렌더 복구([#1444](https://github.com/ohah/maru/pull/1444))도 이어졌습니다.

동작 계약은 탭 닫기·키보드 탐색·파일 변경을 문서로 먼저 확정한 뒤([#1436](https://github.com/ohah/maru/pull/1436)) 구현했습니다. 도크 탭 닫기와 포커스 기반 ⌘W, 수정된 Markdown의 저장·버리기·취소 흐름이 들어갔고([#1438](https://github.com/ohah/maru/pull/1438)), 파일 트리에는 키보드 포커스·탐색([#1440](https://github.com/ohah/maru/pull/1440))과 파일 생성·이름 변경·휴지통 삭제([#1442](https://github.com/ohah/maru/pull/1442)), 선택 행의 테마 대비와 휴지통 표시 복구([#1443](https://github.com/ohah/maru/pull/1443))가 더해졌습니다. Markdown 안의 로컬 파일 링크는 도크로 열고, 외부 링크를 열 곳은 `file-panel.external-link-target` 설정으로 정하며, percent 인코딩으로 스킴 검사를 우회하던 경로를 막았습니다([#1437](https://github.com/ohah/maru/pull/1437)). Markdown 첫 렌더의 흰 깜빡임도 없앴습니다([#1439](https://github.com/ohah/maru/pull/1439)).

그 밖에 Claude·Codex 워크스페이스 복원이 원본 세션을 직접 공유하지 않고 provider의 fork 세션을 열도록 바꿨고([#1441](https://github.com/ohah/maru/pull/1441)), 한글·CJK 번들 폰트 Jetendard를 추가해 기본 폰트 다음 우선순위에 두었습니다([#1434](https://github.com/ohah/maru/pull/1434)).

zntc는 `--splitting`과 `--preserve-modules`의 심볼 결함 수정 PR 7개를 병합했습니다. 배럴을 거친 namespace 멤버를 canonical 전역명으로 재작성하고([#4565](https://github.com/ohah/zntc/pull/4565)), 함수 안 const가 import 심볼을 가려 자기 자신을 TDZ로 참조하던 문제를 같은 청크([#4567](https://github.com/ohah/zntc/pull/4567))와 크로스-청크·preserve-modules·dev-split([#4568](https://github.com/ohah/zntc/pull/4568))에서 막았습니다. #4532의 증상 3(배럴 경유 ESM-wrap dep re-export, [#4569](https://github.com/ohah/zntc/pull/4569))과 증상 1(CJS 동명 export 붕괴와 minify 시 mangle 통합, [#4570](https://github.com/ohah/zntc/pull/4570), [#4571](https://github.com/ohah/zntc/pull/4571))을 마무리했고, 익명 `export default` class·function이 ESM-wrap에서 미선언 참조가 되던 문제([#4575](https://github.com/ohah/zntc/pull/4575))와 wrap되지 않은 provider의 동명 export 붕괴([#4577](https://github.com/ohah/zntc/pull/4577))도 고쳤습니다. ohah.github.io에는 메타데이터·문서 커밋 4개가 있었습니다.

공개 커밋 33개, 해당일 생성 또는 병합된 PR 25개를 정리했습니다. PR 생성 25개·병합 25개는 같은 PR이 양쪽에 포함될 수 있습니다.
