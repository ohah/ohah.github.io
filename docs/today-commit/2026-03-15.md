## 요약 (AI 작성)

hwpjs는 PR 여덟 개를 main에 병합했습니다. 가장 큰 작업은 LineSeg가 없는 HWP 5.1 이상 문서의 렌더링 지원([#134](https://github.com/ohah/hwpjs/pull/134))으로, 글자 폭 근사로 줄바꿈 위치를 추정해 LineSeg를 합성하고 표·이미지 높이와 들여쓰기·내어쓰기, 셀 안 세로 위치 누적, 페이지 오프셋을 반영했습니다. LineSeg가 이미 있는 파일은 합성을 건너뛰게 했고, 같은 흐름에서 선 도형 SVG 렌더링, 셀 안 그림과 하이퍼링크 렌더링, `software.hwp` 픽스처와 페이지별 스냅숏이 함께 들어왔습니다. 탭 문자를 `htC` span으로 그리는 기능([#136](https://github.com/ohah/hwpjs/pull/136))과 0.1.0-rc.9 버전 올림([#137](https://github.com/ohah/hwpjs/pull/137)), 배포 절차를 담은 release 스킬 추가가 이어졌고, 저녁에는 브라우저 WASM에 불필요한 Buffer 폴리필과 관련 문서를 지우고([#139](https://github.com/ohah/hwpjs/pull/139), [#140](https://github.com/ohah/hwpjs/pull/140)) 셀 안 그림이 두 번 그려지던 문제를 고친 뒤([#141](https://github.com/ohah/hwpjs/pull/141)) 0.1.0-rc.10으로 올렸습니다([#142](https://github.com/ohah/hwpjs/pull/142)). 셀 안 글자처럼 취급하는 그림의 위치 수정 [#143](https://github.com/ohah/hwpjs/pull/143)은 이날 열려 다음 날 병합됐습니다.

cheolsu-proxy는 PR 일곱 개를 병합했습니다. 전날 연 [#250](https://github.com/ohah/cheolsu-proxy/pull/250)으로 SSE 뷰어와 TTFB·콘텐츠 다운로드만 보이는 Timing 탭, 네트워크 표 컬럼 토글이 들어왔고, `proxy_auth_user`로 클라이언트를 구분해 트래픽을 걸러 보고 태그를 붙이는 기능([#251](https://github.com/ohah/cheolsu-proxy/pull/251))이 이어졌습니다. SSE·서버 리플레이·설정·내보내기 등 GUI 기능에 맞춘 MCP 도구 15개([#252](https://github.com/ohah/cheolsu-proxy/pull/252)), 인라인 SVG가 든 HTML·JS를 이미지로 잘못 감지하던 문제 수정([#253](https://github.com/ohah/cheolsu-proxy/pull/253)), 로드맵 문서 정리([#254](https://github.com/ohah/cheolsu-proxy/pull/254)), 리버스 프록시 모드([#255](https://github.com/ohah/cheolsu-proxy/pull/255)), 프런트엔드 FSD 위반과 TypeScript 오류 수정([#256](https://github.com/ohah/cheolsu-proxy/pull/256))도 병합됐습니다.
