## 요약 (AI 작성)

maru의 스크롤 이관을 사이드바와 오버레이까지 끌고 간 날입니다. 전날 열린 소스 컨트롤 스크롤바 [#1936](https://github.com/ohah/maru/pull/1936)(SV3b)이 먼저 병합됐고, SV4로 사이드바 스크롤바를 `ScrollArea` 경로로 옮기며 gutter를 상시 예약하고 드래그를 붙였습니다([#1939](https://github.com/ohah/maru/pull/1939)). 후속으로 스크롤바를 다시 보이게 하면서 그 위 카드 호버를 끄고 막대도 호버하면 진해지게 했습니다. SV5는 흡수 여부를 반대 근거까지 남겨 정한 뒤([#1949](https://github.com/ohah/maru/pull/1949)) 알림 패널을 픽셀로 스크롤하고 카드가 패널을 넘지 않게 자르고([#1951](https://github.com/ohah/maru/pull/1951)), 팔레트 결과 목록에 상태 없이 스크롤바만 내고([#1959](https://github.com/ohah/maru/pull/1959)), 세팅 폼 목록에 스크롤바를 내며 오버레이 발행을 하나로 묶고([#1965](https://github.com/ohah/maru/pull/1965)), 오버레이 목록에 offset 상태를 도입해 휠과 드래그로 스크롤하게 했습니다([#1977](https://github.com/ohah/maru/pull/1977)). 사이드바 셀 scissor를 rich 경로에도 걸어 카드가 검색바를 덮던 것([#1943](https://github.com/ohah/maru/pull/1943)), 카드 ✕가 그려진 칸에서 닫히지 않던 것([#1957](https://github.com/ohah/maru/pull/1957)), 터미널 탭 바와 도크 뷰 스위처의 높이가 어긋나던 것([#1947](https://github.com/ohah/maru/pull/1947))도 고쳤습니다.

세션 도크는 목록의 신뢰도를 끌어올렸습니다. 도크 첫 진입에 스캔이 돌게 하고 잘림을 화면에 알리며, 구버전 Codex 세션을 살리고 서브에이전트 개수를 카드에 보이며, 세션 재개를 로그인 셸 경유로 바꿔 Dock 실행에서도 찾게 하고 스캔 계약을 실측에 맞췄습니다([#1946](https://github.com/ohah/maru/pull/1946)). 스캔을 스트리밍으로 바꿔 read cap을 없애고 열 때마다 달라지던 목록을 결정적으로 만들었으며([#1961](https://github.com/ohah/maru/pull/1961)), 부분 목록을 "이전 목록 있음"으로 오인하던 판정과 첫 스캔 중 헤더가 "0개 표시"로 보이던 것도 고쳤습니다. AS6으로 정렬 키를 transcript의 마지막 활동 시각으로 바꾸고 헤더에 최신순/오래된순 토글을 넣었고([#1969](https://github.com/ohah/maru/pull/1969)), 도크 텍스트를 사용자 폰트로 그리게 했습니다([#1972](https://github.com/ohah/maru/pull/1972)). 에이전트 판정은 플랜 승인·도구 권한 대기를 blocked로 보고([#1963](https://github.com/ohah/maru/pull/1963)), composer에 친 확인 문구를 codex 승인 대기로 오인하지 않게 했습니다([#1967](https://github.com/ohah/maru/pull/1967)).

상태바에는 브랜치를 누르면 목록이 뜨는 메뉴가 붙었고([#1941](https://github.com/ohah/maru/pull/1941)), 요청 중 상태바가 사라지면 메뉴를 열지 않게 했으며([#1950](https://github.com/ohah/maru/pull/1950)), 표시 여부를 설정으로 끌 수 있게 했습니다([#1937](https://github.com/ohah/maru/pull/1937)). 전날 열린 경로 중간 생략 [#1934](https://github.com/ohah/maru/pull/1934)도 병합됐습니다. Chrome Lab에는 사이드바 strip 시나리오를 더하고([#1942](https://github.com/ohah/maru/pull/1942)) 그 시나리오에서 도크 chrome을 뺐습니다([#1944](https://github.com/ohah/maru/pull/1944)). 웹 탭에서는 ⌘F가 스크롤백 찾기 대신 그 페이지를 찾게 했고([#1979](https://github.com/ohah/maru/pull/1979)), 문자열 시퀀스 abort가 ESC를 삼키던 터미널 버그([#1970](https://github.com/ohah/maru/pull/1970))와 reload가 pane을 옛 설정으로 재던 config 버그([#1938](https://github.com/ohah/maru/pull/1938))를 고쳤으며, 스크롤백 Find에 perf 예산 게이트를 붙였습니다. 사이드바 헤더를 오른쪽 두 밴드와 한 줄로 맞추는 [#1978](https://github.com/ohah/maru/pull/1978)은 이날 열렸습니다.

session-host는 attach 실행 트랜잭션을 봉인하고 RPC 응답 소유권 계열을 닫았습니다. wire progress 실행을 통합하고([#1966](https://github.com/ohah/maru/pull/1966)) 응답 전이 permit, prepared response read 분리, 반복 응답 발행과 바이트 소유, 발행 실패의 terminalize와 콜백 재검증을 거쳐 B3-4/5를 완성했으며([#1976](https://github.com/ohah/maru/pull/1976)), 응답 슬롯을 재사용 가능하게 만들고 B3-6 증거 계약과 exact-count 게이트로 닫았습니다([#1982](https://github.com/ohah/maru/pull/1982)). 이어 generation control facade를 추가하고 큐잉된 control을 그 facade로 보내 blocking control facade까지 완성했습니다([#1986](https://github.com/ohah/maru/pull/1986)). CI는 app_session 판정자 751개를 실제로 돌리게 하고([#1974](https://github.com/ohah/maru/pull/1974)), 이름 필터 게이트가 0개 매치에도 green이던 것을 막았으며, Zig 빌드 캐시와 주기 정리를 넣고 session host ReleaseFast를 main push로 옮겼습니다. zntc는 디렉토리 symlink를 파일로 잡던 #4612([#4615](https://github.com/ohah/zntc/pull/4615)), CSS `@import`의 bare 지정자가 tsconfig paths에 가로채이던 #4611([#4617](https://github.com/ohah/zntc/pull/4617)), node_modules 안 import에도 paths가 적용되던 #4607([#4618](https://github.com/ohah/zntc/pull/4618)), namespace 부분 멤버 집합이 union을 덮어쓰던 #4600([#4619](https://github.com/ohah/zntc/pull/4619)), external re-export의 파싱 불가 출력 #4621([#4622](https://github.com/ohah/zntc/pull/4622)), 소문자로 시작하지 않는 bare JSX 태그의 참조 누락 #4599([#4623](https://github.com/ohah/zntc/pull/4623))를 고치고, external 지정자를 다른 이름으로 방출하는 매핑 #4616([#4620](https://github.com/ohah/zntc/pull/4620))을 추가했습니다.

공개 커밋 95개, 해당일 생성 또는 병합된 PR 59개를 정리했습니다. PR 생성 57개·병합 58개는 같은 PR이 양쪽에 포함될 수 있습니다.
