# 2026-08-08

## 요약 (AI 작성)

스크롤 이관(SV4·SV5)을 사이드바와 오버레이까지 끌고 가 마무리한 날입니다. SV4 로 사이드바 스크롤바를 선언된 tree 로 옮기고 gutter 를 상시 예약한 뒤 드래그를 붙였고, 후속으로 스크롤바를 다시 보이게 하면서 그 위 카드 호버를 끄고 막대도 호버 시 진해지도록 했습니다. SV5 는 흡수 여부를 반대 근거까지 남겨 결정한 뒤 알림 패널을 픽셀 스크롤로 바꾸고 카드가 패널을 넘지 않게 자르고(SV5a), 팔레트 결과 목록에 상태를 만들지 않고 스크롤바만 내고(SV5b), 세팅 폼 목록에 스크롤바를 내며 오버레이 발행을 하나로 묶고(SV5c), 오버레이 목록에 offset 상태를 도입해 휠·드래그 스크롤을 지원했습니다(SV5d).

세션 도크(에이전트 세션)는 목록의 신뢰도를 끌어올렸습니다. 스캔을 스트리밍으로 바꿔 read cap 을 없애고 목록이 열 때마다 달라지던 것을 결정적으로 만들었으며, 부분 목록을 "이전 목록 있음"으로 오인하던 판정과 첫 스캔 중 헤더가 "0개 표시"로 세션 없음처럼 보이던 것을 고쳤습니다. 도크 첫 진입에 스캔이 돌게 하고 잘림을 화면에 알리며, 구버전 Codex 세션을 살리고 서브에이전트 개수를 카드에 보이도록 했고, 세션 재개를 로그인 셸 경유로 바꿔 Dock 실행에서도 찾게 했습니다. AS6 으로 정렬 키를 transcript 의 마지막 활동 시각으로 바꾸고 헤더에 최신순/오래된순 토글을 두되 좁은 도크에서는 발행하지 않도록 했으며, 토글을 ghost Button 으로 바꾸고 헤더를 보는 골든을 만들었습니다. 스캔 계약은 실측에 맞춰 개정하고 드리프트를 기록했습니다. 에이전트 판정도 손봐서 플랜 승인·도구 권한 대기를 유휴가 아닌 blocked 로 보고, composer 에 친 확인 문구를 codex 승인 대기로 오인하지 않게 했습니다.

상태바에는 브랜치 메뉴가 붙었습니다. 브랜치를 누르면 목록이 뜨도록 하고 결함 셋을 고치며 헤드리스 캡처 훅을 더했고, 요청 중 상태바가 사라지면 메뉴를 열지 않도록 했으며 표시 여부를 설정으로 끌 수 있게 했습니다. Chrome Lab 에는 사이드바 strip 시나리오를 더해 §5.2 공백을 닫되, strip 시나리오에서 도크 chrome 을 빼 캡처가 제품을 오도하지 않게 했습니다. 그 밖에 웹 탭에서 ⌘F 가 스크롤백 찾기 대신 그 페이지를 찾도록 고치고, 문자열 시퀀스 abort 가 ESC 를 삼키던 터미널 버그와 reload 가 pane 을 옛 설정으로 재던 config 버그를 잡았습니다.

session-host 는 RPC 응답 소유권 계열(B3-3~B3-6)을 닫고 generation control facade 를 세웠습니다. wire progress 실행을 통합하고 응답 전이 permit 과 prepared response read 분리, 반복 응답 발행과 바이트 소유, 발행 실패의 terminalize 와 콜백 재검증을 거쳐 B3-4/5 소유권을 완성했으며, 응답 슬롯을 재사용 가능하게 만들고 B3-6 의 엄격한 증거 계약과 exact-count 게이트로 닫았습니다. 이어 typed generation control facade 를 추가하고 큐잉된 control 을 그 facade 로 라우팅해 blocking control facade 까지 완성했습니다. CI 는 실측을 근거로 크게 손봤습니다 — app_session 판정자 751개를 실제로 돌리게 하고, 이름 필터 게이트가 0개 매치에도 green 이던 것을 막았으며, 무거운 잡부터 Zig 빌드 캐시를 넣고 캐시가 한도를 밀어 올리지 않게 주기 정리를 걸었고, session host ReleaseFast 를 PR 에서 빼 main push 로 옮겼습니다. zntc 에서는 tsconfig paths 관련 오적용(#4607 node_modules 안 import, #4611 CSS `@import` 의 bare 지정자)과 #4612 디렉토리 symlink 를 파일로 잡던 문제, #4621 external re-export 의 파싱 불가 출력, #4600 namespace 부분 멤버 집합이 union 을 덮어쓰던 문제, #4599 소문자로 시작하지 않는 bare JSX 태그의 참조 누락을 고치고, #4616 으로 external 지정자를 다른 이름으로 방출하는 매핑을 추가했습니다.
