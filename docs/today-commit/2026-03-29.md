## 요약 (AI 작성)

이날 공개 활동은 zntc에 모였습니다. 오전에는 전날 연 minify 옵션 분리([#497](https://github.com/ohah/zntc/pull/497))를 병합하면서 선언문 뒤 tagged template이 사라지던 문제를 함께 고쳤고, `__extends`·`__generator`·`__rest` 같은 런타임 헬퍼를 필요할 때 자동으로 넣도록 했습니다([#499](https://github.com/ohah/zntc/pull/499)). 이어 테스트 코드를 `*_test.zig` 파일로 나누고 런타임 헬퍼와 linker 함수, CLI 파싱을 정리하는 리팩터링([#501](https://github.com/ohah/zntc/pull/501)부터 [#504](https://github.com/ohah/zntc/pull/504)까지)이 들어왔습니다.

오후에는 성능을 다뤘습니다. `c_allocator`와 스레드 풀, `--timing` 옵션과 파이프라인 벤치마크([#505](https://github.com/ohah/zntc/pull/505)), mimalloc 통합([#506](https://github.com/ohah/zntc/pull/506))에 이어 finalize·emit·resolve 단계를 병렬화했고([#508](https://github.com/ohah/zntc/pull/508)), 커밋 기록상 번들 속도가 최대 4.7배 빨라졌습니다. 트리 셰이킹 fixpoint가 진동하며 100회 돌던 문제를 2회 만에 수렴하도록 고쳐 238ms가 50ms가 됐습니다([#509](https://github.com/ohah/zntc/pull/509)). 저녁 무렵에는 AST 미니파이어를 상수 접기, 죽은 코드 제거, 불리언 단순화, 쉼표 연산자와 템플릿 리터럴 접기의 4단계로 구현했습니다([#511](https://github.com/ohah/zntc/pull/511)부터 [#514](https://github.com/ohah/zntc/pull/514)까지).

밤에는 esbuild·rolldown·rspack에 비해 빠져 있던 번들러 옵션을 묶음 단위로 채웠습니다. `--alias`·`--banner`·`--global-name`·`--out-extension`·`--log-level` 등 10개(Batch A, [#516](https://github.com/ohah/zntc/pull/516)), content hash와 파일 이름 패턴(Batch B, [#517](https://github.com/ohah/zntc/pull/517)), file·dataurl·text·binary·copy 에셋 로더(Batch C, [#519](https://github.com/ohah/zntc/pull/519)), metafile·analyze·legal comments·inject·keepNames(Batch D, [#520](https://github.com/ohah/zntc/pull/520))가 들어왔고, CLAUDE.md의 상세 내용은 `docs/` 문서로 옮겼습니다. 마지막으로 플러그인 인프라를 Zig 함수 포인터 기반 훅으로 시작해([#521](https://github.com/ohah/zntc/pull/521)), Node.js 프로세스를 띄워 JSON으로 통신하는 subprocess 플러그인과 그 JS API를 담은 `@zts/core` 패키지, CLI `--plugin` 옵션, 비 JS 확장자 load 훅과 virtual module 지원까지 이어 갔습니다([#523](https://github.com/ohah/zntc/pull/523)부터 [#530](https://github.com/ohah/zntc/pull/530)까지).

공개 커밋 72개, 해당일 생성 또는 병합된 PR 34개를 정리했습니다. PR 생성 33개·병합 34개는 같은 PR이 양쪽에 포함될 수 있습니다.
