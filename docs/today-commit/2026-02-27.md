## 요약 (AI 작성)

react-wasm-table은 PR 아홉 개를 병합하며 그리드 기능을 넓혔습니다. 이벤트 콜백·선택·정렬 훅과 훅 조합 데모 페이지를 테스트와 함께 추가하고([#21](https://github.com/ohah/react-wasm-table/pull/21)), 프레임을 그린 뒤 호출되는 `onAfterDraw` 콜백과 테스트용 adapter 의존성 주입으로 헤드리스 리팩터링 0단계를 마무리했습니다([#22](https://github.com/ohah/react-wasm-table/pull/22)). 열 단위 저장소에 기반한 행 모델과 필터링, 제어·비제어 모드를 지원하는 `useFiltering` 훅과 데모를 넣었고([#23](https://github.com/ohah/react-wasm-table/pull/23)), 열 순서·표시·크기·고정 상태와 열 너비 조절 핸들, 레이아웃 엔진의 실제 행 높이를 렌더러까지 전달하는 수정, 제어 모드에서 선택 기준점이 사라지던 문제 수정을 [#24](https://github.com/ohah/react-wasm-table/pull/24)로 병합했습니다.

이어 트리 데이터를 위한 `getExpandedRowModel`과 펼침 상태([#25](https://github.com/ohah/react-wasm-table/pull/25)), `onTouchStart`·`onTouchMove`·`onTouchEnd` 터치 이벤트 API([#26](https://github.com/ohah/react-wasm-table/pull/26)), 이벤트 미들웨어와 내보내기 API, 레이아웃 캐시([#27](https://github.com/ohah/react-wasm-table/pull/27))를 추가했습니다. 셀 그리기는 `CellRendererRegistry`로 분기하도록 바꿔 진행률 표시 같은 사용자 정의 셀 렌더러를 등록할 수 있게 했고([#28](https://github.com/ohah/react-wasm-table/pull/28)), 캔버스 렌더 파이프라인에 콘텐츠·뷰포트 좌표계의 렌더 레이어를 조합해 오버레이를 그릴 수 있게 했습니다([#29](https://github.com/ohah/react-wasm-table/pull/29)). 로드맵은 완료 항목과 단계, 의존 관계 그래프로 다시 정리했고, 커밋 메시지에 도구 표기를 남기지 않는 규칙과 이를 지우는 스크립트를 추가했습니다.

hwpjs는 Markdown 뷰어 `ctrl_header`의 표·도형·꼬리말 등에 실제 동작을 검증하는 테스트를 추가했습니다. ohah.github.io에서는 맞춤법 크론이 hwpjs 기술 스택 문서 점검과 전체 완료 표시를 남겼고, 2월 27일 요약이 올라갔습니다.
