> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 ES 버전 타깃에 더해 `--target=chrome80,safari14` 같은 브라우저·엔진 버전 타깃을 지원하도록 esbuild compat-table 기반 기능별 다운레벨링을 넣었습니다([#576](https://github.com/ohah/zntc/pull/576)). Vue SFC와 Svelte 컴파일러를 subprocess 플러그인으로 번들링하는 통합 테스트([#577](https://github.com/ohah/zntc/pull/577), [#578](https://github.com/ohah/zntc/pull/578)), `--plugin`·`--proxy` 사용 시 메모리 누수 수정([#579](https://github.com/ohah/zntc/pull/579))에 이어, `new Worker(new URL(...))` 패턴을 찾아 워커 파일을 별도 IIFE 번들로 만드는 Web Worker 자동 번들링([#580](https://github.com/ohah/zntc/pull/580))이 들어왔습니다. 오후에는 parse와 resolve를 배치 단위로 반복하던 scan을 파이프라인으로 바꿔 15% 빨라졌고([#582](https://github.com/ohah/zntc/pull/582)), 이를 bun·esbuild처럼 Producer-Consumer 구조로 다시 짜 포인터 안정성 문제를 정리했습니다([#584](https://github.com/ohah/zntc/pull/584), [#585](https://github.com/ohah/zntc/pull/585)). CJS가 `require()`로 참조하는 JSON 모듈의 scope hoisting 분기도 고쳤습니다([#586](https://github.com/ohah/zntc/pull/586)).

밤에는 문자열·템플릿 SIMD 렉서와 이벤트 큐 스캔, 디렉터리 엔트리 캐시를 묶은 성능 개선([#587](https://github.com/ohah/zntc/pull/587))과, bungae 연동을 위해 `--platform=react-native` 프리셋과 watch-json 출력, 증분 빌드를 넣은 [#588](https://github.com/ohah/zntc/pull/588)을 병합했습니다.

suji는 EventBus를 WebView와 연결해 모든 백엔드가 JS로 이벤트를 보낼 수 있게 했고, 백엔드 이름 없이 `invoke("ping")`처럼 채널만으로 호출하는 Electron식 자동 라우팅과 선택적 target 지정, 중복 채널 경고를 추가했습니다. 채널 키 수명 문제로 나던 라우팅 크래시를 고치고 예제를 새 API로 바꾼 뒤, 타입을 갖춘 TypeScript SDK `@suji/api`와 테스트 16개를 추가했습니다.

공개 커밋 29개, 해당일 생성 또는 병합된 PR 13개를 정리했습니다. PR 생성 13개·병합 13개는 같은 PR이 양쪽에 포함될 수 있습니다.
