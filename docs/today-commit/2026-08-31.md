# 2026-08-31

## 요약 (AI 작성)

zntc v0.1.5 와 v0.1.6 이 나간 날입니다. 한 줄 블록 안 주석 뒤 소스맵이 한 줄씩 밀리던 것을 고치고, bun.lock 동기화를 PR 로 내며, 릴리스가 만든 CHANGELOG 를 oxfmt 형식에 맞췄습니다. `@ohah/pdf` 는 하루에 크게 자랐습니다 — 문서 정보 넷(권한·쪽 라벨·열 때 설정·지문), 종류 가리지 않는 주석 걷기와 얹어서 다룰 수 있는 주석 층, 이름 목적지·뷰어 설정·XMP, 표준 14종 글꼴의 AFM 자간, 주소로 열기와 내려받기 진행률, 글자 덩이와 구조 나무, 뷰어에 아쉽던 넷(렌더 취소·뷰포트·글자층·렌더 옵션), Node.js 지원. 여는 값은 34MB 기준 417ms 에서 120ms 로 줄었고, 갱신이 얹힌 암호 문서와 trailer 로 좁히며 놓칠 뻔한 결함을 잡았습니다.

maru 는 소스 컨트롤이 원격 pane 을 알기 시작했습니다 — 원격 pane 이 활성이면 그 저장소를 읽습니다(RS1·RS2). 원격 이벤트가 행을 «에이전트 행» 으로 바꾸고, HOME 이 상대경로면 abort 하던 것과 pid 를 posix 로 물어 Windows 빌드가 죽던 것을 고쳤습니다. 이미지 갤러리는 디코드를 틱에서 풀고 크게 보기를 뷰포트만큼만 풉니다(IG14·IG15). session-host 는 GitHub API·CLI 와 Apple command transport 를 bound 로 묶고, DMG·attestation·predecessor release 권위를 세우고 predecessor manifest 를 인증합니다. Windows 는 카드를 펼치면 대화가 뜨고(W8.22), ssh 원격 셸 규율은 네 곳이 나란히 틀려 한 곳으로 모았습니다.
