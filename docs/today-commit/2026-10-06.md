# 2026-10-06

> 한국 시간(KST) 기준으로 하루를 나눴습니다. 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 조회: 2026-10-07 KST. 공개 저장소에서 조회한 활동만 포함합니다.

## 요약 (AI 작성)

maru는 앱이 죽던 결함 두 가지를 고쳤습니다. 창을 닫을 때 정리 루프가 이미 해제한 탭을 목록에 남겨 뒤 탭의 정리가 그 탭을 읽다 SIGSEGV로 죽던 use-after-free를 [#4186](https://github.com/ohah/maru/pull/4186)에서 막았습니다. 재접속 작업이 얼린 attachment를 창 drain이 읽다가 앱이 abort하던 순서 경쟁은 [#4184](https://github.com/ohah/maru/pull/4184)에서 고쳤습니다. 이어서 재접속 작업이 붙든 runtime의 탭을 닫으면 backend가 닫기를 맡았다가 작업이 끝난 뒤 마저 닫도록 했습니다([#4187](https://github.com/ohah/maru/pull/4187)). 10월 5일에 열렸던 [#4162](https://github.com/ohah/maru/pull/4162)도 이날 병합됐습니다. 10월 4일 변경이 저장 헤더를 v2로 올리면서 기존 v1 파일을 거절해 실행할 때마다 빈 창이 되던 문제라, 헤더를 `maru.workspace.v1`로 되돌리고 옛 v2는 읽기만 하도록 했고 저장 파일을 읽지 못하면 그 사실을 기록에 남기게 했습니다.

화면 쪽에서는 확인 모달과 메뉴의 경계 처리를 여러 건 손봤습니다. 긴 URL 때문에 권한 질문이 잘리지 않게 했고([#4168](https://github.com/ohah/maru/pull/4168)), 이어서 URL을 줄일 때 호스트의 오른쪽 끝(등록 도메인)이 잘려 실제 사이트가 가려질 수 있던 문제를 [#4188](https://github.com/ohah/maru/pull/4188)에서 고쳤습니다. 버튼이 상자 밖으로 빠지지 않게 줄을 나누고([#4169](https://github.com/ohah/maru/pull/4169)), 창보다 긴 우클릭 메뉴와 깨진 UTF-8이 섞인 라벨, 창 가장자리에서 잘리던 긴 알림도 처리했습니다([#4174](https://github.com/ohah/maru/pull/4174)·[#4179](https://github.com/ohah/maru/pull/4179)·[#4183](https://github.com/ohah/maru/pull/4183)). 알림 패널은 걸친 카드의 강조 배경과 구분선, 스크롤 중 클릭·호버가 한 줄 위 카드를 잡던 문제를 고쳤습니다([#4173](https://github.com/ohah/maru/pull/4173)·[#4182](https://github.com/ohah/maru/pull/4182)). 편집기 찾기는 단어 단위 옵션과 빈 일치 처리를 VS Code 기본 동작에 맞췄고([#4170](https://github.com/ohah/maru/pull/4170)), 메뉴의 Reload·전체 리셋이 다른 창에 미뤄 둔 적용도 마저 하도록 했습니다([#4189](https://github.com/ohah/maru/pull/4189)).

Chromium 웹 패널의 W6i·W6j·W6k([#4171](https://github.com/ohah/maru/pull/4171)·[#4175](https://github.com/ohah/maru/pull/4175)·[#4181](https://github.com/ohah/maru/pull/4181))는 기능 브랜치 `docs/web-panel-osr-backend`에 병합돼 main 반영이 아닙니다. 확인 모달을 좁은 창에 맞추는 [#4190](https://github.com/ohah/maru/pull/4190)과 공유 뷰 닫기·백업 보존 검증 [#4185](https://github.com/ohah/maru/pull/4185)는 미병합입니다.

zntc는 번들러가 ES5로 내리는 클래스에서 의미 그래프를 버리지 않고 유지하는 범위를 넓혔습니다. 빈 클래스에서 시작해 메서드·정적 메서드·접근자, 빈 생성자, 생성자 안의 대입·조건·반환·throw·반복문까지 조건을 하나씩 늘렸습니다([#5124](https://github.com/ohah/zntc/pull/5124)부터 [#5150](https://github.com/ohah/zntc/pull/5150)까지). 그 밖에 namespace·enum IIFE 매개변수를 SymbolId로 요구하도록 codegen을 바꾸고, default export facade와 로컬 export를 정확한 심볼로 묶었으며, for-await·using·익명 클래스 래퍼의 임시 심볼을 생성 시점에 등록했습니다. 이날 PR 45개는 모두 병합됐고, 새 릴리스는 없습니다(최신 v0.1.10). 블로그 저장소에는 9월 하순부터 10월 5일까지의 기록과 오늘의 커밋 전수 보강 커밋이 올라갔습니다.

공개 커밋 98개, 해당일 생성 또는 병합된 PR 70개를 정리했습니다. PR 생성 68개·병합 68개는 같은 PR이 양쪽에 포함될 수 있습니다.
