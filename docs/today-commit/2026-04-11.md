# 2026-04-11

> 날짜는 UTC 기준으로 나눴습니다(9월 22일부터는 한국 시간 기준). 커밋은 커미터 시각(committer date), PR은 생성·병합 시각으로 분류했습니다. 목록은 2026-10-06 KST에 GitHub에서 다시 조회해 보강했습니다. 공개 저장소의 기본 브랜치 활동만 포함합니다.

## 요약 (AI 작성)

zntc는 TC39 Stage 3 데코레이터 변환을 하루 안에 구현했습니다. 기존 experimental 데코레이터와 별도로 TypeScript 5.0+/Babel/SWC와 같은 `__esDecorate`·`__runInitializers` 출력을 내고, access 프로퍼티, 필드별 initializer, auto-accessor의 private backing field 변환, class expression, `Symbol.metadata`, private 필드·getter·setter·메서드 데코레이터까지 다뤘습니다([#1075](https://github.com/ohah/zntc/pull/1075)). 식 평가와 적용을 분리해 TC39 스펙의 평가 순서를 따르게 했고, Babel 2023-11 conformance 테스트 46개를 포팅했으며, MobX 6 `@computed` getter가 실패하던 initializer 누락을 고친 뒤([#1077](https://github.com/ohah/zntc/pull/1077)) MobX 스모크 테스트를 붙였습니다.

CSS 번들링 1단계로 Zig 네이티브 `@import` 추출기와 인라이닝, Lightning CSS minify를 넣고([#1080](https://github.com/ohah/zntc/pull/1080)) 순환 import·미디어 쿼리 등 엣지 케이스와 Emotion·styled-components 스모크 테스트를 추가했습니다([#1081](https://github.com/ohah/zntc/pull/1081), [#1083](https://github.com/ohah/zntc/pull/1083)). Vite의 esbuild transform을 ZTS로 바꾸는 `vite-plugin-zts`([#1085](https://github.com/ohah/zntc/pull/1085), [#1087](https://github.com/ohah/zntc/pull/1087)), `--certfile`/`--keyfile` HTTPS dev 서버([#1068](https://github.com/ohah/zntc/pull/1068)), `import.meta.glob`의 eager·import 옵션([#1071](https://github.com/ohah/zntc/pull/1071)), UMD/AMD 포맷의 external 의존성 처리([#1070](https://github.com/ohah/zntc/pull/1070))도 들어왔습니다. scope hoisting 쪽은 모듈별 namespace 변수 이름으로 충돌을 막고([#1072](https://github.com/ohah/zntc/pull/1072)), TS enum이 `__esm` 팩토리 안에 갇히던 버그([#1073](https://github.com/ohah/zntc/pull/1073)), 순환 참조 init 순서([#1093](https://github.com/ohah/zntc/pull/1093))를 고쳤으며, Rolldown의 `strictExecutionOrder`에 해당하는 옵션과 팩토리가 throw해도 다른 모듈로 번지지 않게 하는 복구를 넣었습니다([#1078](https://github.com/ohah/zntc/pull/1078)).

후반에는 Zig 네이티브 AST 플러그인 인터페이스와 Reanimated worklet 변환을 만들고([#1088](https://github.com/ohah/zntc/pull/1088)), 문자열 기반 플러그인과 AST 플러그인을 하나로 합쳐 NAPI에 연결했으며([#1090](https://github.com/ohah/zntc/pull/1090)), `workletTransform` 옵션을 NAPI에 노출했습니다([#1098](https://github.com/ohah/zntc/pull/1098)). 이어 node_modules의 reanimated/worklets 적용 범위, 식 위치 worklet의 IIFE factory, initData 코드를 Codegen으로 생성, ES5 매개변수 변환 뒤 directive 탐색, rest 매개변수와 런타임 헬퍼 처리([#1099](https://github.com/ohah/zntc/pull/1099)~[#1106](https://github.com/ohah/zntc/pull/1106))를 차례로 고쳤습니다. `[...map.values()]`가 `concat`으로 바뀌어 iterator가 깨지던 ES5 spread 문제는 `__toConsumableArray` 헬퍼로 해결했습니다([#1096](https://github.com/ohah/zntc/pull/1096)).

bungae는 이 변경들을 따라 ZTS 서브모듈을 여덟 차례 올리고 `workletTransform`을 켰습니다.

공개 커밋 91개, 해당일 생성 또는 병합된 PR 33개를 정리했습니다. PR 생성 32개·병합 33개는 같은 PR이 양쪽에 포함될 수 있습니다.
