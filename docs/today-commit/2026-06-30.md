## 요약 (AI 작성)

maru는 자간 렌더링을 바로잡았습니다. `font.letter-spacing`이 glyph atlas 슬롯까지 좁혀 음수 자간에서 글자가 세로로 흔들리고 찌그러지던 문제를, 자간은 셀 배치 간격에만 반영하고 glyph는 자연 폭으로 래스터하며 셀마다 배경·전경 quad 두 개로 그리는 방식으로 고쳤습니다([#1110](https://github.com/ohah/maru/pull/1110)). 셀보다 넓은 glyph를 맞추는 처리는 정해진 역할의 기호에만 적용해 Hack 폰트의 'w'가 들뜨던 문제를 없앴습니다([#1111](https://github.com/ohah/maru/pull/1111)). 30Hz로 고정돼 있던 frame loop에 `render.frame-rate` 설정을 추가해 기본값을 60Hz로 올리고 설정 화면에 노출했으며([#1114](https://github.com/ohah/maru/pull/1114)), cadence를 세션 공통으로 맞추고([#1117](https://github.com/ohah/maru/pull/1117)) 드래그 자동 스크롤 속도가 frame rate에 따라 빨라지지 않도록 경과 시간 기준으로 바꿨습니다([#1118](https://github.com/ohah/maru/pull/1118)). 같은 주제로 먼저 열린 [#1113](https://github.com/ohah/maru/pull/1113)은 병합되지 않고 닫혔습니다.

알림 설정 토글을 켤 때 macOS 권한을 요청하고, 이미 거부된 경우에는 시스템 설정 창으로 안내하게 했습니다([#1116](https://github.com/ohah/maru/pull/1116), 앞선 [#1115](https://github.com/ohah/maru/pull/1115)는 닫힘). 말줄임표가 붙은 추정 링크는 거부하되 말줄임표 옆의 온전한 링크는 살리고 hover와 클릭 판정을 일치시켰으며([#1119](https://github.com/ohah/maru/pull/1119)), PR metadata 워크플로의 concurrency 설정이 필수 체크를 취소 상태로 만들어 병합이 막히던 문제도 고쳤습니다([#1112](https://github.com/ohah/maru/pull/1112)).

공개 커밋 11개, 해당일 생성 또는 병합된 PR 10개를 정리했습니다. PR 생성 10개·병합 8개는 같은 PR이 양쪽에 포함될 수 있습니다.
