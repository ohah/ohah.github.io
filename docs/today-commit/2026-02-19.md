## 요약 (AI 작성)

react-native-mcp는 VS Code 확장(React Native MCP DevTools)을 추가했습니다. 사이드바 트리와 콘솔·네트워크·렌더·상태 패널을 갖추고 MCP 서버 WebSocket에 확장 클라이언트로 붙어 `eval`·`getDevices`를 쓰는 구조이며, 서버에는 `extension-init` 핸드셰이크와 프로토콜 테스트, 렌더 추적에서 빌트인 컴포넌트를 가까운 사용자 컴포넌트로 묶는 개선, `init` 실행 시 adb·idb 설치 여부 검사가 함께 들어갔습니다([#54](https://github.com/ohah/react-native-mcp/pull/54)). 확장은 publisher를 `ohah`로 바꾸고 마켓플레이스 규격에 맞춰 버전을 0.1.0으로 정했고, 서버 패키지 버전은 0.1.0-rc.1로 설정했으며, RC 버전은 npm `rc` 태그로 배포하도록 워크플로를 고쳤습니다.

문서 사이트는 architecture·Expo·troubleshooting 문서를 추가하고([#55](https://github.com/ohah/react-native-mcp/pull/55)), Rspress v2의 테마 import 경로 오류를 고쳤습니다([#56](https://github.com/ohah/react-native-mcp/pull/56), [#57](https://github.com/ohah/react-native-mcp/pull/57)). 별도였던 client·test 패키지를 서버 패키지로 합치는 모노레포 정리([#58](https://github.com/ohah/react-native-mcp/pull/58))와 앱 진입점의 `enable()` 호출 안내 제거([#59](https://github.com/ohah/react-native-mcp/pull/59))도 병합했습니다.

기능으로는 react-scan처럼 리렌더된 요소를 화면에 표시하는 `start_render_highlight`·`stop_render_highlight` 도구와 VS Code 연동([#60](https://github.com/ohah/react-native-mcp/pull/60)), 앱 로드 때 이를 켜는 Babel preset의 `renderHighlight` 옵션([#61](https://github.com/ohah/react-native-mcp/pull/61))을 넣었습니다. `_debugStack`과 Metro 소스맵으로 컴포넌트의 원본 파일·줄·열을 돌려주는 `get_component_source`와 심볼리케이트 보정은 [#62](https://github.com/ohah/react-native-mcp/pull/62)로, E2E·스펙 문서를 구현 상태에 맞춘 정리는 [#63](https://github.com/ohah/react-native-mcp/pull/63)으로 병합됐습니다. 도구 38개의 설명을 명확히 하고 버퍼 비우기 도구를 합치는 [#64](https://github.com/ohah/react-native-mcp/pull/64)는 이날 열렸습니다.

hwpjs는 `hwpjs` 패키지의 Clippy 경고를 억제하고 문단 렌더러 TODO 정리 작업을 백로그에 적었으며, 머리말·꼬리말·각주·미주의 중복된 `LIST_HEADER` 처리를 줄이는 [#6](https://github.com/ohah/hwpjs/pull/6)을 열었습니다. ohah.github.io에서는 크론이 hwpjs 개발 문서들의 띄어쓰기와 오타를 고쳤고, 2월 18일과 19일 요약이 올라갔습니다.

공개 커밋 53개, 해당일 생성 또는 병합된 PR 12개를 정리했습니다. PR 생성 12개·병합 10개는 같은 PR이 양쪽에 포함될 수 있습니다.
