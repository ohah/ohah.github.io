## 요약 (AI 작성)

maru 컨트롤 플레인은 에이전트 브라우저 제어 프로토콜(5f)을 문서로 먼저 정리한 뒤 곧바로 구현했습니다. §9.4 프로토콜 리뷰와 §9.5 구현 설계, 3차 전수조사 정정, D3·D4·D5 결정 확정([#1326](https://github.com/ohah/maru/pull/1326), [#1327](https://github.com/ohah/maru/pull/1327), [#1328](https://github.com/ohah/maru/pull/1328)) 위에, 이벤트 구독·매칭 코어 `EventBroker`([#1329](https://github.com/ohah/maru/pull/1329))와 응답·이벤트 통합 큐 `OutboundQueue`([#1330](https://github.com/ohah/maru/pull/1330))를 만들었습니다. 서버는 직렬 accept를 연결당 스레드로 바꾸고([#1331](https://github.com/ohah/maru/pull/1331)), auth 한 번 뒤 같은 연결로 요청을 이어 받는 지속 세션([#1332](https://github.com/ohah/maru/pull/1332)), 스레드 안전한 `OutboundChannel`과 연결당 reader·writer 두 스레드 구조([#1334](https://github.com/ohah/maru/pull/1334), [#1335](https://github.com/ohah/maru/pull/1335))로 재구성됐습니다.

이벤트는 메인 스레드 전용 `SubscriberRegistry`와 연결 수명 배선([#1337](https://github.com/ohah/maru/pull/1337), [#1338](https://github.com/ohah/maru/pull/1338)), `browser.subscribe` 배선([#1339](https://github.com/ohah/maru/pull/1339)), WKWebView url KVO로 `browser.navigated`를 보내는 처리([#1342](https://github.com/ohah/maru/pull/1342))를 거쳐 실제로 흐르게 됐고, loadState·dialog·crashed·closed 이벤트와 서버 SIGPIPE 방어가 더해졌습니다([#1345](https://github.com/ohah/maru/pull/1345)). 권한 쪽은 세션 cap 누적([#1348](https://github.com/ohah/maru/pull/1348), [#1349](https://github.com/ohah/maru/pull/1349)), 쿠키·스토리지 열람을 분리한 `browser_storage` scope([#1350](https://github.com/ohah/maru/pull/1350)), `browser.getCookies`([#1351](https://github.com/ohah/maru/pull/1351))로 이어졌습니다. 이어 capability 발급 UX를 pane 단위 확인 grant(Model B)로 개정하고([#1353](https://github.com/ohah/maru/pull/1353)), grant 저장소와 인가 합성, 확인 대기 요청 흐름, 실제 사용자 확인 모달까지 1e-confirm 단계를 모두 병합했습니다([#1354](https://github.com/ohah/maru/pull/1354)부터 [#1360](https://github.com/ohah/maru/pull/1360)). 18차부터 22차까지 매 단계 리뷰 결함 수정도 함께 들어갔습니다.

앱 쪽에서는 파일·이미지·텍스트를 어느 pane에 떨어뜨려도 활성 pane에만 들어가던 회귀를 고치고, 붙여 넣기 대상을 큐에 넣는 시점에 고정했습니다([#1344](https://github.com/ohah/maru/pull/1344)). ESC로 에이전트를 끊으면 사이드바 스피너가 계속 진행 중으로 남던 버그는 인터럽트 감지를 넣고 리뷰 두 차례로 오탐을 줄여 고쳤습니다([#1347](https://github.com/ohah/maru/pull/1347)). `theme.min-contrast`는 다크 배경 위 어두운 전경도 보정하도록 양방향으로 넓히되, 기본 설정에서 밝히는 방향은 좁게 제한했습니다([#1343](https://github.com/ohah/maru/pull/1343)). `read_error` 종료를 trace에 기록하는 관측 PR [#1289](https://github.com/ohah/maru/pull/1289)도 병합됐고, 코드 에디터·git diff 뷰어·LSP surface 설계 문서 PR [#1340](https://github.com/ohah/maru/pull/1340)이 이날 열렸습니다.

zntc는 Vite식 query-suffix import(`?raw`, `?url`, `?inline`, `?worker`)를 문서와 함께 추가하고 리뷰 지적 4건을 반영했습니다([#4478](https://github.com/ohah/zntc/pull/4478)). CSS `url()`이 가리키는 자산을 실제로 방출하고 경로를 재작성하는 수정([#4469](https://github.com/ohah/zntc/pull/4469)), class static block과 `--jsx=preserve`를 원문 복사 대신 AST로 출력하는 수정([#4473](https://github.com/ohah/zntc/pull/4473), [#4477](https://github.com/ohah/zntc/pull/4477)), minify의 쉼표 시퀀스 접기에서 문장 시작 괄호가 빠져 런타임 SyntaxError가 나던 버그 수정([#4474](https://github.com/ohah/zntc/pull/4474)), 동명 basename 자산의 래퍼 이름 충돌 수정([#4476](https://github.com/ohah/zntc/pull/4476))이 병합됐습니다. e2e browser-smoke 패키지 버전 고정([#4471](https://github.com/ohah/zntc/pull/4471)), v0.1.3 릴리스([#4479](https://github.com/ohah/zntc/pull/4479)), 버전 lockstep과 `bun.lock` 동기화 자동화([#4480](https://github.com/ohah/zntc/pull/4480))도 들어갔고, if 폴딩 시 우선순위 괄호와 단항 토큰 병합을 고치는 PR [#4484](https://github.com/ohah/zntc/pull/4484), [#4486](https://github.com/ohah/zntc/pull/4486)이 열렸습니다. ohah.github.io에는 오래된 오늘의 커밋 항목 정리 커밋이 있었습니다.
