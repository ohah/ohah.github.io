## 요약 (AI 작성)

bungae는 설정 로딩 오류를 고치고 코드 구조를 정리한 [#13](https://github.com/ohah/bungae/pull/13)을 병합했습니다. 설정 파일을 불러오지 못할 때 자세한 오류 메시지를 보여 주고 원래 오류를 `cause`로 보존하도록 오류 형식화 로직을 뽑았으며, 하드코딩하던 버전 상수를 package.json에서 읽는 공용 모듈로 옮겼습니다. `build`와 `serve` 함수를 별도 파일로 나누고, bunup에서 코드 분할로 export가 중복되던 문제를 막으려고 분할을 껐으며, HMR 메시지의 동적 import를 정적 import로 바꿨습니다.

에셋 핸들러에는 `/assets/`·`/node_modules/` 경로, `@2x`·`@3x` 배율 접미사, 이미지 형식, 경로 탈출 시도를 확인하는 테스트를 추가하고, `packageJsonPath`를 쓰기 전에 할당하지 않던 문제와 lint·타입 오류를 고쳤습니다. 예제 앱 설정에서는 minifier를 terser로 바꿨습니다.
