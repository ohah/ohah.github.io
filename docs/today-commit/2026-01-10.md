## 요약 (AI 작성)

chrome-remote-devtools는 React Native용 Redux DevTools 통합을 여러 방식으로 시도한 끝에 [#63](https://github.com/ohah/chrome-remote-devtools/pull/63)으로 병합했습니다. 처음에는 JSI 브리지용 C++ Redux DevTools Extension 클래스와 Android·iOS 네이티브 바인딩을 만들었지만, 곧 Metro 변환기로 초기 시점에 폴리필을 주입하는 방식으로 바꾸고 C++ 구현을 지웠습니다. Redux CDP 메시지의 action과 payload는 `Redux.pdl` 명세에 맞춰 JSON 문자열로 보내고, Redux·Zustand 미들웨어에 스토어별 `nextActionId`를 두어 액션 순서를 맞췄습니다.

DevTools 프런트엔드 쪽에는 Redux 패널과 Storage 패널을 추가했고, CDP 메시지를 Redux DevTools 형식으로 바꾸는 `redux-devtools-plugin` 패키지를 만들어 `build:devtools`에 포함했습니다. `ReduxExtensionBridge`가 두 모듈에서 따로 만들어지던 문제는 window 객체에 인스턴스를 두는 방식으로 고쳤습니다. 서버에서는 모든 통신이 CDP를 쓰므로 쓰지 않던 Redux 중계 구현과 `/redux` WebSocket 엔드포인트를 지웠고, 마무리로 예전 Redux 확장 빌드 스크립트와 `@redux-devtools/remote` 의존성, 라우트에 등록되지 않은 Redux DevTools 페이지를 정리했습니다.

이어 병합한 [#64](https://github.com/ohah/chrome-remote-devtools/pull/64)는 예제 앱의 입력 필드와 확장 상태 표시를 지우고, 버튼을 누르면 무작위 항목이 추가되도록 화면을 단순화했습니다.

공개 커밋 29개, 해당일 생성 또는 병합된 PR 2개를 정리했습니다. PR 생성 2개·병합 2개는 같은 PR이 양쪽에 포함될 수 있습니다.
