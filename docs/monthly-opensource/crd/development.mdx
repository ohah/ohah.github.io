# 3. 개발 과정

CRD(Chrome Remote DevTools)의 개발 과정을 시간순으로 정리했다. 2025년 12월 20일 CDP 클라이언트와 중계 서버로 시작해, 세션 리플레이·React Native Inspector·Rust 서버로 범위를 넓혔다. 각 편은 당시 구현과 기여를 기록한다.

| [3-1. CDP 클라이언트와 서버 구현](./development-1) | 2025-12-20 | CDP 도메인, WebSocket 중계, 기본 예제 |
| [3-2. DevTools 프론트엔드 연동](./development-2) | 12/20~12/22 | DevTools UI와 Inspector 연결 |
| [3-3. 세션 리플레이 (rrweb)](./development-3) | 12/23~12/24 | DOM 기록과 CDP 이벤트 재생 |

## 공개 이력으로 확인한 날짜

날짜는 한국 시간이며, 2026년 9월 26일 공개 저장소와 릴리즈를 확인했다.

- **2025-12-20** — [초기 프로젝트 설정](https://github.com/ohah/chrome-remote-devtools/commit/5f0fe254).
- **2025-12-27** — [client v0.1.0-rc.1](https://github.com/ohah/chrome-remote-devtools/releases/tag/chrome-remote-devtools-client-v0.1.0-rc.1)과 [server v0.1.0-rc.1](https://github.com/ohah/chrome-remote-devtools/releases/tag/chrome-remote-devtools-server-v0.1.0-rc.1) 공개.
- **2026-02-09** — [rn-inspector v0.1.0-rc.1](https://github.com/ohah/chrome-remote-devtools/releases/tag/chrome-remote-devtools-rn-inspector-v0.1.0-rc.1) 공개.
- **2026-02-12** — 확인 시점 `main`의 [마지막 커밋](https://github.com/ohah/chrome-remote-devtools/commit/d5e443d031a076ce7b6fa91f5587c0a2e59d97ea). Inspector의 `adb reverse`를 8080·8081 포트에 실행하고 결과를 Toast로 표시하는 변경이다.

최신 등록 릴리즈는 위 세 패키지의 rc.1이며, 2월 9일 RN 릴리즈 이후의 `main` 변경을 담은 추가 GitHub 릴리즈는 확인되지 않았다.
