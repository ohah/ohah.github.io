## 지금 어디까지 왔나

10월 4일 기준 [상태 대장](https://github.com/ohah/spinon/blob/e33f44da/spec/STATUS.md)의 공식 판정은 "현재 제품 지원 완료: 없음"이다. 열흘 가까이 쌓인 것은 다음 세 가지다.

1. **실험(PoC·spike)** — V8 연결, 네이티브 뷰 동적 트리, wgpu 사각형, GPU 복구, CSS 번들러 비교
2. **명세와 계획** — 공개 명세 0.1 초안(0001\~0008), 내부 인터페이스 명세 0001\~0021, 렌더러·CSS·OTA·벤치마크 계획
3. **내부 시제품** — 고정 fixture 위에서 HTML 문서 → Stylo → Taffy → wgpu 화면까지 한 번 이어 본 경로, 그리고 V8 안의 제한된 `document` API

React 어댑터, 텍스트 렌더링, 실제 앱 화면, 공개 API는 아직 없다.
