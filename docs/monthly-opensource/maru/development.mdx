## 반복되는 패턴

각 편을 관통하는 작업 방식은 대체로 같다.

1. **계약 문서를 먼저 쓴다.** 새 축을 열 때마다 단일 출처 문서를 만들고 비목표를 적는다.
2. **슬라이스로 쪼갠다.** `FP1~FP8`, `P1~P3`, `CR2a~CR4c`, `SV1a~SV5`, `I3a 슬라이스 1~6` 같은 좌표가 PR 제목에 그대로 붙는다.
3. **적대적 검증으로 스스로를 깨뜨린다.** 라운드를 여러 번 돌리고, 검증이 이기면 설계를 되돌린다.
4. **되돌린 이유를 문서에 남긴다.** 철회한 결정도 근거와 함께 남아 있어서, 같은 자리를 두 번 파지 않는다.
