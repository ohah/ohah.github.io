# 3-5. 다시 뜯어고치기, 그리고 플랫폼 확장 (8/1 ~ 8/17)

8월은 두 얼굴이다. 전반은 두 달 동안 쌓인 chrome·app_session을 뜯어 제자리에 놓는 정리 작업이고, 후반은 macOS 밖으로 나가는 확장(모바일·Windows·다국어)이다.

## 세션을 잃지 않게

8월 1일, "세션이 사라진다"는 문제를 정면으로 팠다. 세션이 유실되는 세 경로를 고치고 원인을 관측 가능하게 만들었으며, 죽은 host의 잔여 entry가 살아 있는 host를 밀어내지 못하게 했다. 앱 업데이트 경로도 손봐서 살아 있는 host를 exec으로 이어받되 업그레이드된 host만 채택하도록 했다.

다음 날에는 세션 아카이브 UI를 처음부터 끝까지 만들었다 — 카드 그룹화, 워크스페이스 범위 필터, 검색 필터, 선택 항목의 로그 안전 노출, 상세 탭과 bounded 상세 파싱, 새로고침 컨트롤.

## chrome을 제자리에 (CIM · SV · SB)

8월 3일에 도크 텍스트를 시스템 UI 수준으로 끌어올린 뒤(system UI chrome text shaper, public font API rasterize), 8월 4~8일 닷새 동안 세 축을 이관했다.

| 축 | 슬라이스 | 내용 |
|------|------|------|
| CIM | CIM1~CIM3d | 상호작용 소유권을 컴포넌트로 — click 수명만 알던 interaction을 drag 수명까지 넓히고, divider·scrollbar·탭 드래그를 chrome capture 경로로 옮겨 tick당 한 번으로 모음 |
| SV | SV1a~SV5 | `ScrollArea` 추상화 — 스크롤 좌표계를 도크 밖 공용 자리로, 발행과 clip을 `tree.build`가 소유, 뷰포트 높이는 layout에게 묻고, 사이드바·알림 패널·팔레트까지 확장 |
| SB | SB1-S3a~S3e | 하단 상태표시줄 — 좌측 git 브랜치·작업 경로, 우측 알림 수·실행 중 에이전트 수, 막힌 에이전트 구분 표시 |

8월 9일에는 비대해진 `app_session`을 주제별 17개 파일로 갈랐다 — tab·term·workspace·pane·input·scroll·sidebar·dock·settings·notification·git·agent·web·file_panel·agent_dock. 한 그룹만 쓰는 파일 레벨 헬퍼도 함께 옮기고, 호출 그래프로 소유를 확인한 46개를 각 그룹으로 배치했다.

## 편집기가 Term이 된다

- **8/10** — 네이티브 편집기의 selection 계약을 VSCode·CM6·Zed와 전수 대조해 빈틈 셋을 메우고, 열/블록 선택 원본을 `Selections` 안에 두는 쪽으로 §3.2a를 뒤집었다.
- **8/13** — `SurfaceKind`에 `editor`를 더해 편집기를 하나의 Term 종류로 승격했다. `kind == .web`으로 뭉뚱그려 있던 8곳을 분류하고, 훅이 파일을 편집기 Term으로 열어 렌더 블록까지 잇도록 했다.
- **8/14** — 네이티브 diff 본문(N1.5). §7을 고쳐 자체 differ로 가기로 하고, 비교 요청을 화면 네 상태로 잇고 나란한 비교를 세운 뒤 색과 세로 스크롤을 붙였다. 검증은 손으로 고른 예제 대신 불변식을 무작위로 치는 방식으로 바꿨다.
- **8/15~17** — 바뀐 글자만 진하게(N1.5 e), 경로 breadcrumb, 랩/가로 스크롤 성능(첫 가로 휠 501ms, 5만 줄에서 프레임당 498ms를 잡았다), 긴 한글 줄의 조각 수를 21배 적게 세던 계산 오류 수정.

## 문서와 축 정리

- **8/11** — 커진 계약 문서들을 주제별로 갈랐다(네이티브 편집기, 컨트롤 플레인, 파일 패널, 에디터 Surface, 사이드바 그룹, 웹 패널, Metal UI, 설정, 터미널 분해, I/O–렌더). 구현 계획은 `docs/plans/` 아래 이니셔티브별 파일로 내리고, 분할이 남긴 깨진 앵커와 절 참조를 CI 게이트로 잡게 했다.
- **8/12** — cwd를 하나의 축으로 통일했다. 사이드바 폴더·브랜치줄, 에이전트 대화 매핑, 아카이브 범위 칩, 컨트롤 플레인 세션 목록을 모두 소스 컨트롤과 같은 축에 합류시키고, 이 규율을 주석이 아니라 게이트로 옮겼다.

## macOS 밖으로

### 모바일 (8/15)

두 달 가까이 별도 라인에서 굴리던 iOS·Android 작업을 **161커밋으로 main에 합쳤다**([#2205](https://github.com/ohah/maru/pull/2205)).

- M0~M2 — PoC를 제품 구조로, draw-list를 인스턴스 드로우 한 번으로, 빌드를 `build.zig`가 소유, Android IME를 자체 Java shim으로
- M4a — 셀 속성·합성 글리프·글자 상자 정렬, 키를 코어 인코더에 태우기, 컬러 아틀라스 이모지
- M4b — 스크롤·선택·복사·보조 키바
- 한글 IME는 iOS를 UITextInput으로 올려 실측한 뒤 **보류로 기록**했다

이후 8월 16~17일에 config를 실제로 읽어 화면에 닿게 하고(M10b·M10c), 설정 화면을 **스키마에서 자동 생성**했으며, 터치는 손가락 id와 소유권을 코어가 들도록 옮겼다(T0~T3 · R0~R3 · G0~G5). 관성 스크롤도 OS 기계에 맡기지 않고 코어로 가져왔다.

### Windows (8/15~17)

문서부터 열었다. 플랫폼 계약과 구현 계획을 세우고 적대적 검증 12라운드를 반영해 기본 셸을 PowerShell로, OSC 9;9 authority를 확정했다.

| 슬라이스 | 내용 |
|------|------|
| W1.5 | 절대경로 판정을 `[0]=='/'`에서 분리 |
| W2 | `main.zig`가 Windows에서 빌드·실행 |
| W4 | ConPTY 백엔드 — 헤드리스 세로 슬라이스가 선다 |
| W5·W5.5 | 셸 통합 주입(cmd PROMPT / PowerShell 인라인 `-Command`), 상대 경로 링크 감지 |
| W7·W8.5 | 중립 레이어 컴파일 정리, 경로 레이아웃 `%LOCALAPPDATA%\maru\` |

Win32 창과 메시지 펌프(W7.1)는 8월 17일 기준 열린 PR이다.

### 다국어 (8/16~17)

UI 문자열 국제화를 doc-first로 열고 이틀 만에 실사용 단계까지 밀었다. 표시 문자열 테이블·조회·보간의 중립 leaf(I3-0)를 세우고 platform 문자열 40건, notice 토스트 97건, 분기·보간형 13건, 컨텍스트 메뉴, config 설명문 86건, 세션 도크·아카이브 상세·SCM 도크를 차례로 키로 옮겼다(8/17 기준 I3a 225/339, I3c 65/76).

중간에 "옮긴 문자열이 아무도 안 보는 테이블에 쌓이고 있다"는 것을 발견해 `ui.language`를 실제로 배선했고(I4a), 한국어 라벨에 알림 패널 폭이 박혀 있던 것을 고치고 시각 골든 캡처의 UI 언어를 고정했다.

## 8월 17일 시점

터미널로 시작한 앱에 지금 들어 있는 것: 멀티탭·분할, 스크롤백, kitty 그래픽, 유니코드 클러스터, 스키마 설정과 GUI, 사이드바 워크스페이스 그룹, 파일 탐색기와 소스 컨트롤 도크, 네이티브 편집기와 diff, 인앱 브라우저, 에이전트 제어 프로토콜, 앱 종료 후에도 살아남는 세션 호스트, iOS·Android 앱, Windows 지원(진행 중), 한국어·영어 UI.
