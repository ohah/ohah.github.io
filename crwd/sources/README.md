# CRWD Source Files

Place YAML files here with this structure:

```yaml
title: devlog-2026-july-example-post-slug-like-this-no-spaces-or-punct-here-except-dash-lowercase-only-if-required-by-your-docs-per-topic-key-in-topics-yaml-not-using-folder-name-for-article-output-but-file-stem

topic_key: "dev-log"

body_content_markdown:
  # Full Markdown content for the blog post here
```

CRWD will read these files and process them into articles.
