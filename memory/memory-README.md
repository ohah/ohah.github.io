# Memory Files

This directory contains your curated memories from daily sessions.

## Structure
Each day has its own JSON file:
```
YYYY-MM-DD.json # Daily raw notes and events that happened on this date (main session only)
MEMORY         # Long-term distilled knowledge across all time periods; main-session write-only with optional read access in shared contexts per AGENTS.md rules

Note: MEMORY is a single monolithic directory of separate files, not one JSON document.
- Main sessions can load specific daily memories and the aggregated memory
```
